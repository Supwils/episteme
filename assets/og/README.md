# 分享图片字体

这里只供服务端 OG 图片函数读取，不进入页面首载或公开静态目录。字体为固定版本的原始静态 TTF，未修改字形或名称；来源、字重和 SHA-256 见 `fonts.json`，对应 SIL OFL 1.1 许可证与版权声明随文件保留。

中文采用 Noto Sans SC Bold，Noto Sans Bold 补足化学/数学上下标，表情采用 Noto Emoji Regular 的单色字形。生成图片不再依赖字体或表情 CDN；新增语言或字形时先验证字体覆盖，再调整字体清单。更换字体时须同时核对来源、许可证、哈希、生产函数追踪及渲染回归，不把变量字体直接交给当前解析器。
