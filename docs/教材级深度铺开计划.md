# 教材级深度铺开计划

> 建立：2026-09-14。对照 `聚焦方向.md` 的广度口径（核心教科书目录 ≥80% 有可路由主节点）与 `叙事与引用规范.md` 的对象剖析纪律。本文件是「深度铺到教材级」的执行真相源，不替代五薄矩阵与 CS 矩阵；那两份已经宣布**缺章已清**。

## 一、什么叫教材级（本仓库口径）

教材级不是把每篇已满的非前沿再注水。现有非前沿主节点已经落在 3800–4800 汉字。再加厚旧文，只会让同一对象说第二遍，并触发 CS 明确禁令。

教材级有两层，必须同时真：

1. **章**：该域本科核心 TOC 的能力板块，至少 80% 有可独立打开的主节点（总览可以先存在）。
2. **对象**：每个能力板块至少有一篇**真实对象**——定理、实验、判决、事件、系统、作品——而不是只在总览里被点名。

对象篇的硬标准与 #425–#427 相同：非前沿 3800–4800 汉字；`## 跨域连接` ≥4 条、≥3 条以 `**[[slug|中文]]**：` 领头、≥400 汉字、无自链；`related:` 用文件名；不发明 B7；文学 38 / 宗教 36 保持立项规模；不织人类学；跳过语言学（`max-min ≤ 3` 与双表注册）；计算机科学不加厚已满旧文，也不单开薄的独立 PCP 总览（PCP 机制已在 `interactive-proofs-and-zero-knowledge`）。

衡量方法仍是教科书目录对板块，不是「每域再加 N 篇」。
