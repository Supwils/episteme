# Episteme · 格致 — 项目聚焦方向

**本文件定义项目的核心方向。所有开发工作必须严格遵循此文件。**

---

## 核心原则

**我们是一个知识内容平台，不是社交工具，不是效率工具，不是 SaaS 产品。**

我们的唯一目标是：让任何人能够以最深入、最系统、最美好的方式学习人类最重要的知识。

---

## ✅ 我们聚焦的方向

### 1. 内容深度（最高优先级）

每个知识领域的所有内容必须达到**该领域专家级理解**的水平。

- 每篇文章不仅要描述"是什么"，更要解释"为什么"和"如何"
- 每篇文章必须包含：真实数据、具体案例、学术引用、跨领域连接
- 目标：一个物理学博士读完宇宙物理板块后认为"这确实是准确且深入的"
- 目标：一个经济学教授读完经济学板块后认为"这覆盖了本科到研究生水平的核心内容"

**衡量标准（篇幅以汉字数为主口径，行数为辅助口径——两者满足其一即达标）：**

- MDX/KB 文章：≥ 2200 汉字（theorems 类 ≥ 1700；完整分档见 `scripts/check-content.ts` 的 `MIN_CJK_CHARS`），或达到对应行数下限（`MIN_LINES`）
- 前沿文章（`frontier/`）：≥ 1800 汉字或 ≥ 60 非空行（`MIN_FRONTIER_CJK` / `MIN_FRONTIER_LINES`）
- 零「双薄」文件（行数与汉字数同时低于下限才告警——公式/表格密集型文章 CJK 字数天然偏低，行数通道为其保留；只数行数会奖励注水、惩罚合并单句成段的良好排版）
- 每篇文章包含：为什么这很重要、关键洞察、跨领域连接、参考文献

### 2. 内容广度（高优先级）

每个知识领域必须覆盖该领域的**完整知识体系**，不留明显空白。

- 检查方法：列出该领域的核心教科书目录，对比我们的内容覆盖
- 如果教科书有 15 个章节，我们至少要有 12 个章节的对应内容
- 如果一个领域有 50 个核心概念，我们至少要有 40 个

**当前已确认的空白（2026-08-04 复核）：**

> 自 2026-06 起挂账的全部具名空白**已清零**：经济学微观、心理学发展心理学、数学应用数学、生命科学分子生物学、宇宙学观测天文学均已补齐并接入路由；哲学分析哲学人物页（Putnam / Kripke / Searle / Nagel / Chalmers 等）已于 `T-CONTENT-42` 补完——这是 06-08 挂账的最后一处。

现存的是**厚薄不均**而非缺失，按篇数排序的最薄三档是：

| 领域             | 篇数    | 性质                                                          |
| ---------------- | ------- | ------------------------------------------------------------- |
| 法学             | 36      | 新上线（2026-08-03），按发布波推进中                          |
| 工程与技术       | 38      | 新上线（2026-08-03），承诺的 4 个可视化未交付（`T-VIZ-ENG`）  |
| 艺术、建筑与美学 | 41      | 新上线（2026-08-03），承诺的 5 个可视化未交付（`T-VIZ-ARTS`） |
| 语言学 / 社会学  | 53 / 60 | 长期最薄的两个成熟域，已连续四批扩面，仍可继续增补            |

发现新空白的方法不变：列出该领域核心教科书目录，对比我们的板块覆盖；缺口登记进 `任务清单.md` 而不是留在脑子里。

### 3. UI/UX 改善（中优先级）

改善内容的呈现方式，让阅读和学习体验更美好。

- 文章渲染质量（Markdown 清晰度、排版、间距）
- 可视化组件的交互体验
- 导航的直觉性（能快速找到想看的内容）
- 移动端体验
- 加载速度和流畅度

**不做的事情：** 我们不做阅读进度持久化、不做收藏夹、不做文章分享按钮、不做学习路径系统、不做标签浏览、不做用户系统、不做通知推送、不做邮件订阅。这些功能不属于我们的核心方向。

### 4. 新领域扩展（中优先级）

持续扩展新的知识领域，让平台覆盖人类知识的更大部分。**当前 18 个领域已上线**（含医学、计算机科学、政治学、地球科学、化学、社会学、语言学、法学、艺术、工程与技术）。

后续路线（每批走完整立项路径，一批稳定后再开下一批，不并行）：

| 批次 | 领域              | 簇         | 前置                                       |
| ---- | ----------------- | ---------- | ------------------------------------------ |
| B3   | **文学与叙事**    | 人文与艺术 | 确立"事实层与解释层分离"写法与引文版权口径 |
| B4   | 宗教学            | 历史与文明 | —                                          |
| B5   | 人类学 / 考古学   | 历史与文明 | 可先在社会学内试板块                       |
| B6   | 教育学 / 学习科学 | 生命与心灵 | 内容可反哺平台自身                         |

每个新领域需要：候选矩阵七维评分 + 完整知识体系设计（L1–L5 主线、≥6 桥接域）+ 30–60 篇核心内容 + 3–5 个可视化 + 图谱节点与边。完整八阶段接入 Playbook 见 `docs/学科版图与导航架构.md` 第五节。**新学科立项需用户拍板。**

## ❌ 我们明确不做的事情

以下功能不属于项目核心方向，不应投入开发资源：

1. **用户系统**（注册、登录、个人资料）
2. **阅读进度持久化**（记住读到哪里）
3. **收藏夹/书签系统**
4. **文章分享功能**（社交分享按钮）
5. **标签/主题浏览**
6. **通知推送**（浏览器通知、邮件）
7. **用户反馈系统**（投票、评论）
8. **多语言国际化**（i18n）
9. **A/B 测试**
10. **分析/埋点**（已有基础 VitalsReporter，不再扩展）

其中书签、阅读进度、标签浏览、分享按钮曾被实现，已于 2026-07-24 的「产品边界清理」按本文件删除。

**清单与现状的两处偏差（写在这里，免得下一个代理照旧清单误删）：**

| **双主题**（观测台/手记，`next-themes`）                                                 | ✅ **已拍板保留**（2026-07-24 用户决定）。旧版清单第 12 条"不做暗/亮切换"已作废，144 状态 a11y 扫描的一半就是浅色态。                                                                             |

## 每次开发会话的检查清单

开始工作前：

1. 阅读本文件
2. 确认当前任务属于 ✅ 聚焦方向
3. 如果发现不属于聚焦方向的问题，记录到"已知问题"但不修复

结束工作前：

1. 验证内容深度是否达标（行数、结构、引用）
2. 验证是否有新的内容空白被发现
3. 更新本文件（如果有新的空白或方向调整）

### 5. 研究前沿（2026-06-12 起的常设内容类型）

每个领域的「研究前沿」子板块（`/<领域>/frontier`）收录"正在发生的 2020s 知识"——尚未解决的开放问题、谁在攻关、近年突破（带年份与来源）、未知边界与跨域连接。这是对"内容深度/广度"的延伸，也是平台区别于静态百科的差异点：呈现知识的**前沿与悬念**，而非只有定论。

- 现状：14 个域共 **91 篇**（`FRONTIER_DOMAINS` 尚未包含 linguistics / law / arts / engineering——这四域的前沿内容分别落在各自板块内）。
- 内容位置：`content/<领域>/frontier/*.md`；加载器 `lib/frontier.ts`；规范见 `docs/前沿创作指南.md`，范文见 `content/universe-physics/frontier/quantum-error-correction.md`。
- 事实纪律最高优先：前沿内容必须 WebSearch 核实，绝不编造人名/论文/数据。

### 6. 被推翻的理论（2026-08-04 起的常设体裁）

专写"当年被广泛相信、后来被推翻"的理论，36 篇覆盖全部 18 域。统一写法：**它当时有多合理 → 什么真正击穿它 → 代价 → 留下的判断力**，并刻意让条目互相对照（拒绝合理 vs 拒绝拖沓、方法错而直觉对 vs 方法对而前提错）。这是"反对单一叙事"与"科学能自我纠正吗"最具体的载体。
