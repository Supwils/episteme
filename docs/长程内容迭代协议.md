> 建立：2026-09-15。把长程 agent 循环落到 Episteme · 格致的**内容增益**，不替代 `聚焦方向.md` 与 `教材级深度铺开计划.md`。计划第三节缺章已空；本协议管的是关闭后的滚动增益。

## 为什么要有一份协议

公开的长程编码循环（Ouroboros、Self-Harness、Agentic Harness Engineering）共同点不是「不停生成文字」，而是：

1. **弱点可观察**：失败或缺口写成可核对的条目，不靠感觉。
2. **改动可证伪**：每一批写什么、用哪条门禁验收，事先写死。
3. **验证先于宣布**：回归不过，不算完成。
4. **经验进下一轮**：门禁红了什么、related 不能指哪类 slug，写进日志，下一代理不准再踩。

应用到本仓：弱点 = 教科书里反复出现、现有文章只点名、没有独立路由的**装置 / 试验 / 判决 / 事故 / 定理**。改动 = 一篇对象剖析。验证 = 第四节命令。

## 循环（每轮相同）

```
盘点点名对象 → 选定五域五篇（科学/工程优先）→ 写成对象页
→ 入边（正文 wiki；related 只写同域允许的文件名）
→ pnpm gen-all → update-graph-snapshot
→ check-content 0/0 → audit-cross-domain → prepush
→ localhost:3067 新路由 200 → 任务清单 + 工作日志 → 下一轮
```

并行时：**每个代理只写自己的新文件**，不改别人的入边文件。入边由协调代理在汇合后一次性打。禁止并行 `gen-all`。

## 对象硬标准

与教材级计划相同：

- 非前沿 3800–4800 汉字；先破误解，再写装置，再写测到/没测到什么。
- `## 跨域连接` ≥4 条、≥3 条以 `**[[slug|中文]]**：` 领头、≥400 汉字、无自链。
- `related:` 用同域 `.mdx` 文件名（或前沿 `.md`）。经济学概念/理论的 related **不能**指向 `policy-analyses/`。
- 化学 / 宇宙学 / 宇宙物理不在 `MDX_DOMAINS`；入边写在会被扫描的域正文。
- 不发明 B7；文学 38 / 宗教 36 不扩；跳过语言学注册链；计算机科学不加厚已满旧文、不薄开 PCP。
- 默认不 commit / merge / push。
- 教育学与涉及儿童、感知动物的实验：不写操作步骤。双用途：不写病原体或武器路径。
