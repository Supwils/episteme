# docs/ — 文档索引

新代理先读这一页，再按需展开。**根目录下全是活文档**；已耗尽使命的报告在 `archive/`（有索引表，无需阅读）。

> 规范正文的唯一真相源是仓库根目录的 `CLAUDE.md`；根目录 `AGENTS.md` 只是指向它的指针。

## 必读（按顺序）

| 文件                | 作用                                                          |
| ------------------- | ------------------------------------------------------------- |
| `聚焦方向.md`       | ⭐ 项目方向与**禁区**（"不做"清单）。动手前必读。             |
| `任务清单.md`       | **在办/待办**、决策记录与已知问题。找下一件事做就看它。       |
| `工作日志.md`       | 上一个代理做了什么、留了什么坑。每次会话结束必须追加一条。    |
| `叙事与引用规范.md` | ⭐ 写内容的核心准则：四条叙事标准 + 引用结构 + 机器把关规则。 |
| `工程原则.md`       | 代码质量铁律（小文件、无防御性废代码、性能预算、a11y 底线）。 |
| `知识精神.md`       | 内容价值观：为谁做、什么算"够好"。                            |
