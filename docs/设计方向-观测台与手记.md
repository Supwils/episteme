> E1（`T-DESIGN-01`）建立，此后每个 epic 的设计决定都记在这里。任务书原文见 `docs/superpowers/specs/2026-09-23-前端设计改造任务书.md`，基线见 `docs/设计审计-基线.md`。

> **样张页 `/design`**：所有令牌、学科印、功能图标、知识几何与 22 张标本图版都在这一页用真实 CSS 渲染，切主题即可核对。它不在导航、不进 sitemap、`noindex`。

## 一、北极星

「格致」取自格物致知。两个主题恰好对应这件事的两半：

- **观测台**（暗）：向外看世界的结构。首页、领域首页、图谱、3D 用黄铜仪器与星图、等高线的语言：精确的线、刻度、同心结构、有节制的运动。
- **手记**（亮）：写下自己懂了什么。文章与阅读路线用学者批注本的语言：安静的正文、宽页边、批注、索引卡、印章、克制的颜色。

**一套几何贯穿全站**：角度 = 学科，距离/高度 = 认知层级（第五节）。

## 二、色彩

真相源：`lib/design/palette.ts`。CSS 变量在 `app/globals.css`（portal 根）以及 `app/domain-shared.css` 和经济、数学、哲学、心理四个域自带的 `globals.css` 里重复声明（各自编译 `@theme`）。`lib/design/__tests__/palette.test.ts` 做两件事：

1. 计算每个前景色在其主题**每一种底色**（deep / base / panel / floating）上的对比度。文字 ≥ 4.5:1，线与图形 ≥ 3:1。
2. 对账六份 CSS，禁止出现色板以外的值（打印重映射除外）。

改色先改 `palette.ts`，再同步 CSS；测试会指出漏改的文件。

## 三、字体

| 层     | 决定                                                                                                                                                                                      | 理由                                                                                                                                                                                                                                             |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 学科印 | **字形轮廓，不用字体**。`pnpm gen-seal-glyphs` 从 Noto Serif SC Black（OFL 1.1）提取 22 个字的轮廓，写入 `lib/design/seal-glyphs.generated.ts`（20.8 KB raw / 6.4 KB br，按整数单位量化） | 渲染与读者装了什么字体无关；每方印在 HTML 里约 1 KB，不产生字体请求                                                                                                                                                                              |
| 展示   | **网页字体暂不加**                                                                                                                                                                        | 实测 Noto Serif SC 子集：217 个固定展示字（领域名、簇名、导航）就有 **48 KB** woff2，365 字 74 KB。加进全局，每页都要付；做成按页加载，又得等 E4 格致仪、E5 领域首页真正用上它才知道字集。E4 动工时再建 `gen-display-font`，按页面挂载、单列预算 |
| 正文   | 系统宋体栈 `"Songti SC", "Noto Serif CJK SC", "Noto Serif SC", "Source Han Serif SC"`，**Windows 回落到微软雅黑而不是宋体**                                                               | 系统宋体在 macOS 与多数安卓上零下载。Windows 没装思源宋体时，`serif` 会落到点阵味很重的 SimSun，在暗底上尤其难读，所以栈尾放无衬线。正文字体与字号、行高、行长一起在 E6 统一文章模板时落到 `.prose`，避免连续两轮改动阅读观感                    |

中西文排版的渐进增强已加到正文：`text-autospace`（原有）、`text-spacing-trim`、`line-break: strict`、`hanging-punctuation: allow-end`（Safari）。不支持的引擎会静默忽略。

## 四、动效

真相源：`lib/design/motion-tokens.ts`（常量，服务端可用）与 `lib/design/motion.ts`（客户端 hook），CSS 同值变量在 `app/globals.css`。

| 令牌                | 值                               | 用途                             |
| ------------------- | -------------------------------- | -------------------------------- |
| `--duration-fast`   | 150ms                            | 悬停、按下                       |
| `--duration-base`   | 240ms                            | 展开、切换                       |
| `--duration-slow`   | 480ms                            | 浮层、翻页                       |
| 编排入场上限        | 1200ms                           | 一页至多一次                     |
| `--ease-instrument` | `cubic-bezier(0.2, 0.7, 0.1, 1)` | 刻度、指针、镜头：快起、落定精确 |
| `--ease-paper`      | `cubic-bezier(0.33, 1, 0.68, 1)` | 纸页展开：平缓的 ease-out        |

- `useMotionPreference()` 返回 `{ reduced, duration(speed) }`，减少动效时时长归零。现有 78 处各自查询 `matchMedia` 或调用 `useReducedMotion` 的组件**不一次性迁移**：E3–E6 改到哪个面就迁哪个，免得纯机械改动淹没 diff。
- GSAP 与 Framer Motion 按页面各选其一，不引入第三个动画库。
- 标本图版的描线入场：主线 900ms、错峰最多 8 × 30ms，虚线与实心点在 700ms 后淡入，总长 ≤ 1200ms。减少动效时直接静止。

## 五、知识几何

真相源：`lib/knowledge-geometry.ts`，测试在 `lib/__tests__/knowledge-geometry.test.ts`。纯函数，不依赖 DOM 或 React，可用于服务端 SVG 和 Worker。

- **角度 = 学科**。六簇按 `DOMAIN_CLUSTERS` 顺序从正上方顺时针铺满一圈，簇间留 4° 缝，每个领域占一个等宽扇区（约 15.3°）。簇内顺序让相邻学科相邻，整圈首尾相接：
  - 物理 → 宇宙 → 地球 → **化学 → 生命科学** → 医学 → 心理 → 语言 → **教育 → 社会学** → 经济 → 政治 → **法学 → 人类历史** → 人类学 → 宗教 → 艺术 → 文学 → **哲学 → 数学** → 计算机 → **工程 → 物理**。
  - 2026-09-24 随 E4 改为此序（送审稿方案 B）：任务书要「逻辑挨着哲学」，工程挨物理仍成立；代价是艺术（含建筑）改挨宗教。
- **半径 = 认知层级**。L1 直觉启蒙在外缘（半径 1），L5 综合前沿靠近圆心（0.36），圆心 0.2 以内留给「汇流」。理由：L5 的定义就是「跨越学科边界」，放在各学科扇区的交汇处是字面意义上的汇合；这与现有图谱 `spatial-layout.ts` 的 `ringRadius` 方向一致（层级越高环越小）。
- **高度 = 同一个层级**。格致山的 L1 在山脚、L5 在山顶；从上往下看，山的等高线就是这张星盘。
- API：`domainWedge`、`CLUSTER_ARCS`、`levelRadius`、`levelBand`、`levelHeight`、`polarToXY`（0° 在上、顺时针，SVG 坐标）、`placeInWedge`（扇区两侧各留 12% 边）、`annularSectorPath`。
- 现有知识图谱的环序（`subjects/knowledge-graph/lib/constants.ts` 的 `ALL_DOMAINS`）仍是按领域上线先后排列的历史顺序。它改用本模块的顺序，归 E7 / 图谱轮次一起做：那条过期的旋转 e2e 断言会在同一轮重算。

## 六、学科印

- 注册表：`lib/design/seals.ts`。组件：`components/design/Seal.tsx`，服务端渲染的纯 SVG。
- 用字：物 宙 地 化 生 医 心 语 教 社 经 政 法 史 人 宗 哲 艺 文 数 算 工。任务书的候选全部保留：每个都是该学科最常见的单字简称，互不重复，小尺寸下仍可辨认。
- 两种刻法：
  - **白文**（`cut="intaglio"`，默认）：印面着色、字留白，用于卡片与首页。
  - **朱文**（`cut="relief"`）：字与边框着色、底透明，用于行内与小尺寸。
- 印框是略带刀意的圆角方，每边一处起伏，按领域 id 取种子：每方印不同，每次渲染相同。
- **白文用遮罩挖字，不用 evenodd**：字体轮廓的笔画互相重叠，evenodd 会在交叉处多挖出洞（「物」「宙」「教」首版就是这样）。遮罩 id 带上领域名，即使在独立渲染根里撞 id，引用到的也是同一个字形。
- 可访问名：默认 `role="img"` + 领域全名；旁边已有可见标题时传 `label={false}`，改为 `aria-hidden`。
- 颜色默认朱砂；传 `pigmentVar(cluster)` 即用簇颜料。

## 九、全局外壳（E3，`T-DESIGN-03`）

- **页头**：
  - 左边是格致朱砂印（双字白文，右起「格」「致」，`components/design/BrandSeal.tsx`）加字标，宽屏再附 Episteme；
  - 中间是六簇按钮 + 探索；
  - 右边是搜索和主题切换。
  - 站印由根布局在服务端渲染后传入页头，字形数据不进客户端包。
  - 1024 px 宽实测不溢出。
- **图册面板**：六簇按钮与领域页头的「全部领域」共用一块全宽面板，决定过程见 `学科版图与导航架构.md` 第二节。
  - 每栏顶上一道簇颜料刻线，被点的那栏加粗——这是唯一的高亮，不铺底色。
  - 每行是学科印、名称、篇数、一句话（`lib/atlas.ts` 的 `ATLAS_LINES`，≤ 16 字，有测试）。
  - 键盘：方向键左右换栏、上下换行（栏内循环），Home / End，Esc 关闭并还焦点。
  - 面板代码与印的字形在指针或焦点第一次靠近时才加载。
- **手机抽屉**：可折叠的簇列表，默认展开当前所在簇，下面是探索入口（配功能图标）。「最近访问」按用户 2026-09-23 的指示不做。
- **领域子导航**（`SubjectHeader`，经服务端外壳 `components/chrome/DomainHeader.tsx` 注入学科印）：
  - 标签永不折行，横向滚动，两端有渐隐遮罩；
  - 一条指示条滑到当前标签（`--duration-base` + `--ease-instrument`），取代每个标签各自的底色；
  - 窄屏也有抽屉入口（此前领域页在手机上没有跨领域导航）。
- **主题切换**：
  - 按钮显示「点了会去哪」：望远镜 = 观测台，笔尖 = 手记，半明半暗 = 跟随系统；
  - 支持 View Transitions 的浏览器里，新主题从按钮处以圆形展开（480ms、仪器缓动）；不支持或要求减少动效时瞬切。
- **⌘K**：
  - 分组标签换成学科印 + 领域名（去掉了大写字距眉题）；
  - 桌面宽度 ≥ 960px 时右侧出现预览栏：领域印、体裁、标题、副题、命中片段，以及「打开」与「在图谱中定位」；
  - 后者跳到 `/knowledge-graph?at=<文章地址>`，由图谱按 URL 反查节点（`useLocateByUrl`，90% 以上节点有页面）。
  - **对话框改为首次打开时才加载**（`components/SearchLauncher.tsx`）：它的 JS、约 2 KB 样式和学科印都不再随每个页面下发。

  - 预览栏里的「层级」没有做：搜索索引里没有层级字段，加进去要多占索引预算，等 E6 文章页统一后再议。
- **状态页**：
  - 404 是一张「未测绘区域」图版（`lib/plates/uncharted.ts`）+ 预填地址关键词的搜索框（无 JS 也能用的 GET 表单）+ 三个去处，领域内的 404 第一个去处留在该领域；

## 十、阅读体验（E6，`T-DESIGN-06`）

- **正文排版**（`components/markdown/prose.css`，只随文章路由加载）：

## 十一、学科首页（E5，`T-DESIGN-05`）

`components/landing/DomainLanding.tsx` 是统一骨架，全部服务端渲染、没有滚动揭示。自上而下：

- **页首**：
  - 左栏：学科印 + 学科名 + 英文名（这是 h1），下面用大字写**引导问题**（取自该学科学习主线的问题，`lib/domain-spine.ts`），再是一两句导语和计数行；
  - 右栏：大幅标本图版，右下角压一枚小星盘（`MiniAstrolabe`）——22 个学科按簇排成一圈，本学科那一格用簇颜料填满，一根照准线从盘心指过去。
- **学习主线**画成一段攀登：五级台阶自左下向右上，每级是文章名和「为什么走到这一步」；窄屏退回一列。按用户 2026-09-23 的指示，不做依赖本地记录的「已读」标记。
- **板块**：每格顶上一道簇颜料细线，名称、篇数、一句话；去掉了 emoji 和每格一种颜色的计数条。
- **学科专属模块**（`children` 插槽）：
  - 引擎域：原来的「知识星轨」画布（只在桌面显示）。
  - 定制域（05b）：哲学的重要思想家与名言时间线；经济的宏观诊断矩阵；心理的情绪轮；生命科学的地质时代与四个互动演示；数学的时代带；物理的九层 3D 场景入口；宇宙学的尺度层级、演化史、宇宙尺度与三个互动演示；人类历史的七大时代与交互时间线（点「展开」才下载）。
  - 两个共用件：`EraStrip`（时代带，服务端）和 `DemoTabs`（互动演示页签，一次只挂载选中的那个，方向键切换）。
  - 物理首页原是 6.4 秒后自动跳走的闪屏，已废除。
- **最近更新 · 研究前沿**两栏。
- **与其他领域的桥**：`gen-site-stats` 从反链索引统计两个学科之间正文内链的条数（双向合计，至少 3 条），每个学科取最强的 8 座桥，并记下两边最常在哪篇文章相遇。左边一束弧线从本学科出发、落到每一行的学科印上，线越粗桥越强；弧线是装饰，数目与去处都写在行里。

颜色规矩：簇颜料只画线、印与台阶底边（`--landing-pigment`），文字一律用墨色令牌。

迁移时暴露的三个老问题：

- 宇宙学样式表把 `h1`、`p`、`a` 这类元素规则写在层外，压过了一切组件类与 Tailwind 工具类（首页标题变成正文字号、所有链接带下划线，宇宙学文章也一直没用上 E6 的正文排版）。已移入 `@layer base`。
- 旧首页把一些模块藏在滚动揭示后面，扫描器看不到。拿掉之后露出名言卡、事件卡、基因表达演示里的低对比度文字，均已改用墨色令牌。
- 人类历史首页的旧渲染器删除后，时间线页成了时代数据的唯一客户端使用者，打包器把整份时代长文并进了时间线外壳（16 KB，预算 12）。改为由 `gen-history-route-data` 生成只含八个字段的 `era-summary`，外壳降到 8.6 KB。

有几条学习主线的问题偏窄（社会学是平台劳动、经济学是国家债务），做首页大标题时读起来像一条专题线而不是整个学科。骨架支持 `question` 覆盖，但写哪一句属内容决定，留给作者。

## 十二、首页格致仪（E4，`T-DESIGN-04`）

送审稿 `docs/superpowers/specs/2026-09-24-E4-格致仪-线框与几何规格.md`，用户 2026-09-24 批准其中四条建议：环序改为方案 B（第五节）、学科印与图版走图标集、⑥ 先指向知识图谱、「今天」书架按日轮换。首页由八段收成六段，全部服务端渲染，没有滚动揭示，不再加载 GSAP：

- **① 格致仪**（`components/portal/Astrolabe.tsx`）：星盘 SVG 在服务端从 `DOMAINS` 与知识几何画出，22 个扇区都是学科链接，每个扇区沿中线落五颗主线星（L1 在外），五个汇流点按所涉学科的圆周平均方位放在盘心。水合后 `AstrolabeController` 只接管选择：鼠标悬停或拖动照准规选学科，方向键按环序扫过（roving tabindex，一个 Tab 停点），回车或第二次点击进入学科。读数面板在服务端只带当天那门学科，其余 21 门的读数是 `/api/astrolabe` 的一份静态 JSON，水合后空闲时取。手机上照准规固定朝上、盘面在下方露出上半圈，左右滑动转盘。
  - 入场一次编排（环线刻入 → 照准规从 0° 摆到当天学科，共约 1.1 秒），减少动效时直接画终态。偏离送审稿的一处：照准规停在「当天的学科」（按日期轮换），减少动效时也停在这里，而不是固定停在法学——两种读者看到同一张图更简单。
  - 拖动柄不接收指针事件：它随照准规转动时会从静止的鼠标下扫过，接收事件就会让鼠标重新「进入」原扇区、把选择拉回去（实测踩到）。
- **② 六簇二十二域**：学科卡换成「标本图版 + 学科印」，簇内按环序排。
- **③ 今天**：今日一篇（每日知识首条）+ 趣味知识、今日书架（22 条学习主线里 L2–L3 的文章，按日期种子每天抽 6 篇、每科至多一篇）与一条跨学科巧合、最近更新五条。原「每日知识 / 最新更新 / 精选内容 / 平台特色」四段并入这里和页脚。
- **④ 读完一个主题**：25 条阅读路线是 25 本书，书脊颜色取学科簇颜料、底部刻度是章数；点一本抽出来，下面换成它的前四章与「从第一章开始读」。
- **⑤ 知识连续体**：五个深层模块收成页签（主干地图、地形与路线、可达前沿、多学科汇流、策展覆盖），一次只挂一个、挂过的留着；分享链接带 `confluence` 或学习路线参数时直接打开对应页签。载入前的占位画成页签加五阶矩阵的形状。
- **⑥ 登上格致山**：一张俯视星盘随滚动后仰（CSS 滚动时间线，零 JS），按钮「看全图」指向知识图谱，E7 落地后换成过渡到三维。
- **图标集**：学科印与标本图版改由两个 force-static 路由 `/sprites/seals.svg`、`/sprites/plates.svg` 生成，页面用 `<use>` 引用。22 张图版内联约 88 KB 原文，会同时进 HTML 与 RSC；走图标集后首页文档 26.1 KB br、RSC 16.7 KB br。图标集是外部文档，页面样式进不去，所以印只用朱文（白文依赖 mask，外部引用的 mask 各浏览器支持不一），线色靠 `currentColor` 与继承下去的 `--plate-accent`。
- **展示网页字体**：决定不引入。首页标题用现有的系统衬线栈已经够用，48 KB 的子集不值得让全站付。
