15. **性能预算全面复核：按读者实际付出的字节重写规则**（2026-09-23，用户授权「不合理就按技术判断定新规则」）。逐项复核结论如下。
    - **测量口径改为 brotli**（CSS / HTML / RSC / JSON）。依据：生产环境对这四类响应全部返回 `content-encoding: br`，带 hash 的 chunk 为 `immutable` 缓存一年；按 gzip 计系统性高估约 25–30%。**JS 预算保留 gzip**：JS 的成本主要是解析与执行，gzip 是业界惯例，且现有 180 / 220 / 285 KB 三条线余量合理，不动。
    - **路由 CSS「每路由 ≤ 48 KB gzip」拆成三条**：全站共享表 ≤ 30 KB br、单路由增量 ≤ 10 KB br、单路由首访合计 ≤ 40 KB br。依据：47 KB 里 37.4 KB 是 429 个路由共用、首访后即缓存的同一张 Tailwind 表，领域增量只有约 9 KB。旧规则把「首访付一次的共享表」和「每页都付的增量」混在一条线里，任何门户样式都会挤爆所有路由。新规则让增长去对的地方：页面专属样式放到组件旁的样式表（`@reference` 全局入口），而不是塞进全局表。重复编译 Tailwind（+25 KB）仍会立刻被「增量 10 KB」拦住。
    - **优化同时落地**：门户专属样式（首屏、簇、卡片、今日、精选）移到 `components/home/home.css`，引擎域首页样式移到 `components/domain/domain-home.css`。全局表 27.9 → 24.9 KB br，每个非首页路由首访少 3 KB；最大路由合计 36.0 → 33.0 KB br（43.3 KB gzip）。首页、`/daily`、法学文章逐像素比对无差异。法学首页板块计数标签原来的 `font-mono` 在全局表里从未赢得层叠，读者一直看到的是正文字体；迁移后按线上实际外观去掉，行高回到 22 px。
    - **首页「HTML raw 500 KB / gzip 80 KB」与「RSC raw 95 KB」改为「首页文档 ≤ 40 KB br」与「首页 RSC ≤ 20 KB br」**。依据：95 KB raw 的 RSC 实际只传 12.4 KB br，这条线在守的是可压缩的重复文本；它却会直接挡住 E4 在服务端渲染的星盘 SVG。主线程代价（水合的元素数）由 Lighthouse TBT 守，不由原始字节守。现值：文档 21.0 KB br、RSC 12.4 KB br。
    - **图谱数据 600 KB br 拆为「首绘 ≤ 350 KB br + 延后描述 ≤ 400 KB br」，原始合计 5 MB 不变**（原始字节在主线程 `JSON.parse`，这条仍有意义）。落地的优化：wire v3 把节点描述（占 52%）移到 `/knowledge-graph/graph-descriptions`，图谱画出后再取；全图力导向布局改在构建期计算，随数据下发（布局是确定性的，浏览器里跑要约 2 秒）；`<link rel="preload" as="fetch">` 让数据与 JS 并行下载。首绘数据 575 → 286 KB br。
    - **Lighthouse 门禁的两处测量缺陷已修**。① `next start` 不压缩 force-static 路由处理器的输出，图谱数据在本地以 3 MB 明文传输，本地 LCP 18.6 秒，而线上实测 1.24 秒。`scripts/lighthouse.mjs` 现在在前面挂一个模拟 CDN 的 brotli 代理（`scripts/performance/compressing-proxy.mjs`，先热身一次，使用与线上同等级的 q11 压缩），`LH_NO_CDN=1` 可以绕过。② 图谱路由改用 devtools 实测节流：它的首绘依赖页面自己发起的请求，Lantern 模拟对此不敏感，四次优化把实测 LCP 从 5.7 秒压到 4.2 秒，模拟值始终在 5.73 秒 ±5 ms。其余四条路由仍用模拟节流（CI 方差更小）。修后 5 条路由全部通过：图谱性能分 84、LCP 4226 ms。
    - **维持不变且判定合理**：共享 JS 180 KB gzip（现 144.7）；通用文章 JS 220（166.2）；单 chunk 285；3D 路由 180；搜索索引 800 KB br（671，懒加载进 Worker，只有搜索者付费）；历史时间线两条；图像两条；Lighthouse 各路由阈值。
    - **下一次触发条件**：共享 CSS 超过 27 KB br 时，先把新增的页面专属样式移出全局表；首页 RSC 超过 16 KB br 时，检查是否把数据而非标记塞进了 RSC；图谱首绘数据超过 320 KB br 时，先看节点字段（`tags` 59 KB、`label` 39 KB 为次大项）。任何提额仍须写入本节。
