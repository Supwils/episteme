# 宗教学立项口径（B4 launchGate）

> 2026-09-10。本文件关闭 `lib/subject-candidate-matrix.ts` 里 `religion-studies` 的前置：描述性而非认信，以及事实层与解释层分离。未满足本文件的文章不得标 `published`。
>
> 领域路由用 `/religion`（候选 id 仍是 `religion-studies`）。完整 Playbook 见 `学科版图与导航架构.md` 第五节。

---

## 一、领域定位

本域写的是**人类如何组织神圣、仪式、经典与制度**，不是传教、护教或无神论宣传。读者应能核对年代、文本、机构和统计口径，并看见学界分歧。

检查口诀：删掉救赎承诺和嘲讽之后，剩下的句子是否仍能被文本、年表或制度对质？能，就是事实层；不能，就必须改成解释层并点名论者。

---

## 二、事实层（可用作者口吻）

- 文本事件：某抄本、译本、碑铭、法令写了什么（标版本）
- 制度：教阶、寺院、教产、国家承认、人口统计口径（标年份与机构）
- 年表：创立传说与可核的建制年份必须分开
- 比较：可观察的实践差异（历法、饮食禁忌、朝圣地），不写成「谁更真」

## 三、解释层（必须归属）

- 神、救赎、来世是否「存在」
- 某传统的「本质」或「真正精神」
- 宗教导致暴力 / 宗教导致道德：只能写成具体论者的命题，并给反证

## 四、安全边界

- 不写可复现的仪式操作步骤、驱魔手册、圣战战术
- 不把在世群体写成标本或阴谋
- 人口与「世界宗教百分比」必须带来源年份；示意图不得假装精确底图

## 五、与文学口径的衔接

事实/解释分层与文学域相同。文学禁的是把口味写成作品属性；本域禁的是把认信写成世界属性。
