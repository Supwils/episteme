## 四、几何规格

全部取自 `lib/knowledge-geometry.ts`（E1 已落地、有单测），格致仪不另起一套数字。

- **画布**：`viewBox="-1.12 -1.12 2.24 2.24"`（单位圆外留 12% 给簇弧与学科印），桌面渲染直径 560 px，手机只显示上半圆（直径 720 px，裁到 300 px 高）。
- **角度 = 学科**：0° 在正上方、顺时针；六簇按 `RING_ORDER` 排，簇间留 `CLUSTER_GAP_DEG = 4°`，每个学科一格等宽扇区（`DOMAIN_WEDGES`）。
- **半径 = 层级**：`levelRadius(L) = 0.2 + 0.8 × (6 − L) / 5`，L1 在外缘 1.0，L5 在 0.36；圆心 0.2 以内是汇流区。五条同心环画在 `levelBand` 的外缘。
- **外圈**：六段簇弧，半径 1.04–1.06，填对应簇颜料；22 个学科印放在半径 1.10 处，随角度摆正（字头朝外）。
- **汇流**：5 个汇流专题（AI 治理、城市气候适应、人口老龄化、宏观财政、公共卫生优先排序）画成圆心区内的小亮点，按各专题涉及学科的平均角度放在半径 0.1 处，可点进 `/knowledge-confluence/[id]`。
- **照准规**：一根从圆心指向所选学科扇区中线的线。选中后，该学科学习主线的五个节点按层级落在这条半径上（L1 最外），每个点是一篇真实文章的链接，读数面板同步列出五步。
- **入场**：一次编排、≤1200 ms：环线刻入（沿用标本图版的描线动画）→ 刻度落定 → 照准规从 0° 摆到随机学科。之后除非读者操作，什么都不动。减少动效时直接画终态，照准规停在「法学」。

## 五、交互、无障碍与预算

- **服务端完整**：星盘 SVG 在服务端从 `DOMAINS` 与几何模块渲染，无 JS 时就是一张可读的图，22 个学科都是链接，读数面板显示默认学科。
- **交互**：水合后的小客户端控制器只接管选择状态，不重画 SVG。拖动照准规或点击扇区选择学科；键盘按 `radiogroup` 模式，方向键扫过 22 个学科，Enter 进入该学科首页。读数面板 `aria-live="polite"`。
- **手机**：半星盘固定在首屏底部，左右滑动转动盘面，照准规固定朝上；读数面板在盘上方。
- **不引入 three.js**，首页不加任何新库。
- **预算**（当前首页文档 22.5 / 40 KB br，RSC 13.9 / 20 KB br）：
  - 学科印字形约 6.6 KB br，若直接内联会同时进 HTML 与 RSC，RSC 会超 20 KB。
  - 方案：构建期生成一份静态 `public/seals.svg` 图标集（`<symbol>`），星盘用 `<use href="/seals.svg#law">` 引用，可长期缓存，不进 HTML 与 RSC。
  - 星盘其余部分（环、扇区、刻度、汇流点、主线点）估计 3–4 KB br。
  - 同时删掉 `HeroBackdrop` 星座画布、`HeroQuestions` 轮播与 `FeatureGrid`，首页客户端 JS 预计持平或下降。

## 六、需要拍板的取舍

1. **环序**：任务书要「逻辑挨着哲学」；E1 落地的环序是「数学挨着物理、艺术挨着工程」（设计方向文档第五节）。两种都闭合：
   - **A（现状）**：…艺术 → 工程 → 计算机 → 数学 → 物理…。数学与物理、建筑与工程是真邻居，但哲学与数学在环上隔了两簇。
   - **B（任务书）**：把人文簇排成「艺术 → 文学 → 哲学」，数理簇排成「数学 → 计算机 → 工程」，于是哲学挨数学（逻辑），工程挨物理。代价：艺术（建筑）改挨宗教。
   - 我倾向 **B**：「逻辑挨着哲学」是这张图想讲的故事，工程挨物理也仍成立。改动只是 `RING_ORDER` 两个数组的顺序，测试会跟着验证。E7 格致山会继承同一环序。
2. **学科印进图标集**（第五节）：多一个构建产物 `public/seals.svg`，换来 RSC 不超预算。同意吗？
3. **⑥ 登上格致山**：E7 尚未批准前，这一段指向 `/knowledge-graph`（2D 图谱），文案写「看全图」；E7 落地后再换成过渡到 3D。可以吗？
4. **③ 今天 的书架**：精选条目从现有 `FeaturedContent` 取，还是改为每日轮换的 6 篇（按日期种子，从各学科学习主线的 L2–L3 抽）？我倾向后者：每天不一样，也保证是能读下去的层级。
