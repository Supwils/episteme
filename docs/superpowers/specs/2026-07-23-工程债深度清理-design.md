## ① 退役搜索镜像层（真相源统一）

**现状**：`scripts/gen-{domain,frontier,math}-index.ts` 从 MDX frontmatter 生成 `lib/search-index/{domain,frontier,mathematics}-data.ts`（206KB），供 `getSearchIndex` 为引擎驱动域产出搜索实体文档。但这些域的文章已由新搜索管道的 `collectArticles` 作为 MDX 文章全部抓取——镜像只额外提供 `titleEn` + `type`。

**精确依赖**（已核实）：3 个镜像仅被 `lib/search-index/index.ts` + `subjects/linguistics/lib/__tests__/foundation.test.ts` 引用；`check-content`/`valid-routes` 读真实源，不受影响；每个 gen 脚本只产出对应镜像、无其他副产物。

**改动**：

1. 扩展 `lib/search/articles.ts` 的 `Article`：从 frontmatter 读 `title_en` → `titleEn`，`category` → 用于 `type`。
2. `scripts/gen-search-index.ts`：MDX 文章用自带 `titleEn`/`type`，不再依赖镜像实体；非 MDX 实体（species/events/figures 等 38 个真实数据模块）继续经 `getSearchIndex` 提供。
3. `lib/search-index/index.ts`：移除 `indexDomains`/`indexFrontier`/`indexMathematics` 调用与 import。
4. 删除 `lib/search-index/{domain,frontier,mathematics}-data.ts`、`{domain,frontier,mathematics}-index.ts`、`scripts/gen-{domain,frontier,math}-index.ts`；移除 `gen-all` 与 `package.json` 中 `gen-domain`/`gen-frontier`/`gen-math`。
5. 迁移语言学测试：`DOMAIN_DATA` → 改从真实源（`public/search-index.json` 或 frontmatter）断言语言学覆盖。

**决定性验证**：退役前快照 `public/search-index.json` 全部 doc URL 集合；退役后重新生成，断言 **URL 集合无缺失**（覆盖零回归）。加召回率门禁 + section-coverage + route-integrity 复核。

**风险**：中。引擎驱动域文章的 `type` 可能由 `"entry"` 变为按 frontmatter 推导——用 URL 集合快照 + 一个"每篇引擎驱动域文章仍有 titleEn"的断言兜住。
