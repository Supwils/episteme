# E7 格致山 — 端到端设计（送审稿）

> 日期：2026-10-28。对应 `T-DESIGN-07`。用户当天批准稿末四处后，已在本地落地，尚未发布。生产包体、Lighthouse 与渲染审计留到 `pnpm predeploy`。落地和原稿的差别见第十一节。

## 一、读者从哪进、从哪出

格致山是知识结构的俯视变成侧视。它不替代文章，也不替代现有的二维力导向图谱。

1. 首页第六段「看全图」进入 `/knowledge-summit`。
2. `/knowledge-summit` 先给出和首页星盘相同的俯视：六簇、二十二域、五层、盘心五个汇流。允许动效时，镜头用一次不超过 1200 毫秒的倾斜落到四分之三视角，可跳过。减少动效时直接停在四分之三视角，不播倾斜。
3. 悬停一个点：标题、学科印、层级名。点选：侧栏给出已有导语、层级、前置、邻居，以及「开始阅读」。开始阅读去该节点已有的文章 URL。
4. 点盘心汇流，去已有的 `/knowledge-confluence/[id]`。点领域印或目录里的学科名，去 `/knowledge-summit/[domain]`。
5. 领域页是 `/knowledge-summit/[domain]`，二十二个路由在构建期静态生成，未知 slug 为 404。节点用 `#summit-node-<index>`。
6. 页内始终有「网络视图」，链到现有 `/knowledge-graph`。二维图谱页加一条反向链接「格致山」。两条视图都不删。
7. 文章页在该 URL 已是图节点时给出「在格致山中查看」，链到对应领域页的节点锚点。⌘K 与搜索预览这一轮没有加。

没有账号，没有已读，没有足迹，没有「以此为起点规划路线」。侧栏不写这些词。

## 二、几何：沿用已经落地的知识几何

真相源是 `lib/knowledge-geometry.ts`。星盘、领域首页和格致山读同一套数。不另写一套角度。

- 角度是学科。环序是 `RING_ORDER`（方案 B）：物理 → 宇宙 → 地球 → 化学 → 生命科学 → 医学 → 心理 → 语言 → 教育 → 社会 → 经济 → 政治 → 法学 → 人类历史 → 人类学 → 宗教 → 艺术 → 文学 → 哲学 → 数学 → 计算机 → 工程，再接回物理。簇间缝 `CLUSTER_GAP_DEG = 4`。领域等宽，`(360 − 24) / 22 = 15.2727°`。0° 在正上方，顺时针。
- 半径是认知层级。`CORE_RADIUS = 0.2`。`levelRadius(level) = 0.2 + 0.8 × (6 − level) / 5`。L1 在外缘 1，L2 0.84，L3 0.68，L4 0.52，L5 0.36。圆心 0.2 以内留给汇流。
- 高度是同一个层级。`levelHeight(level) = (level − 1) / 4`。L1 山脚 0，L5 山顶 1。从上往下看，等高线就是星盘。
- 扇区内的位置用现成的 `placeInWedge`：两侧各留扇区宽度的 12%，`along` 与 `depth` 来自节点 id 的稳定哈希，服务端 SVG 和布局 JSON 用同一函数。
- 前置链只在本层环带内把半径略向内推，不把节点送进别的层级，也不跑力导向。推距不超过该层环带宽度的 15%。没有前置的节点停在 `placeInWedge` 的原半径。
- 五个汇流灯标直接用 `astrolabeConfluences()` 的角度，半径用首页同一系数 `CORE_RADIUS × 0.55`，高度放在 L5 之上一个固定小偏移（归一化高度 1.04）。五条是：AI 治理、城市气候适应、人口老龄化、宏观财政治理、公共卫生优先。链接用它们现成的 id。

三维坐标（Three.js，Y 朝上）：`x = r sin θ`，`z = −r cos θ`，`y = levelHeight`。俯视相机在正 Y 上看向原点，`up = (0, 0, −1)`，这样 θ = 0 仍在画面上方，和星盘一致。极角限制在山的上方，镜头不能钻到地面以下。

现有二维图谱的 `ALL_DOMAINS` 仍是上线先后，不在本轮改。设计方向第五节把那次重排留给图谱轮次；它会碰到旋转断言，和这座山的布局无关。

## 三、画面上有什么

山体是半透明密度面，不是每个节点一根柱。按角度和半径铺一张固定栅格（建议 96×64，实现时可以更小，不能更大），格子的高度取该格节点 `levelHeight` 的最大值。着色用簇颜料，等高线用 `fract(height)`。没有节点的格子落到该扇区的基线，不凭空长出另一座峰。

节点是一层点，不是每个节点一个网格。点的大小只随度数分三档。颜色默认是簇颜料。枢纽点可以有一圈淡光，弱设备上关掉。

边默认不画。读者打开「显示桥梁」，或选中一个点时，只画该点已经存在的跨域边，弧线从现有图谱数据里取，不进布局 JSON。域内的两万多条边不进这座山。

字不用 CJK SDF 图集。HTML 叠层只标二十二个领域名、五个汇流名，以及当前悬停或选中的一个节点。领域名放在该扇区中线、L1 外缘稍外。

两套主题都用现成的簇颜料变量。不新增调色板，不新增展示字体。

## 四、布局数据

构建期新增一步 `gen-summit-layout`，放进 `gen-all`，幂等。输入是现有图节点（领域、层级、前置、度数）和 `astrolabeConfluences()`。不在浏览器里重算位置。

产物 `public/summit-layout.json` 只放坐标，不放导语、不放边、不放正文：

- 文件头：版本、节点数、栅格宽高、量化比例。
- 节点按现有图的稳定顺序排列。每条是 `u16` 索引加三个 `i16`（x、y、z）。层级和领域可以从索引回查图数据；为了无脚本目录不必再取图，另附一张和节点等长的 `u8` 层级。
- 汇流五条：id、标题、三个 `i16`。标题用现成策展标题。
- 山体栅格：`i16` 高度，行优先。

设计上限：这个文件 brotli 后不超过 80 KB，raw 不超过 400 KB。任务书写过 250 KB brotli 的总盘子；80 KB 是本稿主动收紧的线，避免去挤知识图谱「首绘 350 KB brotli」那一档。超了就减栅格或改量化，不先提预算。提预算仍要写进任务清单决策记录。

节点数以 `generated/site-stats.json` 的 `graphNodes` 为准。写这份稿时是 3634。生成器不手写这个数。

时间透镜不做。任务书要求先看「想法首次成形年份」的覆盖率。`07a` 可以印一行覆盖率；低于 80% 就从本 epic 删除，不留开关。

## 五、交互

桌面：拖动旋转，滚轮只缩放，不把页面滚走。极角有上下限。悬停和点选如上。Escape 关闭侧栏并把焦点还回触发该点的控件。侧栏是对话框时锁住背景滚动，规则与现有导航弹层相同。

键盘：山的画布不是唯一入口。页上有一棵和画布同一选择集的树（下一节）。方向键在树里移动。画布获得焦点时，左右转一个领域扇区，上下在当前领域里改层级，Enter 打开侧栏。

手机（宽度低于 768 px）：默认是第二节那张俯视 SVG 加上这棵树，不自动创建 WebGL。另有一个按钮「看立体」，由读者打开后才加载三维。窄屏上三维同样遵守帧时预算；达不到就停在 SVG，不先降到不可读。

⌘K 选中一篇已在图上的文章时，结果行可以出现「在格致山中查看」。这一行跟文章出口同一阶段落地，路由不存在时不加。

透镜只有两档，都是着色，不改位置：

- 按学科：簇颜料。默认。
- 按阶段：五层各一色，颜色必须同时过两套主题的对比度。色值在实现时从现有令牌里选，本稿不新造色。

任务书里的「我的足迹」和「阅读路线」透镜依赖本地阅读记录和学习编排。两者都在产品禁区里，本 epic 不建。

## 六、无脚本、无 WebGL、减少动效

路由服务端输出完整目录，不靠画布才有链接：

- 六个簇，簇内按环序。
- 每域一个 `<details>`，里面按 L1 到 L5 列出该域已有节点，每条是文章链接。
- 五个汇流链接。
- 一段说明：山的高度是认知层级，俯视就是首页星盘。

无脚本时 details 仍可打开，链接可走。无 WebGL 或 WebGL 上下文失败时，留下同一份目录和一张服务端 SVG 俯视，点扇区展开对应 details。减少动效时不播入场，等高线和点直接在终态。

这棵树就是读屏和键盘的同一套操作：选择、打开侧栏、开始阅读。不另做一套只有画布才懂的手势。

首页 RSC 预算不接收这棵树。山的文档自己计量。设计目标是文档 brotli 不超过 200 KB。`07b` 实测；超过就改成二十二个领域子路由，每个子路由只含该域节点，总索引页只留簇、域和汇流。子路由是固定二十二页，不是文章那种高基数动态路由。

## 七、性能与送审包

三维代码只在 `/knowledge-summit` 动态引入。不进全站共享包，不进二维图谱的首包，不进文章页。

沿用已有预算，本稿不提额：

- 该路由初始 JS ≤ 180 KB gzip（与现有 3D 路由同一档）。
- 单块 JS ≤ 285 KB gzip。
- 布局 JSON ≤ 80 KB brotli。
- 共享 CSS 不增加。山的样式放在路由旁，并入该路由自己的 CSS 增量（≤ 10 KB brotli）。

运行时：`frameloop` 在静止时改为按需；标签页隐藏时停；像素比限制在 `[1, 1.75]`。弱设备去掉光晕，栅格可以降一档，但不删节点。目标是静止后桌面中位帧不超过 16.7 毫秒，中端手机不超过 33 毫秒。这是送审时要测量的目标，不是本稿已经测到的数。

送审包在任何场景代码进入仓库之前交齐：

1. 本稿。
2. 真数据原型在两套主题、1440 与 390 宽度下的俯视和四分之三截图。
3. 镜头落定后连续 5 秒的帧时：桌面 Chrome 与一台中端手机，各报中位数和最差 1% 帧。
4. `public/summit-layout.json` 的 raw 与 brotli 字节数，以及山的文档 brotli 字节数。

四项里任一项超过上面的线，先改设计再谈实现。不把二维图谱绘制搬进 Worker。那是另一项未批准的工作，这座山的布局是构建期算好的，不靠它。

## 八、动工顺序

用户先批准本稿，再做测量原型。测量不过就停。测量通过并再次批准之后，才按下面的顺序写进产品。每步都能单独停，不把半座山接到首页按钮上。

| 步  | 交付                                                                                                             | 停的条件                              |
| --- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| 07a | `gen-summit-layout` 与幂等测试。位置与 `placeInWedge`、`astrolabeConfluences()` 一致。印出年份覆盖率。不挂路由。 | JSON 超过 80 KB brotli                |
| 07b | 仅本地的原型页：点、山体、俯视与一次倾斜。交截图、帧时、体积。不进导航。                                         | 帧时或文档体积超线                    |
| 07c | `/knowledge-summit` 正式路由：服务端目录、SVG 回退、点与山体。首页按钮仍指向二维图谱。                           | 无脚本目录缺链接，或三维包进了共享 JS |
| 07d | 侧栏、桥梁开关、两档透镜、键盘、窄屏「看立体」、文章出口与 ⌘K 的「在格致山中查看」。                             | 出现足迹、已读或学习路线入口          |
| 07e | 首页第六段改指向这座山；两套主题、桌面与手机、减少动效、无 WebGL 走一遍。                                        | 首页 RSC 或共享 CSS 超预算            |

`07b` 的原型文件在 `07c` 落地时删掉或收成正式路由，不留第二套场景。

## 九、验收

- 俯视时，二十二个领域的角序和首页星盘一致，五个汇流的角度与 `astrolabeConfluences()` 一致。
- 任一节点的层级与图上的 `knowledgeLevel` 一致，高度不跨层。
- 无脚本打开 `/knowledge-summit`，能从簇走到一篇现有文章。
- 减少动效、无 WebGL、390 宽，都能读完同一批链接。
- 侧栏没有足迹、已读、稍后读、规划路线。
- `gen-all` 两遍后布局文件哈希不变。
- 不改 `ALL_DOMAINS`，不改二维图谱的线端和延迟导航，不升共享 JS 预算。

## 十、请拍板的四处

1. 窄屏默认 SVG 加目录，三维要点「看立体」才加载。
2. 布局 JSON 的 brotli 上限收在 80 KB，而不是任务书里的 250 KB。
3. 山的无脚本目录先做单页 `<details>`，文档 brotli 目标 200 KB；超过再拆二十二个领域子路由。
4. 时间透镜、足迹透镜、阅读路线透镜和「规划路线」不进入本 epic。

这四处已在 2026-10-28 批准，并按第十一节落地。

## 十一、落地记录（2026-10-28）

1. 窄屏默认平面图。「看立体」之后才取布局、卡片和 three。桌面自动打开立体图。读者若已选「看平面」，拉宽窗口不会自动再开立体图。
2. 布局 JSON 维持 80 KB brotli，另加 200 KB raw。实测 13696 brotli / 77325 raw。标题不进这份文件。77275 是 JavaScript 字符数。
3. 单页目录的去脚本正文约 177 KB brotli。生产 HTML 相对去脚本正文大约再胀 1.25–1.48 倍，会过 200 KB。索引只留山、六簇、学科名和五个汇流；条目在二十二个静态领域页。开发服上去脚本后，索引约 7.5 KB brotli，人类历史领域页约 40 KB brotli。
4. 时间透镜、足迹、阅读路线透镜和「规划路线」没有做。文章页原有的阅读出口保留。
5. 卡片另存 `public/summit-cards.json`，立体图打开时才取。实测 147676 brotli / 500133 raw。门禁 200 KB brotli、500 KB raw。362497 是字符数，不是文件字节。
6. 节点地址是 `/knowledge-summit/[domain]#summit-node-N`。索引上的侧栏读卡片文件；领域页的锚点侧栏读服务端写进元素的层级、导语和链接。
7. 第一版镜头太近，环落到 NDC 1.7–1.9。拉开后，半径 1.16 的环在默认距离下 NDC 绝对值小于 0.98。汇流标题不再叠在山顶，铜点还在。无头 Chromium 落定后 `data-frame-ms` 为 8.3。这不是桌面中位数，也还没有中端手机的帧时。
8. 2026-10-28 用 `NEXT_DIST_DIR=.next-prod` 跑过生产构建和路由 JS/CSS 审计，预算内。渲染审计通过，只点名索引；二十二个领域页在 prerender manifest 里是闭合静态页。Lighthouse、无障碍全扫和 predeploy 未跑。未提交。
