# docs/archive — 历史归档

本目录存放**已耗尽使命的一次性时间点报告与研究稿**。它们记录的是某个日期的快照或某项已完成决策的依据，保留用于追溯，但**不是真相源，新代理无需阅读**。

真相源在 `docs/` 根目录：`任务清单.md`、`工作日志.md`、`聚焦方向.md`、`知识精神.md`、`叙事与引用规范.md`、`工程原则.md`。

> **归档标准**：报告里的可行动项必须**先迁移**到 `任务清单.md`（在办/待办、已知问题），或其研究对象已经建成、其发现已被修复，才可归档。不能连同待办一起埋掉。
