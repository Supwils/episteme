# 文学与叙事立项口径（B3 launchGate）

> 2026-09-05。本文件关闭 `lib/subject-candidate-matrix.ts` 里 `literature-narrative` 的两项前置：事实层与解释层分离，以及引文版权口径。未满足本文件的文章不得标 `published`。
>
> 领域路由拟用 `/literature`（候选 id 仍是 `literature-narrative`）。完整 Playbook 见 `学科版图与导航架构.md` 第五节。

---

## 一、为什么必须分层

文学内容最容易把**口味写成事实**。读者无法核验“伟大”“深刻”“正典”，却能核验版本、年代、抄本系统和一句引文是否真在某页。

本平台的作者口吻只陈述可核查项。评价、主题、意图、政治读法一律挂到具体论者或学派，并允许对立读法并存。

检查口诀：删掉所有评价形容词之后，剩下的句子是否仍能被版本、年表或文本对质？能，就是事实层；不能，就必须改成解释层。

---

## 二、事实层（可用作者口吻断言）

只包括能指出核验路径的命题：

| 类型       | 可以写                                   | 必须同时写出                       |
| ---------- | ---------------------------------------- | ---------------------------------- |
| 作者归属   | 学界主流归属                             | 有力异议（续书、托名、集体创作）   |
| 年代       | 创作、刊刻、最早抄本、现代整理本         | 不确定区间，不用一个假精确年顶替   |
| 语言与形式 | 原文语言、诗体、章回、韵部、可计数的格律 | 所据韵书或诗学手册                 |
| 文本事件   | 书页上发生的情节、对白、场景             | 所据版本（程甲本、脂评本、某译本） |
| 版本史     | 禁毁、删改、通行本、考古发现             | 来源（目录、校记、发掘报告）       |
| 生平       | 生卒、仕履、可核的交游                   | 标准传记或墓志；传说标为传说       |

禁止用作者口吻写：

- “最伟大”“巅峰”“真正的文学”
- “作者想说的是……”
- “这部作品证明了民族精神 / 人性永恒”
- 把一家评点写成作品的客观属性

不确定就写“目前整理者多把……定在……”，不要补一个整齐年份。

---

## 三、解释层（必须归属）

下列内容必须点名论者、学派或传统，并尽量给对立读法：

- 主题、象征、寓意、作者意图
- 美学判断与排行
- 正典地位、教材入选、诺奖作为“世界承认”
- 性别、殖民、民族、阶级读法
- 影响史（除非有互文、翻译、序跋等文献链）

句式：

- 事实：`《红楼梦》前八十回在程本之前以抄本流传；作者归属曹雪芹是主流意见，后四十回作者问题没有闭合。`
- 解释：`鲁迅在《中国小说史略》里把它看作人情小说的高峰——这是评价，不是可测量属性。`

一篇里解释层应多于口号、少于无归属的鉴赏散文。至少给一条与主流评价不同的认真读法。

## 四、引文版权口径（2026-09）

### 4.1 优先公有领域

一手引文优先：

- [Project Gutenberg](https://www.gutenberg.org/)（须核该条记录的版权说明）
- [中国哲学书电子化计划](https://ctext.org/) 及可靠古籍整理本
- 维基文库中**已标明公有领域**的条目

美国作品：在 2026 年，**1929 年及更早发表**的作品已进入公有领域（发表后 95 年；1930 年发表的作品 2026-01-01 起进入）。不得把“网上能搜到全文”当成公有领域。

中国大陆一般规则是作者死后五十年；翻译、注释、标点整理本另有版权。先秦原文可能公有，杨伯峻、余冠英等今人译文仍受保护。

### 4.2 保护期内：只引用、不代替阅读

保护期内作品（含绝大多数 20 世纪小说、歌词、当代诗、受保护译本）：

| 体裁        | 单篇上限                             | 硬禁                       |
| ----------- | ------------------------------------ | -------------------------- |
| 韵文        | ≤ 8 行，且不超过该诗 20%             | 整首诗、整组诗             |
| 散文 / 剧本 | 单段 ≤ 200 汉字，每篇累计 ≤ 400 汉字 | 整章、整场、歌词全文       |
| 译本        | 计入上表；优先自己转写               | 把今人译文当“原文”大段粘贴 |

每条引文必须有：作者、作品、所用版本或译者。没有版本的引文视为未完成。

教学转写（用自己的现代汉语概述情节或诗意）不算引用，但不得整段改写当代受保护译文的句式。

禁止：用模型“默写”保护期内全文；爬取盗版站；给未授权全文加外链。

### 4.3 图像

封面、剧照、手稿照片走既有 `docs/图像管线指南.md`。不得从检索结果热链一张封面。书影须有权利元数据。

### 4.4 机器把关（接入后）

`check-content` 应对 `content/literature/` 额外检查：

1. 未归属的评价词（最伟大 / 千古 / 正典 / 深刻揭示）出现在作者口吻中 → warning。
2. 独立引用块（`>` 或围栏引文）单块超过 200 汉字且 frontmatter 未标 `publicDomain: true` → warning。
3. 缺 `## 参考文献` 或来源不可核 → 与全库同一 error。

在检查脚本落地前，写作者按本表自检。

## 五、板块与首发规模

与候选矩阵一致：首发 **36 篇 / 6 板块 / 4 个可视化（后置）**。

| 板块 key                | 中文           | 学习层级 |
| ----------------------- | -------------- | -------- |
| `narrative-basics`      | 叙事基础       | L1       |
| `poetics-and-form`      | 诗学与形式     | L2       |
| `world-traditions`      | 世界文学传统   | L3       |
| `theory-and-method`     | 文学理论与方法 | L4       |
| `reading-and-reception` | 阅读与接受     | L4       |
| `contemporary-edges`    | 当代边界       | L5       |

全球覆盖承诺（每簇至少 1 篇进入 world-traditions 或对应桥）：汉语、欧洲正典及其批评、阿拉伯—波斯、南亚、非洲口头文学、拉美与加勒比、东亚与东南亚现代。

可视化（`叙事结构图谱` / `格律与音步实验室` / `世界文学时空地图` / `译本比较器`）不阻塞第一波文字上线，但不得在首页承诺可点。
