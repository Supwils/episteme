## 一、现状诊断

### 1.1 已有的事实（不是白板）

- `components/nav-data.ts` 已有 `NAV_GROUPS` 三组分类（自然与形式 8 / 人文与社会 5 / 探索 4），但**社会学、语言学不在任何组**——桌面下拉与移动抽屉双双缺失这两个上线领域（真实 bug）。
- 门户首页 15 张 DomainCard 按数组顺序平铺，无分组概念。
- 页脚「知识领域」15 条扁平一列。
- 领域内页面（如 `/chemistry`）**没有任何跨领域切换入口**（SectionAwareNav/Footer 在领域前缀下返回 null，SubjectHeader 只有返回首页链接）。

### 1.2 清单漂移（真相源缺失的代价）

领域清单散落在 10+ 处，已出现三处真实漂移：

| 位置                                                                     | 问题                                               |
| ------------------------------------------------------------------------ | -------------------------------------------------- |
| `components/nav-data.ts`                                                 | 缺 sociology、linguistics                          |
| `lib/knowledge-continuum.ts`                                             | 缺 linguistics（影响桥域校验）                     |
| `lib/frontier.ts`                                                        | 缺 linguistics                                     |
| `app/page.tsx:20,24`、`app/search/page.tsx:13`、`public/manifest.json:5` | 硬编码「15 个领域」（实际 15 域 + 图谱 = 16 入口） |

### 1.3 附带发现的缺陷

- **断点重叠**：DesktopNav 自 `lg`(1024px) 显示，MobileNav 到 `xl`(1280px) 才隐藏——1024–1280px 区间两套导航同时渲染。
- 领域色在 5 处独立维护（nav-data / subject-nav / frontier / search / graph），值互有出入。
- 「物理学」与「宇宙物理」等标签在不同表面不一致。

### 桌面导航：六簇按钮 + 图册面板（2026-09-23 起，`T-DESIGN-03`）

> 取代 2026-08 的「4 个超组下拉」。当时的顾虑是「6 簇各带一个下拉放不下」；现在六个按钮不各自带下拉，而是**共用一块全宽图册面板**。点哪一簇，面板就打开并加粗那一栏的刻线，所以六个按钮在 1024 px 宽度也放得下。

- **页头**：格致朱砂印 + 字标（回首页）· 六簇按钮 · 探索（下拉，配功能图标）· 搜索（⌘K）· 主题切换。
- **图册面板**（`components/chrome/AtlasMenu.tsx` + `AtlasGrid.tsx`，数据来自 `lib/atlas.ts`）：
  - 六栏，每栏顶上一道簇颜料刻线；
  - 每行是学科印、领域名、篇数（`site-stats`）和一句话；
  - 方向键在格子间移动，Esc 关闭并把焦点还给触发按钮。
  - 面板本体在指针或焦点靠近时才加载，学科印字形不进全站共享包。
- **领域页头**：右侧「全部领域」打开同一块面板。
- **移动端**：抽屉里是可折叠的簇列表，默认展开读者当前所在的簇；下方是探索入口。
- 已删除 `NAV_SUPER_GROUPS` / `getNavSuperGroups()`。

## 三、真相源统一

**原则：`lib/data.tsx` 的 DOMAINS 是唯一真相源，一切表面派生。**

1. DOMAINS 条目新增 `cluster` 字段（六簇 id 之一）与可选 `clusterOrder`。
2. 新增 `lib/domain-clusters.ts`：簇元数据（id/中文名/英文名/超组映射）+ `getNavSuperGroups()` / `getClustersWithDomains()` 派生函数。
3. `components/nav-data.ts` 的 NAV_GROUPS 改为从 DOMAINS 派生（删除手工拷贝，社会学/语言学缺失这类 bug 在结构上不再可能）；条目颜色直接用 `glowColor`。
4. 硬编码「15」全部改为 `DOMAINS.length` 派生：`app/page.tsx`、`app/search/page.tsx`、`public/manifest.json`（描述同步更新为 16 领域全名）。
5. 附带修复：MobileNav 断点 `xl:hidden` → `lg:hidden`（消除 1024–1280 双导航重叠）。

不做（本轮）：knowledge-continuum / frontier 缺 linguistics 的补齐——那两个清单是功能特性清单（连续体 thread、前沿配置），不是导航清单，纳入各自后续任务。

## 四、导航改造方案（五个表面）

| 表面                               | 现状                  | 改造                                                                       |
| ---------------------------------- | --------------------- | -------------------------------------------------------------------------- |
| 桌面下拉（DesktopNav/NavDropdown） | 3 组手工清单，缺 2 域 | 4 超组 + 探索，从 DOMAINS 派生；超组面板内按簇分小节（两栏）               |
| 移动抽屉（MobileNav）              | 平铺无组头，缺 2 域   | 6 簇带组头分组展示                                                         |
| 领域内 header（SubjectHeader）     | 零跨领域入口          | 右侧加「全部领域」超组下拉（与桌面同源数据），任意领域页可直接跳转其他领域 |
| 门户首页网格                       | 15 卡平铺             | 按 6 簇分区，簇标题 + 卡片；卡片顺序 = DOMAINS 在簇内声明顺序              |
| 页脚                               | 扁平一列              | 按簇分列（小屏自动堆叠）                                                   |

a11y 约束：下拉键盘可达（Esc 关闭、方向键）、移动端组头为 `<h2>`/列表语义、144 状态 a11y 扫描复验。

## 五、新域接入 Playbook（从 linguistics 完整路径提炼）

> 完整 checklist 见调研记录；此处为决策要点。两条路径：sociology 路径（快速）与 linguistics 路径（正式立项）。**新学科一律走 linguistics 路径。**

阶段 0 立项：`lib/subject-candidate-matrix.ts` 加候选（7 维评分、L1–L5 spine、桥域 ≥6、30–60 篇、3–5 可视化、≥6 覆盖簇、≥1 open source）+ `lib/<domain>-subject-plan.ts`（sections/发布波/可视化/全球覆盖）。
阶段 1 引擎注册：`lib/new-domains.ts` KNOWLEDGE_DOMAINS（sitemap/导航 tab/valid-routes/search-index 全部自动派生）。
阶段 2 路由薄壳：`app/<domain>/`（layout/globals.css/page/section/[slug]/loading/error/not-found，全部照抄 sociology）+ DomainHeroMotif 加一个 motif。
阶段 3 门户清单：DOMAINS 入口卡（含 cluster 字段）、APP_URLS、continuum、coverage-meta。🔒 `home-domain-catalog.test.ts` 的 EXPECTED_DOMAIN_IDS、`audit-learning-continuum.ts` 的 established 计数需同步。
阶段 4 内容：frontmatter 按 linguistics Zod schema 标准（≥2200 汉字、L 级、证据模式、跨域节）。
阶段 5 前沿（可选）；阶段 6 图谱（-nodes + -coverage + SCOPES floor + domain-spine 五步）；阶段 7 每日知识（可选）；阶段 8 验收件（e2e + 专属审计）。
