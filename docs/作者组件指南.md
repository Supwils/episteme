# 作者组件指南

> T-DESIGN-06e。正文走自研的块级 Markdown 渲染器（`components/MarkdownRenderer.tsx`），**不是 MDX 管线**，所以作者组件写成**带语言名的围栏块**，不是 JSX 标签。渲染实现在 `components/markdown/AuthorBlocks.tsx`，样式在 `components/markdown/author-kit.css`。

## 何时用

只在散文讲不清**结构**时用：层级、对照、流程、年代。一篇文章用一两个就够；能用一段话说清的，就写一段话。组件不替代叙事（见 `docs/叙事与引用规范.md`）。

## 通用规则

- 围栏首行写组件名：` ```levels `，末行 ` ``` ` 收尾。
- 每行一条，列之间用 **空格 + 竖线 + 空格**（`|`）分隔。列内文字可以用行内语法：加粗、`[[wiki-link]]`、`$公式$`、脚注 `[^1]`。
- 围栏里的空行会保留（`aside` 用它分段），不会把组件切断。
- 未知的组件名按普通代码块渲染，不会报错——拼错名字时页面会出现一个代码框，这就是提示。

## 组件

### `levels` 层级阶梯

适合：线段喻、认知层级、马斯洛式的由低到高。**自下而上书写**（第一行是最低一级），页面上最高一级在顶端、逐级缩进；读屏按书写顺序读。列：`标记 | 名称 | 说明（可省）`。

````markdown
```levels
想象 | 影子与映像 | 对影像的把握，最不确定
信念 | 可见事物 | 对实物的常识判断
思想 | 数学对象 | 借助假设向下推演
理性 | 理型 | 不借助图像，上升到第一原理
```
````

### `compare` 对照

两（或多）栏并列。首行是栏名，其后每行一组对照，渲染成带列表头的真表格（读屏可逐列导航）。

````markdown
```compare
理性论 | 经验论
知识始于天赋观念 | 心灵原是一块白板
代表：笛卡尔、莱布尼茨 | 代表：洛克、休谟
```
````

### `steps` 步骤

有先后的流程。列：`步骤名 | 说明（可省）`。编号自动生成。

````markdown
```steps
观察 | 记下反常现象
假设 | 提出可被检验的解释
检验 | 设计能推翻假设的实验
```
````

### `timeline` 时间线

短年表（十条以内；更长的年表属于领域的时间线页）。列：`时间 | 事件`。

````markdown
```timeline
1543 | 哥白尼《天球运行论》出版
1687 | 牛顿《自然哲学的数学原理》出版
```
````

### `aside` 旁注

正文之外的补充：术语来历、一个旁支故事。用空行分段。

````markdown
```aside
“格致”出自《礼记·大学》“致知在格物”。

晚清以“格致”译 science，后来才让位于“科学”。
```
````

### 行内术语 `{{term:术语|释义}}`

给第一次出现的术语一个随手的释义：悬停或键盘聚焦时浮出，读屏会连同括注一起读出，打印时直接印在术语后。

```markdown
柏拉图把它称为{{term:理型|eidos，可知世界中事物的原型}}。
```

必须带 `term:` 前缀——集合论里的 `{{{∅}}}` 这类花括号不会被误识别。

## 图

图像沿用 `![说明](/images/<id>)`，走图像权利管线（见 `docs/图像管线指南.md`），不另设组件。
