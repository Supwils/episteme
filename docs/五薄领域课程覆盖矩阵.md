# 五个较薄领域课程覆盖矩阵

> 建立日期：2026-08-09 · 基线：法学 53、工程 50、艺术 54、语言学 61、社会学 62 篇
>
> 目的：不再用“每域再加若干篇”替代覆盖判断。矩阵把专业培养框架映射到现有板块，区分知识是否存在、是否有方法训练、是否有真实对象剖析，以及能否形成进阶路径。

## 评估方法

- **完整**：至少有一组互补文章，覆盖概念、方法、证据边界和应用。
- **基本**：有正式文章，但主要是总览或单一传统，缺少对象分析或方法压力测试。
- **薄弱**：只有邻近内容、前沿短板块或跨域提及，没有可独立学习的主节点。
- **缺失**：没有公开、可路由的对应内容。

外部基准不是照搬某一学校课表，而是提取跨项目反复出现的能力结构：

- 工程采用 [ABET 2025–2026 工程认证标准](https://www.abet.org/accreditation/accreditation-criteria/criteria-for-accrediting-engineering-programs-2025-2026/)：复杂问题求解、约束下设计、实验与数据、伦理责任、团队沟通和综合设计。
- 法学采用 [ABA 2025–2026 法学院标准](https://www.americanbar.org/groups/legal_education/accreditation/standards/) 及其[学习成果说明](https://www.americanbar.org/groups/legal_education/about/committees/outcomes-assessments/about/)：实体与程序法、分析推理、研究沟通、职业伦理和形成性评估。
- 艺术采用 [NASAD 标准与本科能力索引](https://nasad.arts-accredit.org/accreditation/standards-guidelines/)：创作实践、视觉分析、艺术史、材料与技术、专业实践及跨媒介综合。
- 语言学以密歇根大学公开的[本科核心](https://lsa.umich.edu/lsa/academics/majors-minors/linguistics-major.html)作结构参照，并用其[学科范围说明](https://lsa.umich.edu/linguistics/about-us/what-is-linguistics.html)补足形态、田野和跨语言比较。
- 社会学采用 [ASA 本科专业建议](https://www.asanet.org/wp-content/uploads/ASA_Task_Force_on_the_Undergraduate_Major.pdf) 与 [2017 更新报告](https://www.asanet.org/wp-content/uploads/asa-booklet-2017.pdf)：理论、方法、统计、经验研究、分层递进，以及种族、阶级、性别和跨国比较。
