> 最后更新：2026-09-24（22 域全部上线；前端设计改造进行中）
>
> 本文是**平台全景**：有什么、多大、怎么组织。在办事项看 `任务清单.md`，方向与禁区看 `聚焦方向.md`。

## 平台愿景

> 让任何人随时都能以美好的方式接触人类最重要的知识。

**Episteme · 格致** 是一个知识即服务平台（Knowledge as a Service），以浏览器为唯一交付方式，用可视化、沉浸式的方式探索 22 个知识领域。我们呈现的不是百科词条，而是人类认识世界的完整过程——包括震撼、疑惑、错误与顿悟。

## 一、架构：单一 Next.js 应用

**所有代码运行在仓库根目录的一个 Next.js 15 应用中**（2026-06-02 已从 Turborepo monorepo 收敛完成，不再有 `apps/`、`packages/`、`turbo.json`、`pnpm-workspace.yaml`）。

```
universe-knowledge/
├── app/             ← App Router：343 个 page.tsx + 14 个 route handler
├── components/      ← 全局 / 跨领域 / 领域专属 UI 组件
├── subjects/        ← 12 个有专属前端逻辑的领域
├── lib/             ← 内容加载器、领域引擎、搜索、图引擎、知识编排层
├── content/         ← 全部知识内容（每域一个子目录，另有 curiosities 数据）
├── content-assets/  ← 图像原图与权利元数据
├── generated/ public/ ← 派生索引与静态资源
├── scripts/ e2e/ docs/
└── reference/       ← 旧源码参考（不参与构建/测试/部署）
```

| 层级     | 目录          | 职责                                   |
| -------- | ------------- | -------------------------------------- |
| **内容** | `content/`    | 知识文章、类型化数据、前沿稿           |
| **路由** | `app/`        | App Router 页面、布局、API             |
| **组件** | `components/` | 全局与跨领域 UI                        |
| **领域** | `subjects/`   | 各领域私有前端逻辑（互相隔离）         |
| **工具** | `lib/`        | loader、领域引擎、搜索、图引擎、编排层 |

访问：`pnpm dev` → **http://localhost:3067**（生产模式 `pnpm start` 为 3000）。

### 两类领域实现

| 类型             | 说明                                                                  | 领域                                                                                                |
| ---------------- | --------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| **专属实现**     | 有独立数据模型 / 可视化 / 场景，代码在 `subjects/<域>/`               | 物理、历史、哲学、生命科学、宇宙学、数学、经济学、心理学、化学、医学、语言学、知识图谱              |
| **通用领域引擎** | `lib/knowledge-domain.ts` + `lib/new-domains.ts` 配置驱动，路由是薄壳 | 计算机科学、政治学、地球科学、医学、化学、社会学、心理学（methods）、语言学、法学、艺术、工程与技术 |

引擎驱动 = 「配置 + 内容 + 薄路由」即可上线一个新板块，sitemap / 导航 / valid-routes / 搜索索引全部自动派生。两类并非互斥：化学、医学、心理学、语言学同时有专属组件与引擎板块。

## 二、内容盘点

篇数、每域的收藏数（哲学家、流派、物种……）与图谱规模都由构建生成，读 `generated/site-stats.json`（`pnpm gen-site-stats`），不在文档里手写——2026-09 之前的三份手写表就是这样互相矛盾的。板块结构看各域的 `lib/new-domains.ts` 配置或 `lib/subject-nav.ts`。

### 常设内容类型

- **研究前沿**（`content/<域>/frontier/*.md`）：正在发生的 2020s 知识——开放问题、谁在攻关、近年突破（带年份与来源）、未知边界。规范见 `前沿创作指南.md`。
- **虚构对话体**（`dialogues/`）：叙事体裁，豁免跨域连接节与引用门槛，但必须标注体裁声明。
- **被推翻的理论**（2026-08 新增系列，36 篇覆盖全部域）：统一写法为「它当时有多合理 → 什么真正击穿它 → 代价 → 留下的判断力」。
- **跨域连接节**：每篇文章末尾的 `## 跨域连接`，达标口径 ≥4 条 bullet、≥3 条粗体 `[[slug]]` 领头、≥400 汉字、无自链（`pnpm audit-cross-domain` 强制）。

## 三、旗舰体验

### 宇宙物理（`/universe-physics`）

跨尺度漫游：从可见宇宙（10²⁶ 米）逐层下钻到地球（10⁶ 米），每层有 WebGL 3D 场景与科学叙事。三种场景过场、5 步性能降级、LOD 粒子系统、相邻层预加载、无 WebGL 时降级为手写 SVG 路线。3D 路由初始 JS 约 149 KB gzip（预算 180 KB，`pnpm audit:physics-runtime` 强制）。

### 人类历史（`/human-history`）

时间线 + Atlas 知识图谱 + SVG 世界地图 + 人物传记 + 学术视角。事件/人物数据按「时代 × 内容类型」分片到 `content/human-history/data/generated/`，按需动态 import；19 个页面共享首载 180 KB gzip。

### 知识图谱（`/knowledge-graph`）

Canvas 2D 力导向图（Barnes-Hut O(n log n) + Web Worker），覆盖全部 22 域。全图布局在构建期算好随数据下发，节点描述在首绘之后再取。认知分层布局、BFS 最短路径高亮、聚类模式、语义 LOD、跨域邻居标注、策展导览。节点来源三类：mdx-derived（`derived-node-taxonomy.ts` 登记的板块自动派生，占绝大多数）、curated（手写的策展锚点与骨架节点，优先级最高）、domain-specific 生成器。

### 学科首页与文章页（2026-09 设计改造）

22 个学科共用一套首页骨架（`components/landing/DomainLanding.tsx`）：引导问题、标本图版与小星盘、学习主线、板块、学科专属模块、最近更新与前沿、与其他领域的桥。文章页按段型识别误解、事实、名言、洞察与跨域连接，文末是向前 / 向上 / 向旁三向出口。细节见 `设计方向-观测台与手记.md`。

### 知识编排层（跨领域）

- **知识连续体** `/`（首页嵌入）+ `/api/knowledge-continuum/*`：L1→L5 认知阶段的跨域主线与覆盖度快照。
- **知识汇流** `/knowledge-confluence/[id]`：多域交汇专题。
- **阅读路线** `/read/[slug]`：策展式核心知识路径。
- **每日知识** `/daily` + **奇趣知识** `/curiosities`：轻量入口，可"换一批"。
- **分子图鉴** `/molecules`：自托管 Mol\* 3D 分子查看器（CSP 按路由放宽，仅 medicine/chemistry/molecules）。
