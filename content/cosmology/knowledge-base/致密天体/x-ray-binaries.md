# X射线双星：用双星系统解剖极端天体物理

## 概述

**X射线双星**（X-ray binary，XRB）是宇宙中研究中子星和黑洞物理最重要的天然实验室。它们是双星系统，由一颗致密天体（中子星或黑洞）和一颗供质伴星，后者可为普通恒星或某些超紧致系统中的白矮星组成，伴星向致密天体转移物质，吸积过程释放的引力能量以 X 射线的形式辐射出来，明亮吸积阶段光度可达10³⁷–10³⁹erg/s，约为太阳总光度的数千至数十万倍；宁静态可低得多，超亮源又可更高[1]。

X射线双星提供恒星级黑洞动力学质量测量，也是研究吸积盘物理、相对论喷流、核聚变爆发（X 射线爆发）和中子星状态方程的主要途径之一。

常见误解是把它们当成“自己在烧 X 射线的恒星”。持续吸积X射线主要来自引力能，另有中子星表面热核爆发，不能将全部辐射都归为同一种能源。氢聚变为氦的质量转能效率约百分之零点七，吸积可以把静止质量的几个百分点变成辐射，所以一颗并不特别亮的伴星也能点亮整个双星。观测入口是[[X射线天文学]]，时变本身则属于[[时域天文学]]。

分类按**伴星质量**，不按致密天体种类。同一颗[[black-holes|黑洞]]既可以在大质量系统里吃恒星风，也可以在低质量系统里吃洛希瓣溢流。中子星同样如此。分型问的是物质怎么送过来、系统能活多久、落在银河哪里；致密天体种类决定是否有物质表面和边界层、有没有热核爆发、脉冲能不能被看到。

## 两种主要类型

划分并不干净。两端之间还有中间质量伴星系统，且分类所用当前伴星质量未必等于出生质量；界限是演化与观测上的约定。下面两节说的是两端的典型图像，不是一张无例外的身份证。

### 大质量X射线双星（HMXB）

**大质量 X 射线双星**（High-Mass X-ray Binary）的伴星通常是约8–10太阳质量以上的早型星（O 型或 B 型超巨星或 Be 星）。

**转移机制**：

- **超巨星 HMXB**：伴星通过强恒星风向致密天体供给物质（风吸积，wind accretion）；
- **Be/X 射线双星**：Be 星周围的旋转支撑的赤道外流盘（decretion disk）可在近心点等轨道阶段被致密天体摄取，也有不严格锁定轨道相位的巨大爆发[2]，导致 X 射线爆发

风吸积走的是 Bondi–Hoyle–Lyttleton 通道：致密天体在风里扫过一个捕获截面，截到的气体不必先绕成一张薄盘。在Be/X系统中，中子星与赤道盘的轨道关系可使供质随相位显著变化；不能把这种盘供质等同于超巨星的球对称风吸积。观测到的是 X 射线光度随轨道相位起伏，不是一张事先量好的质量转移率表。把光度直接换成 $\dot{M}$，还要假定辐射效率、几何和距离，这三样都有系统误差。

**代表性天体**：

- **Cygnus X-1**（天鹅 X-1）：最早建立黑洞动力学证据的X射线双星之一。[5]黑洞质量约 $21\,M_\odot$（Miller-Jones et al. 2021，_Science_，371，1046），伴星为OB型超巨星，距离约 $2.2$ kpc。其持续的 X 射线辐射和强喷流使其成为研究吸积和喷流的标杆
- **Centaurus X-3**（半人马 X-3）：经典的吸积X射线脉冲双星，轨道周期约 $2.09$ 天，展示了吸积中子星的 X 射线脉冲与掩食

HMXB 的寿命受伴星的演化时标限制（约 $10^7$ 年），因此多分布在年轻恒星形成区。

大质量伴星来自[[massive-star-evolution|大质量恒星演化]]，演化较快，HMXB常与年轻成星环境相关；诞生踢速和双星演化仍可使其偏离出生地。银河盘上的 HMXB 因此贴着旋臂和年轻星协，空间分布还受发现灵敏度和遮蔽影响。[3]Grimm、Gilfanov 与 Sunyaev（2003）[3]把近邻星系里 HMXB 的数目和集体 X 射线光度当作恒星形成率的示踪：源的数目大致随形成率线性增加，低形成率时集体光度会被最亮的几颗源主导，关系先变陡再回到线性。HMXB 数的是最近一次大质量星形成，不是整盘的恒星质量。

### 低质量X射线双星（LMXB）

**低质量 X 射线双星**（Low-Mass X-ray Binary）的伴星质量约 $\le 1\,M_\odot$，可为主序星、亚巨星、巨星或超紧致系统中的白矮星；典型供质是洛希瓣溢流[4]。

**转移机制**：伴星膨胀充满洛希瓣，物质通过**洛希瓣溢流**（Roche lobe overflow）流向致密天体，形成带角动量的吸积流；是否为标准薄盘还依吸积状态。物质带来角动量，在吸积盘中螺旋向内，在盘、热流以及中子星边界层等区域释放能量；标准薄盘与ISCO对应有其适用条件[1]。

洛希瓣溢流要靠轨道角动量损失或伴星核演化把恒星半径推到接触。主序低质量伴星靠磁制动缩轨，更紧的轨道还可以靠引力波辐射。伴星一旦充满洛希瓣，转移率由轨道收缩时标和伴星热时标共同定，不是一个可以事先报出的常数。观测直接给的是 X 射线光度；把它读成吸积率，必须先选定效率和距离，文中因此只用光度相对爱丁顿值来谈状态，不另编一套转移率。盘的几何与光谱见[[accretion-disks-relativistic-jets|吸积盘与相对论喷流]]，这里只跟谱态走。

**代表性天体**：

- **Sco X-1**（天蝎 X-1）：X 射线天文学历史上最早发现的太阳系外X射线源（Giacconi et al. 1962，_Physical Review Letters_，9，439）——贾科尼2002年获奖理由是对天体物理学的开创性贡献、促成宇宙X射线源的发现[15]
- **4U 1820-30**：轨道周期仅 $11$ 分钟，是经典的超紧致LMXB例子，伴星可能是氦白矮星
- **A0620–00**：低质量伴星的黑洞瞬变，宁静期伴星动力学可用于约束质量；不能因为爆发很亮便划入大质量伴星类。[5]

LMXB 的轨道周期通常较短（数小时到数天），寿命较长（约 $10^9$ 年），在球状星团中密度高（动力学形成概率大）。**大多数已知毫秒脉冲星被认为是 LMXB 的演化终产品**——中子星在长期吸积过程中被自旋加速。

许多LMXB处于较老星族，但系统年龄不能只由当前低质量伴星唯一判断，；长期演化、诞生踢速与不同形成通道影响空间分布。银河LMXB常向银心和[[球状星团]]集中：星团核密度高，潮汐捕获和交换可以把致密天体捉进双星，这是动力学形成，不是从原始双星一路演化下来。多数银河黑洞瞬变是 LMXB：盘在低吸积时电离不稳，外盘变中性、粘滞骤降，系统在宁静与爆发之间切换，爆发可持续数周到数月。

经典回收模型提出，弱磁场中子星若长期从开普勒盘吸积，可以被加速到毫秒周期；吸积停掉之后，它可表现为射电毫秒脉冲星；是否可见还受磁层状态与视线影响。[6]这把 LMXB 和毫秒脉冲星连成一条演化链，也解释了后者表观年龄很长、磁场却比普通脉冲星弱。脉冲星计时阵用的正是这类被回收过的钟，见[[pulsar-timing-array|脉冲星计时阵]]。中子星内部能承受多大自旋，则要问[[neutron-star-interior-eos|中子星内部状态方程]]。

## 吸积状态与谱态转换

X 射线双星最迷人的现象之一是它们在不同吸积率下表现出截然不同的**谱态**（spectral state），对应不同的物理结构：

### 软态（Soft State / High Soft State）

以下主要讨论黑洞X射线双星；不能为所有系统设置同一个吸积率门槛。软态的热盘分量较强，光度与质量流率换算仍需效率。[1][7]吸积盘延伸至 ISCO，辐射以热软 X 射线为主（多温黑体，峰值约 $1$ keV）。此时喷流通常被抑制（没有强烈的射电发射）。

软态的连续谱主要由盘的热成分主导，硬 X 射线冕变弱。对恒星级黑洞，盘的峰值落在约 $1$ keV，所以叫软；同一套盘放到超大质量黑洞上峰值会挪到紫外，那是[[活动星系核与类星体|活动星系核]]的问题，不是另一台机器。射电减弱与持续紧致喷流受到抑制相容，不等于盘本身不存在，也不证明所有外流都消失。

### 硬态（Hard State / Low Hard State）

硬态可见于较宽光度范围，并非都低于1%爱丁顿光度；质量流率也不能用光度单位表达。低光度截断盘加热内流是一类重要模型，物质形成热的、稀薄的"冕"（corona），产生硬 X 射线幂律谱（光子指数 $\Gamma \approx 1.6$–$1.8$，截止能量约 $100$–$200$ keV）。同时射电喷流强烈，射电与X射线相关提供吸积和喷流耦合的线索；跨质量“基本平面”还含黑洞质量与样本状态，不能与任意双星两波段相关混为同一式[1]。

硬态不是“源变暗所以光谱变硬”这么简单。截断盘加热流模型把内区写成辐射冷却效率低的热流，薄盘的内边缘被推到几个到几十个引力半径之外。热电子用逆康普顿把软光子抬到硬 X 射线，截止能量与电子温度及光学深度等共同有关。射电在这一侧常在，X 射线与射电光度大致相关，但这是观测相关，不是把喷流功率从视界磁场里算出来。

名字里的 low/high 来自早期对天鹅 X-1 的软 X 射线监测：软态在 $2$–$10$ keV 更亮。换成硬 X 射线，硬态反而可以更亮。Homan与Belloni（2005）[7]因此改用硬度–强度图上的轨迹来分态，而不是按瞬时光度贴标签。

### 态变：硬态到软态的迁移

黑洞 X 射线双星在亮度上升时往往先停在硬态，然后突然迁移到软态（迟滞效应，hysteresis）——在硬-软迁移时的临界亮度高于软-硬迁移时的临界亮度，形成"迟滞环"（hysteresis loop）。这一现象至今没有完全公认的理论解释，可能与磁场和冕的形成有关。

把爆发画在硬度–强度图上，轨迹常常呈逆时针的 q 形：从宁静硬态爬升，在高光度处向软转弯，下降时沿软态走更远，再在低光度处回到硬态。Maccarone（2003）[8]汇编有可靠距离与质量的源，发现**软到硬**的过渡光度大约在爱丁顿光度的 $1\%$–$4\%$，均值约 $2\%$；硬到软可以高好几倍。同一光度可以对应两种光谱，说明状态不是吸积率的单值函数。

中间还有硬中间态和软中间态。功率谱从宽带噪声变成准周期振荡，射电有时出现孤立耀发。不是每次爆发都走完全程：有的源在硬态爬到相当高的光度后直接衰减，称为失败的软态过渡。中子星系统也可以软硬转换，但固体表面和边界层让光谱分类更碎，不能把黑洞的 q 图原样贴上去。

## X射线爆发：中子星表面的核聚变

一些吸积中子星可出现的现象是**I 型 X 射线爆发**（Type I X-ray burst）：从伴星转移来的氢/氦在中子星表面积累，当底层温度和压强达到热核点火条件时，发生失控的热核聚变，典型持续数十秒，也有更短或更长事件；部分达到爱丁顿标尺并出现光球膨胀[9]：

达到光球膨胀的爆发，峰值可在10³⁸erg/s量级；不同组成和引力红移会改变远处所见临界光度。

不是所有I型爆发都到同一峰值。PRE爆发可作为经验距离标尺，但需检验组成、红移、各向异性、光谱颜色修正和所采用的峰值或回落时刻。[9][10]

Kuulkers等（2003）[10]用球状星团里距离已知的爆发源做校准：所研究爆发源中约三分之二，其光球膨胀爆发的最大峰值光度接近 $(3.79\pm 0.15)\times 10^{38}$ erg/s，接近贫氢物质的爱丁顿光度。他们同时强调，个别源会明显偏离，这条经验烛光大约只有百分之十五的精度。黑洞没有固体表面，不会出现 I 型爆发；看见热核爆发，致密天体就不是黑洞。

**超爆发**（Superburst）：更稀少（复发依供质和内部热状态，不能统一规定每年一次），持续数小时，由积累的碳在更深层发生核聚变触发，能量可在10⁴²erg量级[9]——这为研究中子星外壳深层物理提供了独特窗口。

## 超亮X射线源（ULX）

一些河外、非核区点X射线源的各向同性等效光度超过约10³⁹erg/s；这是经验分类阈值，不是所有黑洞质量共同的爱丁顿上限，被称为**超亮 X 射线源**（Ultra-Luminous X-ray Source，ULX）。其来源长期有争议，目前认为可能是：

- 超爱丁顿吸积的恒星级黑洞（$M \sim 10$–$100\,M_\odot$），超临界流与几何准直可产生较高的各向同性等效光度
- 中等质量黑洞（IMBH，$M \sim 10^2$–$10^4\,M_\odot$）的正常吸积

2014年Bachetti等[11]发现 M82 X-2 是一颗**吸积中子星**（脉冲周期 $1.37$ s），光度却达到 $2 \times 10^{40}$ erg/s，远超中子星爱丁顿光度 $\sim 10^{38}$ erg/s！随后Fürst等2016年在NGC7793P13检测到约0.42秒相干脉冲，推断中子星、等效峰值约10⁴⁰erg/s，并在其自转增长模型中估计约1.5×10¹²G的场。原文不是NGC5907ULX–1的发现报告，也不支持“所有ULX都已证实必须有磁星量级场”。[12]

吸积柱、磁场、辐射输运与准直都可能改变等效光度和临界条件。脉冲证明部分ULX有中子星发动机；没有脉冲则不自动证明黑洞，因为几何、散射和资料灵敏度可使调制难以看见。[11][12]

## 黑洞质量测量：动力学方法

X 射线双星是**精确测量恒星级黑洞质量**的最佳实验室。通过测量伴星的视向速度曲线（径向速度半幅 $K_2$）和轨道周期 $P$，可以得到**质量函数**：

对近圆轨道单线双星，可分开写成：[5]

$$
\begin{aligned}
f&=\frac{PK_2^3}{2\pi G},\\
f&=\frac{M_1\sin^3i}{(1+q)^2},\qquad q=\frac{M_2}{M_1}.
\end{aligned}
$$

有偏心率e时，第一式还乘$(1-e^2)^{3/2}$。K必须追踪供质星质心，P与速度直接给出质量函数；在相应轨道模型内，它是致密天体质量下限。要解出具体质量，还需质量比、倾角及其他资料，不能只由光谱型就声称已经精确测定倾角。[5]

光度曲线中的椭球形变、掩食、旋转展宽和独立距离等提供补充信息；盘污染、照射与星风谱线也带来系统误差。天鹅座X–1的2021年射电视差与光学资料给约21.2±2.2太阳质量，而旧X射线目录的数量及最高质量不能当作所有当前黑洞的上限。[5][13]

X射线双星中常见数至数十太阳质量黑洞，与引力波并合样本的质量范围和选择函数不同；较低质量的本地吸积样本与较重并合源并存。科学上应比较完整的带误差分布，不能只按两个峰值判定形成通道。自旋的外部输入与盘模型另见[[black-hole-spin-measurement|黑洞自旋测量]]。[5][14]

## 为什么这很重要

X 射线双星是极端物理的天然"可重复实验"：同一个系统可以在数年、数十年内反复经历吸积爆发，让天文学家直接追踪吸积状态的演变。它们提供了恒星级黑洞质量和自旋的精确测量，约束了恒星演化和超新星爆发理论，同时揭示了中子星核聚变爆发、吸积-喷流耦合等丰富物理。

HMXB 与 LMXB 的差别追到供质方式和星族年龄，软硬态转换追到盘与冕谁占主导。两套问题叠在同一类天体上，所以它既是星系里年轻恒星形成的示踪，也是老年星族里致密天体的户口册。把所有 X 射线点源都当成同一种双星，会把形成率、寿命和谱态全部读错。

## 跨域连接

- **[[binary-star-evolution|双星演化]]**：供质方式由伴星决定——大质量系统常见恒星风、Be盘及部分洛希瓣供质，低质量系统常见洛希瓣溢流，后者带来更多角动量，才形成典型的薄盘。推论是：两类系统在寿命、所在星族和轨道周期上的差别，追到底是双星演化的差别，而不是致密天体本身的差别。
- **[[磁性与铁磁体|磁滞]]**：亮度上升时系统先停在硬态，下降时更晚才回到硬态，两个临界亮度并不重合，这是一条迟滞环。推论是：状态不只由当前吸积率决定，还依赖走过的路径，所以单值的静态光度阈值不足以描述路径依赖，模型需处理内部结构、历史和时间演化；这一现象至今没有公认解释。
- **[[combustion|燃烧]]**：中子星表面积累的氢与氦达到点火条件后发生失控热核燃烧，与化学里的自加热失控同一个结构：放热速率随温度上升得比散热速率更快。推论是：爆发的复发周期由燃料堆积速率定，而并非每次都达到相同峰值；达到PRE的事件可在组成、红移及各向异性等条件下作经验距离标尺。
- **[[causal-inference-credibility-revolution|识别与因果推断]]**：质量函数只用轨道周期和伴星视向速度振幅，就给出致密天体质量的一条严格不等式，倾角与质量比未知也不影响它。推论是：这类"不完全识别但有界"的结论比点估计稳健得多——若质量函数本身已超过中子星允许的上限，就能排除中子星；天鹅座X–1等系统则仍需倾角与质量比等补充信息，不能把这条充分条件套给所有历史候选体。
- **[[experiments-and-quasi-experiments|实验与准实验]]**：同一个系统会反复爆发，一次爆发就是一次重复实验，同一对象在数年内多次穿越硬态与软态。推论是：这把观测从"只能看一眼"变成同一对象内部的对照，于是可以减少不同天体间差异，却仍需处理吸积历史、几何和隐藏变量，不能仅靠同一对象就唯一归因质量流率——这正是它成为吸积物理标杆的原因。
