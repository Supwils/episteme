# 系外行星宜居性：哪里可能存在生命

## 概述

宜居性（habitability）是天文生物学的核心概念，描述某个天体环境是否具备支持生命存在的基本条件。目前地球是唯一已知的生命存在案例，因此"宜居性"的定义不可避免地以地球生命为参照：**表面液态水能否长期存在**，是遥感搜索常用的可操作指标，但不是一切宜居环境的定义，地下液水也值得研究。这一保守但可操作的定义催生了"**宜居带**"（habitable zone, HZ）的概念——恒星周围一个环形区域，在其中行星接收到的恒星辐射既不太多（水全部蒸发）也不太少（水全部冻结），使液态水原则上可在大气压调节下稳定存在于行星表面。

然而，宜居性远比这个一维判据复杂：大气成分、地质活动、磁场保护、恒星活动、轨道稳定性……每一项因素都可能决定一颗行星的生死。

把宜居性写成清单很容易，把它写成可观测判据却很难。望远镜最先碰到的往往是恒星光谱与行星半径，而不是板块是否在动、内核是否在对流。因此当代讨论常分两层推进：一层用宜居带给出“能量预算上说得通”的候选名单；另一层再用大气、气候与地质模型，问这些候选是否真能把液态水留在表面足够久。名单会很长，真正经得起第二层追问的会短得多。

## 宜居带的理论框架

### 凯斯廷-科普巴劳（Kasting-Kopparapu）宜居带

凯斯廷（James Kasting）1993年建立了宜居带计算的理论框架，科普巴劳（Ravi Kopparapu）于2013年更新了计算（使用更精确的辐射传输模型）：

边界需要注明所用模型与判据。Kasting等1993年给太阳的水损失边界约0.95 AU、最大温室边界约1.67 AU；水损失与失控温室不是同一个阈值。Kopparapu等2013年的更新给出约0.99–1.70 AU的保守区间，后续2014年研究还讨论了行星质量依赖。

“近期金星”和“早期火星”约0.75与1.77 AU是常用乐观经验边界，不表示已经证明金星在某时刻必然有海洋。最大温室外边界涉及额外CO₂的红外增温与短波散射等竞争，不能只归因于CO₂云反射。太阳、行星质量、大气、云与模型版本变化时，边界也会变化；地球位于1 AU，并没有一个与这些假设无关的固定“安全距离”。

### 宜居带的局限性

宜居带计算有几个重要的简化假设：

- 假设行星具有类地球大气（N₂-CO₂-H₂O）
- 允许CO₂丰度随外部条件调整；这是一类长期碳循环动机下的计算方案，不等于每颗候选都已被证明能自动调温
- 经典一维模型未完整处理偏心率、自转与海陆分布等；后续三维模型可纳入部分因素

一颗地球大小的行星位于宜居带并不保证它宜居；一颗位于宜居带外的星球（如木星的卫星欧罗巴）也可能在冰层下拥有液态水洋。

宜居带更像一张能量收据，而不是宜居证书。它回答的是：在给定恒星光度与简化大气假设下，表面温压与水循环是否允许稳定液态水。它不回答大气是否已被剥光、碳循环是否闭合、潮汐热是否把水全部锁进蒸汽或冰壳。把“落在带内”误读成“像地球”，会把统计候选直接升格成生命预期——这是概念上的短路。

## 宜居带的多维复杂性

### 磁场保护

[[earths-magnetic-field|地磁场]]会影响带电粒子的路径，但全球磁场不是保留大气或维持宜居性的充分必要条件。磁场也能引导粒子沿极区进入或参与逃逸；大气厚度、辐射、引力、化学与内部补给都重要。金星没有地球式全球偶极场，却保留厚重大气，已经说明不能把“无磁场”直接等同“大气必被剥光”（Gunell等2018）。

火星失去大气经历了多种逃逸和表面、内部演化过程，不能压成一次磁场消失后的单因果故事。行星发电机还需要合适的导电流体、对流和热演化；不能只按行星质量猜核是否熔融，也不能把目前难以直接测量的磁场宣布为原则上永远不可遥测。

### 潮汐锁定与气候

围绕M型矮星宜居带的行星轨道非常近（如TRAPPIST-1的部分宜居带候选位于几百分之一AU），极可能处于**潮汐锁定**（一面永远朝向恒星）。它会使恒星照射固定在一侧，实际昼夜温差与冷凝范围仍取决于大气和海洋输运；某些模型下水或CO₂可在夜侧冷凝（"气体坍塌"，atmospheric collapse）。数值大气环流模型（GCM）研究显示，对于特定的大气成分和质量，超旋转大气风可以有效传热，使整颗行星保持足以有液态水的温度（Wordsworth et al. 2011；Yang et al. 2013）。但潮汐锁定行星的宜居性仍是活跃争议领域。

争议的焦点常落在云与环流能否改写昼夜温差：白天侧若形成厚云，反射会把有效加热压低，在Yang等2013年的特定慢自转模型中可使宜居带内边界向内移动，允许承受更强辐照；夜晚侧若热量输送不足，挥发物会冻出大气，触发坍塌。同一颗潮汐锁定行星，在不同云反馈与大气质量假设下，可以被模型画成“温和水世界”或“永久冻结的夜面金库”。观测要做的，是用光谱去约束这些假设，而不是在图纸上选一幅喜欢的气候。

### 恒星活动：M型矮星的困境

低质量M矮星的主序寿命很长，但高能辐照随质量、自转与年龄变化，不能给所有宜居带行星套用“比地球高10–100倍”。尤其是漫长的主序前阶段与早期活动，会改变行星的水损失和大气历史；今天看似温和也不保证过去一直如此。

TRAPPIST-1的七颗行星提供了可比较的样本，e、f、g常被列入特定保守宜居带模型。JWST对b和c的测量不利于所检验的厚CO₂或强温室大气模型，仍须按成员、波段、气压与组成说明约束；不能外推成整个系统都没有大气。2025年的e行星研究已分析四次NIRSpec凌星：恒星表面污染显著，数据不支持所检验的富氢原生大气，次生大气是否存在仍未确定（Espinoza等2025）。其他联合观测正在尝试用相邻行星凌星校正恒星污染，但耀斑与分析假设仍是限制（Allen等2025）。

M 矮星宜居研究因此带有双重紧迫感：统计上它们数量巨大、宜居带近、凌星概率高，是 JWST 与下一代极大型望远镜最容易咬住的岩石行星样本；物理上它们又把恒星活动、潮汐锁定与大气逃逸叠在一起，使“宜居”比类日情形更脆弱。TRAPPIST-1 的价值，正在于把这些张力集中到一个可反复观测的系统里。

### 地质活动：碳循环调节器

长期宜居性可能依赖行星维持活跃的地质活动（[[plate-tectonics|板块构造]]、火山作用），因为这是**碳-硅循环**的关键组成：

1. 大气CO₂溶于雨水形成碳酸，侵蚀硅酸盐岩石
2. 碳酸钙沉积于海底
3. 板块俯冲将碳酸盐带入地幔
4. 火山活动将CO₂重新释放入大气

硅酸盐风化与碳埋藏可形成长期负反馈，是解释地球气候的重要机制，但地球也经历过冰封与显著气候变化；年轻太阳弱悖论并不能单独证明某个反馈始终自动生效。板块构造如何在其他行星上运行仍有待约束，停滞盖层等不同地质状态也可能存在碳交换。

若碳循环失灵，宜居带内的行星仍可能滑向两种极端：CO₂ 堆积导致失控温室，或碳被锁进地壳/地幔后气候坠入全球冰封。地球之所以看起来“刚好”，部分原因是负反馈在很长时标上把系统按回液态水窗口。对系外行星而言，须检验具体的碳供给与消耗；地球式板块循环不是全部可设想宜居环境的唯一稳定机制。

## 已知宜居带行星候选

| 行星         | 已知背景与待解问题                                                    |
| ------------ | --------------------------------------------------------------------- |
| TRAPPIST-1 e | 凌星测得半径约0.92倍地球；位于常用保守宜居带，尚未确认次生大气        |
| Kepler-442 b | 凌星半径约1.34倍地球；轨道可列为宜居带候选，表面与大气未知            |
| Proxima b    | 距离约4.24光年；RV确认的行星，最低质量可测，半径尚未由凌星测得        |
| K2-18 b      | 大气分析常用半径约2.6倍地球；具有CH₄、CO₂等线索，海洋与内部结构依模型 |
| GJ 667 C c   | RV行星、质量含倾角退化；没有已测凌星半径，宜居性还取决于大气与演化    |

这些是值得研究的对象，不是已经确认适合生命的名单。将质量—半径模型估计当成直接测得半径，会给“类地”标签制造虚假精度。参数参照NASA系外行星档案对应轨道解；K2-18 b明确采用2023–2025常见大气分析的尺度，不混作档案默认解。

## 超越传统宜居带：地下宜居性

"表面液态水"的宜居标准过于保守。太阳系内已有充分证据支持地表以下的液态水环境：

- **木卫二（Europa）**：多种证据支持地下咸水海洋，深度和体积依内部模型。欧罗巴快船2024年10月已发射，目前仍在航行，计划2030年4月抵达木星开展飞掠，不是已经在欧罗巴现场探测。
- **土卫二（Enceladus）**：海洋、喷流、盐和有机物的证据来自卡西尼多种仪器与多年分析。2017年发表的分子氢研究支持水岩反应与化学能的可能性；2023年E环冰粒磷酸盐分析补充了关键元素线索，均未检测到生命。
- **土卫六（Titan）**：甲烷-乙烷液态湖泊在表面约−179°C的条件下稳定存在，提供了一种基于非水溶剂的生命化学假想环境（NASA的Dragonfly计划不早于2028年发射、2034年末抵达，研究前生物化学与环境）。

类似地，系外岩石行星的"地下洋"可能不需要位于恒星的光学宜居带内，但其可探测性远低于表面宜居行星——因为透射光谱主要采样晨昏圈中足够透光的大气层，通常不能直接读取被云或厚大气遮蔽的地表，更不能穿透冰壳。

地下宜居性把问题从“恒星照得够不够”挪到“内部热与冰壳力学够不够”。潮汐耗散、放射性生热与反照率都可以在远离经典宜居带的地方维持液态水，但这几乎不留下易于远程读取的大气生物标志。天文生物学因此被迫承认一种不对称：最容易被光谱审问的世界，未必是液态水最稳妥的世界。

## 宜居性的多样性：不只是碳基生命？

主流宜居性标准以碳基水溶剂生命为参照，但这并非唯一的理论可能：

**硅基化学**：硅和碳同属第14族，不代表二者在所有溶剂、温度与氧化环境中都能构成相同的生命化学。硅氧化物、键合稳定性和可用反应网络需要具体比较；不能仅由二氧化硅在常温是固体，就推出硅基生命必然需要熔化岩石的温度。目前没有硅基生命被确认。

**替代溶剂**：氨与甲烷等是常见讨论对象，改变溶剂不等于改变碳骨架。纯氨在约一个大气压下的液相温区大致为195–240 K，−33°C接近其常压沸点；压力变化时液相边界也会改变。土卫六地表约94 K的湖泊主要是甲烷、乙烷，并非液氨湖。混合物和压力会改变相图，也会改变溶解性和反应动力学（NIST Chemistry WebBook）。

遥感仪器可以记录预期之外的光谱异常，但把异常解释成生命仍需化学模型。地球生命提供可操作的参照，却也可能带来遗漏；对未知化学保持开放，不能替代对噪声、非生物来源和可检验预测的要求。

## 生物标志气体：大气中的生命信号

生物标志物是可能为生命提供证据的物质或现象，并非定义上“只能由生命产生”的分子。大气源汇与恒星环境决定同一种气体有多大解释力（Meadows等2018；Schwieterman等2018）。

| 候选信号    | 已知生命联系与解释边界                                                                  |
| ----------- | --------------------------------------------------------------------------------------- |
| O₂、O₃      | 地球上与产氧生物圈有关；水光解、氢逃逸和CO₂光化学等可产生非生物氧，臭氧也不独立证明生命 |
| CH₄与O₂组合 | 可约束补给与消耗，但需考虑反应速率、岩石化学和照射环境，不能把热力学不平衡直接等同生命  |
| N₂O         | 地球微生物活动是重要来源；远程可测丰度取决于通量、光化学和仪器条件                      |
| DMS         | 地球上与生物过程有关，但彗星67P已有非生物DMS证据，不能把它当唯一生命分子                |

K2-18 b的DMS/DMDS解释仍受数据处理、分子混淆与大气模型影响，海洋也尚非直接观测事实。JWST对低质量恒星行星的大气研究正取得约束，不代表任意类地大气都能按固定小时数测出；太阳型恒星旁地球类目标更需要未来反射光成像等方法。没有确定的大气，也谈不上确定的生物标志。

**信号真实、分子识别与生物来源是不同推断。** 多次、多个波段的结果可减少部分退化，但重复看到同一吸收不自动排除地质来源。未检出也可能来自云、灵敏度、标志物通量不足或与大气隔离的生物圈，不能直接换算成没有生命。

## 宜居性的时间维度

宜居性不仅是空间问题，也是时间问题：

**早期地球的宜居性悖论**：太阳在主序早期的亮度约为现在的70%，若以现在的大气成分，早期地球的表面温度应该低于冰点——但地质记录表明，太古代存在液态水，并有早期生命记录。这一矛盾被称为**年轻太阳弱悖论**（Faint Young Sun Paradox）。

增强温室气体、云与反照率等是研究中的解释，具体贡献仍需地质和气候模型约束。太阳型恒星在主序上逐渐增亮，可使表面宜居带向外移动；低质量恒星的主序前阶段却可能比后来更亮，不能笼统说年轻恒星都较暗。连续宜居的时长依恒星演化、轨道与气候反馈，没有每颗行星通用的数十亿年窗口。

时间维度还要求把“曾经宜居”与“现在宜居”分开写。一颗行星可能在主序早期拥有液态水，却在后来因恒星增亮、大气逃逸或碳循环停摆而失去表面海洋；反过来，早期冰封世界也可能在恒星演化晚期进入宜居窗口。对观测者，这意味着光谱快照只切开演化轨迹的一个时刻；对理论家，宜居性必须被建模成轨道、恒星光度与气候反馈耦合的时间函数。

## 跨域连接

- **[[太阳系--solar-structure-activity|太阳结构与活动]]**：大气演化取决于随时间累积的高能辐照、耀斑频率与逃逸效率，今天的恒星光谱只是一部分信息。不同质量恒星的主序前演化也不同，不能把太阳由暗变亮的历史照搬到所有M矮星。需要把恒星年龄、活动和行星补给、消耗一起计算，才能解释当前仍有哪些挥发物。
- **[[earths-magnetic-field|地磁场]]**：磁场改变等离子体与大气的相互作用，但也可能引导极区逃逸，是否减少净损失取决于实际结构和环境。遥测困难意味着约束不足，不意味着逻辑上永远不可测。**不能在未知磁场时先判不可宜居，再把有磁场当作大气保证。**
- **[[carbon-cycle|碳循环]]**：硅酸盐风化能够形成温度—CO₂负反馈，但反馈强度依赖降水、岩性、新鲜岩石供给和地质活动。弱太阳下仍有液水是需要解释的证据，不单独证明某个控制回路始终生效。把地球机制用于系外行星时，需检验边界条件，而非默认每个候选都有板块和自动稳压器。
- **[[solutions-and-solubility|溶液与溶解性]]**：替代溶剂会改变相图、介电环境、反应途径和速率；温度降低通常影响动力学，但不同反应并不共享一个统一减速倍数。纯氨常压液相与土卫六表面碳氢湖泊属于不同条件。讨论假想生命，需要把元素骨架、溶剂和能量来源分别说明，不能只换一个名称。
- **[[tardigrade|水熊虫]]**：短期耐受与长期生长繁殖不同，休眠能保存生命个体，却不一定持续改变大气。反过来，即使一个环境有活跃代谢，产物也可能被海洋、冰壳或大气汇吸收。遥感优先找到的是能把特定信号输送到可观测层、且通量足够的生物圈；这不是对全部生命的等灵敏搜索。
