# 宜居带

## 概述

**宜居带**（habitable zone，HZ）是恒星周围的一段轨道范围：在指定的行星大气与气候条件下，表面有可能长期维持液态水。它也被称为“金发姑娘区”（Goldilocks zone），借用童话里“不太热、不太冷”的比喻。但真实边界并不是把一个温度计放到太空里测得的，而是辐射、温室效应和水循环共同作用的模型结果。

液态水是已知地球生命的重要溶剂，这使表面宜居带成为寻找地外生命的实用筛选条件。它既不保证行星有水，也不是一切潜在生命环境的必要条件：冰壳下的海洋可以依靠内部热源存在于带外。金星、地球和火星的对比说明，大气库存、地质演化和恒星历史都参与决定地表环境；仅凭轨道位置，无法把一颗行星判为适居或荒芜。

研究者因此区分三件事：行星接受多少辐照、在什么模型中能够维持表面水、实际有没有这样的环境。宜居带主要回答前两件事，观测大气与地表才逐渐接近第三件事。[1][2]

## 宜居带的计算原理

### Kasting经典模型

Kasting、Whitmire与Reynolds于1993年建立了影响深远的一维辐射—对流模型，研究主序星周围具有类地水和二氧化碳循环条件的行星。对于当今太阳，他们给出的约0.95—1.67 AU区间对应**水损失内边界**与**最大温室外边界**，不能把所有炎热极限合并成一个数。[1][2]

靠近恒星时，水汽增加可增强[[greenhouse-effect|温室效应]]。在湿温室情形下，高层大气含水增多，光解和氢逃逸可逐渐耗水；失控温室则涉及向外热辐射无法平衡吸收能量。两者的阈值和时间尺度不同。原研究中约0.84 AU的失控温室估计与约0.95 AU的水损失边界，描述的不是同一个极限。

远离恒星时，增加CO2通常先加强红外保温，但更高压下的短波散射、凝结等效应会限制继续增温的收益。最大温室边界取决于这些竞争，并不是简单地由“CO2云反光”一项决定。超出它，所设定的CO2—水大气已不足以维持温暖地表；换用其他温室气体或内部热源，结论还须重算。

Kopparapu等2013更新水和CO2吸收数据，在其无云一维设定下，将当今太阳的水损失—最大温室区间估为约0.99—1.70 AU。常用的较乐观区间约0.75—1.77 AU，则借用“近期金星”和“早期火星”的经验限度，不是把湿温室直接改名为乐观边界。2014年的后续研究再考察行星质量等条件，属于另一篇论文。[2][3]

火星今天约1.52 AU的轨道落在某些此类区间内，不代表古火星必然温暖：早期太阳更暗，火星的大气、云和地表水史也不同。引用一个AU范围时，必须同时保留恒星时代、边界定义和大气设定。

### 宜居带与恒星类型的关系

把辐照写成相对地球所收太阳辐照的有效值，轨道距离可表示为：

$$\frac{d}{\mathrm{AU}}=\sqrt{\frac{L/L_\odot}{S_{\rm eff}}}$$

这里$L$是恒星光度，$L_\odot$为太阳光度，$S_{\rm eff}$是某一气候边界所对应的相对辐照。它随恒星有效温度和模型而变，因为不同光谱与大气、水冰的相互作用不同。只有固定$S_{\rm eff}$时，距离才按光度平方根缩放。

下表只是**地球等辐照距离**的算例，均取$S_{\rm eff}=1$，不是各类恒星的完整宜居带边界：

| 示例恒星光度（太阳=1） | 地球等辐照距离（AU） |
| ---------------------- | -------------------- |
| 2.5                    | 约1.58               |
| 1.0                    | 1.00                 |
| 0.17                   | 约0.41               |
| 0.004                  | 约0.063              |

低光度M矮星的表面宜居带因而靠近恒星。这有利于凌星与视向速度探测，却也使潮汐演化、高能辐射和大气保留成为必须研究的条件。[2][4]

## 宜居带的局限与扩展

### 潮汐锁定的挑战

近轨道行星可能演化到同步自转，同一半球长期朝向恒星。达到这种状态的时间取决于轨道、内部耗散、初始自转等，不能统一指定为一亿到十亿年；偏心轨道和自转—轨道共振还会带来其他状态。

同步自转使照明高度不均，但不必然造成昼侧无法生存、夜侧大气全部冻结。大气与海洋可以输送热量，温度分布还依组成、压强、云和自转周期。是否发生大气塌陷，需要比较局地温度与各气体凝结条件，没有适用于所有行星的0.1或1 bar保证线。[4]

Yang等2013的三维气候模拟给出一个有启发性的机制：在其同步自转等设定下，星下点强对流形成厚水云，提高反照率；更强辐照可触发更强的反射反馈。这让部分模型中的内边界移向**更靠近恒星**的位置，即允许更大的入射通量。它是特定模型中的扩展，不保证所有近轨道行星都获得同样保护。[5]

### 恒星活动的威胁

M矮星的耀斑、高能辐射及漫长的主序前演化，可能改变近轨道行星的水和大气库存。结果依恒星质量与年龄、行星引力、初始挥发分、补给和多种逃逸过程而变，不能只按恒星类别给出统一剥蚀年限。[4][6]

磁场会改变粒子进入和逃逸的路径，却不是保留大气的充分或必要条件：极区外流也可能增强。火星失气涉及太阳演化、引力、撞击与地质补给等，不能归结为失去磁场一个原因。[6]

TRAPPIST-1提供了同一超冷矮星下七颗近地球大小行星的比较机会，其中e、f、g常被列入表面宜居带目标。JWST对b、c的热发射及后续相位曲线，已限制若干厚大气模型；这些较内侧成员的结果不能直接外推成e、f、g也没有大气。2026刊印的相位研究仍容许c的部分稀薄、弱温室大气方案。[7]

### 表面宜居带之外——地下液态水

木卫二和土卫二展示了另一类候选环境：在太阳表面宜居带之外，冰壳下海洋可受内部热量维持，其中潮汐耗散是重要能量来源。它们有液态水环境的证据，**还没有获得生命确认**。地下水、可用化学能与岩石—水交换，也不能仅由表面低温判断。

放射性衰变和潮汐加热因此拓宽了研究对象。讨论流浪行星或系外卫星时，还需计算热量能否保留、冰层是否隔热、化学能能否持续供应，而不是把“有内部热源”直接等同于“宜居”。木卫一的强潮汐火山活动也提醒我们，加热过多和加热不足是不同的限制。

## 宜居带行星的观测搜寻

Kepler的长期凌星监测建立了小半径行星的统计样本。筛选宜居带候选时，研究者结合恒星性质、轨道周期和半径；地球相似性指数不是Kepler确认行星或定义宜居带的必要门槛。

**比邻星b**是已确认的近邻行星，距离约4.2光年；候选的是它的宜居环境，而非把行星本身仍称作未确认目标。TRAPPIST-1e、f、g则因近地球大小及辐照条件而受到关注。距离近、位于带内，都不自动意味着可以测到地表温度或存在海洋。

长周期凌星难以反复捕获，且轨道倾角必须合适。TESS通常每个扇区观测约27天，对近邻短周期系统有优势；但周期10—30天不保证能在单个扇区中得到多次凌星，重叠扇区、持续观测区、噪声和后续确认都会影响选择函数。因此观测名单必须与未被发现的同类目标一起考虑，才能估计发生率。

## 宜居带研究的最新进展

Bryson等2021结合Kepler与Gaia，估计有效温度4800—6300 K恒星周围、半径0.5—1.5地球半径行星的发生率。在其保守宜居带定义下，不同探测完整性外推给出的中心值从**每颗恒星0.37颗到0.60颗**；68%可信区间分别为0.16—0.85与0.24—1.50颗。[8]

这些宽区间反映长周期小半径行星样本与完整性修正的困难。发生率是**每颗恒星的平均行星数**，不是“有行星的恒星比例”，更不是有生命的比例。也不能把针对这段恒星温度和半径范围的结果直接乘上银河系全部恒星数。比较M矮星与太阳型星时，应先对齐半径、辐照区间和完备性定义。

后续仪器将补充不同信息。截至2026年10月，ESA把PLATO的发射计划列为**2027年4月**，拟用26台相机观测超过20万颗恒星，结合凌星与**星震学**研究行星和宿主星性质。ESO对ELT的计划区分2029年3月望远镜首次见光与2030年12月科学首次见光，两者不是同一里程碑。HWO则仍在任务概念和关键技术发展中，旨在推进潜在宜居行星的直接成像。这些是项目计划与目标，不能预先保证在指定年份测出某颗行星的大气或生命。[9][10][11]

## 跨域连接

- **[[main-sequence-stars|主序星]]**：太阳型恒星在主序演化中逐渐增亮，使同一定义下的宜居带向外移动。“连续宜居带”取一个明确时间区间内各时刻宜居带的交集，因而通常更窄；这个区间不必覆盖整个主序寿命。M矮星主序前收缩期又可能更亮，因此今天的辐照条件不能代表全部历史。
- **[[greenhouse-effect|温室效应]]**：水汽增加能加强保温，CO2增加则同时改变红外吸收与短波散射。两端边界取决于这些竞争反馈如何影响能量平衡，而非单一的轨道温度。对比两项模型时，先比较气体库存、云和辐射传输设定，才能理解同一距离为何得出不同结果。
- **[[相变|相变]]**：水的稳定相依赖温度与压强，低于三相点压强时没有稳定液相区。把宜居性写成一段距离，隐含固定了压强和大气演化条件；若大气持续逃逸，即便辐照几乎不变，地表水的稳定状态也可能改变。这连接了轨道筛选与实际气候演化。
- **[[dynamical-systems|动力系统]]**：气候的稳定解可以随控制参数变化而消失，也可能有多种稳定状态和滞后。因而升温越过某个阈值，未必沿原路降温就能恢复；具体是否出现分岔，需检查所用模型的能量收支与反馈。宜居带边界是研究这种稳定性的一种工具。
- **[[climate-modeling|气候模型]]**：一维模型不能自行预报三维云分布，三维模拟则需要处理对流、云微物理和输运。Yang等的星下点云反馈，在其设定下把内边界向内推；换一种自转、海洋或云参数化未必相同。云是重要不确定来源之一，而恒星光谱和大气组成也必须共同检验。

## 为什么宜居带如此重要

宜居带把庞大的目标名单转化为可安排观测的问题，却也迫使研究者清楚表达假设：寻找的是表面海洋、地下水，还是一种尚无实证的替代溶剂环境？每次扩展定义，都需要给出能量、物质循环和可观测结果。

**相似性不是宜居概率。** 地球相似性指数（ESI）可将半径、密度、逃逸速度和温度等参数相对地球的差异组合起来：

$$\mathrm{ESI}=\left(\prod_i S_i\right)^{1/n}$$

$$S_i=\left(1-\left|\frac{p_i-p_{i,\oplus}}{p_i+p_{i,\oplus}}\right|\right)^{w_i}$$

这里$S_i$是各参数的相似性分量；$p_i$为选用参数，$p_{i,\oplus}$为地球参照值，$w_i$为权重，$n$为参数个数。这是采用多项物理量的一种形式；实际系外行星目录还会采用辐照与半径等较有限的版本。指标数值依输入与权重，地表温度又常无法直接观测。高分只表示在选定参数上相似，不是有水或生命的概率；“大于0.8”等门槛是指标约定，不能替代物理判断。[12]

**空间与时间的扩展同样依赖模型。** Lineweaver等2004把重元素、超新星风险与演化时间等假设放入银河化学演化模型，得到约7—9 kpc的“星系宜居带”。这是该模型的结果，不能当作已测出的生命分布。银心内侧通常重元素更丰富、环境风险也不同，并不是因为普遍缺乏重元素；太阳附近的条件也不足以证明本区生命概率最高。[13]

Loeb等2016进一步讨论宇宙未来的生命机会。在其假定下，若极低质量恒星周围的宜居性没有受到强烈抑制，约0.1太阳质量恒星的漫长寿命可使机会延至约十万亿年尺度。这既不是所有低于0.5太阳质量恒星都活一万亿年，也不是对未来生命数量的观测预测。地球的演化历史只有一个样本，不能将复杂生命出现的时间当作普适生物时钟。[14]

完整评估还需把行星引力、挥发分、地质补给、大气损失与气候稳定性联合起来。没有一个通用的0.1地球质量门槛、磁场要求或生命起源年限，能代替这些计算。宜居带最有用的地方，正是让“值得进一步观测”成为可解释的选择，同时把“实际适居”留给更多证据。
