# 宇宙再电离

## 概述

2001年，Becker等研究SDSS发现、红移6.28的[[活动星系核与类星体|类星体]]，在其莱曼α发射线蓝侧测到几乎无透射的吸收区。这道**古恩—彼得森黑槽**显示沿途星系际中性氢产生了很强的共振吸收。它是早期气体状态的重要线索，但少量中性氢就足以使该谱线饱和，黑槽本身不能证明当时大部分氢仍中性。[1]

**宇宙再电离**是早期光源逐渐将弥散中性氢重新电离的过程。恒星与星系形成后，电离区在数亿年中成长、重叠，宇宙第一十亿年左右的气体状态发生深刻改变。它不是所有波段一起由黑转亮：中性气体对电离紫外线及莱曼共振线很不透明，却仍允许许多更长波长的连续谱传播。黑暗时代在首批光源点亮时已开始结束，再电离则在其后继续推进。[2][3]

再电离不是一张同时按下的开关。电离先在星系周围打出气泡，气泡长大、重叠，中性氢退成残余的岛；古恩-彼得森槽特别敏感于较晚阶段的残余中性氢，[[宇宙微波背景]]的光学深度 τ 抓住的是电子柱密度的积分。两者问的不是同一个问题，也不该被拧成同一个精确的结束红移。

## 物理过程

### 电离泡的成长

再电离并非均匀地在宇宙中同时发生，在许多模型中，大尺度上先从有较多光源的过密区推进；局部致密、自屏蔽气团却可能比周围稀薄气体更晚电离。[3]

过程大致如下：

1. 第一代大质量恒星和星系形成，发出强烈紫外辐射（特别是能量超过13.6 eV的莱曼连续谱光子）
2. 紫外光子在周围形成 **HII 区**（斯特龙根球，Strömgren sphere），内部氢气高度电离，仍有少量由复合维持的中性成分
3. 随着电离光子数量增加，HII 区不断扩展，最终相邻的电离气泡开始合并
4. 当电离气泡填充宇宙体积的大部分，中性氢所剩极少，电离辐射的平均自由程逐渐增加；致密吸收体和残余中性岛仍会影响“完成”的具体定义

经典斯特龙根球描述静态、均匀气体中光子产生与复合平衡的半径。实际宇宙还在膨胀，光源随时间变化，电离前沿的推进并不始终处在平衡。复合率约随电子和离子数密度的乘积增长，所以高密度气团能反复消耗光子，甚至自屏蔽。大尺度的“由内而外”和局部致密气团较晚电离可以同时发生。[3]

相邻气泡开始重叠，电离区从「许多孤岛」变成「互相连通的海洋」，中性氢退成残余的岛。这个重叠阶段在模拟里往往只占再电离史的一小段，却最难用单一红移来标记。

平均电离度达到一半与残余中性岛消失，是两种不同的时刻。CMB给出整段自由电子历史的积分，类星体吸收则对局部中性气体和电离背景敏感。只有先规定电离史参数化、平均方式和完成阈值，才能把不同探针转换为可比较的年代。

### 电离光子需求

完成再电离所需的电离光子数量约等于宇宙中氢原子的总数（加上复合后再次被电离所需的额外光子，即"复合修正"）。光子守恒给出：

$$N_{ion} = N_{H} \cdot (1 + \bar{n}_{rec})$$

其中 $N_H$ 是所考虑共动区域的氢核总数，$\bar{n}_{rec}$ 是平均复合次数（取决于介质的密度不均匀性"团块因子" $C = \langle n^2 \rangle / \langle n \rangle^2$）。团块因子的有效值依赖温度、所计密度范围和自屏蔽处理；它会影响维持电离所需的额外光子预算。[3]

从恒星产量换算为进入星系际介质的光子数，还要乘上逃逸比例：恒星真正制造的电离光子，只有一部分漏出母星系。$f_{esc}$ 低，就要更多星系才能凑齐 $N_{ion}$；团块因子高，已经漏出来的光子又被复合吃掉。电离气泡长得快还是慢，是这两项在抢。逃逸比例、微弱星系数目、恒星谱与复合率的误差，都可能改变推断的电离进程。

电离区逐渐连通后，光子的平均自由程通常增长，但致密吸收体仍可限制它，增长速度也依赖源和气体演化。CMB的τ仍会对同样多电子出现在更早还是更晚有所响应；只是一个积分值不能唯一恢复整条历史，不同的起点、持续时间和形状可以给出相近的τ。[2][3]

类星体“近区”提供另一种局部信息：它是光谱透射超过选定阈值的一段区域，不一定等于类星体电离前沿的半径。类星体寿命、光度、周围密度、温度与电离背景都能影响它；即使介质已高度电离，残余中性氢也可使透射很快下降。将近区与全球电离分数联系，因而需要辐射输运和环境模型。

## 观测证据

### 古恩-彼得森效应

1965年Gunn与Peterson讨论了星系际中性氢的吸收检验：类星体连续谱中的光子，在传播时红移到沿途氢的莱曼α共振频率，便会被散射出原视线。不同波长对应不同吸收红移，从而在源莱曼α线蓝侧形成吸收区。即使中性分数很小，也可能使谱段几乎不透光。[1]

Becker等在SDSS J1030+0524的吸收红移5.95–6.16范围测得相对透射通量 $0.0038\pm0.0026$，与零相容。莱曼β吸收因振子强度较弱，可用于推得**换算到莱曼α的有效光学深度**下限 $\tau_{\rm eff}>20$；这个数字不是莱曼β自身的光深。[1] 原论文也明确提醒，黑槽单独不能判定光源位于再电离完成以前。

光子平均自由程对中性氢分数极为灵敏——即使 $x_{HI} \sim 10^{-4}$ 也足以让莱曼-$\alpha$ 光子光深 $\tau_{GP} \gg 1$，导致完全吸收。黑槽出现，并不等于此时中性氢分数接近 1。莱曼-α 在 $x_{HI}\sim 10^{-4}$ 就已经饱和，它只能告诉你「中性氢还没有低到可以透光」，不能单独告诉你再电离进行到了百分之几。

后续类星体视线显示不同方向有明显的透射与暗区差异；它们可来自电离背景、密度、温度与中性岛的共同变化，必须通过模型分离。[[莱曼alpha森林]]在更低红移变成由离散吸收线组成的森林，是再电离完成之后介质变稀、变透的延续。

### CMB 光学深度

自由电子会再次散射CMB光子，并在大尺度产生额外E模偏振。Planck 2018的TT、TE、EE+lowE+lensing平坦ΛCDM分析给出 $\tau=0.0544\pm0.0073$。在其简单tanh电离史参数化下，中点推为：[2]

$$z_{\rm re}=7.67\pm0.73.$$

这对应年龄约七亿年，但并不是与电离史无关的直接测时。模型还假设氢和氦的第一次电离同步，并对更晚的氦第二次电离另作处理。更宽或更复杂的电离史，可以在相近积分光深下有不同起点与尾部。

τ与原初扰动振幅 $A_s$ 还有简并：较小尺度的原初温度各向异性角功率幅度大致受 $A_se^{-2\tau}$ 控制。大尺度偏振帮助拆开两者。[2] 这解释了为什么精确测量τ很重要，也解释了为何只凭一个τ不能画出所有气泡的成长和连通时间。

### 莱曼-alpha 星系（LAE）

莱曼-$\alpha$ 发射线（Ly$\alpha$，波长 121.6 nm）是高红移星系常用的强发射线之一。但在再电离未完成时，星系周围的中性气体会将 Ly$\alpha$ 光子强烈散射，使到达观察者的线通量降低或谱形改变。因此，Lyα发射体的可见比例及光度函数随红移变化，是再电离时代的重要示踪剂。

它测的是星系附近残留中性氢的散射，而不是全宇宙的平均电离度。一个坐在大气泡内部的星系，即使全球平均中性分数还不低，莱曼-α 也可以逃出来；反过来，一条穿过中性岛的视线可以把一个本来明亮的发射线藏住。LAE 的下降因此是气泡拓扑的探针，和古恩-彼得森槽、CMB τ 一起用，才能把「中点」和「收尾」分开看。[[21cm宇宙学与再电离]]希望直接画出这些气泡的三维地图；这需要克服前景、仪器标定与灵敏度等挑战。[3]

## JWST 时代的新发现

詹姆斯·韦伯空间望远镜自 2022 年开始运行以来，对再电离时代研究产生了革命性影响：

- **高红移星系样本增长**：JWST发现许多高红移亮星系，使光度函数及恒星形成效率受到新约束。星系是否提供足够电离光子，还要结合其谱、数量、微弱端外推和逃逸比例。
- **早期光源的光谱证据**：JADES-GS-z14-0的2024年NIRSpec红移约14.32，后续ALMA谱线将它精确到 $14.1793\pm0.0007$。[5] MoM-z14在2025年预印本中报告、2026年发表，光谱红移 $14.44\pm0.02$，对应热宇宙年龄约2.8亿年。[6] 这些是有版本与测量方法的结果，不能将所有候选或旧纪录并列为当前最高值。
- **间接估计逃逸比例**：在红移6–9，中性星系际气体使莱曼连续谱难以直接观测。研究者利用发射线、紫外谱斜率、恒星与气体模型等间接推断 $f_{\rm esc}$；Choustikov等用辐射流体模拟校准这些指标，并讨论其散布与适用条件。[4]

更早的星系证明再电离光源有很早的前身，却不直接给出全球中性分数。少数明亮天体可能处在较大的电离区，也可能在总光子预算中不占主导。要从新样本重建电离史，还需了解更微弱星系、恒星谱的硬度、光子的逃逸和气体复合。

逃逸比例描述离开母星系进入星系际介质的电离光子份额，随方向、恒星年龄、反馈、气体和尘埃几何而变。高红移JWST光谱提供相关物理量，转换到逃逸比例时仍依赖校准或模拟。观测到非电离紫外线，并不等于直接截获了原本在莱曼极限以下的漏出光子。[4]

> **两种不同的透明度变化**：约38万年时[[复合时期与最后散射面|复合]]降低自由电子密度，使CMB的汤姆逊散射大幅减少；后来的再电离则减少中性氢对电离紫外线和莱曼线的吸收。中性宇宙并不挡住所有可见光。黑暗时代主要指尚无大量恒星光源的时期，随最初光源出现而结束，早于全球再电离完成。

早期亮星系样本对恒星形成、尘埃、星族年龄和反馈模型提出新要求，但不能只由“比某套模型亮”推断ΛCDM失效。宇宙背景与成星处方不是同一层假设。电离史还要同时满足CMB、类星体及星系统计，而不是用单个红移纪录替换它们。

## 再电离的电离源

谁主导了再电离？这是宇宙学的核心问题之一。候选电离源：

| 电离源               | 优点                           | 挑战                     |
| -------------------- | ------------------------------ | ------------------------ |
| 星系（低光度矮星系） | 数量众多，紫外辐射丰富         | 莱曼极限逃逸比例不确定   |
| 类星体（AGN）        | 高能光子丰富                   | $z > 6$ 时类星体数量稀少 |
| Population III 恒星  | 极端紫外辐射，单个离子化功率强 | 质量、寿命不确定         |

低光度成星星系是氢再电离的重要候选主力，联合光度函数与CMB的模型已有相当支持。[7] 其份额仍受微弱端、恒星谱和逃逸比例限制；早期AGN贡献也在研究。较低红移的类星体对氦第二次电离尤其重要，这与“氢在红移6以下全由类星体维持”是不同命题。JWST的间接逃逸指标需要与其他观测共同使用。[4]

## 再电离时代的时间线

| 阶段                   | 大致时期与证据性质                                                     |
| ---------------------- | ---------------------------------------------------------------------- |
| 首批恒星形成           | 常见模型放在最初约一两亿年，确切年代和质量分布尚待确认                 |
| 很早的星系与局部电离区 | JWST已取得不足三亿年时星系的光谱；局部气泡不等于全球已电离             |
| 电离史中段             | Planck的简单tanh模型给出中点红移约7.7，依赖参数化                      |
| 较晚阶段               | 红移约6及以下的类星体、莱曼α统计等约束残余中性岛、平均自由程和电离背景 |

这些阶段有重叠，不能用一个固定中性分数阈值把它们压成四个已直接测准的时刻。不同“完成”定义，以及体积加权、质量加权和视线选择，都会影响比较。[1][2][3]

## 跨域连接

- **[[活动星系核与类星体|活动星系核与类星体]]**：类星体既可产生电离光子，也是照亮沿途气体的背景灯。黑槽对少量中性氢就会饱和，所以不能只凭吸收为零确定全球再电离完成的时刻；近区和阻尼翼还需气体、源寿命及环境模型。候选电离源的贡献，则要另算数量、光谱和光子预算。
- **[[photochemistry|光化学]]**：电离与复合不断竞争，静态平衡只是其中一种极限。复合率依赖电子与离子密度的乘积，局部致密、自屏蔽气体会消耗更多光子。因而大尺度光源过密区先电离，与小尺度气团比周围稀薄气体更晚电离并不矛盾；平均团块因子只是把复杂结构压成预算参数的一种近似。
- **[[monte-carlo-methods|蒙特卡洛方法]]**：辐射输运可采用随机光子包，也可采用射线追踪或矩方程等方法。独立抽样的统计误差通常随样本数平方根减小，但空间网格、频率离散、角分辨率、光源和反馈处方仍会产生其他误差。比较代码与做收敛试验，才有助于判断气泡的形状和连通尺度是否可靠。
- **[[plasma-physics|等离子体物理]]**：光电离会加热气体，改变电子密度、复合率和冷却过程。温度并非宇宙处处固定的一万开尔文，而依赖电离谱、发生时间、密度与后续膨胀。莱曼α共振、莱曼连续谱和汤姆逊散射各有不同截面及频率依赖，某条谱线不透光不等于所有波段都不透明。
- **[[great-oxidation-event|大氧化事件]]**：两者的定时方法同构：都不直接看到那批"生产者"，而是读介质被改变后的状态——一边是沉积岩的氧化还原指标，一边是中性氢的吸收深度。**这类间接定时的共同弱点是空间不均匀性会被平均掉。**

## 为什么这很重要

再电离记录了早期光源如何反过来改变周围介质。它之前并非所有可见光都无法传播：中性氢主要阻挡电离紫外线及相应共振波段，许多红侧连续谱仍可穿行。这也正是今天能用红移后的红外光谱研究非常早期星系的原因。研究电离、加热与反馈，则帮助理解光源和星系际气体如何共同演化。

电离气泡的重叠拓扑，是这场相变留下的空间指纹；古恩-彼得森槽和 CMB τ 从两端夹住它，却都给不出一张三维图。JWST光谱和低频射电观测将从不同角度缩小它的允许范围。

把再电离写成「某一个红移的开关」，会丢失气泡拓扑和不同探针的响应差异。更稳妥的叙事是一段持续数亿年的相变：先有孤岛，再有连通，最后中性残余被清掉；中点、光学收尾和光子预算分别由不同观测钉住，彼此可以错开，却不该被合成一个伪精确的结束年。
