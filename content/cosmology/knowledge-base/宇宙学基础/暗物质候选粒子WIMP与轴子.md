# 暗物质候选粒子：WIMP 与轴子

## 概述

宇宙中约 27% 的能量密度（Planck 2018：$\Omega_c h^2 = 0.1200 \pm 0.0012$）在平坦ΛCDM拟合中归于冷暗物质。它没有可比普通物质的发光与电磁相互作用信号，具体耦合大小仍待实验检验[1]，但其引力效应在星系旋转曲线、[[引力透镜]]、CMB 功率谱和[[宇宙大尺度结构|大尺度结构]]中都有明确观测。

然而，暗物质的粒子本质至今未知。在众多候选粒子中，**弱相互作用大质量粒子（WIMP）**和**轴子（axion）**是理论动机最充分、实验探索最广泛的两类。

两者的理论入口完全不同：WIMP 从热宇宙的冻结丰度出发，把弱尺度与观测密度绑在一起；轴子从强相互作用的 CP 问题出发，把极轻玻色子与冷暗物质的非热产生绑在一起。轴子原本为强CP问题而提出，一些WIMP模型也来自超对称或额外维度等更广泛理论；另一方面，WIMP本身也是按暗物质的产生与相互作用性质定义的一大类候选者。这也是为什么实验界愿意为它们投入吨级液氙与微腔扫频这类几十年工程。

## 破除误解：找了四十年没找到，不等于"暗物质不存在"

"实验一次次落空"常被读成"暗物质这个概念要塌了"。这个推论跳过了一个关键区分。

**暗物质的存在证据与它是什么粒子，是两个独立问题。** 前者的证据来自至少五类方法不同且可能共享部分理论输入的观测：星系旋转曲线在远离中心处仍然平坦、星系团的[[引力透镜]]质量远超发光物质、[[宇宙微波背景|CMB]] 声学峰的相对高度、[[宇宙大尺度结构]]的形成时标、以及[[大爆炸理论|太初核合成]]给出的重子总量上限。这些证据无需先指定WIMP或轴子，但解释仍依赖引力、结构形成与重子物理模型。标准引力下，它们共同支持额外的非重子物质；这种物质能够聚集成暗晕，并非“不成团块”。[1][2]

落空的是后者：**具体的候选粒子**。四十年来实验排除的，是"WIMP 在某个质量-截面区间"这样的方格。方格一个个被涂黑，格子外面还有大片空白。

这带来一个反直觉但重要的结论：**排除本身是进展**。LZ、XENONnT等已覆盖许多曾受关注的散射模型区域，也推动实验探索轴子、惰性中微子和更轻暗物质。原初黑洞则提供不依赖新粒子的路线。不同研究方向有各自独立的动机，优先次序也随实际数据调整。

热冻结的动机仍值得检验，但“弱尺度恰给合适丰度”并不唯一决定核子散射截面、粒子质量或对撞机产生率。不同中介、共湮灭和共振机制可以同时改变这些量。实验已排除许多曾受重视的具体模型区域，还不能由一类零结果推出所有热遗迹、或整个WIMP思路已经失效。[2][3]

还要分清另一层：排除“某质量—截面方格”不等于排除一切弱耦合粒子。自旋相关散射、非弹性散射、速度依赖截面、或主要与电子而非核子耦合的轻暗物质，都会落在液氙核反冲搜索的盲区之外。轴子路线则根本不靠核反冲——它靠相干场与光子的微弱转换。因此“WIMP 窗口收窄”与“暗物质仍在”可以同时为真；真正改变的是优先排序与实验设计语言。

## 现场：在地下一千米数几个光子

直接探测实验的日常，是一件近乎荒谬的事：**在几乎完全隔绝的环境里，等一个可能一年都不来的信号。**以美国南达科他州废弃金矿中的 LUX-ZEPLIN（LZ）为例，它把液氙放在地下约 1.5 公里深处。为什么这么深？因为地表宇宙线缪子每秒每平方米就有约 100 个，其引发的粒子簇射和中子可能构成严重本底；一千多米岩石能把它衰减几个数量级。

然后是内层的层层设防：氙必须提纯到氪含量低于万亿分之一（$^{85}$Kr 的放射性会伪装成信号）；探测器材料本身要筛选低放射性批次，连不锈钢螺栓都测过本底；氙罐外围还套一层液氙作"自屏蔽"，只把最内部区域算作有效体积。而期待的信号是什么？一个暗物质粒子撞上一个氙核，让它反冲几个keV的能量。微弱的闪烁光和电离电子还要经历光收集、漂移与放大，最后记录的光电子数不等于最初产生的光子数。[3]整个大型装置与长期运行，就为了把这几十个光子从本底里认出来。

双相液氙探测器还要在同一事件里读出闪烁光（S1）与漂移后的电离信号（S2）：核反冲与电子反冲在 S2/S1 比值上分开，才能把 γ、β 本底从候选信号里抠掉。标定靠中子源与已知放射性；分析靠盲目区、边带与系统误差表。一年曝光里若只剩个位数候选，统计结论往往是“与本底相容”，而不是“看见了暗物质”。

这就是"没找到"的真实分量：**它不是没认真找，是找到了这种程度还没有**。

## WIMP：最受关注的候选者

### 什么是 WIMP

弱相互作用大质量粒子（Weakly Interacting Massive Particle，WIMP）是一类质量在 $1$-$1000$ GeV 量级、与标准模型粒子仅通过弱相互作用（或类弱强度的力）耦合的粒子。WIMP 之所以成为最受关注的候选者，是因为"WIMP 奇迹"（WIMP Miracle）：

- 假设 WIMP 在早期宇宙中热平衡产生，当宇宙冷却到 $T \sim m_\chi / 20$（$m_\chi$ 是 WIMP 质量）时，湮灭速率低于膨胀速率，粒子数目"冻结"
- 在通常辐射主导、近似s波湮灭等条件下，丰度可粗写为：

$$\Omega_\chi h^2\sim0.1\frac{3\times10^{-26}\,\mathrm{cm^3s^{-1}}}{\langle\sigma v\rangle}.$$

数值随自由度、质量与反应过程改变。

- 对于弱相互作用强度（$<\sigma v> \sim 3 \times 10^{-26}$ cm$^3$/s，在一些弱尺度模型中自然出现，并不唯一对应100 GeV质量），冻结丰度可在适当模型中给出 $\Omega_\chi h^2 \approx 0.1$，与观测值高度吻合

这种数量级联系被称为WIMP奇迹，适合作为模型动机，不能当成粒子已被预言到一个坐标上的证据。超对称模型中，**若R宇称守恒且最轻超伴侣电中性、寿命足够长**，最轻中性伴随子（neutralino）可成为候选者。它是中性gaugino和higgsino的混合态，与中微子（neutrino）不是同一种粒子，质量和丰度也不由超对称概念本身唯一确定。[2]

### WIMP 的探测策略

三类互补的探测方法：

**直接探测（Direct Detection）**：在深地下实验室用高灵敏探测器等待 WIMP 与原子核碰撞产生的核反冲。当前最灵敏实验：

- LZ的4.2吨年最终发表版（2025，v3）在40 GeV/c²给出自旋无关WIMP—核子截面 **2.2×10⁻⁴⁸ cm²（90%置信上限）**，未见显著WIMP超出。[4]
- XENONnT与PandaX-4T等提供不同靶质量、阈值、曝光与分析条件下的互补结果；比较上限应同时声明质量、相互作用模型和置信度。

这些核反冲上限需要假设本地晕密度、速度分布与耦合方式。自旋相关、非弹性或主要电子耦合的搜索需要各自分析，不能从一张自旋无关排除图中直接读出。[3]

**间接探测（Indirect Detection）**：寻找 WIMP 相互湮灭产生的高能粒子（$\gamma$ 射线、正电子、反质子、中微子）：

- Fermi-LAT 在银河系中心和矮椭球星系方向寻找 $\gamma$ 射线超出
- AMS-02 在国际空间站测量宇宙线正电子谱（2013年公布精密正电子比例测量，早先PAMELA已报告上升趋势；脉冲星是竞争解释）

**对撞机产生（Collider Production）**：在大型强子对撞机（LHC）等加速器中尝试直接产生 WIMP（表现为"丢失横动量"信号）：

- LHC 的单喷流+丢失横动量搜寻对 WIMP 的耦合强度给出约束
- 目前未发现超对称粒子（在LHC Run1+2中，对某些带电/中性电弱超伴侣产生与衰变简化模型的限制达到TeV量级，但对最轻neutralino没有统一的1 TeV下限；压缩谱、混合成分和衰变通道会显著改变约束）

间接探测的难点在于天体物理前景：银河系中心的 γ 超出可被脉冲星或宇宙线传播模型解释；矮星系信号更干净但光子更少。对撞机则给出“产生截面”的上限，而非直接证明湮灭或散射截面——模型依赖强，简化模型与完整超对称谱之间不能一一对照。

**当前状态**：核反冲、间接与对撞机搜索仍无普遍接受的WIMP发现。XENON、LZ与DARWIN团队已联合推进XLZD，2025设计书的基准为60吨活性液氙靶，供应允许时可扩大至80吨。这是设计质量，不是已取得曝光；其灵敏度目标仍取决于建设、运行、本底与模型。中微子相干散射形成“雾”，会使某些质量和截面下的信号辨认更困难，却不是无法以更多统计、不同靶材或方向信息继续推进的硬下限。[5][6]

## 轴子：强 CP 问题的优雅解

### 强 CP 问题

[[quantum-chromodynamics|量子色动力学]]（QCD，描述强相互作用）的拉格朗日量含有一个参数 $\bar{\theta}$，它控制 CP 破缺（电荷-宇称对称性破缺）的强度。理论允许 $\bar{\theta}$ 取 $0$ 到 $2\pi$ 之间的任意值，但实验测量中子电偶极矩给出上限：

$$|\bar\theta|\lesssim10^{-10}$$

为什么 $\bar{\theta}$ 如此接近于零而非某个自然量级（约 1）？这是粒子物理中的"强 CP 问题"。

### Peccei-Quinn 机制与轴子

1977 年，佩斯奇（Roberto Peccei）和奎因（Helen Quinn）提出引入一个新的全局对称性 U(1)$_{PQ}$，该对称性在某个能量尺度 $f_a$（Peccei-Quinn 尺度）自发破缺。破缺产生的轻赝Nambu–Goldstone玻色子即**轴子**，QCD非微扰效应为其生成势能，并把有效真空角的最小值移向 $\bar{\theta} = 0$ 处，自然地解释了强 CP 问题。

轴子的质量由 QCD 非微扰效应决定：

$$m_a\simeq5.7\,\mu\mathrm{eV}\left(\frac{10^{12}\,\mathrm{GeV}}{f_a}\right).$$

这一QCD轴子的质量—破缺尺度关系比某个“允许质量窗口”更稳固。恒星冷却、超新星、宇宙丰度与等曲率约束仍依赖耦合模型、初始错位角，以及PQ对称性是在暴胀前还是暴胀后破缺。常见的微电子伏到毫电子伏范围是重要搜索区间，不能写成所有轴子的普适上下界。[7]

### 轴子作为暗物质

早期宇宙中，轴子场偏离其 CP 守恒的最小值（"错位角" $\theta_i$），随后在宇宙冷却时发生相干振荡，产生轴子的非热丰度（"错位机制"，Misalignment Mechanism）：

$$\Omega_a h^2\sim0.1\,\theta_i^2\left(\frac{f_a}{10^{12}\,\mathrm{GeV}}\right)^{7/6}.$$

这里仅是小错位角、特定温度依赖近似下的量级式，非谐效应、QCD温变质量与拓扑缺陷可改变结果。对于 $f_a \sim 10^{12}$ GeV 和 $\theta_i \sim 1$，可得到 $\Omega_a h^2 \sim 0.1$，与观测值吻合。这是轴子暗物质的另一个"奇迹"。轴子的关键特性：极轻（$\mu$eV 量级）、非热产生（冷暗物质）、与光子有微弱耦合（通过 Primakoff 过程：轴子在强磁场中转化为光子）。

KSVZ与DFSZ是常用基准族：前者通常通过额外重带色费米子实现PQ机制，后者在标准模型费米子与扩展希格斯扇区中实现。常见基准的电磁/色反常比为 $E/N=0$ 与 $8/3$，但KSVZ扩展也可有其他比值，不能仅用“与夸克耦合”区分。若PQ在暴胀后破缺，弦和畴壁的演化还可能增加丰度；其贡献与畴壁数、网络动力学有关。[7]

### 轴子探测实验

轴子—光子耦合可写成：

$$\begin{aligned}g_{a\gamma\gamma}&=\frac{\alpha}{2\pi f_a}\,C_\gamma,\\C_\gamma&\simeq\frac EN-1.92.\end{aligned}$$

第二项来自低能QCD贡献，$E/N$取决于模型。耦合大小和质量共同决定实验灵敏度，单列质量覆盖并不等于排除该质量的一切轴子。[7]

| 实验                   | 原理                                   | 状态                                                               |
| ---------------------- | -------------------------------------- | ------------------------------------------------------------------ |
| ADMX（轴子暗物质实验） | 微腔谐振器 + 强磁场，轴子→光子共振转换 | 扫描特定质量区间，比较指定本地丰度下的KSVZ/DFSZ基准                |
| HAYSTAC                | 共振腔与量子测量技术                   | 检验指定频段的质量—耦合区域                                        |
| ABRACADABRA            | 感应拾取轴子振荡磁场                   | 探索较低质量场的耦合                                               |
| CASPEr                 | NMR（核磁共振）探测                    | 针对超轻轴子                                                       |
| IAXO（国际轴子天文台） | 太阳轴子转化为 X 射线                  | 面向太阳轴子的下一代设计，原型与完整装置须区分；目标灵敏度依赖设计 |

腔体实验的工程核心是：在数特斯拉磁场中让谐振频率跟踪 $m_a$，同时把噪声压到接近量子极限；每换一个频点都要重新积分，假阳性期望随扫过的独立带宽成倍增加，发现阈值因此必须严于单点搜索。太阳轴子路径（CAST、未来的 IAXO）不依赖本地晕密度，而是把日核中产生的轴子在实验室磁体里转成 X 射线，对 $g_{a\gamma}$ 给出与晕搜索互补的约束。

更宽频段的腔体、介质或等离子体共振方案，以及低质量场探测方法，正在探索不同的质量—耦合区域。它们的“覆盖”都依赖假设的本地轴子丰度与基准模型，尚不能承诺在某一年代全面扫空QCD轴子。太阳轴子天文台则检验太阳产生过程，不要求轴子组成全部暗物质。[7]

## 其他候选粒子概览

WIMP 与轴子之外，冷/温暗物质菜单仍然很长。惰性中微子若在 keV 量级，可通过 X 射线单色线被间接约束；原初黑洞则根本不是新粒子，而是早期宇宙密度涨落坍缩的遗迹，受微透镜、动力学摩擦与吸积辐射等多通道限制。超轻轴子或模糊暗物质把德布罗意波长拉到千秒差距尺度，试图同时解释小尺度结构问题——其动机与经典 μeV 轴子相关但实验手段不同。下表只作对照，细节各有专文。

| 候选粒子            | 质量范围                            | 主要特征                                                 |
| ------------------- | ----------------------------------- | -------------------------------------------------------- |
| WIMP（neutralino）  | $10$-$1000$ GeV                     | 热丰度，弱耦合                                           |
| 轴子                | $\mu$eV-meV                         | 非热丰度，极轻，强 CP 问题                               |
| 惰性中微子暗物质    | 常讨论keV尺度；更重方案另需产生机制 | 是否冷/温依赖动量分布，辐射衰变可受X射线限制             |
| 原初黑洞            | 可有很宽质量谱                      | 非新粒子；是否能占全部暗物质取决于质量函数及多类观测约束 |
| 超轻轴子/模糊暗物质 | $\sim 10^{-22}$ eV                  | 量子压力抑制小尺度结构                                   |

## 为什么这很重要

暗物质是宇宙中最大的已知"未解问题"之一——我们知道它存在（引力效应受到多类观测支持），但不知道它是什么。发现暗物质的粒子本质将是粒子物理和宇宙学的革命性突破，不仅解答关于宇宙组成的基本问题，还可能揭示标准模型之外的新物理。WIMP 奇迹和轴子对强 CP 问题的优雅解决，使这两类候选粒子成为最有理论依据的方向，而即将到来的新一代实验将继续检验两类候选者的重要参数区域，发现与排除的范围仍由实际灵敏度决定。

每条零结果都有明确适用范围。液氙对某些核子散射模型越来越敏感，共振腔则在假定本地轴子密度下扫描质量与光子耦合。把实际排除区域与理论的相关参数一起画出，才能判断某个模型是否仍成立；两个常用基准未被发现，也不会自动抹去全部WIMP或QCD轴子的可能。

## 跨域连接

- **[[dark-matter-direct-detection|暗物质直接探测]]**：两条路线在探测原理上就分开了。**液氙看的是核反冲能量，只有几个千电子伏、几十个光子，对质量在吉电子伏以上的候选者最灵**；常见QCD轴子质量太低，不适合相同的核反冲搜索；共振腔利用磁场中的相干光子转换，另有自旋进动与其他场耦合路线。
- **[[quantum-chromodynamics|量子色动力学]]**：轴子不是为暗物质发明的，它是强 CP 问题的解——那个本可任意取值的参数被中子电偶极矩的实验压得极小，佩斯奇-奎因机制让势能最小值自动落在零。**质量由非微扰效应给定、与破缺尺度成反比**，暗物质候选只是副产品。理论动机来自别处，这正是它比纯粹拟合而来的候选者更有分量的原因。
- **[[noble-gases|稀有气体]]**：液氙当靶材是化学性质选出来的：惰性、原子序数高、可液化并自屏蔽。**代价是同族的放射性氪必须压到万亿分之一以下**，否则它的衰变会伪装成信号——纯化指标本身就是灵敏度的一部分。
- **[[signal-processing|信号处理]]**：共振腔搜索须逐步调谐。粗略总时长等于独立频点数乘每点积分时间，再加调谐与标定开销；扫频策略还要计入信号线宽与调谐步长。多次检验还带来试验次数效应，但相邻频点相关，不能机械地按采样点数相乘。候选信号需要复测、换磁场或其他一致性检查，才能区分噪声峰与真实轴子。
- **[[screening-and-early-detection|筛查与早期发现]]**：极弱信号会遇上能模仿它的本底。中微子雾与筛查的假阳性有可比较之处，但中微子是可建模的物理事例，并非不可逾越的统计墙。曝光、本底不确定度、能谱差异和独立信息一起决定发现能力；选择更低阈值时，既要计算信号收益，也要重新评估辨别本底所需的证据。[6]
