# 共动距离与宇宙学红移

## 概述

遥远星系 GN-z11 的红移 $z \approx 10.6$（JWST 2023 确认值）。问"它离我们多远"，答案却不止一个：光从它走到我们花了约 134 亿年（光行距离），但发出这束光的物质如今已被膨胀带到约 320 亿光年之外（共动距离），而当年它真正发光时，离我们只有约 28 亿光年（角直径距离）。同一个天体，三个相差十倍的"距离"，没有一个是错的。

问题出在：宇宙空间本身在膨胀，"距离"不再是一个单一明确的概念。同一对天体之间存在多种合理定义的距离——共动距离、角直径距离、光度距离——它们随时间演化，在不同物理情境下各有适用。这不是单纯的数学定义问题，而是涉及宇宙膨胀的本质：空间本身在拉伸，不同于通常意义上的"物体在空间中运动"。理解这套距离概念以及宇宙学红移的物理机制，是读懂所有宇宙学观测的基础。

把「离我们多远」当成一个数字，是把膨胀宇宙误当成静止的欧几里得房间。共动距离回答的是：把今天的标尺铺到两点之间有多长。光度距离回答的是：这盏灯该有多暗。角直径距离回答的是：一把已知尺子会张多大的角。

三者在低红移处几乎重合，红移一高就会分道扬镳。GN-z11 的三个答案相差一个数量级，不是测量出错，而是三种问题本来就不是同一个问题。

宇宙学红移常被顺口说成「它在退行」。这句话只在 $z \ll 1$ 时数值上近似成立。红移本身只记录发射与接收两个时刻的标度因子之比，并不给出光源此刻的局域速度。把 $z = 1$ 读成「半光速逃离」，是把宇宙学红移误认成了局域多普勒。

## 弗里德曼-罗伯逊-沃克（FRW）度规

均匀各向同性宇宙的时空度规为：

$$ds^2 = -c^2 dt^2 + a(t)^2 \left[\frac{dr^2}{1-kr^2} + r^2 d\Omega^2\right]$$

其中：

- $a(t)$ 是**标度因子**（今天 $a_0 = 1$，过去 $a < 1$，未来 $a > 1$）
- $r$ 是**共动坐标**（随宇宙膨胀而固定）
- $k = 0, +1, -1$ 分别对应平坦、正曲率、负曲率空间
- $d\Omega^2 = d\theta^2 + \sin^2\theta \, d\phi^2$ 是球面元

这套度规把时间与空间分开写：$t$ 是共动观测者的固有时，空间部分整体乘上 $a(t)$。光子沿零测地线走，$ds = 0$，径向积分就给出共动距离的积分式。曲率 $k$ 出现在径向因子里，但今天的观测把 $\Omega_k$ 压在零附近，平坦宇宙的公式因此成为默认工作假设。数字沿用 Planck 2018，不另换一套曲率。

## 共动距离

### 定义

共动距离（comoving distance）$\chi$ 是两点之间在今天时刻（$a = 1$）的坐标距离，它与宇宙膨胀"一起运动"——如果两个星系只受哈勃流（无本动速度），则它们之间的共动距离恒定不变（宇宙在膨胀，但共动坐标不变）。

对于在时刻 $t_{em}$（对应红移 $z$）发射、今天（$t_0$）接收的光子，其共动距离为：

$$\chi(z) = c \int_0^z \frac{dz'}{H(z')}$$

其中 $H(z) = H_0 \sqrt{\Omega_m(1+z)^3 + \Omega_k(1+z)^2 + \Omega_\Lambda}$ 是红移 $z$ 处的哈勃参数（假设平坦宇宙时 $\Omega_k = 0$）。

### 固有距离与共动坐标

固有距离（proper distance）是某一固定时刻、把光停住后用尺子量出的瞬时距离，它等于 $a(t)\chi$。共动距离把 $a$ 钉在今天，所以只随坐标、不随膨胀变。两个只随哈勃流走的星系，$\chi$ 保持不变，固有距离却按 $a(t)$ 拉长。成团统计、功率谱、相关函数都在共动坐标里做，正是为了把「空间在胀」从「物质在聚」里拆出去。

光行距离则是光子路上积累的坐标时，不等于任何一张「此刻快照」上的尺子读数。问「光走了多久」和问「今天两点相距多远」，答案本来就该不一样。GN-z11 那组约 134 亿年与约 320 亿光年，对应的正是这两种问题，而不是同一次测量的两种误差。

### 数值示例（Planck 2018 $\Lambda$CDM，$H_0 = 67.4$ km/s/Mpc）

| 红移 $z$ | 共动距离（Mpc） | 宇宙年龄（Gyr）   |
| -------- | --------------- | ----------------- |
| 0.1      | 421             | 12.5              |
| 0.5      | 1906            | 8.6               |
| 1.0      | 3303            | 5.8               |
| 2.0      | 5178            | 3.3               |
| 6.0      | 8680            | 0.93              |
| 1100     | 13922           | 0.00038（38万年） |

**CMB 最后散射面的共动距离**约为 13900 Mpc（约 453 亿光年），这是宇宙的"视觉边界"。

表中的数字全部按 Planck 2018 的 $\Lambda$CDM、$H_0 = 67.4$ km/s/Mpc 算出，不另换本地超新星那套偏高的哈勃常数。$z = 1$ 对应共动距离 3303 Mpc、宇宙年龄 5.8 Gyr：光走了大半个宇宙年龄，坐标距离却仍在增长。最后散射面那一行 $z = 1100$、$\chi \approx 13922$ Mpc，对应的是[[复合时期与最后散射面]]，也就是[[宇宙微波背景]]的发光时刻。视觉边界是共动意义上的，不是一张静止的球面。

回看时间（lookback time）$t_L = \int_0^z dz'/[(1+z')H(z')]$ 回答的是「光在路上走了多久」，它与共动距离 $\chi$ 共用同一个 $H(z)$，却差一个 $(1+z')$ 因子。两者在低红移处几乎成正比，高红移处分道：回看时间被早期较高的膨胀率压住，共动距离仍可继续积分到最后散射面。把回看时间直接乘上光速当成「今天的距离」，等于把光行历史误读成瞬时快照。

## 宇宙学红移

### 物理机制

光子从红移 $z$ 处发射到今天被接收，波长发生红移：

$$\frac{\lambda_{obs}}{\lambda_{em}} = 1 + z = \frac{a_0}{a(t_{em})} = \frac{1}{a(t_{em})}$$

宇宙学红移不是多普勒效应（尽管在小红移处可以近似用多普勒公式），而是光子在传播过程中，由于宇宙空间的膨胀，**波长随宇宙标度因子等比拉伸**。

这一区别有深刻含义：当我们说"某星系红移 $z = 1$"，我们的意思是在光子从该星系发出时，宇宙的尺度仅为今天的 $1/(1+1) = 0.5$，而不是该星系"正在以某个速度逃离我们"。

红移是两个时刻的标度因子之比，不是路径上一段段局域多普勒的代数和。光子在膨胀空间里被拉长，中间不必经过任何「退行介质」。把 $1+z = 1/a$ 改写成一个速度，只在 $z \ll 1$ 时碰巧数值接近狭义相对论的多普勒公式。Harrison 把这件事写清楚了：线性的 $cz = H_0 d$ 是观测近似，线性的退行速度—距离关系才是均匀膨胀里的理论式，两者只在低红移处重合。

### 多普勒红移 vs 宇宙学红移

| 特征     | 多普勒红移（狭义相对论）       | 宇宙学红移             |
| -------- | ------------------------------ | ---------------------- |
| 物理起源 | 光源相对观测者的运动           | 宇宙空间本身的膨胀     |
| 公式     | $1+z = \sqrt{(1+v/c)/(1-v/c)}$ | $1+z = 1/a(t_{em})$    |
| 叠加性   | 路径上的总多普勒红移           | 对标度因子比的单一贡献 |
| 适用尺度 | 局部（$z \ll 1$）              | 所有宇宙学尺度         |

在小红移（$z \ll 1$）时，哈勃定律 $cz \approx v = H_0 d$ 是宇宙学红移的线性近似，此时多普勒和宇宙学解释数值相近。

### 本动速度不是宇宙学红移

星系除了随哈勃流走，还在周围引力场里运动。这份本动速度会在光谱上叠一份真正的局域多普勒，[[红移巡天与宇宙三维制图]]必须把它和宇宙学红移分开处理。团内速度弥散可以把球状星系团拉成「上帝之指」，那是红移空间的假象，不是共动空间里真有一根细针。

判别式仍然干净：宇宙学红移由发射与接收时刻的标度因子之比给出；多普勒由相对速度的单一函数给出。小红移处两者数值接近，所以只有把 $z$ 推高，才能看清膨胀本身。[[多普勒效应与相对论多普勒]]描述的是局域惯性系里的运动，不能直接接到 FRW 的全局膨胀上。

### 视界的存在

由于宇宙学红移的累积效应，存在两个关键视界：

**哈勃视界（Hubble sphere）**：$d_H = c/H \approx 14.3$ Gpc（今天），其内部星系的退行速度低于光速。注意：超出哈勃视界的星系退行速度超过光速——这不违反相对论，因为是空间本身膨胀，而非物体在空间中运动。

**粒子视界（Particle horizon）**：宇宙诞生以来光能传播的最大共动距离，即

$$\chi_{ph} = c \int_0^{t_0} \frac{dt'}{a(t')} = c \int_0^\infty \frac{dz}{H(z)} \approx 46.5 \text{ Gly（亿光年）}$$

（约 14.27 Gpc 共动距离）。这是可观测宇宙的边界——粒子视界之外的事件对我们没有因果影响。

**事件视界（Event horizon）**：在加速膨胀的宇宙中，超过一定距离的星系将**永远**无法与我们建立因果联系：

$$\chi_{eh} = c \int_{t_0}^\infty \frac{dt'}{a(t')} \approx 16.7 \text{ Gly（亿光年）}$$

（约 5.1 Gpc 共动距离，假设宇宙学常数不变）。今天距我们约 16.7 亿光年外的星系，它现在发出的光永远无法到达我们。

超光速退行不违反相对论，因为退行速度是 $\chi$ 乘上 $H(t)$，描述的是坐标间距的变化率，不是物体在局域惯性系里的运动。哈勃球只标出退行速度等于光速的那一圈，粒子视界才是因果上「已经看得到」的边界。[[宇宙学原理与可观测宇宙]]把这三者拆开：混用它们，会把「现在退行超光速」读成「永远收不到光」。

## 其他重要距离定义

### 角直径距离 $D_A$

若天体的物理尺寸为 $d$，张角为 $\theta$，则角直径距离定义为：

$$D_A = \frac{d}{\theta} = \frac{\chi}{1+z}$$

**反直觉的特性**：$D_A$ 在 $z \approx 1.6$ 处达到最大值（约 1.8 Gpc），之后随红移**减小**。这意味着极高红移的天体比中间红移的天体张角**更大**（如果物理尺寸相同）。这是因为它们在非常"年轻"的宇宙中占据了较大的视角。

角直径距离是 CMB 声学峰、BAO 标准尺测量的基础。

标准尺测量吃的是 $D_A$。[[重子声学振荡]]的声视界、CMB 声学峰的角尺度，用的都是这把尺子。它在 $z \approx 1.6$ 处达到约 1.8 Gpc 的极大值，之后随红移减小。

极高红移天体可以显得比中等红移天体更大。这不是透镜放大，而是发射时刻的宇宙更小，同一把共动尺子当时张角更大。数字沿用上文，不另造峰值红移。

### 光度距离 $D_L$

若天体的本征光度为 $L$，观测流量为 $F$，则光度距离定义为：

$$D_L = \sqrt{\frac{L}{4\pi F}} = (1+z) \chi = (1+z)^2 D_A$$

**两个 $(1+z)$ 因子的来源**：

1. 第一个 $(1+z)$：光子能量被宇宙膨胀红移降低
2. 第二个 $(1+z)$：单位时间到达的光子数因膨胀而减少

光度距离是超新星标准烛光测量的基础，距离模数定义为 $\mu = 5\log_{10}(D_L / 10 \text{ pc})$。

标准烛光吃的是 $D_L$。[[标准烛光与Ia超新星测距]]走的就是这条路。两个 $(1+z)$ 分别来自光子能量被拉长、以及到达率被时间膨胀稀释，几何上再乘上共动距离 $\chi$。

因此同一颗超新星，在高红移处会显得比「按共动距离估的」更暗。距离模数把这条链写进测光，不经过任何局域速度解释。

### 距离度量关系

$$D_L = (1+z) \chi = (1+z)^2 D_A$$

这个关系（Etherington 关系）是一个精确的几何结论，不依赖于具体的宇宙学模型，只要光子测地线是唯一的且没有多路径效应。违反 Etherington 关系将暗示新物理（如光子与轴子的转化、额外维度效应）。

I. M. H. Etherington 在 1933 年给出的互易关系，把光度距离与角直径距离锁在一起：$D_L = (1+z)^2 D_A$。它不依赖 $\Omega_m$ 或 $\Omega_\Lambda$，只要求光子走唯一的零测地线、光子数守恒。超新星给出 $D_L$，BAO 与 CMB 给出 $D_A$，两边对不上才是新物理。[[哈勃张力]]改变的是整体标尺，不自动破坏这条几何关系。

### 三种距离各管什么

选哪种距离，取决于要测什么。成团统计与模拟星表用共动距离，因为坐标不随膨胀漂。标准尺用角直径距离，因为观测到的是张角。标准烛光用光度距离，因为观测到的是流量。

光行时间只回答「光子在路上走了多久」，不能拿来当今天的尺子。它记录的是沿测地线积累的坐标时，与今天快照上的 $\chi$ 不是同一个量。

低红移处三种宇宙学距离几乎相等，所以近邻宇宙里「距离」可以含糊着用。红移一高，$(1+z)$ 因子把它们拉开，含糊就变成错误。GN-z11 那一组数是示范，不是特例：同一条测地线，三种投影。

## 哈勃常数的测量与宇宙学距离

距离测量链（宇宙距离阶梯）对哈勃常数 $H_0$ 极为敏感，因为：

$$D_L(z) = \frac{c}{H_0} \int_0^z \frac{(1+z') \, dz'}{E(z')} \cdot (1+z)$$

其中 $E(z) = H(z)/H_0$。改变 $H_0$ 会等比例改变所有宇宙学距离，这是"哈勃张力"（Planck 给出 $H_0 = 67.4$ km/s/Mpc，SH0ES 给出 $H_0 = 73.0$ km/s/Mpc）影响如此深远的原因——它不仅改变单个距离测量，而是影响整个宇宙距离标尺。

[[宇宙距离阶梯]]把近处的几何距离一节节传到高红移。阶梯的零点钉在 $H_0$ 上，整条 $D_L(z)$ 随 $1/H_0$ 缩放。Planck 2018 给出 $H_0 = 67.4$ km/s/Mpc，SH0ES 给出 $73.0$ km/s/Mpc：不是某一个天体测错了，而是整把宇宙学尺子的刻度有两套。本文表格与积分一律用 Planck 2018，不把两套数混进同一列。

在实际数据分析里，红移到共动距离的换算必须声明一套背景宇宙学：$H_0$、$\Omega_m$、$\Omega_\Lambda$。换一套参数，同一条光谱红移会映射到不同的 $\chi$，功率谱的波数刻度随之整体缩放。这不是测量误差，而是坐标系约定。比较两篇成团论文时，若一方用 Planck 2018、另一方用偏高的本地 $H_0$，共动体积与相关函数幅度会系统性错位，必须先统一标尺再谈张力。

## 跨域连接

- **[[宇宙学原理与可观测宇宙|宇宙学原理与可观测宇宙]]**：三种视界必须分开：粒子视界划定"已经看得到"，事件视界划定"永远看不到"，哈勃半径只标出退行速度等于光速的位置。**三者在加速膨胀的宇宙里互不重合**，混用它们正是"超光速就永远失联"这一误解的根源。
- **[[多普勒效应与相对论多普勒|多普勒效应]]**：判别式很干净——多普勒红移由相对速度的单一函数给出，宇宙学红移只由发射与接收时刻的标度因子之比给出。**小红移处两者数值重合，所以只有高红移才能分辨**；把远处星系的红移读成"它正以某速度逃离"在概念上已经错了。
- **[[differential-geometry|微分几何]]**：光度距离与角直径距离之间只差两个红移因子，这是纯几何结论，不依赖宇宙的成分。**正因为它不依赖模型，违反它才是硬信号**：要么光子不沿唯一测地线传播，要么光子数不守恒。
- **[[spectroscopy|光谱学]]**：定红移要求整条谱线族按同一因子位移，而不是单条线移动。**这条要求把化学环境、压强或引力造成的位移排除在外**，也解释了为什么高红移天体必须先认出莱曼系或金属线的图样，才谈得上给出红移。
- **[[map-projections|地图投影]]**：同一对天体有多种合理距离，与地图上没有唯一正确的距离是同一类问题：在弯曲或演化的几何上，保角、保面积、保距离不能同时满足。**选哪种距离取决于要测什么**——成团用共动距离，标准尺用角直径距离，标准烛光用光度距离。

## 为什么这很重要

距离概念是宇宙学的语言。没有清晰的距离定义，宇宙学中的任何定量陈述都缺乏基础：CMB 来自多远？宇宙年龄多大？哈勃常数是什么意思？可观测宇宙有多大？这些问题的答案都依赖于对 FRW 度规和弗里德曼方程的正确理解。宇宙学距离还揭示了膨胀宇宙的深刻特性：可观测宇宙的边界不是不变的，而是随时间推移不断向外扩展（粒子视界）的同时，未来能联系的宇宙却在收缩（事件视界）。

选错距离，就会把标准烛光的暗度读成错误的膨胀史，或把标准尺的张角读成错误的曲率。共动距离适合讲「物质在哪里」；角直径距离适合讲「尺子有多大」；光度距离适合讲「灯有多暗」。红移则只负责告诉你 $a(t)$ 当时是多少。把这四件事拆开，宇宙学观测才有共同语言。
