# 恒星结构与流体静力平衡：支撑恒星的力量平衡

## 概述

一颗恒星为何能长时间保持形状？在近似球对称、转动与大规模加速度可忽略时，向外递减的总压强可以平衡向内的自引力，这就是**流体静力平衡**。它是许多恒星模型的机械条件，但并不自动规定能量从哪里来，也不保证任何扰动都会恢复。[1][2]

恒星的光主要不是化学火焰。主序星由核聚变补偿表面辐射，主序前星则可主要靠引力收缩供能；两者都能在缓慢演化时近似满足静力平衡。稳定的主序结构通常在动力学时标上调整，远快于热与核演化时标；脉动、闪燃和坍缩则需要额外的稳定性或流体动力学分析。[1][2]

## 流体静力平衡方程

考虑恒星内部距中心距离 $r$ 处的一薄层壳体。这层壳体受到两个力的作用：

- **向内的引力**：来自半径 $r$ 以内所有质量 M(r) 对该壳体的引力
- **向外的压力差**：下方（更高压力）和上方（更低压力）之间的压力差

当两者平衡时，得到流体静力平衡方程：

$$\frac{dP}{dr} = -\frac{G M(r) \rho(r)}{r^2}$$

其中 $P$ 是压力，$\rho$ 是密度，$G$ 是万有引力常数。这个方程意味着：越靠近恒星中心，上方压着的质量越多，所需的支撑压力也越大。 这里的 $P$ 包括所采用模型中的气体、辐射等压力贡献；若已用辐射压梯度计入光子的动量，就不能再把同一作用重复加一遍。[1][3]

太阳中心压强为约 $10^{16}$ Pa、温度为约 $10^7$ K量级，具体数值来自经过组成、年龄与边界标定的太阳模型，而非静力方程单独给出的唯一答案。中心温度让氢聚变有足够的反应率；没有一条对所有质量、组成均相同的瞬时“点火温度线”。[1]

负号表示总压强向外递减。稳定扰动下，声波和压力调整发生在动力学时标 $\tau_{\rm dyn}\sim\sqrt{R^3/(GM)}$ 上：代入太阳质量与半径约为1600秒。这是数量级估计，不能从静力平衡等式独自推出全局稳定；日震观测的声波正是在平均结构附近的小振动。[1][2]

将同一方程用于近似球对称的行星或气体巨星，M(r) 与 $\rho(r)$ 的意义不变，但组成、温度和状态方程不同。简并残骸也可在没有持续核聚变时保持平衡；是否位于主序，还要问核反应能否长期补偿能量损失。[1]

## 质量连续性方程

与流体静力平衡方程配套的是**质量连续性方程**，描述质量随半径的分布：

$$\frac{dM(r)}{dr} = 4\pi r^2 \rho(r)$$

这两个方程构成了描述恒星结构的基础方程组的前两条。

质量连续说的是：半径 $r$ 处往外走一小步，包进去的质量等于当地密度乘球壳体积。中心边界是 $M(0)=0$，表面是 $M(R)=M$。给定密度分布，积分一次就得到 M(r)；反过来，测到 M(r) 的斜率除以 $4\pi r^2$ 后才等于当地密度。流体静力方程里的 M(r) 必须和这条连续方程自洽，不能随手指定一个质量再另给一套密度。

两条方程还不够闭合。压强要靠状态方程写成密度和温度的函数，温度又要靠能量传输和产能。所以“结构”不是单独解一条静力平衡，而是四条方程连同状态方程、不透明度、反应率和组成演化一起求解。质量连续保证球对称质量不丢不造；静力平衡令模型中的平均径向加速度近似为零。缺了连续方程，静力平衡右边的 M(r) 就没有定义。[2]

数值计算常以包围质量 $m$ 为坐标，求 r(m)、P(m)、T(m) 和 L(m)。中心有 $r=0$、$L=0$；外边界则需接大气模型或采用光球近似。在光球处温度与压强有限，不能把最简零边界近似当作实际表面条件。[2]

## 压力的物理来源

恒星内部维持压力的机制随密度和温度不同而变化：

### 热压力（气体压力）

大多数主序星的主要支撑来自**理想气体压力**：

$$P_{gas} = \frac{\rho k_B T}{\mu m_H}$$

其中 $k_B$ 是玻尔兹曼常数，$T$ 是温度，$\mu$ 是以氢原子质量为单位的平均粒子质量（须同时计入离子和电子），$m_H$ 是氢原子质量。此理想气体近似需在非强简并等条件下使用，部分电离、非理想相互作用会修改它。[1]

热压来自粒子热运动的动量交换，微观图像见[[kinetic-theory-of-gases|气体动理论]]。氢聚成氦以后，同样质量里的粒子数变少，$\mu$ 上升，同温同密下压强下降。核心必须升温才能继续托住外层，主序星的光度因此会随年龄缓慢增加。这是结合能量传输、核反应和组成演化后得到的主序模型趋势；三条机械关系本身还不够确定光度。[1][2]

### 辐射压力

在质量大于约 $10\,M_\odot$ 的大质量恒星中，光子的辐射压力变得重要：

$$P_{rad} = \frac{4\sigma T^4}{3c}$$

其中 $\sigma$ 是斯特藩–玻尔兹曼常数，$c$ 是光速。该式适用于近局域热平衡、近各向同性的辐射场；真实逃逸辐射的大气不能无条件套用。大质量星内部辐射压往往更重要，但它占总压的比例与当地辐射力是否接近引力，是相关而不相同的问题。[1][3]

在球对称与给定不透明度的近似下，爱丁顿光度为 $L_{\rm Edd}=4\pi cGM/\kappa$；电子散射只是常用的 $\kappa$ 近似之一。局部不透明度、实际由辐射携带的光度及对流都会改变包层处境。接近这一限制可促使膨胀或质量损失，但不能一概说辐射压重要的所有恒星都已失去静力平衡。[3]

辐射压占比升高时，混合物的绝热响应更接近相对论粒子的情形，恒星对扰动的恢复可能变弱。是否出现失稳仍取决于温度、组成、能量输运和几何条件，需要做稳定性分析；持续质量损失不是每个辐射压显著模型成立的必要前提。[1][2]

### 简并压力

高密度下，电子或中子的量子简并可在很低温时仍提供压力。强简并极限的主要项对温度不敏感，但有限温度、相互作用与其他成分仍会修正状态方程；也不是只有核燃烧完全结束后才可能简并。[1]

费米子不能全部占据同一量子态，密度增加会抬高所需动量。[[pauli-exclusion-principle|泡利不相容原理]]因此参与[[white-dwarfs|白矮星]]支撑。碳氧核各约**两个核子对应一个电子**，即 $\mu_e\simeq2$；冷、非转动、理想电子简并的模型上限约为 $1.4\,M_\odot$，并非每核子一个电子。实际结局还受电子俘获、核反应、转动等影响。[1]

中子星需要广义相对论静力方程及包含核相互作用的状态方程，不能只把白矮星电子换成理想中子后就当作真实天体。不同致密物质模型有不同最大质量，约束见[[neutron-star-interior-eos|致密物质状态方程]]；本节的牛顿球对称方程不适合直接精算中子星。

## 能量传输方程

能量还必须穿过恒星并从表面离开。常见机制是辐射与对流；致密简并区域的电子导热也可能重要。因此下面两式分别有各自适用条件，不能覆盖所有区域。[3]

### 辐射传输

在光学厚、近局域热平衡的**辐射扩散近似**下，用Rosseland平均不透明度 $\kappa$ 描述输运：[3]

$$\frac{dT}{dr} = -\frac{3\kappa \rho L(r)}{64 \pi \sigma T^3 r^2}$$

太阳辐射区大致延伸至0.7倍太阳半径。光子的传播涉及反复散射、吸收和再发射，扩散所需时间远长于直线光行时；不能把它看成同一个核反应光子保持身份一路走到可见表面。对流层以上还需要大气中的辐射传输处理。[3]

辐射传输方程把当地光度、不透明度和温度梯度锁在一起。不透明度高，同样的光度就要求更陡的温度梯度。在组成均匀等条件下，纯辐射所需梯度若超过绝热值，辐射通道不够用，对流接手。辐射、对流与导热的分工见[[热传导对流与辐射|热传导对流与辐射]]，恒星内部只是把同一套选择规则放到球对称引力场里。[3]

日震与中微子提供互补探针：前者由模式频率反演平均机械结构，后者较直接地携带核心反应信息。它们都要经过传播与测量模型，不能说其中一种观测独自无条件还原恒星所有内部量。[4][5]

### 对流传输

太阳外部约三成半径范围主要由对流输送内部能量。上升与下沉物质的平均运动可搬运热量，并参与表面结构与化学混合；时间平均结构仍常近似满足静力平衡。[3]

**施瓦西判据**：在忽略组成梯度等条件下，若假设全由辐射传输所需的梯度超过绝热梯度，辐射分层会发生对流不稳定：[3]

$$\nabla_{rad} > \nabla_{ad}$$

其中 $\nabla_{rad}$ 是维持辐射传输所需的对数温度梯度，$\nabla_{ad}$ 是绝热对数温度梯度。 若平均粒子质量随深度变化，则还需考虑Ledoux判据中的组成项；不能把这个不等式不加条件地当成实际对流层温度剖面。[3]

深部高效率对流的实际梯度通常接近绝热值，但靠近表面的低效率对流可明显超绝热。约低于0.35倍太阳质量的主序模型常近乎全对流，太阳主要有对流包层，更大质量主序星常有对流核；边界依赖组成和模型。对流改变输运与混合，不必摧毁时间平均的静力平衡。[2][3]

## 核能产生方程

用单位质量的**净供能率**写，第四条方程为：[2]

$$
\begin{aligned}
\frac{dL}{dr}&=4\pi r^2\rho\epsilon_{\rm net},\\
\epsilon_{\rm net}&=\epsilon_{\rm nuc}-\epsilon_\nu-T\frac{Ds}{Dt}.
\end{aligned}
$$

这里各项单位为功率/质量，$s$ 是比熵，$D/Dt$ 跟随质量元。核供能、中微子能量损失及收缩/膨胀的热变化都要计入；只有热平衡且损失可忽略时，才能把净供能简化为核反应率。反应的温度幂指数是局部近似，随温度、反应支路与组成改变。[2]

[[恒星核合成]]决定反应网络，结构与输运决定温度和能量如何变化。非简并主序核心常有膨胀降温的负反馈，但简并点火或薄壳燃烧可以失稳；静力平衡与维里关系不能单独保证所有核燃烧都天然稳定。[1][2]

## 维里定理与恒星的自我调节

**维里定理**联系机械平衡、引力势能和压强。忽略表面压强、转动等项，且内部为非相对论单原子理想气体时，才可将它写成热能与引力势能的简单关系：[1]

$$E_{thermal} = -\frac{1}{2} E_{grav}$$

在这些近似下、组成固定且无其他重要能量源时，缓慢收缩所释放的引力势能约一半增加内部热能，一半辐射出去。这解释太阳型主序前星失去总能量却升高内部温度的趋势；它不是所有引力系统或所有演化阶段都遵守的热学定律。[1]

简并星同样满足适当形式的维里关系，只是主要内能与压力不再由经典热运动决定。白矮星可以主要降低离子热含量而缓慢冷却，半径变化较小；不能说“简并星没有维里定理”。辐射压显著时也要改写热能与势能的关系。[1]

当核心核反应供能能长期补偿表面损失，主序前收缩才逐步转向稳定氢燃烧。这个过程需要反应率、组成和热平衡方程共同确定；维里定理给能量尺度，不单独给出通用点火门槛。[1][2]

## 标准太阳模型

恒星结构方程组（流体静力平衡 + 质量连续 + 能量传输 + 核能产生）加上合适的状态方程和不透明度表，可以用数值方法求解，得到**标准太阳模型**（Standard Solar Model, SSM）。

标准太阳模型的预言已通过多种途径检验：

- **日震学**：可靠的太阳压力模式等观测能限制内部声速、密度和对流区边界；太阳重力模式的部分探测主张曾受到独立稳健性检验质疑，不能与压力模式一样笼统写成已稳固测得。[4][6]
- **太阳中微子**：SNO分别测量不同反应通道，2002年报告非电子味分量及与太阳模型相容的总通量，支持味转化解释。它有力检验了太阳供能模型，但不代表每项输入已无误差或丰度问题全部解决。[5]

太阳丰度问题正显示这种差别：Bahcall等2005年比较不同丰度与不透明度组合，发现较低重元素丰度的模型在对流边界、表面氦、声速与密度上明显偏离日震约束。偏差随模型与位置改变，不能为全部标准太阳模型统一指定0.1%吻合、1%局部差异。[7]

## 恒星结构方程的更广泛应用

同一机械框架可用于许多近似球对称、缓慢演化的天体，但状态方程和能量输运必须随条件改变：[1][2]

| 天体/阶段          | 重要支撑与能量条件                                    |
| ------------------ | ----------------------------------------------------- |
| 棕矮星             | 热压与部分电子简并；是否经历氘燃烧依赖质量和组成      |
| 很低质量主序星     | 主要热压、常近乎全对流，pp链供能                      |
| 太阳附近质量主序星 | 辐射与对流区域并存，pp与CNO占比随质量、温度和组成改变 |
| 大质量主序星       | 辐射压更重要，常有对流核与强质量损失                  |
| 白矮星             | 主要电子简并支撑，冷却、结晶及可能残余燃烧需另计      |
| 中子星             | 需要广义相对论与致密物质状态方程                      |

对牛顿近似下的球对称天体，M(r) 仍由密度积分确定。但快速转动、强磁场、大幅脉动或爆炸时要补相应项；相对论致密星还要换用相对论方程。先检查近似成立，才能谈换状态方程而保持机械形式。[1][2]

## 为什么这很重要

结构方程把质量分布、支撑、供能和输运连在一起，解释恒星为何有不同光度、寿命和结局。它们不是任何状态下都成立的存在性证明；演化代码需要随时间更新组成与热结构，在平衡失效时转向更完整的动力学问题。[2]

热压、辐射压和简并压在不同环境下共同参与支撑；质量连续保证引力项对应真实包围质量。把能量平衡与边界也纳入，才从一条静力公式走向可以检验的恒星模型。[1][2]

## 跨域连接

- **[[atmosphere-structure|大气层结构]]**：地球大气也满足近似的压强梯度平衡，但它与恒星还在自引力、组成和输运上不同。由梯度推质量必须同时知道密度与半径，并确认转动或加速度可忽略；只测一个梯度就“称重”会漏掉必要条件。
- **[[differential-equation|微分方程]]**：恒星结构常是两点边值问题，中心与光球条件需要共同满足。松弛法和调整猜测值的射击方法都可用于相应问题；不能由边值性质推出只有一种算法，更不能将质量与组成唯一决定结构当成无例外的数学定理。[2]
- **[[kinetic-theory-of-gases|气体动理论]]**：氢转为氦使给定质量的自由粒子数改变，理想气体式中的平均粒子质量随之上升。但恒星如何补偿、光度怎样变化，还要联立反应率与输运方程。状态方程提供局部响应，演化趋势来自整个耦合解。[1][2]
- **[[atomic-structure|原子结构]]**：不透明度有电子散射、自由–自由、束缚–自由及束缚–束缚等贡献，主导过程随温度和密度改变。氧、铁等丰度会影响输运，丰度定标与原子数据的不确定性都可传到太阳结构；不能把太阳丰度问题唯一归为某一种跃迁。[3][7]
- **[[中微子探测器|中微子探测器]]**：中微子提供不同于光球与日震的观测窗口，但探测反应、能谱、味转化和阈值共同决定读数。SNO比较带电流、中性流和散射通道，才把缺少电子味与缺少总通量区分开；“直接看到核心”仍需清楚的测量模型。[5]
