# 核心坍缩超新星：大质量恒星的壮烈终结

## 概述

**核心坍缩超新星**（core-collapse supernova）来自大质量恒星生命末期核心的引力坍缩。初始质量约八倍太阳质量以上的恒星可能走入这一结局，但边界依赖组成、混合和双星作用，也并非每次坍缩都产生明亮爆炸。一个典型原中子星释放的引力能为几乘 $10^{46}$ J，约百分之九十九最终由中微子带走；普通爆炸的抛射动能约 $10^{44}$ J，可见光辐射又低一到两个数量级。作为比较，太阳以现今光度辐射一百亿年约为 $1.2\times10^{44}$ J，不能把坍缩总能量说成仅相当于这个数的几倍。SN 1987A 的中微子信号第一次让人类在太阳系以外直接看到这笔能量账的线索。[1][2][3]

把核心坍缩超新星写成“中微子一加热就爆了”，会把仍在计算的机制说成已经结案。延迟中微子加热是目前解释普通 II 型、Ib/c 型爆发的主流图像，三维模拟也越来越常给出成功的爆炸，但它对前身星结构、对流和核物质状态方程敏感，并不是唯一通道。快速旋转、强磁场的核心可能走磁旋转爆发，对应超超新星和某些长伽马射线暴；有的铁核也可能塌成黑洞而看不见成功的冲击波。它与[[type-ia-supernovae|Ia 型超新星]]的差别首先是引擎：这里是引力坍缩加中微子，那里是白矮星热核解体，两套光变不能互相套用。[3][4]

## 大质量恒星的洋葱层结构

核心坍缩超新星的起点是一颗接近死亡的大质量恒星。经过数百万年的核燃烧，这颗恒星的内部形成了**洋葱层结构**（onion-shell structure），从外到内依次是：

- 氢包层
- 氦壳层
- 碳/氧壳层
- 氖/镁壳层
- 氧/硅壳层
- **铁核心**（核燃烧的终点）

燃烧进入铁族附近后，继续聚变不再能像氢、氦燃烧那样持续供能。这里的“铁核”是铁族核素的混合物，不等于纯铁-56；每核子结合能峰值也不精确落在铁-56上。电子简并压力、热压力与引力暂时平衡，但电子俘获降低每核子电子数，光致分解消耗热能，使核心失稳。常说的约 $1.4\,M_\odot$ 只给出一个质量尺度，热的演化核心的有效极限还依赖熵、电子丰度等。较低质量一端的氧氖镁核可由电子俘获触发坍缩，不必先造出同样的铁核。[3][5]

这些壳层不是同时点着的，而是前一层的灰烬变成下一层的燃料，时标还被中微子冷却急剧压缩。对大约十五倍太阳质量的模型，氢燃烧大约是千万年量级，氦燃烧大约两百万年，碳燃烧大约两千年，氖、氧大约年到几年，硅燃烧只剩下约十八天的量级[5]。具体数字随质量和对流处理而变，不能当成所有前身星共用的精确时钟；硅燃烧产物逐渐接近核统计平衡，光致分解与 $\alpha$ 俘获来回倒腾，最后把核子堆到铁族，铁核因此是结合能峰值处的终点产物，不是还能继续烧的炉膛。

## 从失稳到冲击波停滞

核心的动力学坍缩持续约十分之几秒，反弹和最初冲击波演变则包含毫秒时标，后续吸积与加热可持续数百毫秒甚至更久。这些阶段存在重叠，不能把整条过程都压缩成“每一步仅几毫秒”。[3]

### 电子俘获与光致分解

电子俘获发生在重核上，也发生在自由质子上；后一种反应可写成：

$$p + e^- \rightarrow n + \nu_e$$

在中微子尚可逃逸时，俘获既带走能量也降低电子丰度；密度继续升高后，中微子会被困住，不能假设它们始终自由逃离。高温下的**光致分解**把重核拆成较轻核乃至自由核子，消耗热能。下面的净反应只示意铁-56分解到氦核与中子的能量差：

$$
\begin{aligned}
{}^{56}\mathrm{Fe}+\gamma
&\longrightarrow13\,{}^4\mathrm{He}+4n,\\
E_{\rm absorbed}&\simeq124\ \mathrm{MeV}.
\end{aligned}
$$

这不是整个激波分解损失的统一账单：若进一步把铁核完全拆成自由核子，耗能约为每核子8.8 MeV。电子俘获改变压力与轻子数，核分解改变热能储备；二者通过温度、密度和组成耦合，共同进入坍缩计算。[3][5]

### 核反弹（约 $1$ ms）

当核心密度达到**核物质密度**（约 $2.7 \times 10^{17}$ kg/m$^3$，约 $2.7 \times 10^{14}$ g/cm$^3$）时，核相互作用与简并等使状态方程迅速变硬，内核减速并发生反弹——核心变硬，内核（约 $0.5\,M_\odot$）作为一个整体弹回，产生向外传播的冲击波。

参与反弹的是亚音速收缩的内核，并非整颗恒星同时弹开。物质在核密度附近变得难以继续压缩，内核减速，冲击波向仍在下落的外核传播。[[neutron-star-interior-eos|核物质状态方程]]会改变原中子星半径、温度、中微子发射和吸积历史；这些效应相互竞争，不能由“越软、反弹越弱”直接排出一条普适的黑洞概率顺序。残骸还取决于前身星结构、爆炸能量与后续落回。[3]

### 冲击波变成吸积激波

冲击波向外传播，但在穿过仍在坍缩的外铁核物质时快速失去能量：

- 加热并拆解流入的重核；完全分解为自由核子时，每核子的耗能约为8.8 MeV。
- 随后的电子中微子暴与持续中微子冷却进一步带走能量，但不能把它们误写成最初停滞的唯一原因。[3]

必须区分“激波后物质不再向外运动”和“激波半径不再增加”。在典型铁核模型里，正的激波后速度只维持约1–2毫秒，随后物质重新向中心吸积；激波位置仍可在约一百毫秒里缓慢外移，达到约100–150公里后再收缩。因此不同文章所称的“停滞时刻”可能采用不同定义。[3]

形成准定常吸积激波后，问题变成：怎样使不断流入的物质获得足够能量，重新把激波推向外层？没有有效复活机制时，持续吸积可使原中子星最终变成黑洞。但早期吸积本身不等于已经注定失败，关键仍是后续加热、物质驻留时间与前身星各壳层抵达的先后。[3][4]

### 延迟中微子加热

中微子球是中微子从频繁相互作用转向自由传播的过渡区域，其位置依赖能量和种类，不能用一个固定密度代表所有中微子。在原中子星外侧的增益区，电子中微子和反中微子的一部分通量被吸收，把能量交给物质：

$$\nu_e + n \rightarrow p + e^-$$
$$\bar{\nu}_e + p \rightarrow n + e^+$$

这一延迟中微子加热图像并不要求吸收全部中微子。典型估算中，增益层可吸收穿过它的电子中微子与反中微子光度的百分之几；分母是相关种类和时段的入射光度，不能直接换成十几秒里所有种类辐射的总能量。[3]

对流、驻定吸积激波不稳定性（SASI）及湍流会改变增益区内的驻留时间和压力支持。Blondin等人的二维研究展示了球形吸积激波对非径向扰动的不稳定性；现代多维模型把这些流动与中微子输运一起计算。Burrows与Vartanyan的综述认为延迟中微子加热已成为有力解释，同时明确保留动力学混沌、前身星依赖等未决问题。[4][6]

## 1987A：近邻超新星的中微子信号

SN 1987A位于大麦哲伦云。Hirata等1987年首报的Kamiokande-II信号，是世界时2月23日7:35:35前后（绝对时钟不确定度约一分钟）十三秒内的11个电子事件，重建能量7.5–36 MeV；IMB报告了六秒内8个事件，可见能量20–40 MeV。这里保留首报各自的选择和计数，不把后来不同阈值的候选事件列表拼成唯一的总数，也不要求各台绝对时钟精确同步。[1][2]

探测器记录的是少量粒子与靶物质相互作用留下的信号。结合截面、探测效率、距离、能谱和各味中微子分配，才能推断源的总辐射能约为几乘 $10^{46}$ J；这绝不是地面那十几个事件本身携带的能量。[1][2][3]

到达时间和能量还可用于限制传播速度、质量及衰变，但结果依赖源发射历史、混合和衰变产物是否可见等假设。一个基本量纲检查是：五万秒差距的飞行时间约为五乘 $10^{12}$ 秒，再除以约一千万电子伏特的粒子能量，得到的寿命/质量敏感尺度约为五乘 $10^5$ 秒/电子伏特。这只是传播尺度估算，不是无条件的实验排除界。

SN 1987A支持了核心坍缩通过中微子释放绝大部分引力能的图像，却没有分辨出增益区那百分之几的加热效率。下一次银河系事件有望提供更丰富的时间与能谱信息；它们需与不同爆发模型及振荡情景共同比较，不能保证仅凭某个峰就唯一判定发动机。[3][4]

## 超新星的光学表现

核心坍缩超新星的光变形态很多：冲击波突破可产生很短的闪光，冷却包层、氢复合、放射性衰变及与周围物质碰撞又会在不同阶段供能。不存在所有亚型共同的“两三周达峰”模板。光谱分类主要描述看见的包层与激发状态：[3][4]

| 类型 | 氢线 | 氦线 | 主要特征                | 前身星                                         |
| ---- | ---- | ---- | ----------------------- | ---------------------------------------------- |
| II-P | 有   | 有   | 平坦光变曲线（plateau） | 红超巨星，保留氢包层                           |
| II-L | 有   | 有   | 线性下降光变曲线        | 较薄氢包层                                     |
| IIb  | 弱   | 有   | 氢线早期有、晚期消失    | 氢包层被剥离                                   |
| Ib   | 无   | 有   |                         | 氢包层完全被剥离                               |
| Ic   | 无   | 无   |                         | 缺少明显氢、氦谱线；部分宽线事件与长伽马暴相关 |

II-P型常见的百日左右平台与氢包层的复合有关，时长还受包层质量、半径、爆炸能量和放射性加热影响。氢包层被风或双星作用显著剥去后，外观可变成IIb、Ib或Ic；Ic谱中缺少氦线也不严格等于氦质量为零，谱线还依赖激发与混合。同一类核心引擎因此能产生不同光学外貌。[4]

## 超新星遗迹

爆炸抛射的物质以约 $10{,}000$–$20{,}000$ km/s 的初速度膨胀，与周围星际介质碰撞形成**[[超新星遗迹]]**（supernova remnant, SNR）。超新星遗迹是：

- **加速[[宇宙射线]]的主要场所**：冲击波通过费米加速机制将粒子加速到接近光速
- **星际气体的主要加热源**：维持星际介质的热平衡
- **重元素的扩散介质**：将超新星合成的元素播撒到银河系

著名的超新星遗迹包括：

- **蟹状星云**（Crab Nebula）：1054 年 SN 历史记录超新星的遗迹，中心是蟹状星云脉冲星（$33$ ms 周期）
- **仙后座 A**（Cas A）：约 $17$ 世纪末爆发，X 射线影像显示清晰的元素分层结构
- **SN 1987A 遗迹**：仍在膨胀，冲击波与周围环状气体的相互作用提供持续的多波段观测机会

遗迹阶段回答的是另一组问题：抛射物怎么减速、怎么把动能交给星际介质、怎样把氧和铁族撒进下一轮成星。它不能反过来替爆发瞬间结案——停滞冲击波是否被中微子重新点燃，发生在坍缩后最初数秒的动力学里，而不是在几百年后的壳层形态里补票。把遗迹形态读成爆炸机制的直接底片，会把两种时标混成一张图。

## 伽马射线暴的连接：超新星与相对论喷流

某些宽线Ic型超新星与**[[gamma-ray-bursts|长伽马射线暴]]**相伴。Galama等在GRB 980425误差框内发现了光谱、光变和射电性质特殊的SN 1998bw，提供了重要的观测联系；这不表示所有长暴或所有Ic事件都具有相同光度和喷流。[7]

其中一些爆炸具有高于普通事件的抛射动能，常被称为超超新星。旋转的核心与强磁场、吸积中的黑洞或迅速旋转的中子星，都出现在候选引擎模型中。喷流能否穿出包层、持续多久及观测方向，会影响是否看见明亮的伽马射线暴；低光度事件也提醒人们不应强迫所有关联服从一个统一几何。[3][4][7]

喷流通道要求角动量和磁场同时到位：包层若太厚、旋转若太慢，喷流可能闷死在恒星内部，光学上仍是一颗普通的 Ic，却看不到伽马射线暴。因此“Ic 型等于长暴”并不成立；经典明亮长暴的可见性常受到喷流方向和引擎条件的选择。磁旋转与中微子加热可以并存于不同前身星，把两者写成互相排斥的唯一答案会缩小真实参数空间。

## 为什么这很重要

核心坍缩超新星是宇宙中化学演化的核心驱动力之一：

- **氧的主要来源**：氧主要由大质量恒星燃烧合成，成功的抛射把它送入星际介质；具体产额随恒星模型而变
- **r 过程元素合成场所之一**：可能是较轻 r 过程元素（如钌、银）的重要来源
- **中子星和黑洞的产生**：核心坍缩留下的遗迹决定了银河系中中子星和恒星级黑洞的数量与分布
- **中微子天体物理学的实验室**：探测超新星中微子信号是下一代中微子探测器（如 Hyper-Kamiokande）的核心科学目标

大质量恒星合成并抛出氧、硅、钙和部分铁族元素，普通中微子风是否能提供某些轻重元素，还需检查风的电子丰度等条件。完整重r过程的来源须与[[kilonova-r-process|千新星与r过程]]的并合证据比较，不能把金、铂写成所有核心坍缩的必然产物。[3][8] 失败坍缩则改变致密残骸与化学产额的人口统计。把洋葱层、反弹、吸积、加热和光学包层分开，是为了让每一类观测回答它真正能回答的问题。

## 跨域连接

- **[[nuclear-shell-liquid-drop-models|核壳模型与液滴模型]]**：核密度附近的物质可压缩性影响反弹后的温度、半径与中微子谱。地面实验和中子星观测能限制这些输入，但状态方程改变的不止一个环节；把某个参数的软硬直接等同于爆炸成败，会丢失吸积历史和多维流动的共同作用。[3]
- **[[thermochemistry|热化学]]**：核分解消耗热能，不能把释放能量的聚变直觉沿用到铁族拆解。每核、每核子和每单位质量是三种不同账本；铁核拆到氦与拆到自由核子的终态不同，耗能也不同。反应式必须同时说明反应物、产物与所报能量的分母。
- **[[computational-complexity|计算复杂度]]**：中微子输运包含空间、方向和能量自由度，多维流体又引入湍流。简化可以使计算可行，也会限制结论的范围；比较不同分辨率、输运近似和前身星，才能判断成功爆炸究竟有多稳健，而不是把单次模拟当成所有恒星的命运。[3][4]
- **[[细胞呼吸与能量代谢|细胞呼吸与能量代谢]]**：需氧代谢使用的氧最终来自恒星核合成，但从恒星产氧到行星拥有可呼吸大气，中间还有混合、成星、行星形成和生物地球化学等多层过程。元素来源是必要背景，不能仅由一次爆炸的产额推定生命出现的年代。[8]
- **[[中微子探测器|中微子探测器]]**：地面探测的是相互作用事件，不是把源辐射总能量直接收进探测器。反推源能量必须加入截面、效率、距离与味转换；将来更多事件会增强判别力，但仍要比较模型预测和背景。SN 1987A的珍贵之处在于它提供了独立于光学的内核信息。[1][2]
