# 双星演化与质量转移：恒星之间的引力博弈

## 概述

双星相互作用会改写恒星的包层、质量与结局，但发生率须注明母体样本。Raghavan 等的近邻类太阳星样本中，观测到约 56% 为单星，约 44% 属双星及更高多重系统；Sana 等对大质量 O 星的研究则推断，超过七成会在演化中经历伴星间的质量交换。**系统多重率与未来相互作用比例并不是同一个量。** Ia 型超新星、X 射线双星与双致密星并合，展示了这种相互作用的不同出口。[1][2]

有伴星也不意味着从出生起就有强质量交换。宽双星的成分可在很长时间内近似单独演化，密近双星则可能在一颗星膨胀或轨道收缩后相互影响。[[massive-star-evolution|大质量恒星演化]]里的单星轨迹仍是有用基准；要用于真实系统，还须给定伴星质量、间距、偏心率和质量损失。[2][4]

## 洛希瓣几何：双星系统的引力边界

经典**洛希瓣**（Roche lobe）是圆轨道、同步自转近似下，共转参考系有效势的一条临界闭合面；有效势包含两颗星的引力与离心项。两瓣在内拉格朗日点 L1 接触，物质可经附近形成流束。Eggleton 给出其**等体积球半径**的近似式：[3][4]

$$\frac{R_L}{a} = \frac{0.49 q^{2/3}}{0.6 q^{2/3} + \ln(1 + q^{1/3})}$$

其中 a 是两颗星中心的间距，q=M₁/M₂，对应星1的洛希瓣。公式的半径不等于从星心到L1的直线距离。施主星膨胀到接近这个临界体积时，可能发生**洛希瓣溢流**（RLOF）；近似的几何边界还须与真实流体、辐射及恒星大气一起使用。[3][4]

洛希瓣不是实体墙。L1是有效势的鞍点，物质通过后会形成流束；根据受主星大小与流束角动量，它可以直接撞击受主，也可以先形成吸积盘。等体积半径把复杂三维几何压缩成演化计算可用的尺度，不能据此忽略流束本身的动力学。[4]

溢流可以由两件事触发。施主星自己膨胀，主序结束后进入巨星或 AGB，半径涨过 $R_L$；或者轨道因磁制动、潮汐或引力波辐射而收缩，洛希瓣反过来去撞恒星表面。两种触发在观测上都可以表现为正在转移的密近双星，但后续稳不稳定完全不同。一旦自转与轨道不同步，或轨道明显偏心，这套等势面几何本身就要改写，不能再把瞬时的泪滴轮廓当成严格边界。

## 质量转移类型

Case A/B/C 按**施主星在开始溢流时的核心演化阶段**命名，而不是按转移的驱动力命名。本文沿所引综述，以核心氦耗尽作为B/C分界，使用其他文献时须核对其约定：[4]

| 情况   | 开始溢流时的施主阶段         |
| ------ | ---------------------------- |
| Case A | 核心仍在燃烧氢               |
| Case B | 核心氢已耗尽，核心氦尚未耗尽 |
| Case C | 核心氦已耗尽之后             |

质量转移的稳定性取决于两颗星的质量比和施主星的状态。如果质量转移速率过快，受主星无法处理流入的物质，系统可能进入**共包层演化**（Common Envelope Evolution, CEE）。

Case A 的质量交换可以与核心氢燃烧长期并行；Case B 跨越的结构状态更宽，包括氢壳燃烧、核心氦点火前后的不同情形，常需再细分。Case C 发生在更晚阶段，对低中质量星可对应 AGB，对大质量星则不能只用“AGB”替代。分类告诉我们施主的结构背景，不单独决定速率与稳定性。[4]

稳定与否不看转移“看起来有多猛”，而看质量比和施主的半径—质量响应。施主更重时，丢掉质量往往让它相对洛希瓣更满，形成正反馈，轨道也因质量比反转前的收缩而更紧。受主若来不及热调整，物质在它周围堆积，系统就滑向共包层。同一质量比，在主序和红巨星阶段可以走出完全相反的结局。

## 共包层演化：轨道急剧收缩

当质量转移变得不稳定（通常发生在大质量比 $q \gg 1$ 的系统或巨星的热时标上的快速 RLOF），施主星的整个外包层可能迅速膨胀并包裹伴星，形成**共包层**。在共包层中：

1. 伴星（和施主星的核心）在致密包层中旋转
2. 阻力与激波等作用把释放的轨道能量传给包层
3. 包层被逐渐加热并可能被驱逐出去
4. 如果包层成功驱逐，留下一个轨道大幅收缩的紧密双星（致密残骸+伴星）

能量守恒近似（$\alpha_{CE}$ 参数化）：

$$
\begin{aligned}
E_{\rm bind}&=\alpha_{\rm CE}\Delta E_{\rm orb},\\
\Delta E_{\rm orb}&=\frac{GM_{d,c}M_a}{2a_f}\\
&\quad-\frac{GM_dM_a}{2a_i}.
\end{aligned}
$$

这里 M_d、M_d,c、M_a 分别是施主总质量、留下的核心质量与受主质量，E_bind取需要提供的正束缚能；a_i、a_f为初末间距。α_CE把采用的轨道能量账与抛包层联系起来。若只允许这一能源且定义一致，效率不应超过1；若定义中遗漏内能、复合、吸积或辐射损失，反推值的含义会改变，不能把0到1当成所有参数化的无条件定理。[5]

共包层可把巨星尺度的轨道收缩成紧密双星，是若干双致密星形成通道的重要环节。它却不是每个引力波源必经的步骤：化学均一演化可抑制大幅巨星膨胀，星团动力学也可以组装或收紧双星。能量形式讨论某次包层是否被抛掉，并不替所有形成通道给出唯一生命史。[4][5][7]

α_CE并非已经由三维流体模拟唯一标定的常数。不同前身结构、包层束缚能定义和能量输运，会改变同一轨道收缩释放的能量怎样分配。比较种群合成与观测时，还要同时变化超新星踢速度、初始双星分布和质量保持效率；不能把所有并合率误差都压给一个参数。[5]

## Ia 型超新星：白矮星的多种爆炸通道

Ia 型超新星通常被解释为碳氧白矮星的热核失控。接近钱德拉塞卡质量的吸积模型是一条重要路径；较低质量白矮星的双引爆、双白矮星相互作用等也在研究。因此“怎样点燃”与“伴星是什么”需要分别讨论，不能先把所有事件都限定在近极限质量。[6]

### 单简并模型（Single Degenerate, SD）

白矮星从正常伴星（主序星、巨星）通过 RLOF 积累氢/氦，在表面燃烧后逐渐增加碳氧核质量，最终在质量接近 $M_{Ch} \approx 1.4\,M_\odot$ 时发生热核爆炸。

- **可检验线索**：伴星、吸积造成的星周物质、稳态燃烧阶段及爆炸后的幸存星。
- **限制**：若干近邻事件与遗迹未发现预期的明亮伴星，限制了相应分支；不同遗迹、伴星类型和搜寻深度不能混成“从未找到任何可能伴星”的全体否定。[6]

单简并模型的困难是让白矮星净增重。低于稳定燃烧窗口的吸积，往往让氢在简并层中积累并发生新星；过高的供应则可能引起包层膨胀、风和质量流失。氦层的后续燃烧也影响保持效率。某种吸积状态能增长，不代表它足以供应全部 Ia 型超新星发生率。[6]

### 双简并模型（Double Degenerate, DD）

两颗白矮星可以经引力波耗散而靠近，并在相互作用或并合中点燃核反应。总质量超过钱德拉塞卡值，不保证一定爆炸；反过来，某些氦壳触发的双引爆模型也不要求主白矮星先达到这个质量。点火位置、组成和热历史决定爆炸与塌缩之间的分叉。[6]

- **可检验线索**：双白矮星的质量与轨道分布、并合率、延迟时间及爆炸后的残余结构。
- **限制**：并合并不自动产生正常 Ia 型光谱；某些条件会得到不同类型的爆发或吸积诱导塌缩，必须用具体模型检验。[6]

双简并不必留下普通恒星伴星，这与部分搜寻的否定结果相容；但“没有亮伴星”还不能唯一证明一次爆炸来自双简并。观测的延迟时间分布与双星人口提供另一类约束，仍须和火焰传播、产额及光谱共同对照。[6]

目前学界共识是 Ia 型超新星可能来自**多种前体系统**（"多前体通道"，Maoz, Mannucci & Nelemans 2014，_ARA&A_，52，107），不同环境和时标对应不同渠道。

比较两类通道，要同时追踪供应、保留与点火：物质到达白矮星不等于全部留住，留住也不等于以同一种方式爆炸。许多紧密双白矮星形成模型经历过共包层，但这条常见路径不应变成一条对所有系统无例外的定义。[4][6]

单简并、双简并及双引爆等通道仍在比较中，观测正检验各自能解释哪些速率、光谱与环境。测距上的相关问题见[[标准烛光与Ia超新星测距]]：若人口组成随红移变化，需检验标准化后是否留下残差。爆炸物理本身见[[type-ia-supernovae|Ia型超新星]]。[6]

## X 射线双星：活跃的质量转移系统

**X 射线双星**（X-ray Binary, XRB）是质量转移正在进行的双星系统，其中致密天体（中子星或黑洞）从伴星吸积物质，物质落入的引力势能转化为 X 射线辐射：

$$
\begin{aligned}
L_{\rm acc}&\sim GM\dot M/R,\\
L_{\rm acc}&\approx1.2\times10^{38}\,\mathrm{erg\,s^{-1}}\\
&\quad\times\frac{M}{1.4M_\odot}\frac{10\,\mathrm{km}}{R}\\
&\quad\times\frac{\dot M}{10^{-8}M_\odot\,\mathrm{yr^{-1}}}.
\end{aligned}
$$

这个归一化对应中子星表面势能的数量级，并未保证全部能量都在 X 射线释放。黑洞应以吸积效率和相对论轨道来处理，不能把事件视界当成同样的物质表面。常按伴星质量区分的两类系统是：[4]

- **高质量 X 射线双星（HMXB）**：供体是较大质量恒星，可通过星风、Be星盘或溢流供给。
- **低质量 X 射线双星（LMXB）**：供体较轻，常通过洛希瓣溢流维持吸积盘。[4]

伴星质量定义了这种人口分类，供给几何却不与分类严格一一对应。风吸积与盘吸积可产生不同时间变化，同一类系统也可经历爆发与静默。把它们合成一个固定的“典型光度”，会掩盖质量供应和辐射效率的差异。[4]

LMXB 中的中子星可以被吸积物质自旋加速到毫秒级旋转周期——这是**毫秒脉冲星**（MSP）的一条重要形成路径，有时称为"再生脉冲星"（recycled pulsar）。毫秒脉冲星的自转极为稳定，可用作高精度时钟，在脉冲星计时阵列中探测引力波背景（PTA 计划）。

正在转移的系统让洛希瓣与吸积理论接受观测检验。物质在[[accretion-disks-relativistic-jets|吸积盘]]及靠近致密星的区域释放能量；光谱与时变记录的是温度、供给与几何。公式中的吸积率、致密星质量和半径都已注明，才能理解为何相同质量供应会在不同受主上发出不同光度。[4]

HMXB 跟着年轻星协走，伴星寿命短，转移窗口也短；LMXB 可以在长得多的时标上慢慢吸，把[[中子星与脉冲星|中子星]]自旋到毫秒。再生之后的脉冲星离开吸积盘，成为计时阵列的钟。[[x-ray-binaries|X 射线双星]]是这条链还在发光的阶段，[[pulsar-timing-array|脉冲星计时阵列]]是它熄灭之后留下的时钟网络。天鹅 X-1 与半人马座 X-4 分别站在风吸积和盘吸积两端，不能互相当成对方的近景。

## 双星对引力波天文学的贡献

LIGO/Virgo/KAGRA 探测到的引力波事件几乎全部来自双致密星系统的并合：

- **BBH（双黑洞并合）**：可来自孤立双星演化、化学均一演化或动力学组装等路径。
- **BNS（双中子星并合）**：GW170817及其千新星将引力波与重元素合成联系起来。
- **NSBH（中子星—黑洞并合）**：GW200105与GW200115在2020年被探测，2021年发表联合分析；探测年与论文年须区分。[7][9][10]

三种末端组合并不各自对应一条唯一的前身史。孤立演化的双中子星必须在形成两颗致密星的质量损失和踢速度后仍然束缚，动力学环境则还会发生交换与遭遇。化学均一模型中，快速旋转混合可让大质量星保持紧凑；它不是“另一种共包层摩擦”。[4][7]

2023年刊印的 GWTC-3 给出首三次观测运行累计90个天体物理起源概率大于0.5的候选，其中新分析的O3后半段包含35个。这不是“O3单次发现90个”，也不是截至2026年的当前事件总数。目录的质量与自旋分布为形成模型提供约束，仍带有探测选择效应。[8]

地面干涉仪主要测量双致密星并合末段的波形，推回恒星形成史需要中间模型。共包层、稳定质量转移、旋转混合和星团相互作用都可能留下不同的质量与自旋分布，却也存在重叠。不能从“观测到双黑洞”直接读出两颗前身星曾经共处哪一层包层。[4][7][8]

GW170817 把[[引力波]]波形接到了千新星 AT2017gfo。[[binary-neutron-star-merger-kilonova|双中子星并合与千新星]]讨论的电磁证据，与 [[kilonova-r-process|千新星与r过程]]中的核合成模型相互约束；光谱重分析中的锶识别，比“已直接看见全部镧系元素”更具体也更有限。若有可靠红移，还可以将这类系统作为[[标准汽笛与引力波宇宙学|标准汽笛]]，其距离路径与 Ia 型烛光不同。[10]

## 跨域连接

- **[[参考系与惯性|参考系与惯性]]**：经典洛希势在圆轨道的共转系中同时写入引力与离心项，L1是其鞍点。这个几何模型让溢流有了可计算边界；偏心、异步自转或显著辐射作用需要额外处理。不能把坐标系中的临界势面，当成与运动状态无关的一堵墙。[3][4]
- **[[control-theory|控制论]]**：质量流失后，施主半径与洛希瓣半径会各自变化。若失去一点质量使施主更超出瓣面，反馈就可能放大溢流；热调整与绝热响应又对应不同时间尺度。判断稳定性须比较这些响应，而不是只凭一次测得的高转移速率给系统贴上“必然共包层”的标签。[4]
- **[[monte-carlo-methods|蒙特卡洛方法]]**：种群合成对初始质量、轨道和演化参数抽样，再将末端人口与观测比较。若修改共包层参数与踢速度分布能得到相似并合率，单一率值就不能分别确定它们。应比较更多分布，并把选择函数和参数简并写入误差，而不是只挑一个最合意的参数值。[5][8]
- **[[spectroscopy|光谱学]]**：表面碳氮氧丰度可显示内部加工物质是否被混合或剥露出来，给质量转移提供线索。但单星旋转混合与演化浚深也会改变表面组成；一种氮增丰指纹不能独自证明伴星曾经供料。轨道、其他元素及演化状态一起使用，证据才更有辨别力。[4]
- **[[标准烛光与Ia超新星测距|标准烛光与Ia超新星测距]]**：爆炸通道的组成、点火密度和年龄分布会影响光变与光谱。若这些分布随环境变化，标准化残差就需要检验。前身星未决不使测距自动失效，却要求把经验标定与未观测到的通道变化分开评估，而不能假定样本量增加就消除全部误差。[6]
