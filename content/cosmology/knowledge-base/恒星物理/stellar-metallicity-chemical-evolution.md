# 恒星金属丰度与化学演化：宇宙如何铸造重元素

## 概述

太初核合成主要留下氢、氦与少量轻核。碳至铀等元素随后通过恒星燃烧、爆炸和中子俘获等途径形成，锂、铍、硼的一部分还来自宇宙射线散裂。追踪产物如何混合、流失、被锁入后来的恒星，就是**星系化学演化**的核心问题。[1]

通过分析不同年龄恒星（年龄需独立估计，不能直接用金属丰度替代）的化学组成，天文学家可以重建银河系的"化学考古记录"——就像地质学家从岩层中读取地球历史一样，只是时间尺度是数十亿年，地点是整个银河系。GCE 关心的不是单次核反应的细节清单，而是**产率、延迟时间分布、气体流入流出与恒星形成史如何共同把星际介质的丰度向量推着走**。同一套元素表，在不同星系里会走出完全不同的轨迹。把 GCE 写成"恒星吐出什么元素"的清单加总，会漏掉气体何时流入、何时被锁进长寿恒星、何时被风吹走这一步：产率表只给出每次吐出量，观测到的是被时间与循环重新编排后的残余。

化学演化研究的工作语言是丰度比，而不是元素清单。$[\mathrm{X/Fe}]$ 这类对数比把共同的整体金属标度消掉，突出不同合成通道的相对权重；再配合恒星年龄、轨道与空间分布，才能把" enrichment 历史"从"此刻看到的丰度场"里解出来。这也是为何 GCE 与恒星核合成综述必须分开写：后者罗列反应与产率来源，前者追问这些产率如何在星系尺度上被时间与气体循环重新编排。一篇合格的化学演化叙述，应能说明"若把 Ia 延迟拉长一倍，膝部往哪边移"，而不是只复述氧来自核心坍缩。

## 破除误解：天文学里的"金属"包括氧和碳

天文学家说的**金属**（metallicity）指的是**比氦重的所有元素**——氧、碳、氮、氖全算金属，尽管化学上它们是非金属。

“金属”在天文学中只是组成的约定分类，并不对应化学上的导电性。原初气体也并非只有两种核素，后来的锂等轻核又有多条来源；这套术语方便描述重元素含量，却不能代替核合成渠道的逐项分析。[1]

金属总质量分数记为 $Z$，而铁氢对数比记为 $[\mathrm{Fe/H}]$。氧在近太阳组成中是重要金属成分，但铁、氧和总金属丰度不是可无条件互换的观测量；非太阳比例的α增强星尤其需要区分。[1]

**第二个误解：金属丰度不是年龄。** 常听到"金属丰度越低越古老"，这在同一个星系的同一处大致成立，但作为普遍规律是错的。原因是化学增丰**不是全宇宙同步的**——它取决于局部的恒星形成史。一个恒星形成极其活跃的星系，可能在很早的宇宙里就把金属丰度拉得很高；而一个至今几乎不形成恒星的矮星系，其恒星今天仍然极度金属贫乏。

金属丰度也不是严格的“世代计数器”：相同代数的恒星可以有不同质量分布和产额，少量高产事件、不同稀释量或金属外流都能改变结果。它记录增丰与气体循环的共同历史，需要配合年龄和运动学才能约束形成过程。[1][2]

## 现场：一张 α/Fe 图如何还原星系的一生

化学演化最有力的工具是一张二维图：横轴是铁丰度 $[\mathrm{Fe/H}]$，纵轴是 α 元素与铁的比 $[\alpha/\mathrm{Fe}]$（α 元素指氧、镁、硅、钙这类由 α 粒子逐个堆叠而成的核）。

有用的是不同来源的**延迟时间分布**，而非一个固定的百倍时间差：

- **核心坍缩通道**：大质量恒星常在数百万到数千万年后供给α元素及部分铁。
- **Ia型超新星**：白矮星热核爆炸可有不同前身通道；最早事件受白矮星形成所需约数千万年限制，延迟分布可延伸至数十亿年，而非全在十亿年才开启。[3][4]

于是这张图上出现一条特征形状：

1. 在大质量星首先供给产物的阶段，常出现较高α/Fe。
2. Ia型逐渐贡献更多铁后，某些系统的α/Fe下降，形成膝部；变化发生的时间与铁丰度依赖成星史、延迟分布和气体流动。[2][3]

**膝部位置可限制成星与增丰速度，但需要模型。** 恒星形成剧烈而短暂的系统（如银河系厚盘、椭圆星系），在 Ia 超新星赶到之前就把铁丰度推得很高，膝部出现在高 $[\mathrm{Fe/H}]$ 处；而形成缓慢的矮星系，膝部可出现在较低铁丰度处；这不等于绝对时间一定更早。

**这就是"银河系考古学"的核心方法**：今天测一批恒星的化学成分，就能反推出它们诞生时那团气体的历史，从而重建星系过去上百亿年的恒星形成史——**借助长寿命恒星留下的记录与演化模型**。近年盖亚卫星（见[[宇宙学观测--天体测量与盖亚卫星|天体测量与盖亚卫星]]）把运动学数据与化学丰度结合，正是靠这套方法识别出了银河系早期并合留下的恒星族群。化学与轨道给出互补但可能相关的信息，才可能把已被相空间打散的残骸重新认出来。

把膝部读成"快慢计"时，还要同时看气体稀释：持续的低金属流入会把横轴上的 $[\mathrm{Fe/H}]$ 往左拉，使膝部看起来更"早"；强恒星风则可能把已增丰气体带走，改变平台高度。因此 α/Fe 图是强诊断，却不是无模型读数器——同一条曲线可以对应多种流入/流出组合，必须用更多元素比与恒星形成率约束来拆开。

## 元素合成的核心机制

不同元素有不同的合成渠道：

| 来源                       | 重要产物及时间条件                              |
| -------------------------- | ----------------------------------------------- |
| 太初核合成                 | 主要氢、氦及少量轻核，最初数分钟                |
| 大质量恒星与核心坍缩       | 氧及许多α元素、部分铁族，短延迟；产额随模型而变 |
| AGB星                      | 碳、氮及不少s过程核，随初始质量有不同延迟       |
| Ia型超新星                 | 很多铁族核，延迟分布宽                          |
| 中子星并合与可能的罕见爆炸 | r过程核；事件率、产额、延迟和混合共同决定贡献   |
| 宇宙射线散裂等             | 锂、铍、硼的一部分，需与其他来源共同计量        |

GW170817的引力波与千新星资料支持中子星并合能制造重元素。2019年Watson等在其光谱中识别出锶；早期光谱与光变对重r过程物质的推断还依赖不透明度和抛射模型，与逐项辨认元素谱线属于不同层次的证据。[5][6]

对 GCE 建模而言，重要的不是把上表背成百科，而是抓住**延迟时间分布（DTD）**：同样是"造铁"或"造铕"，若事件发生得早晚不同，丰度比对恒星形成脉冲的响应就完全不同。产率表给出每个事件吐出多少；DTD 给出这些事件何时吐出。化学演化方程本质上是恒星形成率与各通道核的卷积。

r 过程尤其能说明这一点：若主通道是中子星并合，延迟可很长，贫金属星铕散射大；若存在很早的稀有坍缩通道，散射图案会不同。$[\mathrm{Eu/Fe}]$ 散布同时约束产率与 DTD，而不是只回答"铕从哪来"。

## 简单闭箱模型

最基础的 GCE 框架是**简单闭箱模型**（Simple Closed-Box Model），假设：

1. 系统初始无金属（$Z = 0$）
2. 气体在内部转化为恒星，无流入或流出
3. 恒星即时增丰（瞬时回收近似）
4. 气体瞬时均匀混合，初始质量函数和净产率等按所用简单模型固定。[2]

在这些假设下，金属丰度 $Z$ 与气体质量分数 $\mu = M_{gas}/(M_{gas}+M_{stars})$ 的关系为：

$$Z = -p \ln \mu$$

此处 $p$ 是每单位**最终锁在长寿命恒星与残骸中的质量**所新合成并返还的金属质量，而不是每形成一单位恒星就返还的全部金属；必须区分新生产物与原来已有的金属，以及返还分数。[2]

闭箱模型给出近似 $dN/dZ\propto e^{-Z/p}$；若改用对数金属丰度作横轴，则还要乘相应雅可比因子，形状并非同一句“越贫越多”。它对太阳邻域长寿命G矮星的金属贫端预测过多，构成经典的G矮星问题。[2]

持续流入允许星盘在尚未形成大量贫金属长寿命星前，积累气体并增丰，从而改变丰度分布；它不只是把气体“稀释一下”。不同流入史、预增丰、流出和非瞬时回收模型提供不同解释，应同时与多项观测比较。[2]

流出（风与喷流带走金属）同样关键：它降低有效产率，并让矮星系更容易停在低金属丰度。现代 GCE 很少再谈"真正封闭的箱子"；闭箱公式的价值在于提供可解析的零阶对照，用来诊断流入、流出与延迟增丰各自缺了哪一项。流入模型还常把星盘形成拆成不同时标的脉冲：早期快速内流解释厚盘的高 α 平台，晚期缓慢内流解释薄盘的持续增丰与较低的 $[\alpha/\mathrm{Fe}]$。这样，G 矮星问题与 α/Fe 膝部不再是两套故事，而成为同一气体循环图像的不同投影。

## $[\alpha/\text{Fe}]$-$[\text{Fe}/\text{H}]$ 图：化学演化的指纹

$[\alpha/\text{Fe}]$ vs. $[\text{Fe}/\text{H}]$ 图是 GCE 研究中最信息丰富的诊断工具之一：

- 高α平台可以反映大质量星先供给产物，但平台高度随元素、产额和初始质量函数而变。
- 膝部不固定在 $[\mathrm{Fe/H}]=-1$；不同环境、不同序列可以不同。
- $[\alpha/\mathrm{Fe}]=0$ 仅表示数目比与所选太阳基准相同，不表示两类超新星各贡献一半或达到动力学平衡。[1][2]

这张图在不同星系环境中表现不同：

- **椭圆星系**：由于星形成历史短暂且强烈，即使在高金属丰度时也保持高 $[\alpha/\text{Fe}]$
- **矮球状星系**：星形成缓慢，Ia 型超新星来得及在低金属丰度时就贡献 Fe，导致"膝点"出现在更低的 $[\text{Fe}/\text{H}]$；具体位置依系统的成星和气体交换历史而异

今天存活的矮星系丰度模式，不能直接替代早已并入银河的所有矮星系。Helmi等2018年联合运动、年龄与化学资料，提出内晕很大部分来自Gaia–Enceladus的并合残骸；这正说明不同质量和成星史的被吞并系统需分别研究，不能由当前某些卫星不匹配便排除所有吸积起源。[7]

## 银河系考古学：从当下推算过去

"**银河系考古学**"（Galactic Archaeology）是利用今天仍存在的恒星的化学成分来重建银河系的形成历史。核心思想：

- 足够低质量的恒星寿命可以超过宇宙当前年龄，因此保留早期气体的部分信息；一倍太阳质量约百亿年的主序寿命本身并没有超过138亿年。
- 表面丰度也会受扩散、挖掘、内部混合或双星污染改变，尤其轻元素需谨慎；它不是完全不变的出生标签。

近年来大规模分光巡天（APOGEE、GALAH、Gaia-ESO 等）已经系统测量了数十万颗恒星的详细元素丰度，使 GCE 进入"精确化学考古"时代：

- **APOGEE DR17**：官方记录约657,000个独立目标、266万次单次观测，最多报告20种谱学物种的丰度；物种与元素数不完全相同，也不是每个目标都有全部可靠丰度。[8]
- **GALAH DR3**：官方记录678,423条光谱、588,571颗恒星，观测来自2013年11月至2019年2月。这是指定发布版的历史样本，不能归给2015年的项目动机论文或称为2026年最新总量。[9]

大规模巡天把 GCE 从"几十颗恒星的精细故事"推进到"数十万颗恒星的统计地形图"。随之而来的是选择函数问题：红外巡天更易穿透尘埃盘、光学巡天更敏感晕与厚盘、测光预选会偏好某些颜色—星等切片。若不校正选择函数，"化学地图"会把观测偏置误读成形成历史。精确化学考古的一项关键工作，是搞清楚样本如何被挑选进来。当盖亚的六维相空间与 APOGEE/GALAH 的丰度向量对齐后，"化学—动力学"联合标签可以把已被潮汐打散的并合残骸从盘星背景中剥离出来。重建的不是一张漂亮化学地图，而是可检验的组装时间线：哪次并合带来了哪些贫金属、高偏心轨道的恒星。

年龄仍是最难的一维：等时线、星震与化学时钟并不总一致；色标涂错会把"同时形成"画成"先后形成"。化学考古要在丰度、轨道与年龄三条轴上同时控制系统误差，而不是以为测得越多元素就越确定。

### 化学标签（Chemical Tagging）

化学标签尝试利用多元素丰度识别共同起源候选，但“相似”不等于“同一云”。不同成星区可能走过近似的增丰路径，恒星表面也可被改变；丰度测量误差和相关系统误差会压缩有效信息。运动学与年龄可帮助检验候选，却与组成并非统计上天然独立。需要用已知星团和模拟检验误认率，而不能预先断言某个金属丰度段已保证唯一识别。

## 初始质量函数（IMF）对化学演化的影响

**初始质量函数**（Initial Mass Function, IMF）描述了单次星形成事件中不同质量恒星的数量分布，对 GCE 结果有深刻影响：

$$\xi(m)\equiv\frac{dN}{dm}\propto m^{-\alpha}$$

- **Salpeter式高质量近似**：以 $dN/dm$ 为定义时常用 $\alpha\simeq2.35$，不能与 $dN/d\log m$ 的斜率混淆。
- **Kroupa形式**：低质量端采用分段幂律。
- **Chabrier形式**：低质量端常用对数正态描述；单星与系统质量函数需区分。

初始质量函数的高质量端影响核心坍缩率、α元素及电离光子产额；低质量端影响存活恒星和质量光度比。Kroupa等的综述讨论了简单与复合星族的初始质量函数及环境依赖问题。环境差异仍需与选样、双星和动力学处理共同检验，不能把某种模型主张写成所有星系已达共识。[10]

对解释者而言，IMF 不确定性与产率不确定性高度纠缠：观测到的高 α 既可以来自更 top-heavy 的 IMF，也可以来自更高的单星 α 产率或更短的星形成时标。GCE 的诚实做法是把这些 degeneracy 写进误差预算，而不是用单一旋钮强行拟合膝部位置。

换句话说，化学演化的可观测量是高度积分后的结果：有效产率随 IMF 加权，延迟核随双星演化与星团环境变化，气体循环又把局域增丰抹平或稀释。读 α/Fe 膝部、G 矮星分布或 r 过程散射时，真正在比较的是这些积分核，而不是某一次爆炸的核物理细节。把 GCE 写成核合成条目的加长版，会丢掉这个尺度跃迁。因此比较不同星系的膝部或 r 过程散射时，必须先声明所用的 IMF、DTD 与流入假设；否则表面上的"化学差异"可能只是建模旋钮不同。

高红移"top-heavy"暗示同时抬高 α 产率与电离光子预算，把化学与再电离绑在同一旋钮上。若本地 IMF 不能外推，用本地产率反推高红移金属排出的系统误差，足以改写"早期星系已经很金属丰"的结论——GCE 在此成为宇宙黎明化学的边界条件。

## 跨域连接

- **[[paleontology-and-stratigraphy|古生物与地层学]]**：两者都从现存记录重建历史，但恒星没有一条天然可见的沉积层序。金属丰度受到产额和稀释影响，既非统一时钟，也非精确加工代数；年龄与动力学帮助建立顺序，仍需保留模型的多解性。[2][7]
- **[[signal-processing|信号处理]]**：恒星形成率与不同来源的延迟核卷积，产生后来才见到的供给率。输入、延迟核和气体混合都未知时，反卷积可能不稳定；多种元素及独立年龄能增加约束，却不会自动消除所有退化。[3]
- **[[principal-component-analysis|主成分分析]]**：元素共同来源会造成丰度相关，但有效维数还受样本、误差和波段影响，不能事先固定成α与铁两根轴。降维有助于发现结构，也可能把真正少见的核合成信号与系统偏差混在同一分量里。
- **[[epidemiology|流行病学]]**：只看存活恒星会偏向低质量和长寿命对象，高质量早期成员则需借残骸与产额模型间接研究。巡天还有亮度、颜色和空间选择；把存活偏差与观测漏检分开，才能可靠重建过去的人口。[8][9]
- **[[恒星流与星系晕|恒星流与星系晕]]**：化学、轨道和年龄各有误差，也可能因共同形成史而相关。Gaia–Enceladus的研究联合这些信息寻找一致的残骸群体；关联证据比单一标签更强，但仍需同银河背景与选择函数比较。[7]
