# 大质量恒星演化：燃烧的快速人生

## 概述

初始质量约 $8\,M_\odot$ 以上的恒星可能经历核心坍缩，边界依赖组成、混合与质量交换。它们的主序寿命常只有数百万到数千万年，随后依次处理更重燃料；一些成功爆炸，另一些可能直接或经落回形成黑洞。大质量星是氧及许多α元素的重要来源，但碳、氮、铁和慢中子俘获元素还分别有AGB星、Ia型超新星等贡献，不能统称它们包办所有重元素。[1][2]

大质量恒星数量虽少，却以强紫外辐射、风和爆炸影响周围气体。它们的光度和终生总能量是不同物理量：终生辐射要对随时间变化的光度积分，并受可用核燃料约束，不能把一颗恒星夸成数十亿颗太阳持续数十亿年的总辐射。

这篇要写的不是元素表，而是钟和层：燃料更多为什么活得更短，洋葱壳为什么一层套一层，铁核为什么是静静燃烧的终点。核反应的截面与丰度峰见[[恒星核合成]]；氦闪、第三次挖掘和行星状星云是中低质量星的晚年，见[[red-giants-agb|红巨星与渐近巨星支]]，这里不重写。四条结构方程怎样联立求解，见[[stellar-structure-hydrostatic-equilibrium|恒星结构与流体静力平衡]]那一篇；本文只取大质量这一支的时标、分层和铁核终点。

## 破除误解：大质量恒星不是"燃料更多所以活得更久"

燃料多不保证寿命长。对许多主序质量范围，光度增加得比燃料储量快，所以较重恒星更快耗尽核心氢；然而能参与燃烧的质量比例、时间平均光度及旋转混合也随质量改变。寿命的一般燃料估算是：[3]

$$t_{\rm MS}\simeq\frac{q_cX_0\eta Mc^2}{\langle L\rangle}$$

其中 $q_c$ 是有效参与质量比例、$X_0$ 是初始氢比例、$\eta$ 约为0.007。只有再假定这些比例不变且光度按质量的3.5次方变化，才得到负2.5次方寿命近似；它不能外推到最高质量端，也不能把25倍或100倍太阳质量的详细模型寿命说成由同一简单公式算出。[3]

近太阳组成的大质量主序星常由CNO循环主导，强烈的温度敏感性使产能集中，并促进对流核。辐射压、不透明度和能量输运又会改变结构及质光关系。功率与燃料的共同变化解释了短寿命；仅凭某一条反应率的温度指数，并不能导出唯一的质光指数。[3]

**这个事实有一连串重要推论：**

- 你今天看到的任何一颗大质量蓝色恒星，通常提示较年轻的恒星群体。所以哪里有 O 型星，哪里常能追溯近期的恒星形成，但逃逸星和双星再生等会使简单年龄判断失效——它们是恒星形成区的路标。
- 银河系历史上很早形成的大质量星，早已结束主序生命。我们能研究的只是最近一批。
- 短寿命的大质量星能在较早阶段迅速把核合成产物抛回星际，加快早期增丰；较低质量星随后也以不同时间延迟贡献元素。新生恒星因此可以继承前代留下的金属（见[[第一代恒星PopulationIII]]）。

**换句话说，大质量恒星短命不是缺点，而是宇宙能在有限时间里变得"化学上复杂"的前提条件。** 它们是宇宙的加速器。

## 晚期燃烧为何加速

下面采用一个15倍太阳质量模型示例：核心氢燃烧约1100万年、氦约200万年、碳约2000年，氖和氧降至年量级，硅只剩约18天。不同质量和物理输入会改写数值，却保留晚期明显加速的趋势。[1]

- **每一步的收益越来越薄**。核结合能曲线在接近铁时趋于平坦，所以烧同样质量的燃料，碳燃烧释放的能量远少于氢燃烧。
- **散热漏洞越来越大**。核心温度升高后，能量越来越多地以**中微子**形式直接逃逸（中微子几乎不与物质作用，在坍缩前的许多燃烧条件下能有效逃逸；坍缩到高密度后则会被困住）。这等于在锅底开了个洞——恒星必须烧得更猛，才能补上不断扩大的亏空。

到铁族附近，继续聚变不再能维持同样的放能链。核心仍有热能、简并支撑和外壳燃烧，不能说整个星体的能源在同一瞬间归零；失稳要结合电子俘获、核分解和增长中的核心一起计算。[1][2]

把各阶段的时标读成空间上的分层：外层氢壳还在燃烧的时候，核心早已换成氦、碳、氧、硅，最内层停在铁族。洋葱不是把整颗星依次替换成下一种燃料，而是灰烬变成下一层的燃料，外层炉子还亮着、内层已经在下一档。硅燃烧只剩天到周量级，是因为结合能曲线在铁附近变平，加上中微子把能量直接带走，两件事叠在一起，使临终核心变化明显快于包层的许多响应。

把数百万年的寿命压缩成人的几十年，晚期燃烧只剩短短一瞬。这种比喻能帮助理解时标差异，却不能提供爆发日期：表面温度和光度不唯一对应内部壳层布局。前身星研究要把光学、红外、质量损失及可能的前超新星中微子信息联合起来，才能逐步收窄核心所处阶段。

## 主序阶段：氢燃烧

对近太阳组成的大质量恒星，零龄主序（ZAMS）核心的氢燃烧通常由 **CNO 循环**主导；极低初始CNO丰度的对象需另行处理：

$$
\begin{aligned}
4\,{}^1\mathrm H&\longrightarrow{}^4\mathrm{He}\\
&\quad+2e^++2\nu_e+\text{能量}.
\end{aligned}
$$

这一净反应中，C、N、O核充当催化核，在主循环结束时被再生。反应率的强温度依赖使能量集中在核心，常出现充分混合的对流核；低初始CNO丰度、旋转和边界混合都可能改变细节。[3]

氢燃烧的有效库存并非整颗星的全部质量。对流核越大、核外混合越强，越多氢可以参与；因此模型需要同时给出燃料和光度随时间的变化。

特别高质量处的辐射压重要，质光曲线变缓，寿命也不再沿简单的负2.5次方继续陡降。直接把该幂律代入100倍太阳质量会得到约十万年，显然不能再声称它导出了几百万年的详细模型结果。[3]

核心氢耗尽后，留下的氦核继续收缩，氢壳层仍在外面燃烧。后续膨胀到红超巨星、保持较蓝状态，或因风与双星作用剥离包层，取决于质量、组成和混合。核心和包层的响应相联系，却不按一个统一的颜色顺序演出。

## 主序后演化：洋葱壳结构

大质量恒星在离开主序后相继点燃越来越重的燃料，形成经典的**洋葱壳结构**：

| 15倍太阳质量示例的核心燃烧 | 主要产物     | 持续时间 |
| -------------------------- | ------------ | -------- |
| 氢                         | 氦           | 1100万年 |
| 氦                         | 碳、氧       | 200万年  |
| 碳                         | 氖、钠、镁等 | 2000年   |
| 氖                         | 氧、镁等     | 0.7年    |
| 氧                         | 硅、硫等     | 2.6年    |
| 硅                         | 铁族混合物   | 18天     |

此处为Pols讲义所列15倍太阳质量模型示例，原表引Woosley、Heger与Weaver；不是25倍太阳质量所有阶段的通用时钟。[1]

每一层壳都是上一阶段的灰在新的温度上被重新点燃：氦灰在氢壳底下烧成碳氧，碳氧灰再在更深更热处烧成氖镁，如此直到硅。壳与壳之间有熵和平均分子量的跳变，对流不容易把它们彻底搅匀，所以临终结构看起来像分层的洋葱，而不是均匀的一团铁。表里的温度和时标对应一个十五倍太阳质量的单星模型，金属丰度、自转和双星质量转移都会改各层的质量，但越往里时标越短、最内层停在铁族是常见铁核前身模型的主干；边界附近也有氧氖镁核的电子俘获坍缩例外。

### 铁核——核燃烧的终点

铁族核素处在结合能峰区；所谓铁核是核素混合物，不必是纯铁-56。冷简并物质的极限给出约1.4倍太阳质量的尺度，但演化核心的有效稳定质量依赖熵与电子丰度。电子俘获降低支撑，核分解消耗热能，铁核随后可在十分之几秒的动力学时标上收缩。[1][2]

铁核长大的同时，光致分解开始拆已经结合的核，电子俘获把质子变成中子并放出中微子，两条路都从压强账里抽走能量。电子简并压本身几乎不随温度升高而变强，所以铁核可以一边丢能量一边仍被同一份量子压强托着，而电子俘获又会降低其可支撑的有效质量。失稳之后，支撑在不到一秒内失效，这是核燃烧终点在流体静力上的表现，不是燃料用完那么简单。

坍缩之后激波能否把整颗星炸开，是[[core-collapse-supernovae|核心坍缩超新星]]的机制问题，本文停在静静燃烧在这里结束。留下中子星还是黑洞，要等落回质量和核物质状态方程一起决定，并不能单凭初始质量读出答案。

## 质量损失：决定命运的关键变量

质量损失把初始质量与临终核心之间的联系变得更复杂。热OB星和WR星可有辐射驱动风，红超巨星风与LBV喷发还涉及不同的气体、尘埃和不稳定过程，不能把所有阶段都写成同一种风。

观测风的谱线及尘埃辐射，再结合大气和流动模型，才能推断质量损失率。团块结构、风速度和几何都会进入估计；这些数值既改变核心最终质量，也影响爆炸前周围介质的密度。[4]

Vink等2001年的OB星风模型，在指定金属范围并计入终端风速的金属依赖后，给出高温支约 $\dot M\propto Z^{0.69}$、较冷B超巨星支约 $Z^{0.64}$。这不是所有WR星、红超巨星风或爆发式质量损失的统一定律。较弱的低金属丰度线驱动风有利于保留质量，但高红移也不等于每个环境都具有相同低金属丰度。[4]

恒星风把外层剥掉，等于在爆炸前改写洋葱的外几层：氢包层若被剥光，超新星光谱里就看不到氢线，分类就会从带氢的二型变成几乎无氢的一型。在相应线驱动风模型的适用范围内，较低金属丰度有利于保留质量；最后黑洞有多重仍取决于爆炸、回落和对不稳定等过程，不能仅由红移或星风单独决定。风损耗不是写完核燃烧再贴上去的修饰，而是把初始质量翻译成最后残骸质量时必须经过的一层。

## 演化路径：一张简化的分叉图

演化结局需要联合初始质量、组成、旋转、质量损失与双星史。下列分叉表示可能的物理路径，不提供一张按初始质量必然决定残骸的查表：

```
保留较厚氢包层 → 红超巨星等前身 → 成功爆炸可表现为II型
包层被风或双星剥离 → 氦星等前身 → 可产生部分IIb/Ib/Ic型
核心坍缩后激波未能成功抛射 → 直接或经落回形成黑洞的候选通道
足够重的氦核 → 脉动或完全对不稳定爆炸，边界依赖核物理与模型
```

对不稳定取决于核心状态，不能简化为“初始质量超过100倍太阳质量便爆炸”。例如Heger与Woosley的零金属、特定反应率模型研究了64–133倍太阳质量氦核的完全破坏；这些条件不能直接移植到所有风损耗和旋转模型。[5] 观测上，N6946-BH1在2009年爆亮后光学变暗，仍是失败超新星候选。2024年JWST分析指出混合光源和恒星并合的替代解释；2026年9月修订的重分析则认为其晚期变暗特征仍与失败超新星较相容。两组对同一目标的分解和模型不同，尚不能把暗源等同于已直接确认黑洞。[6][7]

## 对流与混合的不确定性

大质量恒星内部有多个对流区，对流边界的精确位置（超射/overshoot 参数）对演化路径有显著影响：

- 较大的超射参数意味着更大的对流氢燃烧核心，延长主序寿命，增加氦核质量
- 超射参数的不确定性是恒星演化理论中最大的系统误差来源之一[3]

混合改变氦核与后续壳层结构，进而影响前身星和残骸预测。光度、温度、风和表面丰度能限制这些模型，却难以唯一重建最内层的结构。

对流边界的处理不是一个可随意忽略的小修正。混合更强可扩大氢燃烧燃料库，但最终爆炸还要看壳层密度梯度与吸积史；不能把超射参数直接转换成“是否越过固定铁核极限”的一维开关。[2][3]

## 元素合成的贡献

大质量恒星的重要核合成贡献包括：

- **碳和氧**：来自氦燃烧（三阿尔法过程 + ${}^{12}\text{C}(\alpha,\gamma){}^{16}\text{O}$）
- **氖、镁、硅、硫、氩、钙**：来自碳、氖、氧燃烧
- **铁族元素（Cr、Mn、Fe、Ni）**：来自硅燃烧和爆炸性核合成
- **弱 s 过程元素**：氦燃烧和碳燃烧壳层中的慢中子捕获（约 $60 \lesssim A \lesssim 90$）

爆炸冲击波会进一步改写氧、硅等层的组成，并可产生放射性镍-56。其衰变为钴-56、再为铁-56，能为不少事件的后期光变供能；平台、早期峰值或强相互作用事件还可能由其他能源主导，不能把整条光变一概归给同一衰变链。[1][2]

碳氧到铁族的产量由这些壳层的质量和爆发时冲击波扫过的条件决定，反应网本身见[[恒星核合成]]。本文只强调一件结构事实：大质量星的短寿命提供快速增丰通道；铁核的失稳解释了典型的铁核坍缩，而氧氖核还可能经电子俘获走向坍缩。

## 跨域连接

- **[[热传导对流与辐射|热传导、对流与辐射]]**：能量输运决定核心要多陡的温度梯度，浮力不稳定又使物质混合。边界附近的超射与其他混合会改变燃料库和后续氦核质量，因此对流并非只负责把热送出去，也在改变恒星能烧多久及留下多少灰烬。[3]
- **[[neutrino-physics|中微子物理]]**：晚期燃烧中，中微子可高效带走能量，加快燃料消耗；核心坍缩到高密度后，中微子又会被困住并参与输运。相同粒子的角色随密度与能量变化，不能把“弱相互作用很弱”简化成任何条件下都直接穿透。[1][2]
- **[[nuclear-chemistry|核化学]]**：结合能差决定不同燃烧阶段的单位燃料收益，却不能独自决定持续时间。可用燃料量、壳层结构和散热共同进入预算。到铁族附近，持续聚变失去此前的能源优势，但热能与简并压力不会在同一瞬间消失。[1]
- **[[falsification|可证伪性]]**：恒星变暗支持特定结局，也可能受尘埃或光源混合影响。N6946-BH1的两种JWST分析说明，替代解释需要具体光谱能量分布和晚期光度来比较；候选的科学价值正在于这些模型会给出不同、可继续检查的预测。[6][7]
- **[[第一代恒星PopulationIII|第一代恒星]]**：大质量恒星可以在较短时间内向周围气体注入新元素，改变下一轮成星条件。但第二轮恒星的组成还取决于抛射是否逃离宿主、混入多少原始气体，以及爆炸是否成功。短寿命提供快速增丰的可能，不保证每个后继系统具有相同金属丰度。[1][5]
