# 恒星核合成：宇宙元素的锻造炉

## 概述

**恒星核合成**（stellar nucleosynthesis）研究恒星内部及相关爆发现象怎样制造核素。太初核合成为宇宙留下了主要的氢、氦和微量轻核；此后的碳、氧、硅、铁以及许多更重的核，来自不同质量恒星、超新星和致密星并合的共同加工。锂、铍、硼还涉及宇宙射线散裂，不能把所有天然元素都归到普通恒星核心的一座炉子里。[1][4]

本文沿着几条反应路径读这份元素账：质子—质子链与 CNO 循环怎样维持主序，三阿尔法怎样造碳，晚期燃烧为何趋向铁族，以及慢、快中子俘获怎样继续构建重核。核反应能否发生与发生在哪里是两个问题；反应网要结合温度、密度、电子分数与恒星演化，才能变成可与丰度比较的产额。[1][2][4]

## 大爆炸核合成的遗产

太初核合成在宇宙最初数分钟至约二十分钟的膨胀冷却中，留下质量上大约四分之三的氢和四分之一的氦，并有少量氘、氦-3及锂-7等。质量数 5 与 8 缺少稳定核，加上密度迅速下降，使大量碳及更重核的生成受到抑制。“主要止于轻核”是在说丰度预算，不能当成任何微量重核反应都严格不可能的禁令。[4]

两个氦-4组成的铍-8极短命，通常还没遇到下一个反应伙伴就衰变了。在恒星维持的高温高密条件下，它仍能建立很小的平衡丰度，再捕获第三个氦核；碳-12的共振态使这一步显著增强。这解释了三阿尔法的路径，并不意味着所有重核过程都得重新从氦开始：后续中子俘获常以已经存在的重核作种子。[1][4]

## 恒星内部的核燃烧阶段

### 氢燃烧：质子-质子链与CNO循环

主序星核心将氢聚变为氦，通过两种途径：

**质子—质子链（pp chain）**：在太阳和许多更低质量主序星中占主导。两个质子先生成氘并放出正电子与中微子，氘再与质子生成氦-3；pp-I 支路由两个氦-3组成氦-4，同时释放两个质子。净效应是氢变氦、静质量的一小部分变为能量；在太阳中，pp 链承担约 99% 的产能，CNO 循环约占 1%，这些是太阳条件下的近似比例。[1][3]

pp 链的第一步涉及弱相互作用，速率很慢；这让太阳能长时间稳定产能。氦-3处还有其他支路：与氦-4形成铍-7后，铍-7可以俘获电子形成锂-7，也可以俘获质子进入硼-8支路。不同支路产生的中微子能谱不同，因此地面中微子实验可以检验恒星核心的反应，而不必等核心能量经辐射传到表面。[1]

**碳氮氧循环（CNO cycle）**：在中心更热、且已有 C、N、O 种子的恒星中，四个质子经一串反应转成氦-4，催化核循环使用。在近太阳成分的主序模型中，它通常在约 1.2—1.5 太阳质量以上变得重要；分界随成分和阶段变化。其局部温度敏感性可用很陡的幂律近似，不能把一个固定指数用于所有温区。[1]

CNO 循环与 pp 链有相同的主要净产物，却有不同的瓶颈和温度响应。更集中于核心最热处的产能会影响温度梯度和对流结构。Borexino 探测太阳 CNO 中微子，直接支持太阳内部存在这条链；从中微子通量再推到核心成分或精确光度份额，仍需要振荡参数、反应率与太阳模型。[1][3]

### 氦燃烧：三阿尔法过程

核心氢耗尽后，达到约一亿开尔文的条件可使氦燃烧显著进行。两个氦-4先短暂形成铍-8，铍-8再捕获一个氦-4，经过碳-12激发态衰变到较低能级，这就是**三阿尔法过程**。铍-8的寿命在十的负十六次方秒量级；它不是稳定库存，反应率取决于那一点点瞬时丰度。[1]

随后碳-12捕获另一个氦-4生成氧-16。三阿尔法过程和碳-12(α,γ)氧-16反应的竞争，是影响氦燃烧后碳氧比例的重要因素；最终送入星际介质的产额还依赖混合、后续燃烧与抛射。[1][2]

碳-12中的霍伊尔态使三阿尔法反应在恒星条件下高效得多。宇宙碳丰度可以反过来约束核反应所需条件，但共振能级本身仍须由核实验与反应理论检验。氦燃烧的时长也不是统一的十万年：一个十五倍太阳质量的示例模型约持续两百万年，低质量核心氦燃烧模型则可在一亿年量级；必须注明正在讨论哪一类恒星。[2][10]

### 更重元素的燃烧

大质量恒星依次点燃更重的燃料：

| 燃烧阶段 | 核心温度（K） | 主要产物 | 时长（特定 15 太阳质量模型） |
| -------- | ------------- | -------- | ---------------------------- |
| 氦燃烧   | 1.8×10⁸       | 碳、氧   | 约 200 万年                  |
| 碳燃烧   | 8.3×10⁸       | 氧、氖等 | 约 2000 年                   |
| 氖燃烧   | 1.6×10⁹       | 氧、镁   | 约 0.7 年                    |
| 氧燃烧   | 1.9×10⁹       | 硅、硫等 | 约 2.6 年                    |
| 硅燃烧   | 3.3×10⁹       | 铁族     | 约 18 天                     |

这些是 Pols 讲义所列、引自 Woosley、Heger 与 Weaver 模型的一组数值；质量、混合和微物理变化都会改变时标。[2]

晚期时标急剧缩短，不只因为每单位质量的核能收益变少，也因为中微子冷却带走大量能量。硅燃烧由光致分解和俘获等反应构成，逐渐接近核统计平衡；产物趋向铁族，但具体同位素组成受温度、密度、电子分数和反应时标共同控制。[2]

必须区分**静力燃烧留下的铁核心**与**爆炸性燃烧抛出的镍-56**。前者已经历中子过剩和电子俘获，不能统一说成“弱作用来不及，所以主要是质子中子相等的镍-56”。后者在电子分数接近二分之一等条件下可大量生成镍-56，再经钴-56衰变为铁-56。两条路径会在同一颗超新星前身星中出现，却不是同一份产物账。[2][4]

按原子质量表换算，镍-62的每核子平均结合能略高于铁-56。铁族在恒星核合成中的重要性，来自结合能峰区与反应路径；太阳系铁的丰度还叠加了 Ia 型超新星、核心坍缩、产率与化学演化，不能只用“生产停在镍-56”一句解释。静力燃烧没有继续供能的常规聚变链，并不等于一切铁以上核反应都不存在。[2][4][8]

## 慢中子捕获过程（s过程）

铁以上许多重核主要靠中子俘获生成。中子没有库仑斥力，较容易被核俘获；但截面仍取决于能量与核结构，不是“可以自由穿入”。带电粒子、光致反应及中微子相关过程也会制造部分铁以上核素，只是在整体重元素账目中占据不同份额。[4]

**s 过程**中，沿路径的不稳定核通常有时间在下一次中子俘获前发生 β 衰变；稳定核可以接连俘获，不要求每一步都先衰变。低质量 AGB 星的重要中子源是碳-13(α,n)氧-16，较热条件下还有氖-22(α,n)镁-25；大质量恒星的氦、碳燃烧中也有弱 s 过程。发生在哪一层、能够走多远，要看中子曝光与种子丰度。[4][5]

s过程产生的元素丰度在特定质量数附近（“峰”）处达到极大值，对应于中子幻数核（如锶-88、钡-138、铅-208）——这些核的中子壳层填满，截面较小，中子不易被捕获，因此"堆积"在这些核上。

## 快中子捕获过程（r过程）

**r过程**（rapid neutron capture process）发生在中子密度极高的环境中，中子捕获速率远快于β衰变。原子核在β衰变之前连续捕获大量中子，远离β稳定线，许多产物再通过一系列β衰变趋近稳定核区。r过程产生金、铂、铀、钍等最重的元素。

GW170817 的电磁对应体 AT2017gfo 在 2017 年表现出与放射性加热的快速抛射物相容的千新星辐射。随后光谱重分析辨认出锶，为并合中的重元素合成提供了更具体的元素证据。抛射质量、镧系份额乃至金和铂的分别产额，仍依赖辐射转移和丰度模型；不能把总抛射质量换成已实测的若干个地球质量的黄金。[6][7]

> **“戒指来自一次并合”须留在证据范围内。** 太阳系形成前的气体经历了多种事件的混合，具体一枚戒指的原子不能被逐个追溯到某次爆发。中子星并合能制造 r 过程物质，不等于太阳系每一种重元素都只由并合贡献；s 过程以及较小的其他通道同样要入账。[4]

r过程的另一可能场所是大质量恒星核心坍缩超新星中的中微子驱动风——但近年来的研究表明，典型超新星的条件可能不足以产生显著的r过程元素。磁旋转超新星（具有极强磁场和快速自转的特殊情形）可能是更有效的r过程场所。

## 超新星核合成

核心坍缩超新星爆发时，多种核合成过程同时发生：

- **冲击波加热**：冲击波经过不同层时可触发爆炸性氧、硅燃烧，形成铁族及中等质量核。镍-56衰变链会给许多超新星的晚期光变供能；早期光度还可能由冲击冷却、氢复合或环周相互作用主导。
- **中微子过程**：中微子与外层核反应，可对部分轻核或稀有同位素作出贡献。
- **富中子外流**：是否能走到重 r 过程，取决于电子分数、熵、膨胀时标等；不能把所有普通核心坍缩都当成金、铂的稳定工厂。[4]

超新星抛射物的元素丰度模式可以通过光谱观测与理论模型的比较来验证——这是核天体物理学最重要的观测检验之一。

静力阶段已经建立元素分层，爆发时的冲击波再改写各层的温度和反应网。一部分铁核心留进致密残骸，另一些铁族在可被抛出的爆炸燃烧区形成；回落、爆炸能量与质量切割又改变真正送入星际介质的份额。反应网给出“制造了多少”，化学演化需要的则是“最终抛出了多少”。[2][4][9]

## 元素起源的完整图景

不同元素在不同天体环境中合成：

| 元素或核素类别           | 主要贡献通道的示意                                      |
| ------------------------ | ------------------------------------------------------- |
| 氢、原初氦及微量轻核     | 太初核合成；恒星继续制造氦                              |
| 锂、铍、硼               | 太初、宇宙射线散裂与部分恒星/中微子过程，权重因核素而异 |
| 碳、氮                   | AGB 与大质量恒星的共同贡献                              |
| 氧、氖、镁               | 以大质量恒星及其抛射为重要来源                          |
| 硅、硫、钙及铁族         | 核心坍缩与 Ia 型超新星等，比例随元素和环境变化          |
| 锶、钡、铅等重核         | s 与 r 等过程的不同混合，不能按元素整列只分给一种源     |
| 金、铂及锕系中的重要核素 | r 过程；事件来源与银河系整体份额仍由模型和观测共同约束  |

这是通道图，不是每个元素在所有星系中固定不变的百分比表。[4][9]

## 为什么这很重要

核合成把“我们从哪里来”变成可测量的问题：原子质量、反应截面、恒星光谱和爆发现象需要互相符合。身体里的氢主要继承原初物质，碳氧来自恒星加工，铁族与重核还包含爆炸和俘获的历史。它们没有都在同一种恒星核心停留过，却共同记录了宇宙物质的再加工。[4][9]

把这三条炉子连起来看：质子-质子链与碳氮氧循环决定主序怎么活，三阿尔法决定有没有碳和氧，铁峰决定静静聚变在哪里停。生命化学用的碳和氧，以及行星核里堆积的铁，都是这套恒星炉子分工的产物，而不是大爆炸在最初几分钟里直接交货。地面上想复制太阳的产能，困难不在写出反应式，而在把弱作用瓶颈和库仑势垒同时按进可控的功率密度，见[[核聚变与恒星能源]]。

## 跨域连接

- **[[periodic-table|元素周期表]]**：化学周期表按原子序数和电子结构排列，核合成丰度峰则反映核结合能、壳层和反应路径。铁族峰、慢俘获与快俘获的峰能帮助追查核反应，不能把它们直接当成周期表分族的原因。同一元素还可能含有由不同过程贡献的同位素，元素层面的标签因而只是第一步。[4]
- **[[reaction-kinetics|反应动力学]]**：反应率既受截面影响，也受粒子分布、密度和温度控制。pp 链的弱作用瓶颈、三阿尔法的短寿命中间体和共振，提供了不同类型的速率限制。知道一个反应放热，还不足以断定它能在一颗星内有效发生；必须把速率放回环境与演化时标中比较。[1]
- **[[nuclear-shell-liquid-drop-models|核壳模型与液滴模型]]**：中子幻数附近的截面和衰变性质改变俘获路径，造成物质堆积。s 与 r 过程经过的核区不同，峰也不完全重合。丰度曲线因此能检验核结构输入，但从一条峰反推唯一发生场所仍需要恒星与爆发模型，不能只凭“壳层闭合”完成全部推断。[4]
- **[[细胞呼吸与能量代谢|细胞呼吸与能量代谢]]**：生命利用的碳、氧和铁来自不同核反应与物质循环。核合成决定可用元素的宇宙库存，具体的代谢选择还取决于化学键、氧化还原与环境。元素丰富不等于生命必然采用某条反应，也不能据恒星产额独自推定某种代谢何时出现。[4][9]
- **[[stellar-metallicity-chemical-evolution|恒星金属丰度与化学演化]]**：反应网制造的核素，只有通过星风、爆炸等途径离开恒星，才会进入下一代成星气体。延迟、混合、流入与回落都会改变最终丰度。因此“这次事件能造金”与“它供应了银河系大部分金”是两种需要不同证据的命题，单次漂亮光谱不能自动给出整体比例。[6][9]
