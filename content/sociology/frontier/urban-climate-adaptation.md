# 城市气候适应的社会不平等

IPCC 第六次评估报告第二工作组在 2022 年指出，城市和基础设施面临的气候风险正在变得更强、更复杂。其中最迅速增长的城市脆弱性和暴露，集中在适应能力有限的城市与住区，尤其是低收入和中等收入国家的非规划、非正规住区，以及中小城市。UN-Habitat 的 _World Cities Report 2024_ 进一步把城市放在气候行动中心：热浪、洪水、风暴、干旱和海平面上升正在重塑城市生活。

社会学前沿问题是：城市适应不是简单修堤、种树和装空调，而是谁被保护、谁被迁走、谁承担成本。

## 破除误解

第一个误解，是把城市气候适应理解成工程问题。排水系统、海绵城市、绿地、冷屋顶和预警系统当然重要。但它们进入的是不平等城市：土地、住房、户籍、产权、阶层、族群、年龄、性别和迁移身份决定谁能受益。第二个误解，是认为气候风险天然公平。同一场热浪，对有空调、医保和弹性工作的人，与对户外劳动者、独居老人、非正规住区居民和无证移民，意义完全不同。

第三个误解，是把适应当成地方政府单独能解决的问题。城市适应涉及国家财政、住房市场、土地制度、能源系统、保险、基础设施债务和全球气候融资。

## 核心问题

城市气候适应前沿有三条主线。第一是风险叠加。气候风险常与住房不安全、贫困、疾病、老龄化、种族隔离和迁移身份叠加。一个临河非正规住区不只是“在洪水区”，它可能同时缺少排水、产权、保险、政治代表和搬迁补偿。第二是适应正义。适应项目可能改善城市，也可能制造绿色绅士化。

新公园、滨水治理和防洪工程提高安全性后，房租上涨可能把原居民挤出。第三是治理能力。城市需要跨部门协调：气象、住房、交通、卫生、能源、应急、社区组织和财政。但许多风险最高的城市，恰恰财政能力和数据能力有限。

## 谁在做、做到哪一步

IPCC AR6 第六章集中讨论城市、住区和关键基础设施。UN-Habitat 的 2024 世界城市报告把城市气候行动分为规划设计、基础设施、多层级治理、融资和创新。C40 Cities、ICLEI、IIED 和多个城市实验室推动城市层面的适应案例与政策工具。社会学研究把气候适应与城市贫困、非正规性、迁移、住房正义和基层治理连接起来。

方法上，研究者常用空间数据、灾害统计、社区民族志、政策分析、参与式制图和比较历史分析。

| 适应领域     | 社会学问题                 | 证据来源                     |
| ------------ | -------------------------- | ---------------------------- |
| 热浪治理     | 谁能获得降温空间和医疗支持 | 温度地图、健康数据、社区访谈 |
| 洪水适应     | 搬迁是否公平，补偿是否可达 | 地籍、灾害记录、政策文本     |
| 绿色基础设施 | 改善环境是否导致租金上涨   | 房价数据、规划文件、民族志   |
| 非正规住区   | 无产权居民如何参与适应     | 参与式制图、社区组织资料     |

## 适应的悖论：改善本身会驱逐它想保护的人

城市气候适应有一个反复出现、且难以回避的结果：**一项成功的适应工程，往往抬高该地区的地价，从而把原本最脆弱的居民挤走。**

机制很直接：防洪堤、绿地、遮荫廊道、透水铺装改善了宜居性与安全性 → 房产更值钱 → 租金上涨 → 低收入租户迁出 → **最需要这项保护的人不再住在被保护的地方**。这被称为**气候绅士化**（climate gentrification）。

它还有一个更隐蔽的版本：在沿海城市，地势较高的老旧街区历史上因交通不便而房价偏低、居住着低收入群体；一旦海平面上升风险被定价，**"高地"从劣势变成优势**，这些街区反而最先被资本盯上。风险认知的变化本身就重新分配了空间。

**这个悖论对政策的含义是具体的**：适应工程若不与住房保障（租金管制、公共住房配比、原地安置权）**同步立法**，其分配后果可能与目标相反。评估一项适应项目，因此不能只看它降低了多少风险，还要看**风险降低之后，原住民是否还在那里**。

## 谁的适应：三种被混为一谈的"脆弱性"

"脆弱人群"在政策文件里常作为一个整体出现，但它至少混合了三种不同的脆弱性，对应完全不同的干预：

| 类型         | 含义                               | 有效干预                   |
| ------------ | ---------------------------------- | -------------------------- |
| **暴露**     | 就住在洪泛区、热岛中心             | 空间规划、基础设施         |
| **敏感**     | 老人、慢性病患者、婴幼儿           | 医疗与照护体系             |
| **适应能力** | 无空调、无存款、无法请假、租约不稳 | 收入保障、住房权、劳动保护 |

**混淆三者会导致投错方向**：给一个买不起电费的家庭装空调，解决的是暴露却没解决适应能力；给一个租约随时可能终止的租户加装隔热，收益可能被房东以涨租的方式收走。

由此得到一个诚实的边界：**城市气候适应的多数瓶颈不在工程技术，而在住房与收入制度**。这也是为什么这条前沿是社会学的问题而非只是工程学的问题——技术方案通常已经存在，决定成败的是它落在什么样的产权与劳动关系之上。

## 代价与争议

最大争议是“保护”与“驱逐”的边界。政府可能以气候风险为理由清除非正规住区。如果搬迁缺少参与、补偿和生计安排，适应就会变成气候名义下的城市更新。第二个争议是指标治理。城市可能用绿地面积、排水容量和预警覆盖率展示适应成绩。但指标不一定反映最脆弱者是否真的更安全。

第三个争议是融资。许多城市知道要做什么，却缺少长期资金。气候融资常偏向大型工程，而社区级、小规模、照护型基础设施更难获得支持。

## 未知的边界

- 哪些适应项目真正减少不平等，哪些只是转移风险，仍需要长期追踪。
- 中小城市和非正规住区的数据缺口很大，全球模型常低估它们的风险。
- 城市气候适应与迁移之间的关系仍不稳定：适应可能减少迁移，也可能推动有组织搬迁。
- 老龄化社会中的热浪风险如何治理，需要城市社会学与公共卫生更紧密合作。
- 绿色基础设施如何避免绿色绅士化，目前没有通用制度方案。

## 跨域连接

- **[[urban-heat-risk-adaptation|城市高温风险与适应]]**：城市热岛使同一场热浪在城市内部产生极不均匀的风险，**而其分布与绿地、建筑密度和空调可及性高度相关**——因而它同时是气候问题与不平等问题。**这使降温措施的选址成为分配决策，而非单纯的技术优化。**
- **[[compound-climate-risks|复合气候风险]]**：城市系统的失效往往来自事件叠加而非单一极端——**高温加停电、暴雨加排水超载。**直觉最不擅长处理相关性，**因而"每一项都在可承受范围内"的评估结论可能整体上是错的**，这正是复合风险评估要纠正的。
- **[[sea-level-adaptation-pathways|海平面适应路径]]**：适应路径方法的核心是**在不确定性下保留选择权**——先做无悔措施，把不可逆的大额投入推迟到信息更充分时。**这与"先定目标再一次建成"的传统规划逻辑相反**，而它对沿海城市的实际含义是：决策序列比决策本身更重要。
- **[[social-stratification|社会分层]]**：适应措施本身会产生再分配后果——**绿化与防洪投资推高地价，从而可能置换掉最需要保护的居民**（气候绅士化）。**这使"适应"不能被当作纯粹的技术公共品**，其收益归属需要与措施同时设计。
- **[[commons-governance|公共池塘资源治理]]**：城市适应涉及大量共有资源（雨水、地下水、遮荫、公共空间），**而这些资源的治理往往横跨多个行政边界。**奥斯特罗姆的多中心治理概念在此有直接用处：**层级化而非单一中心的安排，更能处理尺度不匹配**，这也是流域与热风险治理的现实结构。
