# 比较历史分析

## 破除误解

比较历史分析不是把几个国家的历史并排讲一遍，也不是在历史故事后面加一点社会学术语。它是一种用历史过程回答社会科学问题的方法：为什么某些国家形成福利国家，另一些没有？为什么革命在某些地方爆发，另一些地方没有？为什么殖民制度留下不同发展路径？为什么同样的全球冲击在不同社会产生不同后果？

它也不是“样本太少所以不科学”。比较历史分析的严谨不来自大样本统计，而来自案例选择、过程追踪、机制识别、反事实推理和证据链。它关心的是时间顺序、关键节点、制度遗产和复杂因果。

第三个误解，是把历史当成背景。对比较历史分析来说，历史不是背景板，而是因果结构本身。过去的制度安排会改变后来的选择集合，早期冲突会塑造组织能力，关键时刻的决策会让社会进入不同轨道。

约翰·斯图亚特·密尔 1843 年在《逻辑体系》里写下求同法和求异法，本来是给实验归纳用的。比较历史社会学后来把它们改写成案例选择语言。密尔本人警告过：社会现象常是多重原因叠在一起，这两条规则很难单独成立。后来的研究者把它们当成起点，再用过程追踪去补密尔承认补不上的那一段。

小 N 研究的“不科学”指控，常常把案例数当成自由度。三个国家当然不够跑多元回归。可是每个国家内部仍有档案、时序、行动者和制度环节，这些才是推断真正发生的地方。见 [[experiments-and-quasi-experiments|实验与准实验]]。

## 研究什么

比较历史分析常研究宏观制度和长期变化：国家形成、革命、民主化、资本主义发展、福利制度、殖民遗产、族群冲突、社会运动、教育扩张、城市治理和公共卫生体系。

这些问题通常不能通过一次调查或短期实验回答。它们跨越几十年甚至几百年，涉及国家、阶级、战争、财政、法律、宗教、技术和国际体系。研究者必须把时间纳入解释，而不是只比较某一时点的差异。

例如研究福利国家，不能只看今天的福利支出，还要看工人运动、政党制度、战争动员、税收能力、宗教组织、家庭结构和资本力量如何在不同历史阶段组合。结果不是某个变量单独造成的，而是一条路径逐渐形成的。

斯考切波尔 1979 年的《国家与社会革命》把问题收得很窄：不是一切革命，而是社会革命——旧政权的国家机器和阶级结构同时被打碎。她比较法国、俄国和中国。三者传统差得很远，却都出现了国家崩溃与农民起义同时发生。问法已经决定了方法：这不是一次态度调查能回答的题目。

## 案例选择

比较历史分析的第一步，是选择案例。案例不是随便选“有趣国家”。它们要服务解释，而不是装饰叙事。

最相似案例比较会选择许多背景相近但结果不同的案例，寻找导致差异的关键条件。例如两个国家都经历工业化和战争，但一个形成强福利国家，一个没有，差异可能来自政党联盟或国家能力。

最不同案例比较会选择背景差异很大但结果相似的案例，寻找共同机制。例如不同文明、经济水平和制度传统的社会都出现民族主义动员，研究者就要寻找更抽象的机制。

典型案例帮助理解常见机制，异常案例挑战理论。负案例同样重要：如果理论说某条件会导致革命，为什么有些具备条件的社会没有革命？严谨的比较历史分析必须认真处理反例。

密尔的求同法对应最不同体系设计：结果相同，只留下共有条件。求异法对应最相似体系设计：其他条件尽量接近，只留下那一个差异。普沃斯基和特恩 1970 年在《比较社会探究的逻辑》里把这两套设计写成比较政治的标准语言。它们不是抽样公式，而是理论决策：你想排除什么，就选能帮你排除的案例。

芭芭拉·格迪斯 1990 年在《政治分析》上写过一句很难听、也很难反驳的话：你选哪些案例，会决定你得到什么答案。只研究发生了革命的国家，等于在因变量上截取样本。共同出现的前件会被当成原因，即使它们在没有革命的国家里同样常见。斯考切波尔自己知道这一点。她把普鲁士改革（约 1807–1814）、日本明治维新和英国革命当作负案例：这些地方也经历过国际军事压力和政治危机，却没有走向社会革命。负案例不是装饰，是求异法真正干活的地方。

小 N 的上限很硬。案例一多，每个案例能读的档案就变薄；案例太少，竞争性解释又消不掉。没有一种“正确的 N”。有的是：选择逻辑必须写出来，让读者知道结论适用到哪里、不适用到哪里。

## 时间顺序

时间不是简单年表。比较历史分析关心事件顺序如何改变因果意义。先有国家能力再有社会政策，和先有社会动员再有国家能力，解释完全不同。

路径依赖说明早期选择会产生自我强化。一个国家建立了中央集权税收系统，后来就更容易扩展公共服务；一个地区形成土地寡头结构，后来教育和民主可能受到长期限制。路径依赖不是说历史决定一切，而是说过去会改变后来的成本和机会。

关键节点是短时间内多种路径可能打开的时刻，例如战争结束、殖民独立、经济危机、政权崩溃、宪法制定。关键节点之后，制度可能被锁定，后续改革变得更难。

保罗·皮尔逊把路径依赖写得更具体：报酬递增、高转换成本和自我强化的政治反馈。一次战争动员建立了税收官僚，和平到来后这套官僚不会自动消失。比较历史分析要追踪的，正是把短冲击变成长期结构的机制。

顺序还决定什么能当原因。如果农民起义发生在国家崩溃之后，它就更像危机的产物，而不是危机的发动机。斯考切波尔坚持先看旧政权在国际体系中的财政—军事压力，再看农村阶级结构是否允许农民在国家松动时造反。把两件事倒过来讲，故事仍然能写圆，但已经不是她的因果主张。

## 过程追踪

过程追踪是比较历史分析的核心技术。它不是简单证明“先发生 A，后发生 B”，而是寻找 A 如何通过中间机制导致 B。

研究者需要收集档案、法律文本、会议记录、报纸、统计年鉴、口述材料、回忆录和二手史学研究。证据要能显示行动者如何理解选择，组织如何动员资源，制度如何限制选项，冲突如何改变联盟。

例如要解释某国土地改革成功，不能只说农民多、地主弱。还要追踪政党如何组织农村，军队是否支持改革，国际压力如何变化，法律如何执行，地方精英如何抵抗，农民是否有集体行动能力。

过程追踪的强项，是把黑箱打开。它让研究者不只知道变量相关，还能看到中间机制怎样把原因接到结果。

在小 N 设计里，过程追踪补的是密尔方法补不上的那一截。求同法和求异法最多告诉你哪些条件一起出现；它们不能告诉你条件怎么工作。斯考切波尔写法国、俄国和中国时，真正的论证发生在章节内部：旧政权如何失去强制能力，地主如何失去地方控制，村庄如何把反抗升级成全国性危机。跨案例的逻辑只是骨架，过程才是血肉。

过程追踪也有失败模式。研究者知道结局，容易只捡通向结局的文件，把偶然、失误和失败者的选项从故事里删掉。对抗办法不是“再客观一点”，而是预先写下竞争性机制，并规定什么样的档案会证伪自己。找不到那种档案，结论就要降级，不能靠叙事流畅来充数。

## 多重因果

社会历史常是多重因果。一个结果可能由多个条件组合造成，而同一结果也可能通过不同路径出现。革命可能来自战争失败、财政危机和农民动员的组合；民主化可能来自工人运动，也可能来自精英妥协，还可能来自国际压力。

比较历史分析因此强调配置因果。某条件在一个组合中重要，在另一个组合中可能不重要。教育扩张在开放劳动力市场中可能促进流动，在高度封闭的阶层结构中可能只制造文凭通胀。

这也提醒我们不要寻找单一万能变量。宏观社会变化往往需要制度、组织、观念、资源和外部环境共同作用。

密尔当年反对把求同求异直接用于社会研究，理由正是这个：原因常常是组合，而不是单变量开关。拉金后来用定性比较分析（QCA）把组合写成布尔运算：结果 = 条件 A 且条件 B，或者条件 C 且非 D。对小 N 来说，这比“再加一个控制变量”更诚实。它承认充分条件和必要条件不是一回事，也承认同一结果可以有多条路径。

斯考切波尔的主张本身就是配置：国际压力下的国家崩溃，加上农村结构允许的农民起义。缺任何一项，她预期的是改革、政治革命或镇压。俄国 1905 年有农民骚动，国家却没有垮到 1917 年那种程度。负案例在这里是配置缺失的对照，不是“没发生所以不重要”。

## 反事实推理

比较历史分析离不开反事实。研究者会问：如果没有这场战争，国家能力是否仍会扩张？如果殖民政府采用不同土地制度，后来的不平等是否会不同？如果某政治联盟没有破裂，民主化是否可能延迟？

反事实不能随意想象。好的反事实要接近现实历史，在当时确实可能发生，并且改变的条件有限。它的作用是检验某个因素是否真的必要。

反事实推理让历史解释更严格。它迫使研究者说明：为什么这个事件不是背景噪声，而是改变路径的关键。

负案例就是已经发生过的反事实。普鲁士在耶拿战败后没有滑向社会革命，日本在佩里叩关后走了改革道路。这些不是思想实验，而是历史上邻近的另一条轨道。实验做不到把国家随机分配到战争。可接受的反事实通常只移动一个当时确实在争论中的选项。移动得越多，解释越像文学。

## 与统计模型的关系

比较历史分析和统计模型并不敌对。统计模型可以发现跨案例模式，比较历史分析可以解释机制。大样本研究发现殖民制度与当代发展有关，历史分析可以追踪土地制度、教育投资、国家能力和法律秩序如何把早期差异传递到今天。

但两者的单位不同。统计常把国家年份变成数据点，比较历史则把国家作为历史过程。把过程切成数据点会提高可计算性，却可能丢失关键顺序和意义。最好的研究会让两种方法互相约束。

马奥尼和戈尔茨后来把这说成两种文化。大 N 追求平均效应和可推广性，小 N 追求机制和集合内的充分/必要条件。用回归的标准去审一篇三国比较，会得到“样本不够”的判决；用过程追踪的标准去审一篇百国回归，会得到“机制是黑箱”的判决。两种判决都对，只是审的不是同一件事。

准实验在中间地带。双重差分、断点和工具变量能识别局部效应，却仍回答不了“法国 1789 年为什么是社会革命”。比较历史分析也不该假装自己估计了平均处理效应。各自说清识别的是哪一种因果，比互相指责不科学有用。

## 风险与误区

比较历史分析容易落入选择性叙事。研究者知道结果之后，回头挑选看似通向结果的事件，形成“事后看来必然”的故事。避免这种问题，需要清楚列出替代解释和负案例。

它也容易过度宏大。国家、阶级、资本主义、现代性这些概念很有力量，但如果缺少具体机制，会变成大词堆砌。好的历史社会学会把宏观概念落到组织、法律、财政、战争、家庭和日常实践上。

另一个风险是欧洲中心。许多经典理论来自欧洲经验，但国家形成、城市化、宗教、家庭和现代化在亚洲、非洲、拉美和伊斯兰世界有不同路径。比较历史分析的价值，正在于打破单一路径想象。

选择偏差在这里有两张脸。一张是格迪斯说的：只拿成功革命当样本。另一张是韦伯比较宗教时更隐蔽的那种：以结果为标准回头找案例。当代方法论的多数进展，都在迫使研究者把“应该发生却没发生”的负例写进设计。

还有一种相反的风险：为了可比而把案例削成变量表。法国、俄国、中国一旦被编码成两个 1，读者会忘记三国的财政会议、士兵苏维埃和村庄结构不是同一个东西。比较需要抽象，但抽象必须能走回档案。

## 经典问题

巴林顿·摩尔研究通向民主与专制的社会起源，强调地主、资产阶级和农民之间的联盟。斯考切波尔研究社会革命，把国家危机、国际压力和农民结构放在一起。蒂利研究国家形成，提出战争、征税和强制之间的关系。韦伯比较宗教伦理和经济行动，展示观念与制度如何相互嵌入。

这些研究的共同点，不是讲历史故事，而是用历史比较提出可争论、可被反例检验的社会科学解释。

《国家与社会革命》把求同法和求异法用在同一本书里。法国、俄国、中国被当作成功的社会革命：共同格局是旧政权在国际压力下的行政—军事崩溃，叠加农民起义。普鲁士、日本和英国用来做差。她把国家写成相对自主的行政与强制组织，刻意压低伟大领袖的位置。批评者认为她低估了观念和能动性；支持者认为，正是这种结构视角，才让三国比较没有变成三本传记。

摩尔 1966 年的《民主和专制的社会起源》走另一条比较：土地阶级与资产阶级的联盟，通向民主、法西斯或共产主义。案例更杂，选择规则更松。它仍然是经典，因为它把这种方法的力量和风险写成同一件事：你怎么切案例，就会得到哪一种现代性道路。

## 跨域连接

- **[[historiography-methods-debate|史学方法之争]]**：这一方法与史学的分工点很具体——**史学追求对个案的完整解释，比较历史分析追求可跨案例迁移的因果机制。**张力也由此而来：**为使案例可比而做的简化，在史学家看来往往正好抹掉了关键。**双方的争论多数可以还原为这一取舍。
- **[[causal-inference-credibility-revolution|因果推断的可信性革命]]**：小 N 研究的识别策略与大 N 完全不同——**它依赖过程追踪（时序、机制环节的直接证据）而非统计控制。**这不是次等的替代：**当案例数少于变量数时，唯一可行的推断方式就是在单个案例内部检验机制是否实际运作过。**
- **[[max-weber-sociology|韦伯]]**：以差异最大的案例检验因果主张，是韦伯比较宗教研究确立的策略，**而其最大风险是以结果为标准挑选案例**（只研究出现了资本主义的地方）。**当代方法论的多数进展正是围绕如何避免这一选择偏差**，包括有意纳入"应该发生却没发生"的负例。
- **[[security-dilemma-war-peace|安全困境与战争和平]]**：国家形成、革命与战争是这一方法的经典对象，**而它们恰恰是无法实验、案例稀少、且结果极端重要的问题。**这说明方法的价值不由严格程度单独决定：**在这些问题上，比较历史分析不是次优选择而是唯一选择。**
- **[[case-selection-and-small-n|案例选择与小 N 研究]]**：案例选择在此不是抽样而是理论决策——**最相似体系设计与最不同体系设计各自对应不同的推断目标。**明确说出选择逻辑，**是这类研究可被评价的前提**；未说明选择理由的比较，读者无法判断结论的适用范围。
