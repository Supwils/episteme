# 宗教认知科学还剩多少可重复的结论

2012 年，《科学》发表热尔韦与诺伦萨扬的实验：用罗丹《思想者》一类操纵去启动分析性思维，随后宗教信念下降。2017 年，桑切斯等人在《PLOS ONE》上交出预注册、多地点、941 人的直接重复：操纵对宗教信念几乎没有效应，点估计还略朝相反方向（d = 0.07，95% 置信区间 -0.12 到 0.25）。原文不能再被当成“分析性思维导致不信”的可靠证据。

这件事不是单一打脸。它是宗教认知科学（CSR）在 2010 年代末期必须面对的结构问题：许多被写进教科书的机制——过度代理检测装置（HADD）、最小反直觉概念、分析性思维压制直觉信仰——来自小样本、西方大学生和一次性实验。2020 年代的前沿，是把这些机制重新放进可重复、跨文化和预测加工的框架里，而不是继续用 2000 年代的故事讲“宗教从大脑里长出来”。

## 破除误解

第一个误解，是把 CSR 写成“科学已经解释了宗教”。贾斯汀·巴雷特等人提供的是关于超自然概念为何容易被记住、传播的认知约束，不是某一部经文的真值判决。把约束写成起源神话，会把实验室里的记忆优势，升级成历史起源证明。起源问题仍要回到考古、制度和文本。

第二个误解，是把重复失败写成“宗教无法研究”。失败的是特定因果操纵。彭尼库克等人 2016 年的元分析仍显示：认知反思测验（CRT）分数与宗教信念之间存在小而稳定的负相关。相关不是启动实验。CSR 可以保留个体差异上的相关，同时放弃“看一尊雕像就会不信”的故事。

第三个误解，是把 HADD 当成已被脑成像钉死的模块。斯图尔特·格思里的拟人化论与巴雷特的过度代理检测，长期被写成专用装置：宁可误报有主体，不可漏报捕食者。马克·安德森 2019 年指出，许多由此推出的实验预测并未得到支持；他主张用预测编码来重写：在刺激不可靠时，先验把“有主体”的假设送进知觉。方向可能反转——不是误报产生信仰，而是文化教导产生预期，预期再产生误报。

## 现场：相关还在，操纵经常不在

热尔韦与诺伦萨扬 2012 年的论证有两截：一截是分析风格与不信的相关，一截是启动的因果。桑切斯 2017 年打掉的是后一截。范埃尔克 2022 年在《 Frontiers in Psychology》回顾宗教复制项目时写道：直觉思维与宗教性的关系在跨文化上高度可变，在纳入的 13 个国家里只有 3 个清楚出现。把 WEIRD 样本上的相关写成人类心理定律，会重复世俗化理论把西欧写成世界的错误。

最小反直觉（MCI）理论的处境不同。它预测：略微违反本体论预期的概念——会听的石头、不死的人——比完全违反或完全不违反的概念更易传播。记忆实验给出过支持，也给出过边界条件：熟悉度、叙事位置和文化训练会改变优势。2020 年代缺少的不是又一个课堂词表实验，而是在真实传播环境——布道、短视频、儿童读物——里预注册的重复。

哈维·怀特豪斯的宗教模式论把高频低唤起与低频高唤起仪式分开，连接记忆系统与社会规模。它对历史社会学有吸引力，也因此更难做实验室重复。近年围绕“道德化大神是否先于复杂社会”的争论（Seshat 数据库与后续批评）表明：把认知理论直接接上深历史编码，会把编码规则变成理论的一部分。那是另一场可重复性危机，发生在历史数据库而不是心理实验室。

神经科学承诺过“信仰的脑区”。小样本的 fMRI 宗教研究同样受统计功效和逆向推断折磨。霍赫芬与范埃尔克把开放科学写进 CSR 的议程：预注册、数据共享、跨文化直接重复。议程本身说明：领域承认许多“关键发现”仍是初步的。

## 谁在做、做到了哪一步

| 旧结论                  | 2020s 状态               | 代表工作                             |
| ----------------------- | ------------------------ | ------------------------------------ |
| 分析性启动降低信仰      | 直接重复失败             | Sanchez et al., 2017                 |
| CRT 与不信相关          | 小效应、跨文化不稳定     | Pennycook et al., 2016；后续跨国研究 |
| HADD 专用模块产生神观念 | 实验支持弱；预测加工改写 | Andersen, 2019                       |
| MCI 利于传播            | 有证据，边界不明         | 需真实传播环境的重复                 |

巴雷特回应过若干误解：CSR 并不主张信徒比不信徒拥有一台更“过度”的检测器，而主张人人都有容易产生主体经验的认知，不信徒另有策略把这些经验拦下。这个澄清让部分针对 HADD 的实验检验打偏——它们检验的是“信徒误报更多”，而不是原理论的句子。澄清不能挽救启动实验；它只要求批评对准真正的预测。

预测加工把知觉写成贝叶斯推断：大脑不断预测感觉输入的原因。安德森认为，多数主体误报是不可靠刺激下的高先验。宗教教导可以提高“有不可见主体”的先验，于是在噪声、黑暗、仪式和期待中更容易“感知到”。这把文化从 CSR 的外围拉回中心：不是先有普遍误报再有文化，而是文化参与构造知觉。对田野研究者，这是好消息；对想要一条人类普遍起源公式的人，这是坏消息。

## 代价与争议

开放科学有成本。预注册和大规模跨国样本让年轻研究者更难靠一个巧妙的课堂实验出道。代价是值得的，否则教科书会继续引用 2012 年的《科学》论文，而不提 2017 年的重复。科学新闻尤其喜欢“一块脑区 / 一种思维风格解释了宗教”的标题。纠正标题比发表新实验更慢。

另一争议是解释层。即使 CRT 相关稳定，它也不告诉我们宗教是错还是对。相关可以被写成“反思使人离开迷信”，也可以被写成“某种文化训练同时鼓励测试题和高世俗教育”。CSR 若把自己写成无神论心理学，就会失去描述资格；若假装没有规范史，又会假装 2012 年那篇《科学》论文的传播是纯洁的。

跨文化复制还面临翻译。上帝、祖先、业、气，不是同一量表上的刻度。把“belief in God”的李克特题搬到不以人格神为中心的社会，会把理论的自变量做坏。宗教复制项目必须先解决类别，再解决 p 值。

## 未知的边界

- 预测加工能否给出比 HADD 更清晰、可证伪的实验预测，而不是事后解释一切误报？
- 真实仪式环境中的 MCI 优势，是否强于词表记忆？
- 分析风格与不信的相关，在控制教育、国家和党派之后还剩多少？
- 历史数据库里的“大神”编码，怎样才算独立于要检验的理论？

## 跨域连接

- **[[replication-crisis|可重复性危机]]**：CSR 的问题是心理学危机的子集。预注册和多样本直接重复，是同一套治疗，不是宗教研究的特殊疗法。
- **[[cognitive-bias|认知偏差]]**：代理过度检测是偏差家族的成员。把偏差写成宗教的充分原因，会忽略制度如何选择哪些偏差被仪式化。
- **[[religious-experience|宗教经验]]**：经验研究处理的是被报告的遭遇；CSR 处理的是使报告显得自然的认知条件。两者相邻，不能互相还原。
- **[[myth-and-cosmos|神话与宇宙]]**：最小反直觉解释的是概念为何好记，不解释某一部神话为何成为法典。记忆优势不是正典化。
