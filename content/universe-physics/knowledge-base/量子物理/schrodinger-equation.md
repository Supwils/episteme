# 薛定谔方程

## 这个方程不是推导出来的——它是猜出来的

**薛定谔方程不是从经典力学"推导"出来的——它是量子力学的公理**

把最简单的非相对论 Coulomb 模型用于氢原子，会得到约负 13.6 eV 的基态能量及 Balmer 系列的主结构。常说的 Hα 约 656.3 nm 是空气波长，真空值约 656.46 nm；精确光谱还分辨有限核质量、精细结构与辐射修正。方程的成功在于定量联系能谱与实验，而不是说最低阶模型已经算尽每一条细线。[1]

"薛定谔方程是从经典力学推导出来的"——这是一个根深蒂固的误解。薛定谔在1926年建立这个方程的过程包含了直觉的飞跃和类比，而非严格的演绎推导。他从德布罗意的物质波假设出发，借鉴了光的波动方程的形式，但关键步骤——引入虚数单位 $i$ 和约化普朗克常数 $\hbar$、将能量和动量替换为微分算符——这些都是猜测性的。量子动力学的形式需要物理公设及实验检验，不能只从经典轨迹严格推出；在已给定的量子理论中，也可由幺正演化等结构导出它的形式，并从更完整理论取出合适的非相对论极限。

另一个误解是“含时薛定谔方程自动给出坍缩”。闭合系统的幺正演化保留线性叠加，也可把系统与仪器的测量相互作用一起纳入计算；它不是只能用于探测器关闭的时段。但把不同输入与不同记录建立关联，仍不等于选出一个唯一结果。条件化的态更新与整体幺正动力学承担不同角色，这正是测量问题的重要区别。[2]

还有人混淆含时薛定谔方程和定态薛定谔方程。定态薛定谔方程是一个本征值方程，给出系统的能量本征态和能量本征值；含时薛定谔方程描述一般量子态随时间的演化。

方程的另一层"公理性"体现在它保证的守恒律上：若哈密顿量自伴且满足相应演化条件，时间演化就是幺正的——概率总和恒等于一，期望能量在定态哈密顿量下守恒。这些不是额外加出来的好性质，而是方程形式本身的推论。反过来，任何试图把"坍缩"硬塞进同一条线性方程的方案，需要说明额外的随机条件化规则或修改动力学，不能仅凭把装置做大就得到单一结果；测量问题难就难在这里，而不是缺一个更聪明的猜测。

## 1925—1926 年之交：薛定谔如何在滑雪地写出量子波动方程

**1926年：波动力学论文陆续发表**

薛定谔当时任职苏黎世大学。1925—1926 年之交，他结合物质波与 Hamilton–Jacobi 类比发展波动力学；Arosa 位于瑞士，不能写成奥地利。1926 年的《量子化是一个本征值问题》第一篇，出版元数据也明确标注苏黎世大学，不能把它与 ETH Zürich 的机构身份混同。[3]

1926 年四篇奠基论文是全年陆续形成和发表的成果，不能说全在一次滑雪假期写完。第一篇以定态本征值问题处理氢谱；后来论文继续发展波动形式、近似与含时演化。私人度假轶事不能取代论文先后与研究内容的证据；本文也不把未经原始材料确认的同行对话写成逐字引语。

薛定谔的出发点是哈密顿-雅可比方程（Hamilton-Jacobi equation），他注意到几何光学和波动光学的关系——光线是波的短波极限——并猜测经典力学也是量子波动力学的某种极限。他写出含时方程：

$$i\hbar \frac{\partial \psi}{\partial t} = -\frac{\hbar^2}{2m}\nabla^2\psi + V(\mathbf{r})\psi$$

波动力学与 1925 年起发展的矩阵力学提供不同计算表象。1926 年 Schrödinger、Eckart 等人的等价性研究推动它们走向共同结构；后来以 Hilbert 空间、态与算符统一表达。这不意味着某一张直观空间波图就是一切量子系统的完整图像：多体态依赖构型坐标，自旋还需内部标签。

薛定谔（Erwin Schrödinger，1887—1961）于1933年与狄拉克分享诺贝尔物理学奖，但他对自己方程的物理诠释始终与玻尔-玻恩的哥本哈根学派存在根本分歧——薛定谔从未接受概率诠释。1935 年他在《自然科学》上写下「[[schrodinger-1935-cat|薛定谔的猫]]」，把宏观的生死写进波函数，用来表明这种涂糊不可接受。那不是一次做过的实验，也不是他晚年才提出的例子。

值得对照的是：1926—1928 年间，马克斯·玻恩提出概率诠释（对象见 [[量子物理--born-1926-probability|玻恩 1926]]）、海森堡建立不确定性关系、狄拉克写出相对论性电子方程——波动力学只是这波公理化浪潮中的一支。薛定谔方程1926 年的基本坐标形式通常用于非相对论、固定粒子数模型；抽象的态演化形式本身也可用于更广的量子理论；把自旋、正电子、辐射修正一并纳入，需要另立框架。把薛定谔方程与量子场论的拉氏量、费曼图混为一谈，是后来教科书常见的跨层粘贴——本稿只讨论1926年那条波动方程及其直接后果。

## 含时方程、定态方程与三个可精确求解的模型

**含时方程、定态方程与求解策略**

**含时薛定谔方程**（Time-dependent Schrödinger equation, TDSE）描述任意量子态 $|\psi(t)\rangle$ 的时间演化：

$$i\hbar \frac{\partial}{\partial t}|\psi(t)\rangle = \hat{H}|\psi(t)\rangle$$

其中 $\hat{H}$ 是哈密顿算符（Hamiltonian），对应系统的总能量算符。对于一个在势 $V(\mathbf{r})$ 中运动的非相对论性粒子：

$$\hat{H} = -\frac{\hbar^2}{2m}\nabla^2 + V(\mathbf{r})$$

若哈密顿量不随时间变化，可以用**分离变量**法：令 $\psi(\mathbf{r}, t) = \phi(\mathbf{r})\cdot T(t)$，得到两个方程：

- 时间部分：$T(t) = e^{-iEt/\hbar}$
- 空间部分（**定态薛定谔方程**，TISE）：$\hat{H}\phi = E\phi$

定态薛定谔方程是一个本征值方程：$\phi$ 是 $\hat{H}$ 的本征函数，$E$ 是对应本征值（能量）。求解它给出系统所有可能的**能量本征态**（energy eigenstates）和对应**能量本征值**（能谱）。

**三个基准模型**是量子力学入门的核心：

1. **无限深方势阱**（particle in a box）：$V = 0$（$0\lt x\lt L$），$V = \infty$（其他）。解为驻波：$\phi_n(x) = \sqrt{2/L}\sin(n\pi x/L)$，能量 $E_n = n^2\pi^2\hbar^2/(2mL^2)$，$n = 1, 2, 3, \ldots$。能量量子化是边界条件的直接后果。阱越窄，基态能量越高——把电子关进纳米尺度器件时，能级间距可到电子伏特量级，这是量子阱激光与二维电子气器件的设计起点。

2. **谐振子**：$V(x) = \frac{1}{2}m\omega^2 x^2$。能量 $E_n = (n+\frac{1}{2})\hbar\omega$，$n = 0, 1, 2, \ldots$。零点能 $E_0 = \frac{1}{2}\hbar\omega > 0$，即使在基态也有非零的最低振动能量——这是海森堡不确定性原理的直接体现。等间距谱使谐振子成为辐射场模、分子振动与离子阱冷却的通用模板：升、降算符把激发一步步抬高或压低，却始终不离开同一条定态薛定谔方程。

3. **氢原子**：$V(r) = -e^2/(4\pi\epsilon_0 r)$。定态薛定谔方程的解给出近似数值 $E_n\approx-13.6\,\mathrm{eV}/n^2$（$n = 1, 2, 3, \ldots$），再现了 Balmer 公式的主结构，并自然给出了角动量量子数 $l$（$0 \leq l < n$）和磁量子数 $m_l$（$-l \leq m_l \leq l$）。但要诚实指出：这个非相对论薛定谔方程并不包含**电子自旋**，因此算不出谱线的**精细结构**（同一 $n$ 下不同 $j$ 的微小劈裂，约 $10^{-4}$ eV 量级），更算不出兰姆位移（Lamb shift）和超精细结构（即21厘米氢线）。相对论、电子与核自旋及 QED 等修正必须另外纳入，也可在有效低能理论中系统处理——薛定谔方程"算对了能级主项，却漏掉了所有精细效应"。

一般初态可写成能量本征态的叠加：$|\psi(0)\rangle = \sum_n c_n |\phi_n\rangle$，则 $|\psi(t)\rangle = \sum_n c_n e^{-i E_n t/\hbar}|\phi_n\rangle$。每个定态只多一个相位因子，概率密度 $|\phi_n|^2$ 不随时间变；干涉来自不同 $E_n$ 之间的相对相位。势垒隧穿、双缝干涉条纹的漂移、拉比振荡，都可以在这条线性叠加里读出来——不必另引入"隧穿力"或"干涉力"。

**薛定谔方程的普遍性**：从分子轨道、晶体能带到原子核内部，非相对论薛定谔方程是描述低能量子系统的标准框架；电子速度接近光速、或需处理粒子产生与湮灭时，才改用狄拉克方程或量子场论。边界条件与势的对称性直接决定能谱：改边界就改能级，改对称性就改简并——能量量子化不是外加规则，而是波动方程在有限或约束区域上的本征值后果。

## 多体问题：粒子一多，精确解就消失了

**多体问题与精确解的极限**

给定合适的量子哈密顿量后，可研究其态演化；但某个非相对论、固定粒子数的势模型不等于对任意系统都精确。方势阱、谐振子与理想氢原子是重要可解模型；氢分子离子的常见处理还采用固定核的 Born–Oppenheimer 近似。一般相互作用多电子体系很难有封闭解析解，但“两个以上电子绝无任何可解模型”也过于绝对。

这里有两种维数：N 个三维粒子的构型空间有 3N 个位置坐标，随 N 线性增加；若每个粒子自由度在数值模型中保留 d 个基态，未压缩张量积空间的维数则为 $d^N$。例如 100 个二能级系统需要约 $2^{100}\approx10^{30}$ 个复振幅，而不是说 100 个连续空间粒子恰有这么多个自由度。对称性、局域性、纠缠结构与所求误差会显著影响可计算规模，不能给所有问题同一个电子数上限。

**近似方法**因此构成了量子化学和凝聚态物理的核心：

- **变分法**（variational method）：猜测试探波函数，最小化期望能量
- **微扰论**（perturbation theory）：将哈密顿量拆为可解部分加小扰动
- **哈特里-福克方法**（Hartree-Fock）：以单个 Slater 行列式近似费米多体态，包含交换反对称性；普通乘积属于 Hartree 近似
- **密度泛函理论**（DFT，Kohn-Sham方程）：沃尔特·科恩（Walter Kohn）因此获1998年诺贝尔化学奖

量子计算机的一个重要应用场景正是高效求解多体薛定谔方程——这对于药物设计、材料科学和催化剂开发具有重大实际价值。

实践上还会先做**玻恩-奥本海默近似**：把电子与核的运动按质量尺度拆开，先在固定核构型下解电子薛定谔方程，再把电子能量当作核的有效势。这一近似在分子光谱与反应动力学里极其成功，却在锥形交叉、质子转移等核-电子强耦合处失效——提醒我们：多体困难不只是"粒子多"，还在于自由度之间的尺度纠缠。配置相互作用、耦合簇、量子蒙特卡罗等方法，本质上都是在指数维希尔伯特空间里寻找可计算的稀疏结构。

## 从手机里的晶体管到 MRI——薛定谔方程渗透了现代科技每个角落

**从原子到宇宙——薛定谔方程渗透现代科技的每个角落**

薛定谔方程于1926年提出，在近百年的时间里成为了人类最成功的物理理论之一，其应用范围超越了薛定谔本人的想象。

**半导体与集成电路**：固体中电子的量子态（布洛赫态）满足薛定谔方程，能带结构（band structure）由此导出。P型、N型半导体的掺杂原理，晶体管的工作机制，都源于对薛定谔方程在周期势中的求解。现代智能手机中的数十亿晶体管，都是量子力学工程化的直接产物。

**激光**：粒子数反转（population inversion）和受激辐射都依赖于能级结构——薛定谔方程决定的离散能量本征态。没有薛定谔方程，就没有激光，也就没有光纤通信、条形码扫描和激光手术。

**核磁共振与 MRI**：以常用的氢核自旋 1/2 为例，量子哈密顿量描述共振能级与脉冲操控；热系综的密度矩阵和磁化动力学还需弛豫模型。Bloch 方程含经验弛豫参数，并非简单把孤立纯态薛定谔方程换一种写法。MRI 利用横向磁化信号与空间编码成像，不能说在直接读取每个核的纯态波函数。

**量子化学与材料研究**：近似求解分子电子结构，能估计结合能、反应路径和光谱，帮助比较材料与反应机制。机器学习可辅助表示势能面、搜索结构或逼近某些计算，但结构预测模型本身不等于从头精确求解多体薛定谔方程；具体精度、训练范围与实验验证仍需分别报告。

闪存与扫描隧道显微镜依赖势垒隧穿：电子波函数在经典禁区以指数衰减穿透，电流对间距极度敏感——这是定态薛定谔方程在工程势垒上的直接应用，而不是"粒子挖隧道"。约瑟夫森结与超导量子比特则把宏观相位差写进有效薛定谔动力学，使电路本身成为可操控的量子系统。

薛定谔方程是一个方程，但它打开了整个量子世界。

## 事实卡

- **卡1**：薛定谔在1926年1月提交第一篇论文，全年发表四篇奠基性论文，完成波动力学的完整框架。
- **卡2**：定态薛定谔方程对氢原子的精确解，给出能级 $E_n = -13.6\text{ eV}/n^2$，给出非相对论主项，精细光谱还需修正。
- **卡3**：量子谐振子的零点能 $E_0 = \hbar\omega/2$，意味着即使绝对零度下系统也有最小能量——这是不确定性原理的表现。
- **卡4**：薛定谔与保罗·狄拉克分享1933年诺贝尔物理学奖，而推动量子化学发展的沃尔特·科恩（DFT）于1998年获诺贝尔化学奖。

## 引用

第一篇 1926 年论文的标题明确把量子化作为本征值问题；用今天的语言，能级来自算符、定义域与边界条件共同决定的谱。这个谱可能含离散和连续部分，不能从“有一条薛定谔方程”就推出所有能量必然离散。[1][3]

## 跨域连接

- **[[pde|偏微分方程]]**：给定势与适当定义域，定态问题是哈密顿算符的谱问题。束缚态可有离散能级，自由或散射态也可形成连续谱；边界与正规化条件决定何种解有物理意义。因而“波动方程存在”与“所有能量离散”之间不能省掉系统条件。[1]
- **[[linear-algebra|线性代数]]**：线性演化允许叠加，但物理态还需非零并归一化。换正交基改变展开系数而不改变态所给出的实验预言；全局相位也不改变射线。测量概率则取决于态与选定测量之间的关系，不能把任何一组系数当成唯一真实坐标。
- **[[wave-function-probability|波函数与概率诠释]]**：幺正演化告诉我们振幅如何随时间变化，Born 规则把态与测量统计相连。测量仪器可以进入同一动力学模型，但整体关联仍不等于一个单独结果。这个分工说明为何能准确计算统计，同时仍存在关于个体事实的基础问题。[2]
- **[[chemical-bond|化学键]]**：轨道线性组合是构造试探态的方法，是否成键最终取决于包含动能、电子与核相互作用的总能量。多电子反对称性与相关效应不能省掉；单一行列式和更多组态是不同近似层次。化学精度要靠逐步收敛及实验比较，而非只看波形是否在两核间增大。
- **[[quantum-computing-theory|量子计算理论]]**：3N 个构型坐标与离散化后指数大的基底维数不是同一个数。量子模拟利用可控量子动力学表示部分多体问题，但制备、演化、误差与读出都要付出资源；不能把振幅空间很大直接等同于任何化学任务已有高效算法或实用优势。
