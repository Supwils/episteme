## "质量随速度增加"——一个现代物理已经抛弃的旧说法

**标题："相对论性质量"——一个已被抛弃的概念**

在欧洲核子研究中心（CERN）的大型强子对撞机（LHC）Run 3 中，每束质子被加速到 6.8 万亿电子伏特（6.8 TeV），速度约为 0.999 999 99 倍光速，洛伦兹因子 $\gamma \approx 7250$，动量涨到静止时的约 7250 倍。但它的**不变质量始终是 938.3 兆电子伏特/$c^2$**，分毫未变——这正是工程师计算弯转磁铁强度时实际依赖的量。

在旧教材和通俗科学文章中，常见这样的表述："运动物体的质量随速度增加，质量 $m(v) = \gamma m_0$"（$m_0$ 是静止质量）。这种"相对论性质量"的概念在现代物理学和物理教育中已经**基本被废弃**，原因如下：

首先，"质量"在相对论中有两种可能的含义：不变质量（invariant mass，不依赖参考系）和相对论性质量（$\gamma m$，依赖参考系）。前者才是真正有物理意义的、描述物体内禀属性的量；后者只是能量的另一种写法（$\gamma mc^2 = E$）。

其次，"质量随速度增加"容易引起错误推论（如"运动物体更难被引力吸引"或"高速子弹更重"）。事实上，物体的引力（在广义相对论中）由能量-动量张量决定，而非"相对论性质量"；子弹的不变质量不随速度变化。

现代粒子物理中，"质量"专指不变质量（$m = \sqrt{-p^\mu p_\mu}/c$，用四维动量内积定义），它不随参考系变化。相对论性动量 $p = \gamma mv$ 和总能量 $E = \gamma mc^2$ 是分开的量，共同构成四维动量 $p^\mu = (E/c, \mathbf{p})$。

$\gamma$ 并不是“质量增大的倍数”。它是固有时与坐标时之比，来自[[时间膨胀与长度收缩|时间膨胀]]：同一段固有时里，坐标时间被拉长，于是能量与动量一起变大。质量这个洛伦兹标量并没有被改写。

把 $m(v)=\gamma m_0$ 叫做运动质量，等于把总能量 $E=\gamma mc^2$ 重新贴上质量的标签。奥昆（Lev Okun）1989 年在 _Physics Today_ 写明：相对论里只有一个质量 $m$，它不随参考系改变；若把 $E=mc^2$ 读成“能量等于会涨的质量乘 $c^2$”，就把静止能量 $E_0=mc^2$ 和总能量混成一句口号。静止能量的专页见[[质能等价]]。

历史上还曾把“纵向质量”和“横向质量”拆开，因为力平行或垂直于速度时，加速度与力的比值不同。那不是质量长出了两个分量，而是 $\mathbf{p}=\gamma m\mathbf{v}$ 里的 $\gamma$ 随速度一起变。现代写法把质量留给不变质量，把 $\gamma$ 留给[[狭义相对论]]的运动学。

## 换个参考系，经典动量就不守恒了——四维动量从何而来

**标题：为什么经典动量在高速时失效——对称性和守恒定律的要求**

经典动量 $p = mv$ 在相对论框架中有一个根本问题：它不是一个"好的"守恒量。更准确地说，如果两个粒子在 $S$ 参考系中发生弹性碰撞，$\sum m_i v_i$ 守恒；但在另一个相对 $S$ 以速度 $v$ 运动的 $S'$ 参考系中，用洛伦兹速度变换得到各粒子速度，再计算 $\sum m_i v_i'$，**不再守恒**。

这意味着：如果坚持用 $p = mv$ 作为动量，动量守恒律就不满足洛伦兹协变性——在不同惯性参考系中形式不同，这违反了相对性原理（物理定律在所有惯性系中形式相同）。

为了找到满足洛伦兹协变性的守恒量，物理学家需要构造一个在洛伦兹变换下按照四维矢量规律变换的量。答案是：用固有时 $\tau$ 代替坐标时 $t$ 作为参数，定义四维动量：

$$p^\mu = m \frac{dx^\mu}{d\tau} = m\gamma(c, v_x, v_y, v_z) = (E/c, \mathbf{p})$$

其中：

- $\mathbf{p} = \gamma m \mathbf{v}$（相对论性三维动量）
- $E = \gamma mc^2$（总相对论性能量）

四维动量 $p^\mu$ 在洛伦兹变换下按四维矢量规律变换，四维动量守恒（$\sum p^\mu = $ const）在所有惯性参考系中都成立，且满足洛伦兹协变性。

四维动量之所以“好用”，是因为它在[[洛伦兹变换]]下像一个矢量那样把能量和三维动量互相掺和。沿 $x$ 方向以速度 $v$ 的惯性系之间，$E$ 与 $p_x$ 的变换和 $ct$ 与 $x$ 的变换同构：$E'/c=\gamma(E/c-\beta p_x)$，$p'_x=\gamma(p_x-\beta E/c)$。换系之后看起来“能量变了、动量变了”，但它们仍是同一个四维对象的分量。

经典碰撞里守恒的是 $\sum m_i\mathbf{v}_i$，那只在低速、同时性近似下碰巧够用。高速弹性碰撞必须改记 $\sum p^\mu$，否则换一个实验室就会看见动量账对不上。低速极限下 $\gamma\to 1$，四维动量的空间分量回到 $m\mathbf{v}$，与[[momentum-conservation-collisions|动量守恒与碰撞]]的牛顿簿记衔接。

时空平移对称性给出的守恒荷本来就是这条四维动量，而不是三条独立的牛顿动量外加一条单独的能量。物理侧的对称性讨论见[[对称性与诺特定理]]；几何语言见[[闵可夫斯基时空与四维矢量]]。

四维动量还有一个操作定义：它是作用量对时空平移的守恒荷，实验室里则由磁刚度与量能器分别读出 $\mathbf{p}$ 与 $E$。两者必须落在同一条质壳上，差一截就说明粒子中途辐射或测错了。加速器束流的“能量”海报写的其实是动能或总能量，不是质量本身在涨。

## E²=(pc)²+(mc²)²：一条方程统一光子、静止质量与动能

**标题：能量-动量关系与不变质量**

四维动量的内积（洛伦兹标量，所有参考系中相同）为：

$$p^\mu p_\mu = -E^2/c^2 + |\mathbf{p}|^2 = -(mc)^2$$

整理得到**能量-动量色散关系**：

$$E^2 = (pc)^2 + (mc^2)^2$$

这是相对论中最重要的方程之一：

- 静止粒子（$p = 0$）：$E = mc^2$（静止能量）
- 零质量粒子（$m = 0$，如光子）：$E = pc$
- 低速粒子（$v \ll c$）：$E \approx mc^2 + p^2/(2m)$（静止能量 + 经典动能）

**不变质量（invariant mass）**：对于一个粒子系统，不变质量 $M$ 定义为系统四维动量之和的内积：

$$M^2 c^4 = \left(\sum E_i\right)^2 - \left|\sum \mathbf{p}_i\right|^2 c^2$$

不变质量在所有参考系中相同，是描述粒子系统的最有用的量之一。在质心系（center-of-mass frame，$\sum \mathbf{p}_i = 0$）中，不变质量就是系统的总能量除以 $c^2$，即 $M = E_{total}/c^2$。

**阈能（threshold energy）**：在粒子对撞实验中，要产生质量为 $M_{prod}$ 的新粒子，需要系统的不变质量达到 $M_{prod}$。在固定靶实验（beam + target）中，束流粒子质量 $m_b$，靶静止，要产生质量 $M_{prod}$ 的新粒子，所需束流动能（阈能）为：

$$T_{th} = \frac{M_{prod}^2 c^4 - (\sum m_i)^2 c^4}{2m_{target}c^2}$$

固定靶的能量效率很低——大部分束流能量"浪费"在质心系的运动上。对撞机（两束反向运动粒子）的质心系即实验室系，所有能量都可用于创造新粒子，这是粒子对撞机的核心优势，也是LHC比固定靶实验更高效的原因。

$E^2-(pc)^2=(mc^2)^2$ 把自由粒子钉在质量壳（mass shell）上：四维动量的“长度”固定为 $mc$，与参考系无关。在本文使用的度规约定里，这正是 $p^\mu p_\mu=-(mc)^2$。光子 $m=0$，壳条件退化成 $E=pc$，世界线贴在光锥上；有质量粒子永远在光锥之内，速度达不到 $c$。

扰动论里的虚粒子可以暂时离开质量壳，内线的 $p^\mu p_\mu$ 不必等于 $-m^2c^2$，那是传播子的记账，不是实验室里能单独抓住的自由粒子。把实粒子和虚粒子的壳条件混为一谈，会把[[feynman-diagrams-perturbation|费曼图与微扰]]读成“能量不守恒”。外线必须在壳上，内线才允许离壳。

多粒子系统的不变质量不必等于各静止质量之和。两个光子对撞可以给出非零的系统不变质量，正是因为它们的四维动量之和一般不落在光锥上。质心系里把总动量消掉之后，剩下的总能量才是用来创造新粒子的那一笔。

对头碰撞的两个能量各为 $E$ 的光子，系统不变质量就是 $2E/c^2$：单个光子贴在光锥上，两光子系统的四维动量之和却是类时的，对应非零不变质量。有质量粒子的对撞则要把静止能量先扣掉，剩下的才是动能预算。阈能公式无非是把这条几何写成实验室系的入射动能，并不需要质量随速度涨这一笔。

## 负能量解与狄拉克海——方程比发现者更早预言了反物质

**标题：为什么有质量粒子无法达到光速——能量的发散**

从相对论性动量和能量的角度，可以严格地理解"有质量粒子无法达到光速"：

有质量粒子（$m > 0$）的总能量为 $E = \gamma mc^2$。当 $v \to c$ 时，$\gamma \to \infty$，因此 $E \to \infty$。加速一个粒子到光速需要无穷大的能量，这在物理上不可能。

更精确地说：给粒子施加力做功，增加粒子的动能（$K = E - mc^2 = (\gamma-1)mc^2$），但这个动能的增量使粒子的速度的增量越来越小。当速度接近 $c$ 时，每增加一点点速度需要的能量越来越大。理论上，只能无限接近光速，永远无法达到。

**负能量与狄拉克海**：相对论能量-动量关系 $E^2 = (pc)^2 + (mc^2)^2$ 允许 $E$ 取负值（负能量解）。在经典物理中，负能量解可以简单地丢弃；但在量子力学中，负能量态不能被忽略（量子跃迁会使粒子跌入负能量态）。狄拉克（1928年）提出"狄拉克海"来解决这个问题：所有负能量态都已被填满（泡利不相容原理），正能量电子无法跃入，但狄拉克海中的"空穴"表现为正电荷的正能量粒子——这正是正电子（antielectron）的预言，后来（1932年）被卡尔·安德森实验证实。这是量子场论超越单粒子量子力学的关键一步。

负能量解不是把质量改成负数，而是同一条质壳方程的两枝：$E=\pm\sqrt{(pc)^2+(mc^2)^2}$。单粒子量子力学没有合法的方式丢掉负枝，因为跃迁会把它重新接回来。狄拉克海把负能态填满，空穴才表现为带正电的正能量粒子；这套图像后来被量子场论的粒子—反粒子语言取代，实验侧见[[antimatter|反物质]]。

## 不变质量重建：125 GeV处的峰如何揭示希格斯玻色子

**标题：不变质量分析——粒子物理实验的核心工具**

相对论性动量和能量守恒是现代粒子物理实验数据分析的基础框架。

**粒子发现的方法——不变质量重建**：在粒子对撞实验中，探测器测量末态粒子的动量（$\mathbf{p}_i$）和能量（$E_i$）。将某些末态粒子的四维动量相加，计算其不变质量 $M_{inv} = \sqrt{(\sum E_i/c)^2 - |\sum \mathbf{p}_i|^2}$。如果存在一个质量为 $M_{res}$ 的共振态（如Z玻色子、希格斯玻色子）衰变为这些末态粒子，不变质量分布在 $M_{res}$ 附近会出现"峰"（共振峰）。

2012年CERN发现希格斯玻色子（质量约125 GeV），正是通过分析 $H \to \gamma\gamma$（两光子末态）和 $H \to ZZ \to 4\ell$（四轻子末态）等通道的不变质量谱，在约125 GeV处发现了统计显著的峰。

不变质量重建并不依赖“质量随速度增加”。探测器记下的是末态的 $E_i$ 与 $\mathbf{p}_i$，峰的位置是四维动量之和的内积，与实验室选哪个惯性系无关。双光子与四轻子通道在同一处同时出峰，靠的就是这条质壳簿记；机制侧见[[higgs-mechanism|希格斯机制]]，发现叙事见[[希格斯玻色子]]。

固定靶与对撞机的效率差别，也是同一条壳条件的几何：靶静止时，很大一截束流能量锁在整体质心运动里，用不上。对撞把实验室系与质心系对齐，可用能量才接近两束之和。如何把 $\gamma$ 做大，见[[particle-accelerators|粒子加速器]]。

**粒子对产生与反物质**：利用 $E = \gamma mc^2$，在高能对撞中可以"凭空"产生粒子对（正反粒子对）。反质子于1955年在伯克利贝瓦特龙（Bevatron）加速器中首次产生（Nobel 1959，塞格雷和张伯伦）：用能量约6 GeV的质子束轰击固定靶，产生了反质子-质子对。这是 $E = mc^2$ 在粒子物理中的直接应用——束流能量转化为两个新粒子的静止质量。

连接节点：**相对论性动量与能量** → [[质能等价|质能等价E=mc²]]（静止能量是能量-动量关系的特例）；**相对论性动量与能量** → [[洛伦兹变换]]（四维动量的变换是洛伦兹变换的直接应用）；**相对论性动量与能量** → [[闵可夫斯基时空与四维矢量]]（四维动量是四维矢量）

## 事实卡

- **卡1**："相对论性质量"（$\gamma m$）的概念在现代物理学中已被废弃；"质量"专指不变质量，不随参考系变化。
- **卡2**：能量-动量关系 $E^2 = (pc)^2 + (mc^2)^2$ 是相对论最重要的方程之一，光子（$m = 0$）满足 $E = pc$。
- **卡3**：固定靶实验的能量利用效率低（大部分浪费在质心运动）；对撞机将所有能量用于产生新粒子，是现代加速器的核心优势。
- **卡4**：1932年，安德森发现正电子，证实了狄拉克从相对论能量方程负能量解预言的反物质存在。

## 跨域连接

- **[[质能等价]]**：E²=(pc)²+(mc²)² 把三个特例装进一条式子：静止粒子给 E=mc²，光子给 E=pc，低速粒子给静止能量加经典动能。推论是：任何声称"超越相对论"的能量方案都必须先在这三个极限上复原它。
- **[[noethers-theorem|诺特定理（数学）]]**：四维动量是时空平移对称性的守恒荷，按四维矢量变换才保证动量守恒在所有惯性系同形。推论是：经典 p=mv 在高速碰撞中换系即失效——守恒律的"正确形式"由对称性唯一指定，不由直觉指定。
- **[[statistics|统计学]]**：不变质量是参考系无关的簿记量，不同参考系测得的四维动量相加后取内积即可比较；共振态因此在不变质量谱上堆出峰。推论是：125 GeV 处的峰必须在多个衰变通道同时出现，单通道的峰无法排除本底涨落。
- **高能实验工程**：固定靶实验中大部分束流能量浪费在质心运动上，对撞机则让全部能量可用于造粒子——这是同一簿记规则的直接应用。推论是：同样束流能量下，对撞模式的可用质心系能量高出一个量级，这是 LHC 取代固定靶的算术原因。
- **[[philosophy-of-science|科学哲学]]**：负能量解没有被当作数学垃圾丢弃，而是逼出狄拉克海与正电子预言——方程的解空间先于发现者"知道"反物质。推论是：数学解的实在性最终由实验判决，但丢弃解与保留解同样是可被历史检验的理论选择。狄拉克选择保留，换来的是反物质这个二十世纪最漂亮的理论预言，以及整套粒子物理的入场券。
