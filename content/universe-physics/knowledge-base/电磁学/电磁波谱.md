# 电磁波谱

## 一张频谱表，不能直接变成一张危险等级表

收音机接收无线电波，热像仪记录红外辐射，眼睛看见可见光，X射线探测器记录更高能光子。这些都属于电磁辐射，区别包含频率、波长和相应的光子能量。[1] “辐射”这个词本身，并没有指定一次暴露的风险。

电离是把电子从原子或分子中移走。一个光子能否引起某种单光子电离，取决于光子能量与对象的电离阈值；不同对象没有唯一通用阈值。**电离与断裂化学键也不是同一个过程。** 光可以通过激发和后续反应引起化学变化，不必先把电子完全移走。

日常射频通信的光子能量远低于常见生物分子的电离能，但“非电离”仍不等于在任意强度下无害。足够强的射频可以加热组织，强可见光、红外以及紫外也有各自的作用机制。IAEA区分了电离和非电离辐射，ICNIRP射频导则则按已确立的效应与剂量学量建立暴露限制。[2][3]

紫外线尤其容易被简单谱表误导。ICNIRP把其防护范围内的100—400 nm紫外线列入非电离辐射；WHO同时明确，过量紫外暴露可引起DNA损伤、皮肤癌和眼部损伤。[4][5] 因此，“全部紫外都靠电离致害”和“非电离就没有生物学危害”都不能成立。更短波紫外能否电离，也应按具体靶物质与所采用的术语范围判断。

## 频率、波长与光子能量，怎样互相换算？

在真空中，频率 $\nu$、波长 $\lambda$ 与单光子能量满足：

$$
\begin{aligned}
c&=\lambda\nu,\\
E_\gamma&=h\nu=\frac{hc}{\lambda}.
\end{aligned}
$$

SI中的真空光速为299 792 458 m/s，普朗克常数为 $6.62607015\times10^{-34}\ \mathrm{J\,s}$，二者都是精确定义值。[6] 这里写的是**真空波长**。光进入静止、线性的界面时，频率通常保持不变，介质中的波长与相速度却可以改变。

用同一组常数计算：2.45 GHz光子的能量约为 $1.0\times10^{-5}$ eV，500 nm光子约2.48 eV，0.1 nm光子约12.4 keV。这些是指定频率或波长的例子；无线电覆盖很宽，不能替整个谱段指定一个固定光子能量。

许多低能光子合成一束大功率波，可以传递很多总能量，但这不等于每个光子因此变成了高能光子。另一方面，强场与多光子过程也说明，不能把“单光子能量不够”推广成对任意强度和任意过程的绝对禁止。

## 谱段名称方便交流，边界取决于语境

下面使用常见的大致真空波长范围，目的在于定位，不把相邻名称当成精确自然界面。[1]

| 谱段            | 大致尺度与常见用途                                                                   |
| --------------- | ------------------------------------------------------------------------------------ |
| 无线电与微波    | 从很长波长延伸到毫米、亚毫米区域；微波常被看作无线电的一部分，用于通信、雷达与天文。 |
| 红外            | 约0.7 μm到1 mm；用于热辐射测量、分子光谱及红外天文，具体边界随约定改变。             |
| 可见光          | 常概括为约400—700 nm；人眼灵敏度在两端逐渐降低，380—780 nm也是常用范围。             |
| 紫外            | 比紫光更短，常见防护范围为100—400 nm；更短部分还使用极紫外等名称。                   |
| X射线与伽马射线 | 更短波长、更高能区域；两者的能区可重叠，命名还涉及产生过程及学科惯例。               |

核物理中常按电子过程或核跃迁等起源区分X与伽马射线，天文学又常按观测能区命名。因此，一个100 keV附近的数字只是某种分类约定，不能成为所有场合都适用的分界，也不能由名称判断一个光子必定来自核衰变。

热辐射也不限于红外。温度改变热谱分布，炽热恒星可以在可见光和紫外很亮，较冷物体的辐射则更多落在较长波段。微波天空里的 [[宇宙微波背景辐射]]，就是近似黑体谱跨越观测波段的一个例子。

它的温度常取约2.725 K。Fixsen在2009年综合测量得到 $2.72548\pm0.00057$ K。[7] 若画的是**每单位频率**的黑体谱密度，峰在约160 GHz；若画每单位波长的谱密度，峰在约1.06 mm。两张图的峰不直接满足“把一个峰用 $c/\lambda$ 换算就是另一个峰”，因为更换横轴还改变了谱密度的单位区间。

## 一次次改变探测器，才逐渐拼出整条谱

赫歇尔1800年的红外实验，把温度计移到太阳可见光谱红端以外，测量不可见区域的热效应。[8] 仪器测到的是温升，说明人眼的边界并非电磁作用的边界。后来，光化学材料、荧光屏、电火花回路和粒子探测器又让不同频段可以被测量。

赫兹1887—1888年的研究，重点是快速电振荡与空间波的传播、反射等性质，见 [[天线与电磁辐射]]。这些工作与红外、X射线等不同实验传统一起，逐步形成了统一的电磁描述。不能因无线电后来进入通信，就把所有谱段的发现都从1887年算起，也不需要用缺少原始出处的“发现者认为毫无用处”名言制造反差。

同一个天体在不同频段看起来不同，是因为发射、吸收和散射机制各不相同。射电可以追踪冷气体谱线或同步辐射，红外可探测尘埃及被遮挡的源，X射线则能揭示热等离子体等过程。任何一个频段也不只对应一种温度或一种发射机制。

## 大气窗口、仪器与多波段解释

大气会选择性地吸收、散射或折射电磁波，水汽、二氧化碳、氧和臭氧等成分影响不同波段。地面可以利用可见光、射电以及部分红外窗口；“部分”很重要，大气不是在一条粗略谱段边界上突然从全透明变为全不透明。[1]

ICNIRP说明，太阳UVC及大部分UVB被大气吸收，地表太阳紫外以UVA为主。[4] X射线及高能伽马光子的直接观测通常需要到大气之上；某些地面高能望远镜则探测其在大气中产生的次级粒子或切伦科夫光，不能说这些能区的任何观测都只能在太空完成。

空间望远镜也不只是为了绕开吸收。红外观测还要降低仪器自身的热背景。2021年发射的韦伯主要面向红外观测，研究早期星系、恒星形成和行星等对象。[9] “寻找最早恒星或星系”是科学目标，不能据此断言它已经逐颗直接观测到了第一代恒星。

[[spectroscopy|光谱学]]进一步把谱线、连续谱和时间变化联系到物质状态。实验室原子谱线可提供识别线索，但实际天体光谱还受电离状态、丰度、温度、密度、速度、尘埃及辐射转移影响。收到一束光，不代表其中所有成分都能被唯一解出；更不能由发现共同元素推出太阳和全部恒星的组成比例与地球相同。[10]

多波段观测联合不同的电磁窗口；多信使则进一步加入引力波、中微子等不同信号。2017年GW170817的引力波和多波段电磁对应体构成一个具体例子，联合论文同时报告没有找到与源相容的中微子候选事件。[11] 联合观测增加了约束，但不会自动消除所有模型不确定性。

## 事实卡

- **卡1**：非电离不是任意暴露下无害的同义词；光化学、电离和加热应分别讨论。[2][3][4][5]
- **卡2**：真空波长、频率和单光子能量可以换算，入介质后的波长不能无条件继续用 $c/\nu$。[6]
- **卡3**：X射线与伽马射线的命名有学科约定，能区可重叠，不存在适用于所有场景的唯一能量边界。
- **卡4**：约160 GHz的CMB峰指每单位频率谱密度；每单位波长谱密度的峰位是另一种定义。[7]
- **卡5**：GW170817的多信使研究包含电磁与引力波信号，不能据联合观测名单推断中微子也已被检出。[11]

## 跨域连接

- **[[光的本质]]**：频率决定单光子能量，而强度、偏振与光子的统计性质还描述同一频段内不同的辐射状态。推论：**一个谱段名字不足以决定全部物理效应**；普通照明、强激光和热辐射即使能量范围有交叠，也必须连同场强、材料及作用时间比较，不能只按颜色判断。
- **[[多波段天文学]]**：不同探测器约束不同的发射与吸收过程，同一天体的不同图像需要配合模型解释。推论：**联合观测增加证据，却不保证获得没有缺漏的完整图景**；未探测到某个波段既可能是源较暗，也可能涉及吸收、仪器灵敏度或观测时机，不能直接当作该过程不存在。
- **[[x-ray-imaging|X射线成像]]**：光子能量、材料组成与厚度共同决定透射、散射和吸收，探测器还影响最后形成的信号。推论：**穿透能力与成像对比必须在具体系统中权衡**；不能只凭频率更高就断言图像必定更清楚，比较不同成像方案还要说明剂量、几何和所需观察对象。
- **[[spectroscopy|光谱学]]**：实验室谱线能约束元素和离子种类，真实观测还叠加红移、展宽、吸收与激发状态。推论：**光谱反演需要足够的数据和物理模型**；共同谱线不能证明所有天体的组成比例相同，缺失一条线也未必代表完全没有相应元素，信噪比及电离条件同样重要。
- **[[atmosphere-structure|大气层结构]]**：不同气体和电离层共同构成频率依赖的观测窗口，地面、飞机、气球与卫星各有适用位置。推论：**观测平台要按具体波段和测量方式选择**；高能光子被大气吸收后仍可能留下可测的次级信号，因而不能把全部高能天文观测一概排除在地面之外。
