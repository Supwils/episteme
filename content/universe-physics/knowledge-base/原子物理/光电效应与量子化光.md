# 光电效应与量子化光

## 光电效应"证明了光是粒子"——但这句话只说对了一半

**光电效应证明了光是粒子——但光从未停止是波**

"爱因斯坦用光电效应证明了光是粒子，所以光不是波"——这是对波粒二象性最常见的误解之一。光电效应为辐射与物质交换能量的量子解释提供了关键证据：弱光下单光子发射的最大动能随频率线性变化，能量尺度为 $h\nu$。这条方程没有独自决定光在所有实验中的全部性质。[1][2]但这并不意味着波动性消失：光的干涉、衍射和偏振现象至今依然完美地由波动理论描述。

正确的理解是：光既不"是"波，也不"是"粒子，它是量子场（电磁场）的激发，在不同实验条件下表现出不同的面貌。光电效应（光子打出电子）、康普顿散射（光子与电子的弹性碰撞）是粒子性的体现；双缝干涉（哪怕单光子也形成干涉条纹）是波动性的体现。

光电效应是爱因斯坦1905年（他的奇迹年）最重要的论文之一——但他获1921年诺贝尔物理学奖的理由正是光电效应，而非相对论。

课堂演示常把光电效应画成「光原来是粒子」。更准确的说法是：电子从金属里出来时，能量按 $h\nu$ 一份收取。同一束光在双缝后面仍然可以留下条纹。粒子性出现在计数与能量交换，波动性出现在相位与干涉，不是两种物质轮流上场。

## 从赫兹的火花到 1905 年的光量子假说

**火花实验、光电子与光电方程**

1887 年，海因里希·赫兹（Heinrich Hertz）在快速电振荡实验中发现，另一道火花发出的紫外光会帮助接收火花放电。他为此专门改变屏障、材料、气体和几何，发表了详细研究；“讨厌的副效应”“只记录而没有深究”不是适当的史实概括。后来他仍把主要精力放回电磁波问题，但尚未提出电子逸出的机制。[3]

赫兹当时要看的是接收回路里那道微弱火花。他把接收器放进暗盒，好让火花更显眼，却发现最大火花长度变短。玻璃挡在发射火花前会削弱接收火花，换成能透过紫外的石英，火花又回来。

他用石英棱镜把发射火花的光分开，起作用的是可见光以外的紫外。这是放电实验里的次要现象，不是他要验证的电磁波本身。他记下了，没有提出电子被打出的机制。

威廉·哈尔瓦克斯（Wilhelm Hallwachs）在 1888 年接着证明，紫外线能让带负电的金属板放电。这把「火花变容易」写成了电荷从表面离开。光电效应开始从副现象变成可以单独研究的题目。

莱纳德让光电子打进真空管，用磁场偏转测速度，并测量逸出粒子的荷质比，确认它们就是电子。强度加大时，他看到的是更多电子，不是更快的电子。这一条给简单的连续吸能图像带来困难，但不能把频率关系也归为莱纳德 1902 年已完成的测量。密立根 1916 年明确指出，莱纳德尚未测定最大速度对频率的依赖。[2]

经典波动说会让能量在金属表面摊开：足够弱的光要把功函数攒够，应留下可测量的等待。实验上发射几乎没有这种等待。光量子图像里，一个足够硬的光子到来就可以结账，等待的是光子到达的统计，不是能量慢慢灌满一只电子。

1905 年，爱因斯坦提出光量子的启发性假设，并推导光电方程 $K_{\max}=h\nu-W$。今天 SI 中的普朗克常数固定为 $h=6.62607015\times10^{-34}\,\mathrm{J\,s}$。1916 年密立根通过精细的表面制备、接触电势测量和光谱标定，报告 $h\approx6.57\times10^{-27}\,\mathrm{erg\,s}$，不确定度约 0.5%。这些历史测得值不能与今天定义为精确值的常数混为一谈。[1][2][4]

1905 年那篇论文讨论的是光的产生与转化，不是给光下本体论判决。爱因斯坦的工作假设是：在与物质交换能量时，辐射表现得像一份一份、大小为 $h\nu$ 的量子，电子要么收下这一份，要么收不下。

在弱场、单光子发射范围内，提高光强主要增加入射光子数和光电流；最大动能主要由频率与表面功函数决定。阈值满足 $h\nu_0=W$。这个限制不能推广成“无论多强都不可能”：足够强的光场中可出现多光子光电子发射，还可能有热效应和场致效应，需要另一套模型。[1][5]

公式钉住的是金属表面的结账方式。干涉条纹怎样形成，这篇论文既没有取消，也没有改写。见[[普朗克常数与量子化]]。

1921 年的奖直到 1922 年才颁下，评委会表彰的是光电定律，不是把光说成粒子。方程先被承认，光量子图像仍要再等康普顿散射与符合计数。把光电效应说成「证明了光只是粒子」，既不符合这篇论文的标题，也不符合颁奖理由。

## K_max = hν − W：一道公式背后的量子图像

**光电效应的定量分析与工作函数**

**爱因斯坦光电效应方程**：

$$K_{max} = h\nu - W = h(\nu - \nu_0)$$

其中 $K_{max}$ 是光电子的最大动能（J），$h\nu$ 是一个光子的能量（J），$W = h\nu_0$ 是功函数（J 或 eV，1 eV = $1.602176634 \times 10^{-19}$ J（精确值）），$\nu_0$ 是截止频率（Hz）。

下表仅用于数量级估算：功函数随晶面、表面吸附与制备条件而变，不是只由元素名称确定的精确常数。若采用这些代表性 $W$ 值，可用 $\nu_0=W/h$ 算得相应阈值：

| 金属     | 功函数 $W$ (eV) | 截止频率 $\nu_0$ (Hz) |
| -------- | --------------- | --------------------- |
| 铯（Cs） | 2.1             | $5.1 \times 10^{14}$  |
| 钾（K）  | 2.3             | $5.6 \times 10^{14}$  |
| 铝（Al） | 4.1             | $9.9 \times 10^{14}$  |
| 金（Au） | 5.1             | $1.2 \times 10^{15}$  |

采用 2.1 eV 时，阈值波长约为 590 nm，位于黄橙光附近；波长更短的光可进入单光子发射范围。不能据此说铯具有一切材料中最低的功函数。实际可见光光电阴极常采用含铯化合物或多碱材料，其光谱响应需要按具体阴极测量。[6]

实验室并不直接称动能，而是加反向电压 $V_s$，把最快的光电子刚好拦回去。若电压已按发射表面参考校准，理想关系为 $eV_s=K_{\max}=h\nu-W$，其斜率为 $h/e$。实际两电极之间存在接触电势，仪器读到的截距还可能包含这项偏移；不能未经校正就把原始横轴截距直接当成发射表面的功函数。[2]

爱因斯坦的弱光单光子公式里没有光强：在忽略空间电荷等效应时，同一频率的光调亮，主要增加光电子数。光电方程把频率门槛写成硬约束：可见光打得动铯，打不动金，不是因为金「更懒」，而是金的功函数更高，可见光的 $h\nu$ 不够。

密立根把碱金属表面在真空里用旋转刀刮净——他称为真空中的小机床——才得到可重复的直线。斜率给出 $h\approx 6.57\times10^{-27}$ erg·s，精度约百分之零点五，并动用了他油滴实验测过的 $e$。电荷台阶如何被称出来，见 [[原子物理--密立根油滴实验|密立根油滴实验]]。
截止电压测的是最快那一群，不是平均动能。表面沾污、氧化或吸附可能改变有效功函数、把截距推走，变化方向取决于材料与表面状态，所以密立根要在真空里刮出新鲜面。温度升高还会让热电子尾巴变厚，截止点变模糊——直线最干净时，往往同时满足干净表面、低温与单色光。

直线同时给出两种读数：斜率里的 $h$，截距里的 $W$。接触电势等修正完成后，不同表面的截距可不同，斜率应相同；$h$ 是普适常数，$W$ 描述具体表面的逸出能垒。方程被钉住，不等于光的波动描述被废除。

**康普顿效应**（Arthur Compton，1923年）：X射线被自由电子散射后，波长增大（能量减小），增大量与散射角的关系完全符合光子与电子的弹性碰撞公式：$\Delta\lambda = (h/m_ec)(1 - \cos\theta)$，其中 $h/m_ec = 2.43$ pm 是康普顿波长。石墨、钼 K-α 与布拉格分光计见 [[原子物理--compton-scattering-experiment|康普顿散射实验]]。康普顿效应是光子具有动量 $p = h/\lambda = E/c$ 的直接实验证明，1927年诺贝尔物理学奖授予了康普顿。[7]

## 玻尔与密立根：最不情愿接受光子的两个人

**光量子假说的争议与玻尔的抵制**

光量子假说在提出后的近二十年内一直受到强烈质疑，连尼尔斯·玻尔和罗伯特·密立根（后来实验验证了爱因斯坦公式的人）都长期拒绝接受光子的真实性。

密立根在 1916 年论文中区分了两件事：实验强有力地支持爱因斯坦方程，他却仍认为光量子图像与当时的干涉、衍射知识难以相容。这里应转述他的论证，不能把后人的中文概括加上引号当成原话。[2] 玻尔、克拉默斯与斯莱特在 1924 年提出 BKS 方案，尝试保留连续辐射图像与统计意义的守恒；后来的符合和方向关联实验给这一方案带来决定性的困难。

密立根要测的是方程和 $h$，论文里把光量子说成与衍射、干涉无法调和的假说。数据站在方程一边，概念仍站在以太波一边。

玻尔 1924 年的 BKS 方案走得更远，想保住波动场、改写单次过程的能量守恒。这两条抵制路线，对象都是「光在空间中也是粒子」，不是否认 $K_{max}=h\nu-W$ 这条直线。Bothe 与 Geiger 检验散射辐射和反冲电子是否相关；Compton 与 Simon 则研究候选单次事件的方向关联。这些实验支持相关的量子碰撞，不能说计数管逐次完整测量了全部能量。[8]
争议拖了近二十年，不是因为缺数据，而是因为「场在空间中连续」与「能量按 $h\nu$ 一份交付」看起来互斥。康普顿把动量账本也写成弹性碰撞，符合计数又把守恒钉回单次事件——到这一步，光量子才从「解释公式的方便假说」变成多数人愿意使用的工作图像。

这段历史展示了科学接受革命性概念的真实过程：即使实验证据清晰，当理论概念与已有框架深刻冲突时，科学家（包括最伟大的）也会抵制——而最终决定胜负的，是越来越精确的实验。

## 从光电阴极到太阳能电池

**从光电管到太阳能电池——光量子的工程应用**

光电效应的直接技术后裔随处可见：

**光电倍增管**（PMT）：光首先被光电阴极吸收，以一定的量子效率释放光电子。光电子经过聚焦和加速，撞击第一级倍增极，通过次级电子发射产生更多电子；后面各级重复倍增，最后由阳极收集。典型增益可达 $10^6$—$10^7$，具体取决于器件与电压。第一级倍增极主要做的是次级发射，不能把它写成光电阴极。并非每个入射光子都会产生可探测脉冲。[6]

单光子计数还可以使用半导体雪崩二极管或超导探测器。不同器件把光吸收转成电信号的机制不同，不能把所有探测器都描述为“电子飞出金属表面”。太阳能电池中的带间激发同样需要区分：禁带宽度是半导体内部能级结构的尺度，功函数则是电子逸入真空的能垒。两者都影响光电过程，但不是同一个量。

**太阳能电池**：吸收光可产生载流子，合适的结结构与选择性接触帮助分离、收集电荷，向外电路供电。单结电池的光谱利用受带隙与损失机制限制；叠层结构使用不同带隙吸收不同波段，并非简单降低金属功函数。[9]

**CCD 与 CMOS 传感器**：像素中积累的光生电荷被读出，形成数字图像。2009 年诺贝尔物理学奖的一半共同授予 Boyle 与 Smith，表彰 CCD 传感器的发明；另一半授予高锟，表彰光纤通信工作。[10]

## 事实卡

- **卡1**：$K_{\max}=h\nu-W$ 描述理想的弱场、单光子外光电发射；原始截止电压还需处理接触电势。[1][2]
- **卡2**：功函数取决于具体表面；采用 2.1 eV 时，阈值波长约 590 nm，不能称为普适的“铯常数”。
- **卡3**：足够强的光场中可有多光子发射，单光子截止条件不是任意强度下的绝对禁令。[5]
- **卡4**：PMT 的光电阴极负责光电子发射，倍增极负责次级电子发射。[6]

## 跨域连接

- **[[paradigm|范式]]**：密立根的实验支持光电方程，却没有使他立即接受光量子的整个图像。这提醒我们把测量结果与理论解释分开：同一条直线可以成为不同模型共同努力解释的对象。后来散射与关联实验增加了新的约束，理论取舍才在更广的证据集合中发生，不能把概念更替简化成科学家是否愿意承认某一张曲线。
- **[[波粒二象性|波粒二象性]]**：光电方程描述能量交换，干涉实验描述相位和概率振幅的叠加。两种实验的提问不同，却必须被同一个理论容纳。单光子发射的频率阈值有清楚的适用条件；强光中的多光子过程正说明，理解“量子化”需要识别相互作用通道，而不是背下“低频永远不行”这一绝对口号。
- **[[photosynthesis|光合作用]]**：色素吸光、激发能转移与反应中心电荷分离，也涉及特定的量子能级与能量损失。不过，生物分子的吸收带、振动耦合和后续反应并不等于金属的真空功函数。可比较的是吸收能量如何进入电荷转移，不能从金属的截止公式直接推出全部光合生物的有效波段，更不能说可见光之外的所有光都只会加热。
- **[[多波段天文学|多波段天文学]]**：探测器把吸收光转换成可计量的电信号，但其量子效率、暗噪声和读出噪声仍要校准。仅在光子散粒噪声占主导、独立计数近似成立时，信噪比才按 $\sqrt N$ 增长，提升一倍需约四倍有效光子数。望远镜面积与曝光时间能增加信号，背景和系统误差则会改变这种简单比例。
- **能源工程**：半导体电池的带隙决定哪些光子容易产生带间激发，结与接触决定电荷能否被收集。超过带隙的额外能量还可能以热损失，低于带隙的光则可能透过或通过其他通道吸收。叠层电池按不同带隙分配光谱，连接的是能带与输运工程，不能把外光电效应的功函数直接当成电池输出电压。[9]
