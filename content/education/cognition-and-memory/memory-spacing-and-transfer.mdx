# 记忆、间隔与迁移

1885 年，赫尔曼·艾宾浩斯在莱比锡用无意义音节做自己的被试。他记录节省法：重新学会一份材料比第一次少花多少时间。由此画出后来被教材称为遗忘曲线的下降。那是成人自我实验，有可重复的计数程序，不是给儿童贴记忆缺陷标签。读者要核对的是程序与节省量，而不是把曲线抄成命运。

课堂常把这条曲线理解成：人注定忘掉，所以要趁热打铁、一遍接一遍。实验传统后来给出更窄、也更有用的句子。间隔练习改变的是复习时间表；测验效应改变的是提取本身是否被当成练习；迁移问的是学会的东西能否在新表面上被用到。三句话都能被设计对质，也都能被广告夸大。

## 破除误解

第一个误解，是把遗忘当成纯粹失败。艾宾浩斯的节省已经表明：表面想不起来的材料，仍可能让再学习变快。遗忘也可以是辨别的条件：提取失败逼人重新编码。把遗忘写成道德问题，会把时间表问题换成意志问题。

第二个误解，是集中练习一定更高效，因为它当时最熟。2006 年，尼古拉斯·塞佩达、哈罗德·帕什勒等人在《心理学公报》上综述间隔效应：把复习分开，通常优于把同等时间挤在一次。当时更熟，不等于隔周还在。熟是即时表现，不是持久学习。

第三个误解，是练习一种题就会自动迁移到所有题。2002 年，苏珊·巴尼特与斯蒂芬·切奇在《心理学公报》上给出迁移分类：知识领域近或远、程序近或远、记忆要求近或远。近迁移常被当成远迁移来吹。吹过之后，失败就被写成学生笨。

## 核心：练习条件是证据，不是鸡汤

间隔效应的机制仍有争论：编码变异、提取难度、巩固时间窗，都有论者。机制未决，不等于效应不存在。对教学有用的是操作定义：两次复习之间插入其他材料和时间，再在延迟测验上比较。没有延迟测验，间隔只是一种感觉。

测验效应把提取从检查改成学习事件。2006 年，亨利·勒迪格与杰夫瑞·卡皮克在《心理科学》上报告：用测验作为练习，延迟保持常优于重复阅读。这不是鼓励高频排名考试。形成性的低风险提取，和证书性的高风险测验，是两种制度。把实验里的自由回忆抄成月考加码，是政策跳跃。

工作记忆限制解释了为什么条件不能无限加密。材料必须经过有限的即时容量，才能进入更稳的长时痕迹。认知负荷研究据此区分内在负荷与外在负荷。这些区分是模型，不是脑区地图。用彩图证明“某种游戏开发了右脑”，仍属于本域禁止的神经神话处方。

迁移是学习是否值得学校投资的关键句。若学生只会原题，学校训练的是再认线索，不是可用的知识。巴尼特与切奇要求作者标明自己声称的是哪一种迁移。教育学的老实写法是：先证明近迁移，再谨慎地试远迁移，并报告失败。失败也是证据。

把这些效应搬进学期，会变成作业设计问题。今晚的练习册若全是刚讲过的原题，学生当时会很熟，周末再做变式就可能崩。崩不是品德事故，它常常只是提取线索换了。教师若把崩写成“回家没复习”，就用意志覆盖了条件。相反的错误是把所有作业都做成间隔和测验，却不告诉学生为什么当时更难。手感更差时，没有解释的科学练习会被体验成刁难。

约翰·邓洛斯基等人 2013 年在《心理科学公共兴趣》上比较十种常用技术：提取练习与分散练习的证据更强，画线与重复阅读更弱。强弱是相对文献而言，不是一张禁止画线的禁令。技术的效应量随材料、延迟和学生准备而变。把综述抄成全校强制软件，是又一次政策跳跃。

迁移失败最容易被误写成品德。学生说“上课听懂了，作业不会做”，常常被当成没认真。听懂了的手感，往往来自再认：讲解还在耳边，例子还在黑板上。作业换了数字、换了问法，再认线索消失，提取才开始。间隔与测验之所以当时令人不舒服，正是因为它们提前制造这种消失。不舒服可以被解释，也可以被用来责备。本域只承认前一种用法。把责备写成校风，并不能让痕迹在一周后更好提取。校风可以改变练习是否发生，却不能把再认伪装成提取。发生了什么样的练习，仍要靠作业和延迟测验来说。

罗伯特·比约克把理想难度写成：让练习当时更难、但使后日提取更好的那些条件。难度不是越多越好。过难会让提取完全失败，于是没有成功的检索可以被巩固。过易则停在再认。理想落在能够成功但仍费力的区间。区间随材料和准备而移动，不能写成一张全校统一的痛苦配额。把痛苦当成科学，是又一次把条件道德化。

哈里·巴里克对超长间隔保持的研究表明：间隔可以跨年，而不是只跨周末。跨年的保持依赖偶尔的提取，而不是一次“学透了”的誓言。学校的学期结构很少提供这种跨年提取，于是所谓学会会在升学后崩开。崩开常被下一学段的教师写成基础差。基础差有时是真的机会缺口，有时只是没有被安排的延迟测验。两种情况的干预完全不同。混写成意志，两边都治不好。

卡皮克后来把提取练习的边界写得更清楚：重复阅读在即时测验上可以看起来很好；换到延迟，提取练习通常反超。即时与延迟必须分开报告。只报告当堂小测，会让集中练习永远赢。永远赢的是手感，不是一周后还在的痕迹。手感会进入学生的元认知：他们拒绝间隔，因为当时更差。拒绝是判断，判断可以训练，训练仍要对照延迟成绩，而不是对照心情。

因此，练习表是一种公开的证据设计。写清延迟、材料和失败，间隔才是实验传统的后裔。不写这三项，科学记忆法只是把综述卖成了安慰。安慰可以让人买软件。软件若只催促当天再读一遍，它训练的仍是集中练习，只是界面更新鲜。新鲜不是间隔。间隔是日历。

## 争议

争议的第一线，是间隔的最佳间隙。塞佩达等人指出，最佳间隔随保留间隔而变，不存在一张万能日历。面向考试日的复习表，必须说出考试在多久之后。卖“科学记忆曲线”产品却不标测量，是把综述当成了说明书。

第二线是测验是否伤害动机。高风险测验会改变谁被看见、谁被放弃，这是后面评估文的主题。实验室里的提取练习，不能直接回答制度伤害。两件事都真，不能互相取消。

第三线是儿童被试。凡把未成年人带进记忆实验的研究，必须交代伦理审查。本篇主要依据成人学习文献与综述，不提供给儿童做诊断量表的操作步骤。成人曲线可以被谨慎地当作学校练习表的参考，参考不是把儿童当成可调参数。参考时仍要单独报告延迟、材料和失败，而不是只报告当时最熟的那一次。

把间隔写成校历，还会碰到假期、考试周和补课市场。假期把间隙拉大，考试周把练习挤回集中，补课把同一批题目再做一遍。实验室的干净时间表在这里碎掉。碎掉不是否定效应，它要求作者标明：你声称有效的是哪一段真实日历。不标日历的“科学记忆法”，只是把综述卖成了安慰。日历比口号诚实。诚实的日历会写出考试日、假期和两次复习之间实际隔了几天，而不是只写“科学”。

测验效应进入学校时，最常见的跳跃是把低风险提取做成又一次排名。排名改变谁愿意失败。愿意失败，提取练习才有材料；不愿意失败，学生会选择最熟的题目来交。选题之后，教师看见的保持曲线会被样本扭曲。扭曲不是学生欺骗科学。它是制度把检查和学习事件粘在同一张卷子上。粘住之后，实验室里的自由回忆已经不再是原来那个操作定义。操作定义一变，效应量不能直接搬家。

迁移分类之所以必须被写进教案说明，是因为广告永远选择最远的那一种。一份单词表练习被写成“提升思维品质”，一份原题操练被写成“核心素养”。思维与素养可以是真的课程目标。目标要另有证据。证据首先是近迁移：换数字、换表面、换问句。近迁移都站不住时，远迁移只是修辞。修辞可以动员预算。预算买来的若仍是原题再认，学校训练的就还是线索，不是可用的知识。可用必须在新表面上被看到。

儿童记忆研究不能从成人无意义音节直接下达。下达是解释层。谨慎的用法是：把成人文献当成练习表的假说来源，然后在该年龄、该材料上单独报告延迟与失败。不报告失败的儿童记忆产品，与不报告版本日期的学习贫困曲线，犯的是同一类错：把模型当成现场。现场里还有睡眠、语言和家庭作业时间。这些不是干扰项，它们是真正的间隔。间隔被家庭资源改写时，效应会分层。分层要写进结果，不能写进意志。

比约克的理想难度和巴里克的超长保持，都把日历当成实验装置的一部分。学校若把日历交给考试周和补课市场去决定，装置就已经被改写。改写后仍可以练习。练习可能有效。有效必须在该日历上被测量，不能从实验室的干净间隙直接搬家。搬家是广告。广告喜欢画一条平滑的遗忘曲线，再叠一张付费复习提醒。提醒可以增加提取次数，这是真的。次数落在什么间隙、测的是再认还是回忆、失败有没有被报告，广告通常不写。不写的部分，才是教育学要盯住的操作定义。定义一松，间隔就变成催促。催促是集中练习的亲戚，不是间隔的亲戚。

邓洛斯基综述里的强弱，是文献分布，不是教室禁令。画线与重复阅读可以是开始编码的方式。它们弱在延迟保持。把弱写成有罪，会让学生以为一切熟悉的策略都是欺骗。熟悉策略可以是入口。入口之后仍要安排提取和间隔。安排是教师和课表的责任，不能全部转成学生的元认知品德。品德故事在这里特别有害：它让当时更差的手感变成性格鉴定，于是最需要间隔的学生最先退出。退出之后，效应只在已经愿意忍受难度的人身上被看见。看见会被写成方法有效。有效的样本已经被制度筛过。筛过的样本不能代表全班。

间隔效应的机制未决，不等于可以不安排间隙。机制争论（编码变异、提取难度、巩固时间窗）属于实验室。学校能对质的是操作：两次复习之间插入了什么、延迟测验在哪一天。把机制争论当成可以先不练习的理由，是把未决写成了免除。免除对广告有利，因为它让人继续买当天再读一遍的软件。软件可以催促。催促量的是集中。集中当时最熟。最熟不是一周后还在。

## 跨域连接

- **[[memory-systems|记忆系统]]**：心理学把工作记忆、情节记忆与语义记忆拆开，使“记住”不再是一个动词。间隔和提取作用在不同系统上的证据并不相同。教育学若只用一个“记性”来解释所有作业，就无法被这些区分对质。
- **[[false-memory|虚假记忆]]**：提取可以巩固，也可以改写。洛夫特斯传统表明，暗示与重复提问能让人确信未发生的情节。课堂里的“再讲一遍你看到了什么”不是中性手续。记忆研究同时给教学提供工具和警告。
- **[[metacognition-training|元认知训练]]**：知道自己会不会，本身是一种可训练的判断。间隔与测验之所以有时被学生拒绝，是因为当时更难、手感更差。元认知研究解释的是这种手感为何不可靠，而不是责备懒惰。
- **[[children-learn-language|儿童如何学会语言]]**：语言习得里的重复输入与关键期争论，常被误搬进外语单词表。语言学要的是语法发展的证据条件；教育学要的是学校练习表。借用必须标明哪一种输入、哪一种测量，不能把婴儿研究写成中学秘诀。
- **[[machine-learning-overview|机器学习概览]]**：计算机科学把学习写成参数随数据更新。间隔与回放、难度课程，在算法里也有对应物。对应不是证明大脑就是梯度下降。它只说明：没有训练条件的“学会”，在机器和人那里都无法复现。模型若只在训练集上报告准确率，工程师会说它过拟合；学生若只在原题上报告熟练，学校却常常发证书。
