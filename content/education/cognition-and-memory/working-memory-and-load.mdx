# 工作记忆与认知负荷

1956 年，乔治·米勒在《心理学评论》上写下那句后来被简化成口号的话：即时容量大约是七个组块，可加可减两个。他谈的是成人在实验室任务里能同时把握的符号数量，不是给儿童贴“脑子小”的标签。组块本身已经是组织：熟悉的模式能把更多元素收成一个单位。容量句子一旦离开任务，就变成性格鉴定。

1974 年，艾伦·巴德利与格雷厄姆·希契用工作记忆替换“短时记忆”这个更含混的抽屉。他们要解释的是：人不但暂存信息，还在暂存的同时加工。语音回路、视空画板和中央执行，是模型零件，不是脑区彩图上的三个按钮。课堂里的“一次讲太多”，对应的是这个有限的加工窗口被材料塞满，而不是学生突然变懒。

## 破除误解

第一个误解，是把工作记忆写成固定智商。纳尔逊·科万后来把即时容量估计得更窄，大约四个组块，并强调注意焦点。数字会变，因为任务会变。用一次数字广度测验给儿童下终生判词，既越出测量条件，也违反本域对量表手册的限制：这里只讨论构念，不提供可误用的施测步骤。

第二个误解，是多媒体一定减轻负担，因为“看了又听了”。理查德·迈耶的多媒体学习原则里，有一条正好相反：无关的动画、背景音乐和同时出现的冗余文本，会抢同一窗口。通道可以互补，也可以互扰。是否减轻，要看材料关系，不能看软件封面。

第三个误解，是认知负荷理论已经给出万用教案。约翰·斯威勒 1988 年在《认知科学》上提出认知负荷，区分内在负荷、外在负荷和后来补充的生成负荷。模型有用，因为它逼人问：困难来自材料本身的元素交互，还是来自拙劣的呈现。把它写成“少讲就是科学”，是广告。

## 核心：有限窗口如何约束教学呈现

工作记忆的要点不是“人记性差”，而是学习必须经过一条窄路，才能进入更稳的长时痕迹。窄路意味着：同时要保持的新元素越多、元素之间要建立的关系越密，失败就越像“没听懂”。没听懂可能是窗口满了，也可能是先前知识不够，使每个元素都必须当新的来保持。两种诊断指向不同的下一步，不能用同一种激励口号覆盖。

斯威勒传统用元素交互性描述内在负荷。解一道多步方程，必须同时盯住符号、目标和解法约束，交互性高；认一个已经熟悉的词，交互性低。内在负荷不能靠把字号变大来消除。能改的是外在负荷：把需要对照的图文拆到两页、让学生在工作记忆里来回找，就是典型的分裂注意。把必要信息在空间上靠拢，是设计，不是装饰。

生成负荷或生成加工指的是：窗口里仍要留出余量，让学生做组织、推断和自我解释。若材料已经把窗口占满，所谓“启发式提问”只会再加一项任务。于是出现一种常见课堂悖论：教师觉得自己在启发，学生觉得自己在被追问一件还没能保持住的事。悖论的原因常常是时间表，不是态度。

工作记忆研究大多来自实验室和控制较好的教学实验。样本经常是大学生，或特定年级的课堂干预。把它直接写成所有年龄、所有学科的神经事实，会跨过抽样。WEIRD 样本问题在心理学方法里已被反复写出：便利样本上的效应，要声明边界。教育学更应声明：教室噪音、纪律事件和语言转换，都会改变窗口的有效容量。

现场里，负荷显形为很具体的物件。一页讲义若同时给出新符号、新定义、新例题和一句纪律提醒，学生必须决定先保持哪一句。决定本身也占窗口。板书擦得太快，等于把外部记忆撤走，逼人改用内部保持。相反，把每一步都印在学案上，外部记忆变强，但学生可能不再练习自己保持目标。两种安排都能被辩护，前提是标明你在训练哪一种表现。

因此，工作记忆句子对教学的合法用途是诊断呈现，而不是鉴定儿童。合法的下一句是：这个任务此刻要求同时保持什么？不合法的下一句是：这个孩子的工作记忆差，所以不适合普通班。后一句把模型用成了分班武器。本域把分班写成制度，把容量写成条件。两者相关，不可互换。

涉及儿童的工作记忆测验若出现在论文里，应核对该研究的伦理审查与知情同意说明。已发表的效应量可以讨论；把课堂变成未审查的测验场，不是本域要写的操作。

把负荷写成窗口，还有一个学期尺度的后果。单元若把新符号、新程序和新评价标准叠在同一周，窗口会在整周里处于满载，周末的作业只是把满载延长到家里。家庭能否提供安静与时间，于是变成窗口的外部记忆。经费不足的学校更难提供当堂完成的时间，负荷就被转移。转移看起来像学生不努力，其实是时间表把加工赶到了公共学校不再覆盖的时段。

板书、学案和投影不是装饰风格之争，它们是外部记忆的不同形状。教师擦掉中间步骤，等于撤走支架；把每一步都印成填空，等于把生成加工也预支掉。两种极端都能找到理由。理由必须指向你要训练的表现：独立保持目标，还是先建立正确的元素关系。没有指向的“简洁课件”，只是审美。

米勒的“七加减二”与科万后来更窄的容量估计，首先是模型差别，不是科学纠正了一个错误整数。米勒谈的是多种即时记忆任务里的组块上限，组块已经是组织。科万把注意焦点写得更窄，并强调长时记忆里的激活如何把元素收成可同时把握的单位。两个数字不能拿来给儿童贴终生标签。它们约束的是：任务一变，看起来像容量的东西就会变。把口号写成大脑规格，是把模型用成鉴定。

巴德利后来为工作记忆补上情节缓冲，处理的是跨通道绑定：语音、视空与已有知识如何暂时被收成一个情景。零件增加，不是脑区彩图多了一个按钮。课堂含义仍然很窄：同时要保持的关系一密，失败会像没听懂。没听懂可能是窗口满了，也可能是每个元素都必须当新的来保持。两种诊断指向不同的下一步。激励口号不能覆盖。

斯威勒把内在负荷写成材料本身的元素交互，把外在负荷写成拙劣呈现带来的额外保持。内在负荷不能靠把字号变大来消除，只能靠改变任务结构或先建立图式。外在负荷可以改：图文分裂、冗余朗读加屏幕全文、无关动画，都会抢同一窗口。生成加工需要余量。材料已经占满时，所谓启发只是再加一项任务。教师觉得自己在提问，学生觉得自己在被追问一件还没能保持住的事。

把工作记忆失败写成“先买大脑训练软件”，是解释层跳跃。独立综述多次显示：训练任务本身会变熟，远迁移到课程成绩则弱或不稳。梅尔比-勒沃格与胡尔梅把工作记忆训练的迁移写得很谨慎。席普斯特德、雷迪克与恩格尔同样追问：变熟的是训练游戏，还是学校要的作业。本域把商业“练大脑”留在广告层。能对质的是呈现：这个任务此刻要求同时保持什么。

双重通道可以互补，也可以互扰。迈耶原则里有一条正好相反于软件封面：无关动画、背景音乐和同时出现的冗余文本，会抢同一窗口。朗读已经写在屏幕上的全文，不是“再听一遍就更科学”，而是把视觉与语音回路同时塞满。通道不是加法。材料关系才决定是否减轻。封面不能代替关系。

商业脑力训练把容量写成可购买的规格升级。席普斯特德、雷迪克与恩格尔追问的是：变熟的是训练游戏，还是学校要的作业。梅尔比-勒沃格与胡尔梅的元分析把远迁移写得很谨慎。应用题失败，下一步应是改呈现与元素交互，而不是先买另一套游戏。把失败写成大脑硬件，采购会变得很容易。讲义却还是那一页同时给出新符号、新定义和新纪律提醒的纸。

科万把注意焦点写成很小的一束光，周围是暂时激活的长时痕迹。米勒把组块写成组织后的单位。两种写法都允许熟悉模式把更多元素收成一个。差别不在谁赢了整数竞赛。

差别在于：教学能做的是帮助组织，不是给儿童贴容量标签。组织发生在任务里。标签发生在档案里。档案一旦写上“工作记忆差”，后续教师会减少试探。模型被用成了预言。

内在负荷与外在负荷必须能被分开操作，理论才不是循环。改变图文位置而保持题目目标，是一种操作。成绩随后若变，负荷解释才可对质。若只在失败之后命名负荷，标签与分数互相证明，什么都没有被设计。

钱德勒与斯威勒把分裂注意写成外在负荷的典型形状：必要信息被拆到两页或图文远离，学生必须在窗口里来回找。靠拢是设计。装饰性的“丰富媒体”可能把已经靠拢的信息再拆开。是否减轻，要看关系，不能看封面。把封面写成脑科学，是广告。

巴德利与希契的中央执行也不是道德词。它指的是在暂存的同时分配加工，而不是“够不够专心”的纪律档案。课堂口语里的不集中，常常是窗口已被材料与指令同时塞满。把满载写成品质，下一步就会去买训练游戏。合法的下一步仍是：这个任务此刻要求同时保持什么。问句指向呈现。不指向鉴定。

## 争议

争议的第一线，是工作记忆训练能否迁移到学业。商业产品常承诺“练大脑”。独立综述多次显示：训练任务本身会变熟，远迁移到课程成绩则弱或不稳。把应用题失败写成“先买训练软件”，是解释层跳跃。

第二线是认知负荷理论的测量。负荷常靠主观量表或双任务表现来推断，并不是一块可称重的脑物质。批评者指出循环：成绩差就被说成负荷高，负荷高又用来解释成绩差。循环要靠独立操作来打破，例如改变呈现而保持目标不变。

第三线是专长反转。对新手有用的强引导，对已有图式的学习者可能变成干扰。这不是“因材施教”的鸡汤，而是要标明专长水平如何被事先测量。没有测量的因材，只是印象。

第四线是把米勒与科万的数字写成互相取消的真理。七与四都不是儿童规格。它们是不同任务、不同模型对即时把握的写法。用一次数字广度给轨道命名，越出了构念。本域禁止把容量手册当成分班说明书。争论应落在任务与呈现，而不是落在谁的整数更新。

第五线是生成负荷是否可独立测量。有人主张它只是成绩的另一种叫法：学会了就说生成成功，没学会就说生成不足。若改变呈现而目标不变，外在负荷的操作才可对质。若只在事后用分数命名负荷，循环没有被打破。理论有用，当它逼人改讲义。理论无用，当它只给失败贴新标签。

## 跨域连接

- **[[memory-systems|记忆系统]]**：心理学把工作记忆与长时语义、情节记忆拆开。教学若把所有“记住了”当成同一种痕迹，就会用错练习。窗口里的保持，不等于已经进入可延迟提取的系统。把容量写成儿童品质，等于拒绝这条拆分。
- **[[cognitive-bias|认知偏差]]**：判断在负荷高时更容易走捷径。课堂提问若要求学生同时保持新概念并做公平评价，得到的可能是最省力的刻板回答，而不是态度真相。负荷是条件，刻板是在条件下被选中的策略。
- **[[machine-learning-overview|机器学习概观]]**：计算机科学里的容量与过拟合，是另一个领域对“有限资源如何约束学习规则”的写法。类比只能到此：人的窗口不是参数量，也不能靠加大显存来扩。过拟合的警告仍有用——材料一换，当时很熟的表现会塌。
- **[[attention-and-transformers|注意力与变换器]]**：工程上的注意力是权重分配算法。课堂口语里的“注意力不集中”，常是道德词。两者不要互换：一个是可计算的机制，一个是纪律档案。用算法词给儿童贴不专心，是范畴错误。
- **[[weird-samples-and-generalizability|WEIRD 样本与可推广性]]**：心理学方法提醒，实验室大学生的容量估计，不能直接写成全球儿童的神经本质。教学决策若要借用效应，必须声明样本与任务。教室噪音和语言转换，会改变窗口的有效宽度。
