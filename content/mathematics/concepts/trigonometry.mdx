# 三角函数

## 什么是三角函数

**三角函数**（Trigonometric Functions）是数学中描述**角度与比例关系**，以及**周期性现象**的一族函数。它们起源于古代天文学和测量学，今天却无处不在——从声音的传播到量子力学，从GPS卫星到手机信号，三角函数是现代科学和工程的基础语言。

最基本的是**正弦**（sine，$\sin$）和**余弦**（cosine，$\cos$）。把它们看清楚，需要走完三步：直角三角形里的边比，单位圆上的坐标，以及分析学里对任意实数（甚至复数）取值的函数。弧度是这条路上的自然度量：它让角与单位圆上的弧长是同一个数，后面的导数与级数才不必再夹进换算系数。

把角从三角形里解放出来之后，正弦不再只是「对边比斜边」这句口诀，而是绕圆一周又一周的纵坐标。分析学要的就是这个可以求导、可以展开、可以叠加的对象。

## 从直角三角形出发

最直观的定义来自直角三角形。设有一个直角三角形，其中一个角为 $\theta$（非直角），三边分别称为：

- **斜边**（hypotenuse）：直角对面的最长边，长度设为 $c$
- **对边**（opposite）：角 $\theta$ 对面的边，长度设为 $a$
- **邻边**（adjacent）：角 $\theta$ 旁边的直角边，长度设为 $b$

则：

$$\sin\theta = \frac{\text{对边}}{\text{斜边}} = \frac{a}{c}, \quad \cos\theta = \frac{\text{邻边}}{\text{斜边}} = \frac{b}{c}, \quad \tan\theta = \frac{\text{对边}}{\text{邻边}} = \frac{a}{b}$$

三个比只依赖于角，不依赖于三角形被放大多少：相似直角三角形对应边成比例，所以同一个锐角对着同一组比值。这三个定义适用于 $0° < \theta < 90°$ 的锐角。一旦角变成钝角、负角或转过多圈，三角形的边就不够用了。三角函数的真正力量，在于下一步把它从「某个三角形的边比」推广成对所有实数都有意义的函数。

## 单位圆：把三角函数推广到所有角度

更普遍的定义使用**单位圆**（unit circle）——圆心在原点、半径为1的圆。设角度 $\theta$ 是从正 $x$ 轴开始，逆时针旋转的角度（以**弧度**为单位，见下文）。单位圆上对应的点 $(x, y)$ 满足：

$$\cos\theta = x, \quad \sin\theta = y$$

由勾股定理，这个点在单位圆上，因此：

$$\cos^2\theta + \sin^2\theta = 1 \quad \text{（勾股恒等式）}$$

这是三角函数中最重要的恒等式，是一切的基础。对锐角，它就是斜边上的[[pythagorean-theorem|勾股定理]]：把直角三角形斜边缩成 1，邻边与对边就变成横坐标与纵坐标。单位圆把这件事对任意角都做一遍，符号由象限决定，而不再要求边长为正。

单位圆定义的好处：
- 适用于任意角度，包括负角、大于360°的角
- $\sin\theta$ 和 $\cos\theta$ 都有明确的几何意义（纵坐标和横坐标）
- 周期性一目了然：旋转360°（即 $2\pi$ 弧度）回到原点

把实数轴往单位圆上缠，就是映射 $\theta \mapsto (\cos\theta,\sin\theta)$。每增加 $2\pi$，点走回原处，所以正弦与余弦必然以 $2\pi$ 为周期。三角形定义是这个映射在第一象限的局部读法；圆才给出完整的函数。

## 弧度：角度的自然度量

我们习惯用**度**（°）来量角，把一周切成 360 份，这在测绘和天文学里很方便。数学分析里更自然的是**弧度**（radian），因为它直接等于单位圆上的弧长。

**弧度的定义**：在半径为 $r$ 的圆中，圆弧长度等于 $r$ 时，所对的圆心角就是1弧度。角的度量于是等于弧长除以半径，与圆被画多大无关。

因此，整个圆（周长 $2\pi r$）对应圆心角 $2\pi$ 弧度，即 $360° = 2\pi$ 弧度。常见换算：

| 度 | 弧度 |
|----|------|
| $0°$ | $0$ |
| $30°$ | $\pi/6$ |
| $45°$ | $\pi/4$ |
| $60°$ | $\pi/3$ |
| $90°$ | $\pi/2$ |
| $180°$ | $\pi$ |
| $360°$ | $2\pi$ |

**为什么弧度更自然**：当用弧度度量角时，许多公式变得更简洁。最重要的是，导数公式：

$$(\sin x)' = \cos x, \quad (\cos x)' = -\sin x$$

这对**弧度**成立。若用角度，导数会多出一个系数 $\pi/180$，极为繁琐。微积分中所有的三角函数运算，都默认使用弧度。

弧度把角与单位圆上的弧长当成同一个无量纲的数：半径为 1 时，圆心角的度量就是所对弧的长度。极限 $\lim_{x \to 0}\sin x / x = 1$ 也只在弧度下成立；换成度，极限会变成 $\pi/180$。

求导公式里那个干净的「导数是余弦」，来源正是这条极限，而不是某种记法偏好。度数把圆周硬切成 360 份，在测量上方便，在分析上却是外来的换算。弧度才是让三角形、圆与微积分说同一种话的度量。

## 关键值与图像

一些常用的精确值（用弧度）：

| $\theta$ | $\sin\theta$ | $\cos\theta$ | $\tan\theta$ |
|---------|-------------|-------------|-------------|
| $0$ | $0$ | $1$ | $0$ |
| $\pi/6$ | $1/2$ | $\sqrt{3}/2$ | $\sqrt{3}/3$ |
| $\pi/4$ | $\sqrt{2}/2$ | $\sqrt{2}/2$ | $1$ |
| $\pi/3$ | $\sqrt{3}/2$ | $1/2$ | $\sqrt{3}$ |
| $\pi/2$ | $1$ | $0$ | 无定义 |
| $\pi$ | $0$ | $-1$ | $0$ |

这些精确值不是背诵清单，而是两个特殊直角三角形的边比：等腰直角给出 $\pi/4$，半个等边三角形给出 $\pi/6$ 与 $\pi/3$。单位圆只是把这些正的边比连同符号一起写到四个象限里。正切在 $\pi/2$ 无定义，是因为那里余弦为零，邻边消失了。

**正弦函数** $y = \sin x$ 以 $2\pi$ 为周期，振幅为 1，并且是奇函数：$\sin(-x) = -\sin x$。它过原点，在 $(0, \pi)$ 上为正，在 $(\pi, 2\pi)$ 上为负，图像就是单位圆上纵坐标随转角的展开。

**余弦函数** $y = \cos x$ 同样以 $2\pi$ 为周期、振幅为 1，但是偶函数：$\cos(-x) = \cos x$。它与正弦只相差 $\pi/2$ 的相位，$\cos x = \sin(x + \pi/2)$，对应的是横坐标随转角的展开。

**正切函数** $y = \tan x = \sin x/\cos x$ 的周期是 $\pi$，比正弦余弦短一半。它在 $x = \pi/2 + k\pi$ 处没有定义，出现垂直渐近线，值域却是全体实数。邻边为零时比值爆炸，正是单位圆走到上下顶点时的几何事实。

## 重要恒等式

三角恒等式是三角函数计算的工具库。真正需要记住的只有勾股恒等式与和差公式，其余都可以推导。它们记录的是圆上的几何，而不是一堆无关联的变形技巧。

**基本恒等式**：
$$\sin^2\theta + \cos^2\theta = 1$$

用余弦去除恒等式两边，就得到 $1 + \tan^2\theta = \sec^2\theta$；用正弦去除，得到 $\cot^2\theta + 1 = \csc^2\theta$。这些不是新事实，只是勾股恒等式换了分母而已。

**和差公式**：
$$\sin(A \pm B) = \sin A \cos B \pm \cos A \sin B$$
$$\cos(A \pm B) = \cos A \cos B \mp \sin A \sin B$$

**二倍角公式**（令 $A = B$ 代入上式）：
$$\sin 2A = 2\sin A \cos A$$
$$\cos 2A = \cos^2 A - \sin^2 A = 2\cos^2 A - 1 = 1 - 2\sin^2 A$$

这些公式在积分计算、物理中的叠加原理、信号处理中反复用到。和差公式可以读成两次旋转的合成：先转 $B$ 再转 $A$，横坐标与纵坐标按圆的乘法展开，就得到 $\cos(A\pm B)$ 与 $\sin(A\pm B)$。二倍角只是同一次旋转做两遍。记住少数几个核心式，其余都可以从旋转与勾股恒等式推出来，而不必当成互不相关的口诀。

## 历史：从天文学到分析学

三角函数的历史横跨两千年，反映了数学从具体应用走向抽象理论的过程。它先是测天体的弦表，再是圆上的半弦，最后才变成可以求导的函数。弧度是最后这一步的度量，而不是另一种刻度盘。

**古希腊天文学**：三角学（Trigonometry）最早起源于天文计算的需要。希巴恰斯（Hipparchus，约前190—前120年）被认为是三角学的鼻祖，他建立了弦长（chord length）的表格来计算天体位置——这是正弦函数的前身。托勒密（Ptolemy，约100—170年）在《天文学大成》第一卷里给出了系统的弦表：在直径取 120 份的圆上，对半度到 180 度的圆心角列出对应弦长。整弦对应今天的 $2\sin(\theta/2)$，球面三角则用来预报行星在天球上的位置。

**印度数学家**：印度天文学家圣使（Āryabhaṭa，476—550年）在《圣使集》里使用"jya"（半弦，即现代正弦）代替完整的弦，这是正弦函数的直接前身。半弦比整弦更便于计算，概念随后经阿拉伯译本进入欧洲。"sine"这个词来自拉丁语"sinus"：梵语 jiva 音译成阿拉伯语 jiba，因辅音写法被读成意为「海湾、胸湾」的 jaib，十二世纪译成拉丁语时便用了 sinus。名称走了一段误译，对象却一直是那条半弦。

**欧拉的统一**：莱昂哈德·欧拉（Leonhard Euler）在1748年的《无穷小分析引论》（Introductio in analysin infinitorum）中，首次将三角函数定义为数值函数（而不仅仅是几何比例），给出了我们今天使用的 $\sin x$ 和 $\cos x$ 的记法，并建立了欧拉公式：

$$e^{ix} = \cos x + i\sin x$$

这个公式将指数函数、虚数和三角函数统一在一个等式中。它能成立，前提是指数与三角的幂级数使用同一种角的度量——也就是弧度。若把 $x$ 理解成度数，两边的[[series|级数]]对不上，欧拉公式也不会长成今天这副样子。正弦与余弦的幂级数在牛顿与莱布尼茨的微积分里已经出现；欧拉的贡献是把它们提升为与指数函数平起平坐的分析对象。

## 欧拉公式：三角函数的深层本质

欧拉公式 $e^{ix} = \cos x + i\sin x$ 揭示了三角函数的深层结构。从泰勒级数展开验证：

$$e^{ix} = \sum_{n=0}^{\infty}\frac{(ix)^n}{n!} = 1 + ix - \frac{x^2}{2!} - \frac{ix^3}{3!} + \frac{x^4}{4!} + \cdots$$

将实部和虚部分开，恰好得到：

$$\cos x = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots = \sum_{n=0}^{\infty}\frac{(-1)^n x^{2n}}{(2n)!}$$

$$\sin x = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots = \sum_{n=0}^{\infty}\frac{(-1)^n x^{2n+1}}{(2n+1)!}$$

这不只是一种计算方法——它揭示了三角函数的本质：**$\sin x$ 和 $\cos x$ 是指数函数在虚数轴上的投影**。三角函数描述的"旋转"和指数函数描述的"增长"，在[[complex-number|复数]]世界里是同一件事。麦克劳林展开本身来自[[taylor-theorem|泰勒定理]]在零点处的展开；认出实部是余弦、虚部是正弦，靠的是事先独立得到的系数，而不是事后指定。特殊值 $x=\pi$ 时得到 [[euler-identity|欧拉恒等式]] $e^{i\pi}+1=0$，那是这条投影在半周转到位之后的一条推论。

## 傅里叶级数：任何波形都是正弦波之和

19世纪，法国数学家傅里叶（Joseph Fourier，1768—1830）发现了三角函数最惊人的应用——**傅里叶分析**。

**傅里叶定理**（非正式）：几乎任何一个周期函数，都可以表示为正弦波和余弦波的无穷叠加：

$$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty}(a_n \cos nx + b_n \sin nx)$$

其中系数 $a_n, b_n$ 由积分确定，称为**傅里叶系数**。这个定理的意义在于：正弦和余弦函数构成了"函数空间的基"——就像向量空间中任何向量都可以用基向量表示，任何（足够好的）周期函数都可以用三角函数"分解"。从三角形的边比走到这里，函数已经不再记得那个直角三角形，只记得圆上的周期振荡。

傅里叶分析的应用无处不在：
- **音频**：声音是气压随时间的周期振动，MP3压缩就是保留傅里叶级数中能量最大的成分，丢弃人耳感知不到的高频成分。
- **图像处理**：JPEG压缩使用离散余弦变换（DCT），将图像分解为空间频率成分。
- **量子力学**：位置空间的波函数和动量空间的波函数之间的变换，就是傅里叶变换。
- **医学成像**：MRI（磁共振成像）通过采集信号的傅里叶变换来重建人体内部图像。

把任意周期扰动拆成正弦与余弦，靠的是它们在积分内积下互相正交。每一步都默认自变量用弧度：系数公式里的 $\cos nx$、$\sin nx$ 若改用角度，正交关系还在，只是所有积分都会多出换算因子。分析学把三角函数从测角表变成函数空间里的基，弧度是让这组基写起来最干净的单位。

## 三角函数在物理中

三角函数是物理学最常用的数学工具，原因在于许多物理现象本质上是**振动**。弹簧、声波、交流电写下的都是同一类振荡，差别只在自变量叫时间还是叫路程。

**简谐振动**：弹簧-质量系统的运动方程是 $m\ddot{x} = -kx$，解是 $x(t) = A\cos(\omega t + \phi)$，其中 $\omega = \sqrt{k/m}$ 是角频率。相位 $\phi$ 与振幅 $A$ 由初始位置和速度决定，时间自变量必须用弧度，否则 $\omega$ 的单位会对不上。这是物理中最简单也最常用的振动模型。

**波动**：电磁波的电场常写成 $E(x, t) = E_0 \sin(kx - \omega t)$，其中 $k = 2\pi/\lambda$ 是波数，$\omega = 2\pi f$ 是角频率。正弦在这里同时承担空间周期与时间周期，把行波写成一次旋转在时空里的展开。

**电路**：交流电的电压 $V(t) = V_0 \sin(\omega t)$。电子工程用欧拉公式把正弦换成复指数，稳态电路就变成代数运算。换算能成立，仍然要求 $\omega t$ 以弧度计。

## 常见误区

- **弧度vs角度的混用**：在微积分中，$(\sin x)' = \cos x$ 只在 $x$ 用弧度度量时成立。计算器若停在「度」模式，数值微分与极限 $\sin x/x$ 都会差出一个 $\pi/180$。
- **$\sin^{-1}$ 和 $1/\sin$**：$\sin^{-1}x$（反正弦函数，值域 $[-\pi/2, \pi/2]$）不等于 $\csc x = 1/\sin x$（余割函数）。上标 $-1$ 在这里表示反函数，不是倒数。
- **$\sqrt{a^2 + b^2} \neq a + b$**：在使用勾股定理时，斜边是 $\sqrt{a^2+b^2}$，不能写成 $a + b$。把单位圆上的点坐标当成边长直接相加，会立刻破坏 $\sin^2+\cos^2=1$。

## 跨域连接

- **[[waves-and-acoustics|波与声学]]**：线性介质中任意扰动可分解为独立传播的正弦模式，频率之间不交换能量。推论：同时输入两个纯音，输出里不该出现和频与差频；**一旦听到这类新频率，就说明系统已被推进非线性区**，失真程度因此可以用频谱直接量化。
- **[[tides|潮汐]]**：引潮力由天体相对位置的周期运动决定，可展成一组频率固定的分量，各港口只在振幅与相位上不同。推论：用本地一段观测定出各分潮的振幅相位后即可长期外推，观测越长可分辨的分潮越多——**预报能力来自频率已知，而不是来自数据量大**。
- **[[ct-mri|磁共振成像]]**：采集到的原始信号是图像的空间频率成分，图像由这些成分叠加还原。推论：只采低频得到的是模糊但完整的整幅图，漏采高频丢的是边缘而非某一块区域——伪影的形态因此可以反推采样方案的缺陷所在，而不必逐一试错。
- **[[古代天文学|古代天文学]]**：球面上的边角关系把天体位置与观测者的地平坐标直接联系起来，全程不需要知道距离。推论：同一组公式反过来用，可由恒星高度反解纬度——历法编制与航海定位共用一副工具，同一份表格因此可以跨用途复用。
- **[[fourier-analysis|傅里叶分析]]**：正弦与余弦在积分内积下互相正交，因此每个系数都能被独立提取而不受其他分量干扰。推论：正交性一旦被破坏（例如把信号硬截断），系数就会互相串扰，在边缘处留下固定形状的振荡。
