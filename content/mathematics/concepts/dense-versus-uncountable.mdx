# 稠密不是不可数

稠密不是不可数，说的是有理数与实数在三页里已经分开的两件事。希尔伯特旅馆那一页写：有理数在直线上稠密，任意两个实数之间都有有理数，但它们与自然数一样多。集合论那一页写 $|\mathbb{Q}| = \aleph_0$，有理数可数。实数不可数。康托尔定理那一页写，1874年他证明实数比自然数更多，1891年用对角线论证把“没有最大的无穷”写成一般形式。稠密说的是中间还有有理数。可数说的是能与自然数一一配对。两句可以同时为真。

它不是“到处都有，就数不完”。旅馆页直接写：稠密不等于不可数。它也不是把连续统假设写成已经证出的等式。集合论页把假设陈述成不存在介于可数无穷和连续统之间的基数，并写明哥德尔于1938年宣布、1940年完整发表，科恩在1963年证明否定式也一致。康托尔定理页写：$2^{\aleph_0} = \aleph_1$ 不是定义，也不是定理。代数数在旅馆页里可数。可数个可数集的并仍然可数。希尔伯特旅馆的演讲年份，只用那一页写下的1924年。

## 多少看配对，不看挤不挤

集合论页用一一配对比较多少：配完就一样多。自然数与偶数一样多，因为 $n \leftrightarrow 2n$ 把它们配完。旅馆页把这件事做成前台操作。再来一位，用 $f(n) = n+1$，每人挪到下一间。再来可数多位，用 $f(n) = 2n$，奇数房空出来。整体可以与真子集一一对应。旅馆页把这称作戴德金对无穷集合的定义。

可数个可数集的并仍然是可数的。旅馆页用无穷多辆巴士来写，每辆上有无穷多个客人。第 $i$ 辆上的第 $j$ 位客人进 $p_i^j$ 号房间，$p_i$ 是第 $i$ 个素数。算术基本定理使不同的对不会撞房。这个方案会空出一些房间，页内点名的是6号、10号、12号这些非素数幂。它证明并集仍可数，但不是最省的排法。更紧凑的是康托尔的对角线，也就是蛇形配对，能把房间恰好填满。集合论页用另一句概括同一件事：可数集的子集、有限并、可数并仍可数。$\aleph_0 + \aleph_0 = \aleph_0$，以及 $\aleph_0 \times \aleph_0 = \aleph_0$，是旅馆页写下的基数算术，说的就是可数并没有跳出可数。本页不另写页外的基数等式。

实数那么多的客人，前台排不进去。旅馆页写：不可数无穷不能与自然数建立一一对应。这是旅馆的天花板，不是再加一辆可数的巴士。

## 有理数稠密，仍然可数

旅馆页把有理数的可数性写成一件反直觉的事，因为它们在数轴上稠密：任意两个实数之间都有有理数。证明用蛇形遍历。正有理数排成表格，行是分子，列是分母，再沿对角线走。页内列出的开头是 $1/1$、$2/1$、$1/2$、$3/1$、$2/2$、$1/3$，然后跳过重复，得到从正整数到正有理数的一一对应。因此稠密没有挡住可数。集合论页把同一结论写成 $|\mathbb{Q}| = \aleph_0$。

代数数是整系数多项式的根。旅馆页写，其中有全部有理数，也有许多无理数，点名的是 $\sqrt{2}$ 和 $\sqrt[3]{5}$。代数数仍然可数：整系数多项式只有可数多个，每个多项式只有有限个根。超越数是不为任何整系数多项式的根的数，页内点名 $\pi$ 和 $e$。旅馆页接着写：超越数不仅存在，而且几乎所有的实数都是超越数，代数数在实数集中测度为零。可数，加上测度为零，都没有写成一个新的基数等式。本页也不把“几乎所有”改写成页外的等号。

## 实数不可数，幂集只保证更大

实数不可数，在三页里都有。旅馆页的对角线是：假设自然数与实数一一对应，列出十进制展开，再造一个新实数，使它的第 $n$ 位不同于列表里第 $n$ 个实数的第 $n$ 位。这个新实数不在列表中。集合论页把同一论证限制在 $[0,1]$，并写成 $|\mathbb{R}| > |\mathbb{N}|$。康托尔定理页把一般形式写成：任何集合的幂集都严格更大，不存在从集合到其幂集的满射。单射可以先把元素映成单点子集。满射会在对角线上自相矛盾。

由此写下的等式，只重复页内已有的几条。$|\mathbb{N}| = \aleph_0$。$|\mathcal{P}(\mathbb{N})| = 2^{\aleph_0}$。$|\mathbb{R}| = 2^{\aleph_0} = \mathfrak{c}$。康托尔定理页把 $|\mathbb{R}| = 2^{\aleph_0} = |\mathcal{P}(\mathbb{N})|$ 称为定理的特例。方向是 $\aleph_0 < 2^{\aleph_0}$。幂集可以再迭代：$\aleph_0 < 2^{\aleph_0} < 2^{2^{\aleph_0}} < \cdots$。旅馆页的口头算术是 $\infty + 1 = \infty$，$\infty + \infty = \infty$，但 $2^{\infty} > \infty$。这些句子只说幂更大，没有说幂等于哪一个后继基数。

康托尔定理页专门拦住一种读法。幂集这条阶梯是贝特数。$\aleph_1, \aleph_2, \ldots$ 是另一条阶梯，每一级是上一级之后最小的可良序基数。定理只保证 $2^{\aleph_0} > \aleph_0$，没有告诉你 $2^{\aleph_0}$ 落在阿列夫阶梯的哪一格。$(0,1)$ 与全体实数一样大，旅馆页给出的双射是 $\tan(\pi(x - 1/2))$。开区间里已经有稠密的有理数，这个区间的基数却与整条实数线相同。稠密的是其中的有理数，不可数的是区间里的实数。

## 连续统假设保持为假设

连续统假设问的是：有没有严格介于 $\aleph_0$ 和 $2^{\aleph_0}$ 之间的基数。集合论页把陈述写成 $2^{\aleph_0} = \aleph_1$，意思是没有那样的中间基数。康托尔定理页写明，这个等式不是定义，也不是定理，而是独立命题。把它当成显然成立，是那一页指出的常见误用。本页不把该等式写成已证结论。

年份只按页内的写法。集合论页写：哥德尔用可构造宇宙 $L$ 证明，若 ZF 无矛盾，加上选择公理与广义连续统假设后仍无矛盾。结果于1938年宣布、1940年完整发表。这只说明连续统假设不可被否证。科恩在1963年用力迫法证明，否定式也与 ZFC 一致。假设因此独立于 ZFC，不可判定。1938年是宣布的年份，不是把等式证出来的年份。康托尔定理页与旅馆页都写到1940年和1963年的不可判定，没有把假设写成已证等式。

广义连续统假设在集合论页被陈述为：对任意序数 $\alpha$，$2^{\aleph_\alpha} = \aleph_{\alpha+1}$。这仍是假设的句子。同页写它蕴含选择公理，单独的连续统假设并不蕴含选择公理。康托尔定理页写广义形式同样独立于 ZFC，并写在适当模型里 $2^{\aleph_0}$ 可以等于 $\aleph_2$。那不是把连续统假设证成 $\aleph_1$。

基数和序数也不要并成一件事。旅馆页写：基数衡量大小，序数衡量良序的顺序类型。$\omega$ 是最小的无穷序数，$\aleph_0$ 是最小的无穷基数。序数加法不交换：$\omega + 1 \neq 1 + \omega = \omega$。有理数的稠密，是任意两个实数之间还有有理数，这是顺序上的夹缝。可数，是配对。夹缝多，不自动把基数抬过 $\aleph_0$。

## 演讲年份只记1924年

旅馆页写，希尔伯特在1924年的一次公开演讲里用这个比喻说明康托尔的发现。更细的一句是：比喻出自1924年1月，希尔伯特本人没有写下来发表。伽莫夫1947年的《从一到无穷大》才让它广为人知。1947年是书的年份，不是演讲的年份。康托尔在页内是1845年至1918年，希尔伯特是1862年至1943年。这些数字用来标明人物，不用来改写1924年。

## 破除误解

**第一个误解，任意两个实数之间都有有理数，所以有理数和实数一样多，稠密已经排除了可数。**

旅馆页把“任意两个实数之间都有有理数”写成稠密，并在同一段写明它们与自然数一样多。蛇形列举的开头就是 $1/1$、$2/1$、$1/2$、$3/1$、$2/2$、$1/3$，跳过重复之后仍然是一条可数的名单。集合论页写成 $|\mathbb{Q}| = \aleph_0$。实数不可数，写成 $|\mathbb{R}| > |\mathbb{N}|$，以及 $|\mathbb{R}| = 2^{\aleph_0}$。稠密是夹缝，可数是配对。旅馆页的原话是：稠密不等于不可数。

**第二个误解，可数个可数集并起来就会多到无法与自然数配对，旅馆因此住不下这些客人。**

旅馆页的定理句是：可数个可数集的并仍然是可数的。素数幂的排法会空着6号、10号、12号，那是浪费，不是把并集变成实数那么多。蛇形配对把房间填满，填满之后仍是可数无穷。$\aleph_0 \times \aleph_0 = \aleph_0$ 已在页内。住不下的是实数那么多的客人，因为实数不可数，不能与房间一一配对。再添可数辆巴士，还在定理的范围里。

**第三个误解，连续统假设已经写成等式，幂集刚好落在下一个阿列夫上。**

康托尔定理页写，$2^{\aleph_0} = \aleph_1$ 不是定义，也不是定理。定理只保证 $2^{\aleph_0} > \aleph_0$。贝特数的阶梯与阿列夫数的阶梯不是同一条。集合论页把没有中间基数写成假设的陈述，并写明哥德尔1938年宣布、1940年发表一致性，科恩1963年证明否定式也与 ZFC 一致，所以在标准公理下不可判定。不可判定不是已经证出的等号。本页不补一个新的基数等式，来代替这个独立命题。

**第四个误解，代数数连根号二都包括，所以代数数已经和实数同样不可数。**

旅馆页写，代数数包括有理数，也包括 $\sqrt{2}$、$\sqrt[3]{5}$ 这样的无理数，但整个代数数集仍然可数。理由是整系数多项式可数多个，每个只有有限个根。$\pi$ 和 $e$ 被点名为超越数。几乎所有的实数是超越数，代数数的测度为零。可数的集合可以包含一些无理数。包含无理数，没有在页内被写成 $|\mathbb{R}|$ 那个基数。实数不可数，靠的是对角线，不是靠“里面有根号”。

## 跨域连接

- **[[words-and-sentences|词与句子]]**：康托尔定理页写，有限词句能写下的描述至多可数，实数不可数，几乎每一个实数都无法被有限描述指称。不可命名的实数举不出例子，因为一旦举出就命名了。结论靠计数，不靠展示。旅馆页却能把正有理数蛇形列出，开头是 $1/1$、$2/1$、$1/2$。稠密只说明实数之间还有有理数，不说明每个实数都有有限名字。

- **[[compilers|编译器]]**：康托尔定理页写，程序至多可数，从输入到输出的函数不可数，于是绝大多数行为没有程序能实现。程序等价性因此不可判定，优化只能在保守条件下进行。这道缺口与实数不能排进自然数名单是同一种计数。程序像有理数和代数数，站在可数一边。全体函数像实数，站在不可数一边。

- **[[philosophy-of-mathematics|数学哲学]]**：集合论页写，形式主义只要求系统不自相矛盾，柏拉图主义还要求公理描述实在。独立性结果使分歧可操作：连续统假设在现有公理下无从谈起。承认没有答案，还是去找新公理，取决于立场。这里的无从谈起，对应1938年宣布、1940年发表和1963年的力迫，不是把 $2^{\aleph_0} = \aleph_1$ 当成已经写完的等式。

- **[[cognitive-biases-evolutionary|演化视角下的认知偏差]]**：旅馆页写，有限集合里整体大于部分永远成立，这条经验被固化成先验。直觉从小数目、有限对象的环境里选出，超出适用域时不会自己报警。有理数看起来“更密、更多”，就是这种经验：到处都有，好像数不完。页内的更正是蛇形配对仍然成功，稠密不等于不可数。

- **[[lambda-calculus-type-theory|λ演算与类型论]]**：集合论页写，直觉主义要求存在必须给出构造，因而证明要能变成程序。反证法得到的存在性抽不出算法。旅馆页对正有理数给出可以逐项写下的表。实数不可数则是：假定名单完备，对角线就造出名单之外的数。不要把这张表扩到全体实数，也不要因此抹掉“可数并仍可数”。
