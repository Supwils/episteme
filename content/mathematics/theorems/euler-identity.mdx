## 定理陈述

**欧拉恒等式**（Euler's Identity）是数学中最著名的等式：

$$e^{i\pi} + 1 = 0$$

这个等式将五个最重要的数学常数联系在一起：
- $e = 2.71828\ldots$——自然对数的底，分析学的核心
- $i = \sqrt{-1}$——虚数单位，复数的基础
- $\pi = 3.14159\ldots$——圆周率，几何学的基石
- $1$——乘法单位元
- $0$——加法单位元

同时涉及三种基本运算：加法、乘法、幂运算。

这个等式不是在定义其中任何一个常数，而是一条可以从欧拉公式推出来的恒等式。五个符号在进入这一行之前，各自已经有独立的意义。它真正断言的是：一旦接受复指数函数，这五者就必须满足这一条约束。

## 直觉理解

欧拉恒等式是**欧拉公式** $e^{ix} = \cos x + i\sin x$ 在 $x = \pi$ 时的特例。理解欧拉公式的关键是：复指数 $e^{ix}$ 描述了复平面上单位圆上的点。当 $x = 0$ 时，$e^{i \cdot 0} = 1$（圆的最右端）。当 $x$ 增大时，点沿单位圆逆时针旋转。当 $x = \pi$ 时，点恰好旋转到圆的最左端，即 $e^{i\pi} = -1$。所以 $e^{i\pi} + 1 = 0$ 说的是：从 1 出发，沿单位圆旋转半周（$\pi$ 弧度），到达 $-1$，再加 1 回到 0。这是复平面上的一个几何事实。

把 $e^{ix}$ 读成单位圆上的点，是今天最清楚的几何图像。它把“虚数单位没有几何意义”这条常见说法拆开了。$i$ 不是某种不存在的数，而是把平面上的点逆时针转过直角的运算。

半周对应 $\pi$ 弧度，因此 $e^{i\pi}$ 必须落在 $-1$。恒等式只是把这个已经转到位的点再加 $1$，送回原点。旋转与平移都是复平面上的普通操作，并不依赖对“美”的评价。

这条几何读法非常好用，却不宜直接写成欧拉本人的发现路径。1748 年的《无穷分析引论》走的是指数与三角级数，而不是先在阿尔冈平面上画一个圆。卡斯帕·韦塞尔在 1797 年宣读、1799 年发表了方向的解析表示；让-罗贝尔·阿尔冈的论著则在 1806 年。单位圆图像是后来才长成教科书里的标准画面。

## 证明思路

欧拉恒等式由欧拉公式 $e^{ix} = \cos x + i\sin x$ 直接推出。

### 欧拉公式的证明

将 $e^{ix}$、$\cos x$、$\sin x$ 分别展开为麦克劳林级数：

$$e^{ix} = \sum_{n=0}^{\infty} \frac{(ix)^n}{n!} = 1 + ix - \frac{x^2}{2!} - i\frac{x^3}{3!} + \frac{x^4}{4!} + \cdots$$

分离实部和虚部：

$$e^{ix} = \left(1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots\right) + i\left(x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots\right)$$

$$= \cos x + i\sin x$$

代入 $x = \pi$：

$$e^{i\pi} = \cos\pi + i\sin\pi = -1 + 0i = -1$$

因此 $e^{i\pi} + 1 = 0$。

把 $e^{ix}$ 写成级数，再按实部与虚部分组，这一步用到了绝对收敛级数可以重排。正弦与余弦的麦克劳林级数本身来自 [[taylor-theorem|泰勒定理]] 在零点处的展开。因此欧拉公式在这条路线上，并不是一条孤立的神来之笔，而是把三条已经知道的展开式叠在一起。

代入 $x=\pi$ 之后，只剩下 $\cos\pi=-1$ 与 $\sin\pi=0$ 这两条普通的三角事实。常见的误解是：既然结果如此整齐，级数证明一定在“凑”答案。事实相反。认出实部是余弦、虚部是正弦，靠的是事先独立得到的展开，而不是事后指定。

### 替代证明（微分方程方法）

考虑微分方程 $\frac{d}{dx}f(x) = if(x)$，$f(0) = 1$。解为 $f(x) = e^{ix}$。同时 $g(x) = \cos x + i\sin x$ 也满足同一方程和初始条件。由解的唯一性，$e^{ix} = \cos x + i\sin x$。

微分方程路线不展开级数。它只比较两个满足同一初值问题的函数。线性方程 $\frac{d}{dx}f=if$ 在 $f(0)=1$ 时至多一个解，因此两者必须相同。这条论证把欧拉公式变成了一条唯一性定理的推论。它依赖的是常微分方程的唯一性，而不是对三角恒等式的记忆。

## 历史背景

欧拉恒等式的历史与欧拉公式密不可分。

**罗杰·科茨**（Roger Cotes，1682—1716）在 1714 年发表于《自然科学会报》（Philosophical Transactions）的《Logometria》中，首次给出了等价形式 $ix = \ln(\cos x + i\sin x)$（指数化即得欧拉公式）。**欧拉**（Leonhard Euler，1707—1783）在 1748 年的《无穷分析引论》（*Introductio in analysin infinitorum*）中首次发表了 $e^{ix} = \cos x + i\sin x$ 的现代形式。

欧拉对复指数函数的理解建立在他对对数函数的复数推广之上。他注意到 $\ln(-1) = i\pi$（取主值），由此推出 $e^{i\pi} = -1$。费曼在《费曼物理学讲义》（第一卷第 22 章）中称欧拉公式 $e^{ix} = \cos x + i\sin x$ 为"数学中最非凡的公式"（the most remarkable formula in mathematics）。

科茨 1714 年的形式是对数，不是指数。把 $ix=\ln(\cos x+i\sin x)$ 指数化，才能得到今天的欧拉公式。欧拉在 1748 年《无穷分析引论》第一卷里给出的，是 $e^{ix}=\cos x+i\sin x$ 这种现代指数写法。需要分开的是：该书给出的是一般公式，而不是后来被单独陈列的 $e^{i\pi}+1=0$。把五个常数收进一个短等式，是后世教学里的浓缩，不宜直接写成 1748 年的标题定理。

欧拉对 $\ln(-1)$ 的讨论，和莱布尼茨与约翰·伯努利关于负数对数的争论连在一起。若取主值，则 $\ln(-1)=i\pi$，两边指数化即得 $e^{i\pi}=-1$。对数在复数上是多值的，主值只是其中一支。因此 $e^{i(\pi+2\pi k)}=-1$ 对任意整数 $k$ 都成立，恒等式并没有把所有辐角都收成 $\pi$ 这一个数。

欧拉用字母 $i$ 表示 $\sqrt{-1}$，是更晚的事。1777 年的一篇提交彼得堡科学院的论文里，他系统采用这一记号；正式刊出已到 1794 年。1748 年的《引论》里，虚数单位仍常写成 $\sqrt{-1}$。今天课本上的 $e^{i\pi}+1=0$，在符号层面已经过了一次标准化。

费曼称赞的是整条欧拉公式，而不是单独抽出的恒等式。把那句“最非凡的公式”直接安在 $e^{i\pi}+1=0$ 头上，是常见的张冠李戴。恒等式是公式在 $x=\pi$ 时的一个点；公式本身管的是整个圆。

## 应用

欧拉恒等式及其推广（欧拉公式）在科学和工程中有广泛应用：

1. **交流电路分析**：用复指数表示正弦信号——$V(t) = V_0 e^{i\omega t}$ 简化了电路计算
2. **量子力学**：波函数 $\psi = Ae^{i(kx - \omega t)}$ 的核心是复指数
3. **信号处理**：傅里叶变换 $F(\omega) = \int f(t)e^{-i\omega t}dt$ 以欧拉公式为基础
4. **控制理论**：频域分析中传递函数的极点和零点在复平面上表示
5. **旋转表示**：计算机图形学中用 $e^{i\theta}$ 表示二维旋转

这些应用有一条共同的理由。线性微分方程的实部与虚部分别满足同一套实方程，因此用 $e^{i\omega t}$ 代替正弦、余弦，只是把两个实方程打包成一个复方程。算出后再取实部，并不表示物理量本身必须是复数。量子力学是例外：概率幅本身就是复数，相位差会进入可观测的干涉。

在电路与信号处理里，欧拉公式的用处是把频率变成乘法。微分对应乘以 $i\omega$，卷积对应频域相乘。没有这条对应，傅里叶变换只是一条形式积分，而不是一套可计算的代数。

## 与其他定理的关系

- **欧拉公式**：$e^{ix} = \cos x + i\sin x$——欧拉恒等式是 $x = \pi$ 的特例
- **棣莫弗公式**：$(\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta$——由欧拉公式推出
- **傅里叶分析**：欧拉公式将三角函数与复指数联系，是傅里叶分析的基础
- **微积分基本定理**：欧拉公式的证明依赖于幂级数展开，而幂级数理论建立在微积分之上
- **代数基本定理**：欧拉公式与复数的极坐标表示密切相关

[[fundamental-theorem-of-algebra|代数基本定理]] 说每个非常数复多项式都有根。极坐标表示 $z=re^{i\theta}$ 让这条定理的几何图像变得直接：一次因式对应一次旋转与缩放，次数为 $n$ 的多项式在辐角上绕原点 $n$ 圈。欧拉公式并不证明代数基本定理，但它提供了复数乘法的语言。棣莫弗公式则是同一语言在整数幂上的特例。

## 为什么它被称为"最美丽的公式"

欧拉恒等式 $e^{i\pi} + 1 = 0$ 常被称作数学中最美的公式。这句话不是定理，而是后来的评价。1988 年戴维·韦尔斯在《数学情报员》上发起读者调查，1990 年公布结果，所列定理中 $e^{i\pi}+1=0$ 得票最高。这是一份杂志读者的偏好统计，不是对“美”的数学证明，也不是全行业公投。

调查之后，人们仍用几条彼此独立的理由来解释这份偏好。它们说的是结构上的整齐，而不是一份新的证明。

1. **简洁性**：用最简单的符号表达了最深刻的关系
2. **意外性**：五个看似无关的常数——$e$（分析学）、$i$（代数学）、$\pi$（几何学）、$1$（算术）、$0$（集合论）——被一个等式联系
3. **深刻性**：它不是偶然的巧合，而是反映了复指数函数、三角函数和圆的几何之间的深层联系
4. **统一性**：涉及加法、乘法和幂运算三种基本运算

费曼称之为"数学中最非凡的公式"。数学家哈代说："如果有什么东西能让数学家心动，那就是美。"

把五个常数与三种运算并置，是解释这份偏好时最常用的说法。它有教学上的力量，却容易让人以为欧拉当初就是为了把 $0,1,e,i,\pi$ 收进一行才写出公式。更准确的顺序相反：先有复指数与三角的恒等，再在 $\theta=\pi$ 处得到 $-1$，最后才被单独陈列成今天的短式。

## 欧拉公式的其他特例

欧拉公式 $e^{ix} = \cos x + i\sin x$ 在不同 $x$ 值处给出不同的恒等式：

- $x = 0$：$e^{i \cdot 0} = 1$——平凡但正确
- $x = \pi/2$：$e^{i\pi/2} = i$——虚数单位是 $90°$ 旋转
- $x = \pi$：$e^{i\pi} = -1$——欧拉恒等式
- $x = 2\pi$：$e^{2i\pi} = 1$——$2\pi$ 旋转回到原点

每个特例都有深刻的几何意义：$e^{i\theta}$ 表示复平面上角度为 $\theta$ 的旋转。

$x=3\pi/2$ 时，$e^{i3\pi/2}=-i$。它表示再转四分之三圈，落到负虚轴。这些特例合在一起，只是在说同一件事：$e^{i\theta}$ 以 $2\pi$ 为周期，绕单位圆重复。整数圈对应 $e^{2\pi i k}=1$，这正是复对数多值性的来源。

因此“$e^{i\pi}=-1$”与“$e^{-i\pi}=-1$”同时成立，并不互相否定。它们对应从 $1$ 出发的两条半圆。主值约定选取 $\operatorname{Arg}(-1)=\pi$，只是为了把对数做成一个函数，而不是因为另一条路径非法。

## 复数的极坐标表示

欧拉公式给出了复数的极坐标表示：

$$z = r e^{i\theta} = r(\cos\theta + i\sin\theta)$$

其中 $r = |z|$ 是模，$\theta = \arg(z)$ 是辐角。这种表示使得复数的乘法和除法变得极其简单：

$$z_1 z_2 = r_1 r_2 e^{i(\theta_1 + \theta_2)}$$

即：模相乘，辐角相加——复数乘法就是旋转加缩放。

从欧拉公式立刻得到棣莫弗公式。$(re^{i\theta})^n=r^n e^{in\theta}$，也就是模的幂次与辐角的整数倍。反方向看，开 $n$ 次方就是把辐角除以 $n$，并补上 $2\pi k/n$ 的全部分支。单位根因而均匀地坐在单位圆上。这不是三角学里一条额外的技巧，而是 [[complex-number|复数]] 乘法的几何。

## 欧拉公式在物理学中的核心地位

欧拉公式 $e^{ix} = \cos x + i\sin x$ 是现代物理学不可或缺的工具：

**量子力学**：波函数 $\psi(\mathbf{r}, t) = A e^{i(\mathbf{k} \cdot \mathbf{r} - \omega t)}$ 是薛定谔方程的平面波解。复指数表示使得叠加原理的计算极为简洁——相位因子 $e^{i\phi}$ 编码了量子干涉的全部信息。量子力学的概率幅必须是复数——实数不足以描述干涉现象。

**电磁学**：时谐电磁场 $\mathbf{E}(\mathbf{r}, t) = \text{Re}[\mathbf{E}_0(\mathbf{r})e^{-i\omega t}]$ 用复指数表示正弦振荡。麦克斯韦方程在频域中变为代数方程——复指数表示将微分方程转化为代数方程。

**信号处理**：傅里叶变换 $F(\omega) = \int_{-\infty}^{\infty} f(t)e^{-i\omega t}dt$ 将信号分解为复指数分量。离散傅里叶变换（DFT）和快速傅里叶变换（FFT）是数字信号处理的核心算法——从 MP3 压缩到 MRI 成像，无处不在。

**交流电路**：阻抗 $Z = R + iX$ 将电阻和电抗统一为复数。欧姆定律 $V = ZI$ 在复数域中成立——电路分析从微分方程变为复数代数。

在经典波动里，写成复指数是计算约定。麦克斯韦方程是实的，可观测的电场是实部。量子力学不同：薛定谔方程的解本身是复的，整体乘上 $e^{i\alpha}$ 不改变测量统计，相对相位则改变。欧拉公式在两处都出现，扮演的角色并不相同：一处是把振荡写成乘法，一处是给概率幅提供相位。

## $e$、$\pi$、$i$ 的深层联系

欧拉恒等式将三个看似无关的常数联系在一起，但它们之间存在深层的数学联系：

**$e$ 与 $\pi$ 的联系**：$e^{i\pi} = -1$ 表明 $e$ 和 $\pi$ 通过虚数单位 $i$ 联系。更直接的联系是高斯积分 $\int_{-\infty}^{\infty} e^{-x^2}dx = \sqrt{\pi}$——指数函数和圆周率在一个积分中相遇。

**$i$ 的几何意义**：$i$ 是 $90°$ 旋转——$i^2 = -1$ 表示两次 $90°$ 旋转等于 $180°$ 旋转。复数乘法 $z \mapsto iz$ 将复平面上的点逆时针旋转 $90°$。

**$e$ 的分析学意义**：$e$ 是唯一使得 $\frac{d}{dx}e^x = e^x$ 的底数——它是"自然增长"的数学表达。$e^{i\theta}$ 是"自然旋转"——虚指数的增长就是旋转。

这三个常数分别来自分析学（$e$）、几何学（$\pi$）和代数学（$i$），它们在欧拉公式中的统一反映了数学三大分支的深层联系。

高斯积分 $\int_{-\infty}^{\infty}e^{-x^2}dx=\sqrt{\pi}$ 表明 $e$ 与 $\pi$ 还会在实分析里相遇。那条等式走的是另一条路，通常用极坐标把平方指数变成径向积分。它并不依赖 $e^{i\pi}=-1$，却同样说明指数函数与圆的度量纠缠在一起。把欧拉恒等式说成 $e$、$\pi$、$i$ 唯一的汇合点，并不准确：它是最短的汇合点，不是唯一的汇合点。

$e$ 作为 $\frac{d}{dx}e^x=e^x$ 的底，使虚指数的导数恰好是旋转的切向。这就是“自然旋转”的精确含义：切向量始终垂直于径向量，且长度与半径成正比。圆之所以出现，是因为这个微分方程的解必须保持模长。$\pi$ 则是这条闭合轨道的半周长度。

## 跨域连接

- **[[complex-number|复数]]**：复数乘法就是旋转加缩放，而复指数把"角度相加"变成"指数相乘"。**推论是：三角恒等式整体退化成指数律**——和角公式不必死记，它只是把两次旋转合成一次，单位复数的乘法结构才是这些公式真正的来源，记不住时重推一遍即可。
- **[[wave-function-probability|波函数与概率]]**：量子振幅是复数，概率取模平方，因此整体相位不可观测，而相对相位决定干涉。推论是：给整个态乘一个相位因子什么都不改变，只给其中一条路径乘上它，条纹就平移——这正是干涉实验里那个可调的旋钮。
- **[[fast-fourier-transform|快速傅里叶变换]]**：分治之所以成立，靠的是单位根的周期性与共轭对称，把一个长变换拆成两个一半长的变换。**推论是：长度取二的幂时拆分最彻底**，这就是实现中常把数据补零到二的幂的真实原因，而不是什么玄学优化。
- **[[生物钟与昼夜节律|昼夜节律]]**：内源节律可以写成一个绕圈的相位，授时因子的作用是给相位加一个偏移，效果取决于施加的时刻。推论是：同样强度的光，在主观夜的前半段与后半段引起的位移方向相反——相位响应曲线因此可以逐点测出来。
- **[[pulsar-timing-array|脉冲星计时阵]]**：每个脉冲对应一次转动，长期计时模型累积的是相位而非频率，于是极小的频率误差会随时间线性堆成可见的相位残差。推论是：任何未建模的效应都表现为残差的系统性漂移，因此残差本身就是探测手段。
