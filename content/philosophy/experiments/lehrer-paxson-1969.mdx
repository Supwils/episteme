# 未被击败的证成真信念：完全证成之后，是否还要过击败者这一关？

## 这是什么，这不是什么

这是一则关于**知识是否等于「未被击败的、完全证成的真信念」**的印刷论证。一九六九年四月二十四日，基思·莱勒（Keith Lehrer）与托马斯·帕克森（Thomas Paxson, Jr.）在《哲学杂志》第六十六卷第八期发表《知识：未被击败的证成真信念》（"Knowledge: Undefeated Justified True Belief"），页码二百二十五至二百三十七。对象钉在盖梯尔之后仍要保住证成的那一刀：主体完全有理由相信 p，且 p 为真，仍不够；这份完全证成还必须**未被击败**。对象钉在这份十三页里的完全证成、击败者，以及汤姆·格拉比特那一幕，不钉在后来课堂里被改写成「别忽略反证」的劝告，也不钉在知识总论页上的配方清单。

它不是[[gettier-problem|盖梯尔问题]]的封面。盖梯尔一九六三年在《分析》里用两则反例追问：得到证成的真信念是否已经够格叫知识。压力在证成与真理之间的**介入运气**：史密斯从关于琼斯的假前提推出一句碰巧为真的结论，真值从另一扇门溜进来。莱勒与帕克森要做的不是把那三页再演一遍，而是给出一条他们把盖梯尔挡住的第四味：证成必须未被一份真陈述击败。把两则焊成「都是盖梯尔所以都是同一篇文章」，会把[[epistemology|认识论]]里「指出不够」与「加可击败性」焊成同一页。

它不是[[goldman-1967-causal|戈德曼 1967 因果]]。一九六七年要把证成条件改写成恰当因果链：使 p 为真的事实，必须走在引起信念的路上。莱勒与帕克森走另一条。他们留下「完全证成」，再加一条：没有任何真陈述击败这份证成。因果问祖先；可击败性问一份你未必已经握在手里的真陈述，一旦接进证据，会不会把完全证成拆掉。

它不是[[goldman-1976-fake-barns|戈德曼 1976 假谷仓]]。假谷仓要压知觉辨别：亨利看着一座真谷仓，因果链完好，可那一带立满纸壳立面。年份晚七年。一九六九年的药方是「让未知的真陈述来考验证成」；一九七六年承认，知觉知识还要能把真对象从会复制同一经验的仿品里分开。

它更不是[[dretske-1970-zebra|德雷茨克斑马]]。斑马要压认知算子会不会穿透到每一个逻辑后承：你知道那是斑马，是否已经知道那不是涂色骡。相关备择在一九七〇年是闭合税则的配套工具，不是一九六九年的击败者条款。参观者看着真斑马，按可击败性几乎会问：园里有没有一份**为真**的陈述，一旦接进证据就把完全证成拆掉。涂色骡若并不存在，它就当不成击败者。

它也不是[[nozick-1981-tracking|诺齐克 1981 追踪]]。追踪用两条反事实去替换证成。莱勒与帕克森没有丢掉证成。他们问的不是邻近世界里信念会不会翻转，而是实际世界上有没有一份真陈述，使完全证成站不住。它还不是体验机器、威尔特·张伯伦，更不是纽科姆问题。那几则属于价值、分配或决策。本页只领走一九六九年这一份可击败性分析。

## 破除误解

第一种最快的读法是：这就是盖梯尔那三页的注释版，只是把「运气」改叫「击败」。这把短文听成一九六三年的附录。盖梯尔停在反例。他没有写出那条必须挡住未知真陈述的联系。莱勒与帕克森要压的是机制：史密斯的完全证成所依赖的那句其实为假；那句为假这一事实，一旦接进证据，证成就不再完全。把整页听成盖梯尔再演一遍，等于拒绝进入装置。装置要问的是，挡住介入运气的那一刀，能不能写成「证成未被击败」。

第二种读法是：这是在抛弃证成，改走外在因果或可靠过程。年份与刀口都焊错了。一九六七年的戈德曼才把证成换成因果。一九六九年留下完全证成，再要求它未被击败。理由可以很完整，仍可被一份你尚未相信的真陈述拆掉。

第三种读法是：任何你不知道的真事，只要听了会让你犹豫，都算击败者。这把初稿定义当成定稿。初稿确实几乎这么写：q 为真，且把 q 与原来的证据合取之后，你不再完全有理由相信 h。汤姆·格拉比特的母亲那一则立刻把它撑破。母亲说了谎，这句话本身为真；你若听见，证成会动摇；可你既没有关于她的信念，证成也不依赖「她没说过这话」。他们后来把击败者收成：你必须**完全有理由相信 q 为假**。不是「世界上随便哪句真话」。

第四种读法最像处世劝告：把标准再抬高一点，要求排除一切可能的反证，悖论就没了。若「一切可能」都要排除，日常知觉会在怀疑论里破产。击败者必须是真陈述，且你有理由认它为假。没有先写出这两刀，任何「再谨慎一点」都还没有对象。

## 印本里的装置

短文先把知识劈成两半。若一个人知道某句为真，却没有任何别的陈述在为这份信念做证成，这叫**基础知识**。若他之所以知道，是因为另有陈述在为信念做证成，这叫**非基础知识**。基础知识被写成：h 为真，S 相信 h，S 完全有理由相信 h，而且这第三条并不依赖任何证据 p。非基础知识被写成：h 为真，S 相信 h，存在某个 p 完全证成这份信念，又没有任何陈述击败这份证成。他们对自己是否承认任何基础知识保持不可知。

「完全证成」是从齐硕姆那里借来的强度词，短文没有另给一条可操作的刻度。需要钉死的只有五件事。第一，p 为真、S 相信 p，仍不够。第二，S 必须完全有理由相信 p。第三，若这份理由靠别的陈述撑着，证成必须未被击败。第四，击败者必须是真陈述。第五，你的证成必须依赖你完全有理由把它看成假的：不是每一句会让你听了就动摇的真话都算。若丢掉证成，题会滑向因果或追踪。若任何真话都能击败，格拉比特的母亲会误伤目击。五条同时在场，才出现那句对照：内部可以有漂亮的理由，知识仍可因一份未入账的真陈述而撤走。

击败的初稿几乎一句话说完。当 p 完全证成 S 相信 h，这份证成被 q 击败，当且仅当：q 为真，并且 p 与 q 的合取不再完全证成 S 相信 h。把「琼斯没有福特」接进证据，原来那份完全证成就垮了。斯凯姆斯的纵火癖落在同一只篮子里：人凭「必着火柴」完全有理由相信下一根会燃；火柴其实受潮，却被一阵 Q 辐射点燃。初稿说：不是知识。

初稿立刻显得太宽。图书馆里，你熟识的学生汤姆·格拉比特把书塞进大衣偷走。你看见了，完全有理由相信汤姆偷了书，这件事也确实是他做的。随后加上一句你不知道的真话：汤姆的母亲说，当天汤姆不在，偷书的是他的同卵孪生兄弟。若把母亲的话接进证据，完全证成会动摇。按初稿，知识撤走。可是再加一层：母亲是病理性说谎者，根本没有孪生兄弟。这时直觉通常把知识还给你。母亲说过那些话，仍是真的。初稿无法区分「诺戈特其实没有福特」与「格拉比特夫人说过一通谎话」。前者应当击败，后者不应当。

他们因此改写击败。关键不是「有一句真话会让你犹豫」，而是：你的证成是否依赖于你完全有理由相信那句为假。诺戈特那一则里，你看见他开福特、听他自称车主，再推出「班上有人有福特」。哈维特才是真正的车主。你完全有理由相信「诺戈特没有福特」为假。那句其实为真的话，一旦与原来的证据合取，完全证成拆掉。这是真击败者。格拉比特那一则里，你既没有关于他母亲的信念，也不会有理由去形成那些信念。你的证成不依赖「她没说过那些话」。于是第二稿写成：q 为真；你完全有理由相信 q 为假；并且 p 与 q 的合取不再完全证成你相信 h。

第二稿仍有技术漏洞。挑一句与案件无关、你却完全有理由认其为假的 r，再把它与一句本不该击败的真话 q 合取，可以手工制造一个「击败者」。他们补上第四款：若 c 是 q 的逻辑后承，且 p 与 c 的合取也不再完全证成 h，则你也必须完全有理由相信 c 为假。没有这一款，无关合取会把误导性真话重新装进击败者的位置。纸面装置到此为止：非基础知识要求一份未被击败的完全证成。

## 盖梯尔被挡住的那一刀

把盖梯尔两则摊开，可击败性几乎是在问：证成所依赖的那句，你是否完全有理由相信它为真，而它其实为假。史密斯完全有理由相信琼斯将得到工作、琼斯有福特；那些陈述为假。使「得到工作的人口袋里有十枚硬币」为真的，是史密斯自己；使析取为真的，是布朗恰好在巴塞罗那。把「琼斯不会得到工作」「琼斯没有福特」接进证据，完全证成拆掉。真值从旁门进来。可击败性说：不是知识。

这一刀解释了「不许假引理」为什么常常管用，却不必把那句话写成定义。假引理之所以坏事，往往是因为它让你完全有理由把一句假话当成真，从而让「那句为假」成为真击败者。可击败性要比「路上不许出现假句」更宽，也正因为更宽，才必须另写误导性击败者那一款。用「再加一条不许运气」去给一九六九年发答案，是把症状当成病名。莱勒与帕克森要的不是运气的形容词，而是：完全证成所依赖的真假分配，会不会被一份你有理由认其为假、其实为真的陈述推翻。

## 为什么两造都可以像有理

先看日常目击。把「我看见汤姆把书塞进大衣，所以知道是汤姆偷的」判为知识，几乎不需要哲学。对象就在眼前。否认这里有知识，会把目击一起交出去。可击败性把这类成功写成范本：你的完全证成并不依赖某句关于他母亲的假话。再看盖梯尔。史密斯的内心可以有完整的推理步骤，证成在当时的信息里站得住，真值却走另一扇门。若知识要求你不是「碰巧对了」，这一次的碰巧就写在：你完全有理由认其为假的那句，其实为真。两造各自看起来无可指摘。悖论感来自同一套「真信念加当时像样的资格」不能同时支撑两种知识归属。

莱勒与帕克森站在撤回盖梯尔、放行误导性母亲的一边，并把两边写成同一条原则。原则是：非基础知识是未被击败的完全证成的真信念；击败者是你完全有理由认其为假的真陈述。盖梯尔两则里，这样的陈述在场。格拉比特的母亲那一则里，这样的陈述不在场。反对者可以攻「完全」。完全证成要高到什么程度？若高到确定性，日常目击会一起出局；若低到「还算有理由」，门槛本身仍未写出。印本从齐硕姆借来强度词，却没有把尺子刻完。本页必须把没刻完标成没刻完。

另一造则坚持：知识评价的是主体可及的理由，不是主体看不见的真值分配。史密斯已经尽了推理的本分。知识若必须对旁观者的全知地图负责，标准会高到无人能够知道自己推出了什么。这一造保住内在主义的证成，代价是让盖梯尔式的旁门真值继续算作知识。税则是：不含击败者条款，两则会与普通推论无法区分；不限制何种真话算击败，母亲的谎话会误伤目击。

## 钉住什么，不要假装已经结算

把两造写成「莱勒与帕克森算对了、知识从此等于未被击败的证成真信念」，会把对象说成一九六九年已经封卷。文献里没有这种结算。一九六九年的索引是：非基础知识是未被击败的完全证成的真信念；击败者是真陈述，你完全有理由认它为假，它与原来的证据合取后不再完全证成，且同样会拆掉证成的后承也满足同一条。

一条刀改走更彻底的外在可击败性。彼得·克莱因在七十年代不再坚持「你必须已经有理由认击败者为假」。一条刀改走莱勒自己后来的融贯论：一九七四年的《知识》把接受与未被击败改写进另一套装置，不能读回本页摘要。一条刀改走辨别。假谷仓乡里，亨利可以完全有理由相信眼前是谷仓，又从未形成「这一带没有纸壳立面」的信念；按一九六九年的入场券，立面那句真话可能当不成击败者，知识直觉却常常撤回。挡住盖梯尔的那一味，仍可能填不满知觉知识的账单。

一条刀改走反事实。[[nozick-1981-tracking|诺齐克]]一九八一年要求敏感性。击败者问实际世界上的真陈述；追踪问邻近世界上的信念起伏。斑马那一页要压闭合；涂色骡若为假，它不是击败者。这些都是延伸。

还有一条更软的逃路：承认「完全证成」从未被写完，因而宣布可击败性空洞。若直觉仍接受「有些未知真话应当撤走知识、有些不应当」，装置的压力不会因为形容词未完成而消失。你仍须说明：盖梯尔那两则与看见汤姆偷书，差别写在哪一类真陈述上。本页停在已经写死的那一刀上：争论的不是史密斯有没有真信念，而是**挡住盖梯尔的那一味**是不是「完全证成必须未被击败」，以及**击败者**是不是「你有理由认其为假的真陈述」。一九六九年说是。

## 跨域连接

- **[[gettier-problem|盖梯尔问题]]**：两边都把「真信念加上当时像样的认知资格」拆开，这一页写的不是反例封面，而是挡住反例的那一味。盖梯尔停在介入运气。莱勒与帕克森把旁门改写成必须存在真击败者：你完全有理由认其为假的陈述，其实为真，且会拆掉完全证成。用十枚硬币去给一九六九年当目录，等于把「指出不够」偷运进「改写条件」。
- **[[goldman-1967-causal|戈德曼 1967 因果]]**：两边都在盖梯尔之后另开一页。戈德曼丢掉证成条款，改要真值制造者走在引起信念的路上。莱勒与帕克森留下完全证成，改要这份证成不被真陈述击败。史密斯口袋里的硬币没有引起信念，在因果论里已经够撤知识；在可击败性里，撤走知识的是「琼斯没有福特」这类你有理由认其为假的真话。一条问祖先，一条问未入账的真陈述。
- **[[dretske-1970-zebra|德雷茨克斑马]]**：两边都在盖梯尔之后另开税则。德雷茨克要压认知算子：知道 p 会不会自动领走把无关备择换上场的后承 q。莱勒与帕克森要压击败者：实际世界上有没有一句真陈述，使完全证成站不住。园里若没有涂色骡，涂色骡当不成击败者。用击败者去给围栏封卷，是把真陈述入账错接成闭合税则。
- **[[nozick-1981-tracking|诺齐克 1981 追踪]]**：两边都想挡住旁门真值。诺齐克用敏感性与依附性去替换证成。莱勒与帕克森不替换证成，只要求它未被击败。办公室福特那一则，两边都会撤走知识：追踪说你在无人有福特的最近情形里仍会相信，可击败性说「诺戈特没有福特」是真击败者。一条问反事实，一条问实际世界上的击败者。
- **[[epistemology|认识论]]**：这篇把「外在真陈述可以改判知识」写成可指的击败者，又把入场关卡留给「你有理由认它为假」。史密斯从内部无法区分两条路径，知识归属却可以随他看不见的真假分配翻转。内在主义若只承认主体可及的理由，两则应当同判；可击败性允许未入账的真话改判，却不允许任意真话改判。后来的可靠论、辨别、追踪与更强的外在击败者，都在这条税则之后另立账本。
