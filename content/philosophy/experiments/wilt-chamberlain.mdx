# 威尔特·张伯伦：自愿付钱看球，会不会把公正的分配搅乱？

## 这是什么，这不是什么

这是一则关于**模式化分配原则在自由转让下能否站住**的印刷论证。一九七四年，罗伯特·诺齐克（Robert Nozick）在 Basic Books 印成《无政府、国家与乌托邦》（*Anarchy, State, and Utopia*）。分配正义章题为「分配正义」（Distributive Justice），通常标为第七章。对象钉在资格理论里的这一刀：若分配 D1 是正义的，人们又自愿付钱去看威尔特·张伯伦打球，由此得到的 D2 也是正义的；任何按公式裁切份额的**模式化原则**（patterned principles），在人们被允许按自己的持有去交易、馈赠时都会被搅乱。年份钉在一九七四年，因为那是这套装置第一次印成专书的年份。对象钉在张伯伦这一则，以及它要逼出来的那句口号——自由扰乱模式（Liberty upsets patterns）——不钉在整本书的最小国家推导，也不钉在思想家专页上的生平目录。

它不是[[experience-machine|体验机器]]。体验机器印在同一九七四年的同一本书里，对象是快乐主义：人是否应当接入一台能提供任意体验的机器。那是伦理学封面。把张伯伦听成「人更在乎真实而非感觉」，会把价值实验偷运进分配正义。思想家专页见 [[nozick|罗伯特·诺齐克]]。本页只领走一九七四年这一章里的资格论证。

它也不是[[nozick-1981-tracking|诺齐克 1981 追踪]]。追踪印在一九八一年的《哲学解释》，对象是知识：信念是否必须随命题的真假一起起伏。那是认识论封面。把「资格随历史起伏」听成「信念随真理起伏」，年份与评价对象都焊错了。

它不是[[original-position|原初状态]]，也不是[[veil-of-ignorance|无知之幕]]。那两则是一九七一年罗尔斯的装置，问的是：在不知道自己将处于何种社会位置时，理性的立约者会选哪套正义原则。张伯伦不进入幕布。它从你已经承认的 D1 出发，问自愿转让之后你还能否守住那套模式。原初状态与无知之幕是邻居，用来对照「正义先看结构还是先看历史」，不是本页封面。

它更不是[[utility-monster|效用怪兽]]，也不是[[newcomb-problem|纽科姆问题]]。效用怪兽同印一九七四年，靶标是功利主义的总量计算：若有存在从每单位资源里挤出天文效用，最大化总和会把资源全部喂给它。纽科姆是决策论里的预测与选择。本页不领走效用加总，也不领走盒子与预测者。封面是：自愿看球的二十五美分，会不会把你认为公正的那张表撕开。

## 破除误解

第一种最快的读法是：这就是在为球星高薪、为富人辩护，或者在教人「市场给了你什么你就该拿什么」。印本不是从「张伯伦配得上」起笔。它先让你选定**你自己认为正义**的 D1——哪怕是严格平等，哪怕是按需要、按道德价值、按智商裁切。然后再问：这些人拿着自己那一份，自愿把二十五美分交给门口的盒子，你凭什么在赛季结束时宣布 D2 不正义。装置要压的不是球星崇拜，而是：模式一旦允许自愿转让，就无法自己维持。把这一则写成名人收入的道德鉴定，等于把思想实验的起点偷换成了结论。

第二种读法是：这就是整本《无政府、国家与乌托邦》，或者就是最小国家、守夜人、反再分配的政治纲领。书里确有从自然状态推到最小国家的看不见的手叙事，也有「对劳动所得征税等同于强迫劳动」的相邻推论。那些是同一章里的别的刀。张伯伦这一则的税则更窄：它不先要求你接受洛克式产权的全部细节，也不先要求你接受最小国家；它只要求你承认 D1 公正、承认门口那一步是自愿的。用最小国家去给张伯伦当目录，是把邻居认成门牌。

第三种读法是：这就是罗尔斯差别原则的反面教材，或者在说「不平等只要能改善最不利者就可以」。差别原则仍是一种模式：份额要按「最不利者的期望」来排队。诺齐克的攻击对准一切模式，包括这一条。若差别原则所批准的分配是 D1，人们仍可能自愿把票款送给张伯伦，从而走出那条排队。把两造焊成「一个要平等、一个要效率」，会把历史性资格与帕累托改进焊成同一页。本页问的是正义资格，不是资源配置是否有效。

第四种读法最像处世劝告：只要交易看起来没人拿枪，结果就不可批评。这句话漏掉了锋刃。印本把「自愿」钉在持有已经属于当事人、且转让未使用强力与欺诈这一层。它没有自动结算背景产权是否干净，也没有自动结算第三人是否被改写了机会。批评者后来正是从这两处开口。没有先写出 D1 与自愿转让这两步，任何「市场即正义」都还没有对象。

## 印本里的装置

分配正义章把场景写成几乎可以分镜的球场门口。先假定一种你赞成的正义分配 D1。人人持有的份额符合你挑选的模式——为了让刀口最利，诺齐克常请你从平等出发。篮球运动员威尔特·张伯伦极受欢迎。他与球队签下这样的合同：每张主场门票里，有二十五美分进他自己的盒子。一个赛季里，一百万人去看他的主场比赛，每人都额外自愿交出那二十五美分。赛季结束，张伯伦多得二十五万美元，远高于平均收入，也高于其他任何人。新的分配叫 D2。

需要钉死的只有五件事。第一，D1 按你自己的正义标准是正义的。第二，每一位买票者对自己在 D1 中的那二十五美分拥有资格，并且没有被强迫。第三，没有人用欺诈把别人的持有转走。第四，由此形成的 D2 若被判为不正义，你必须说明：正义的资格如何在自愿的一步上断掉。第五，若你坚持回到原模式，你就得持续干预人们拿自己的持有去做的事——禁止把余钱送给球星，也禁止把余钱送给教会、政党、报社，或换成别的服务。少一条，装置会塌成别的题。若 D1 本身不正义，题会退回获取与矫正。若门口那一步不是自愿，题会退回强力与欺诈。若你只羡慕结果平等却不肯说 D1 曾经正义，张伯伦这一则根本还没开打。

诺齐克把这一跳写成原则。原则是：正义的持有，来自正义的获取与正义的转让；一个人有资格持有的东西，可以按自己的意愿转让。D2 里张伯伦的那二十五万美元，是一百万人各自自愿交出的资格的汇流。若每一步都正当，终点也正当。模式在这里不是正义的标准，只是某一瞬间的快照。快照会被下一步自愿行为改写。他由此宣布：没有一种目的状态原则或模式化分配原则，能够在不持续干涉人们生活的情况下被连续实现。自由扰乱模式。若社会主义要守住某种模式，它就得禁止同意的成年人之间的资本主义行为。

纸面装置到此为止。它宣布的是：你不但实际上赞成 D1，而且虚拟地赞成从 D1 出发的自愿链。若你在终点改口，你并不是发现了新的不义事实，而是把一种你事先并未写入资格规则的模式，重新当成了裁判。

## 资格三条：历史，而不是公式

张伯伦这一则挂在资格理论（entitlement theory）上。诺齐克把分配正义写成三条历史原则，而不是一条「各尽所能、按某指标分配」的公式。第一条是获取的正义：无主物如何正当地变成持有，洛克的劳动混合是祖先，附加但书是不得使他人的处境比资源保持无主时更糟。第二条是转让的正义：自愿交换、馈赠、遗产，把已有资格从一人转到另一人。第三条是矫正的正义：若获取或转让曾经不义，如何把资格链条修回去。一个分配是正义的，当且仅当它由正义的获取与正义的转让形成——无论此刻看起来多么不平等。

模式化原则按「各人按其 Φ」来裁切：Φ 可以是需要、道德价值、边际产品、智商，或罗尔斯式的最不利者期望。时间切片的目的状态原则只看当下矩阵，不看这笔钱怎么来的。资格理论是历史性的、非模式化的：它问的是每一笔持有的来路，不问这一刻的份额是否符合某张表。张伯伦要演示的，正是两类原则的冲突。你尽可以把 D1 选成最漂亮的模式；一旦转让自由被承认，表就会皱。要重新熨平，就得不断伸手进别人已经有资格的盒子。

获取原则与洛克但书不是本页封面。它们解释资格链条如何开始，却不是二十五美分那一跳的税则。矫正原则更不是封面，却是批评者最常抓住的邻刀：若历史充满征服与奴役，今天的 D1 可能从未干净，自愿转让也只是在不义上叠加同意的外观。诺齐克承认矫正难写，却拒绝因此退回模式。本页仍停在张伯伦：在你已经承认 D1 的前提下，自愿看球这一步是否足以证成 D2。

## 为什么两造都可以像有理

先看自愿。一百万人各自决定：这二十五美分，看张伯伦比留在口袋里更值。没有人声称自己被骗，也没有人声称门票是摊派。若正义允许人们用自己的持有去追求自己看成更好的事情，这一步几乎不需要哲学。否认这里有资格，会把馈赠、小费、门票、报章订阅一起交出去。再看模式。D2 把巨大份额堆在一个人身上。未去看球的人、未出生的孩子、以及将来只能面对更高门槛的陌生人，没有在门口签字，却活在一个机会矩阵已被改写的世界里。若正义要求某种可辩护的份额关系，这一次的偏离就写在赛季后的那张表上。两造各自看起来无可指摘。悖论感来自同一组自愿行为不能同时支撑「每一步都正当」与「终点仍须符合原模式」。

诺齐克站在「D1 正义且转让自愿，则 D2 正义」的一边，并把这一边写成原则。原则是：资格随历史走，不随当下矩阵走；要维持矩阵，就得持续干涉已经属于当事人的选择。反对者可以攻「自愿」与「D1」。谁来保证门口那一步发生在干净的产权上？印本给出的是虚拟条件式的让步——就算 D1 随你便——不是一部已经写完的世界产权史。

另一造则坚持模式仍有独立分量。G. A. 科恩后来把刀口写成：即便每一笔交换在局部看起来像同意，由此放大的不平等也会缩小他人的有效自由；把维持平等所需的规则叫做「持续干涉」，等于把交通灯与绑架写成同一类手。背景若是对外部世界的共同所有，张伯伦装进盒子里的，就不全是「他自己的」劳动果实。这一造保住模式，代价是：必须说明，何种普遍规则可以限制自愿转让，而不只是在终点羡慕或嫉妒某个人的票房。一九七四年已经把合取摊在桌上：要么让模式被自由改写，要么持续伸手限制同意的成年人拿自己的持有去做的事。

## 钉住什么，不要假装已经结算

把两造写成「诺齐克算对了、再分配从此等于抢劫」，会把对象说成一九七四年已经封卷。文献里没有这种结算。一九七四年的索引是：从你承认的正义 D1 出发，自愿的看球付款产生 D2；若每一步资格都成立，D2 也成立；模式化原则无法在自由下稳定实现。

一条刀改走自我所有与世界所有的分离。张伯伦论证把人对自己劳动的权利，几乎悄悄地连上了对外部资源及其产品的权利。科恩要拆开这两截：即使承认人对自己的能力拥有道德权利，也不必承认现有的资源份额已经是资格。这是延伸。一条刀改走第三人与未来世代：门口签字的是观众，被改写机会的不必是观众。这也是后加的压力，不是一九七四年已经写进目录的反例。还有一条更软的逃路：否认直觉，宣布「D2 当然仍须被校正，思想实验只是修辞」。若直觉连「自愿转让应留下资格」也撤回，装置的压力会减轻，但不会自动把模式化原则变成废话。你仍须说明：为何同一组同意在局部有效、在全局无效，以及那种无效是资格从未产生，还是资格产生后被更高原则覆盖。

本页停在已经写死的那一刀上：争论的不是球星该不该有钱，而是**正义的分配原则应当看历史来路还是看当下模式**，以及**任何一种模式在承认自愿转让之后还能否不靠持续干涉来维持**。一九七四年说：看历史来路；不能。

## 跨域连接

- **[[original-position|原初状态]]**：两边都要给分配正义找一个不偏袒当下赢家的起点，这一页写的不是幕布封面，而是起点被承认之后自愿链会不会撕开模式。罗尔斯让立约者不知道自己的位置，从而选出带词典式优先的两条原则；差别原则仍是一种按最不利者期望来排队的模式。诺齐克从你已经赞成的 D1——包括那种排队——再走一步：门票盒子。用无知之幕去给张伯伦当目录，等于把「如何挑选原则」偷运进「原则能否在自由转让下稳定」。
- **[[distributive-justice|分配正义]]**：两边都把「谁该持有什么」写成可争论的原则，索引不是同一句。政治哲学里的分配正义要同时安放需要、贡献、机会与程序。诺齐克把程序写成历史资格，并把模式贬为快照。张伯伦是那次贬低的演示：哪怕快照曾被你批准，自愿的二十五美分也会让它过期。用「分配要公平」去覆盖门口那一步，等于拒绝进入他设定的前提。
- **[[gini-coefficient|基尼系数]]**：两边都让不平等变得可指，测量对象不同。基尼系数把收入或财富矩阵收成一个介于零与一之间的数，问的是离散程度，不问每一笔钱的来路。张伯伦的 D2 会把那个数推高，而这正是他不在乎的那一类事实。若正义等于压低基尼，维持模式就变成统计目标；若正义等于资格链条，基尼只是旁观仪表。一条问矩阵形状，一条问盒子里的二十五美分有没有来路。
- **[[property-and-ownership|财产与所有权]]**：两边都要把「这是我的」从口号写成可执行的规则。私法里的所有权是一束可对抗他人的权能：占有、使用、收益、处分，并配套善意取得、时效与登记去处理来路不清。诺齐克把处分权推到道德前台：有资格处分，就有资格把二十五美分送进门口。法律不会只问自愿，还会问第三人、公示与权源；资格理论把权源写成哲学上的获取与矫正，却把法庭里那些技术细节留在门外。一条问可执行的权束，一条问权束在道德上该不该随模式一起被重置。
- **[[tax-and-fiscal-law|税法与财政法]]**：两边都碰到「从已经属于你的份额里拿走一笔」，合法性叙事必须对着写。税法把课税权写成法定要件、税基与程序，不先把它等同于强迫劳动。诺齐克在相邻段落里把再分配所得税读成对劳动时间的征用；张伯伦这一则提供的是配套图像——若不许模式被改写，国家就得持续伸手进自愿交易。把税率表直接写成张伯伦的结论，是把财政技术偷运进资格原则；把资格原则写成「一切税都是抢劫」，又把印本里「为再分配而征」的限定焊丢了。
