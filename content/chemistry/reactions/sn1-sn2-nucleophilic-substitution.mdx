# SN1 与 SN2 亲核取代

1896 年，保罗·瓦尔登（Paul Walden）完成一个令人费解的循环：一种旋光性氯代琥珀酸，经过几步反应，变回了组成相同、旋光方向却相反的异构体。碳上的「手性」被翻转了——像一把伞被从背后吹翻。他在《德国化学会志》上把这件事写成光学对映体的互相转化，当时还没有「背面进攻」这四个字。

埃米尔·费歇尔后来称它为巴斯德以来光学活性领域最惊人的观察之一。令人费解之处在于：循环里哪一步翻转、哪一步保持，单靠旋光符号看不出来，因为旋光方向与 R/S 标记并不是同一件事。

近四十年后，1935–1937 年，Christopher Ingold 与 Edward Hughes 用动力学把这类现象钉死在**机理**上：有的反应一步完成、构型翻转；有的反应分两步、产物倾向外消旋。他们命名的 **SN2** 与 **SN1**，至今仍是有机化学入门最硬核、也最有用的两把钥匙。

## 破除误解：取代反应不是"基团一换就完事"

化学方程式 R–X + Nu⁻ → R–Nu + X⁻ 只写结果，隐藏了所有精彩细节。真正要问的是三件事：亲核试剂与底物谁先动手、反应一步还是两步、产物的立体化学是保持、翻转还是各半。

这三个问题的答案，把亲核取代分成 SN2 与 SN1 两条路——同样的反应类型，不同的「剧本」。更宽的机理图景见 [[reaction-mechanisms]]。总反应式相同，并不等于微观路径相同。

第二个误解：以为 SN1 一定慢、SN2 一定快。速率取决于底物结构、溶剂、亲核试剂浓度——**叔卤代烃**在极性溶剂中 SN1 可以极快，**一级卤代烃**在强亲核试剂存在时 SN2 同样迅速。「SN」里的 1 和 2 指的是**动力学级数**（决速步涉及几种分子），不是快慢标签。

## SN2：一步、背面进攻、瓦尔登翻转

**SN2** = Substitution, Nucleophilic, **bimolecular**（双分子）。亲核试剂从离去基团 X 的**正背面**进攻碳中心，旧键渐断、新键渐成，一步完成、无中间体；过渡态里碳近似五配位，像被背面吹翻的伞。

立体化学后果：**构型翻转**——R 变 S，或 S 变 R。这就是瓦尔登 1896 年观察到的现象，Hughes 与 Ingold 1937 年用 2-溴辛烷等底物定量讨论。动力学：速率 = k[R–X][Nu⁻]，**两种反应物浓度**都影响速率，因此属于 [[reaction-kinetics|反应动力学]] 里可辨识的二级过程。

背面进攻不是审美偏好。亲核试剂带着电子对靠近碳，离去基团也要带走电子对；两者若从同一侧挤，电子云互相排斥，能量更高。从离去基团正对面、大约一百八十度的方向靠近，新键生成与旧键断裂可以同步发生，碳上其余三根键像伞骨一样翻到另一面。过渡态里碳暂时接近三角双锥，五个基团围着一个中心，寿命极短，不是可以分离的中间体。

底物要求：**甲基、一级**卤代烃最理想；**三级**碳中心空间拥挤，背面没有通道，SN2 极慢甚至被 SN1 竞争。溶剂：**非质子极性溶剂**（丙酮、DMF、DMSO）利于 SN2——质子溶剂会把 Nu⁻ 溶剂化，削弱亲核性。离去基团必须足够好，否则旧键根本拉不断，背面再空也没有反应。

瓦尔登循环并不等于每一步都是 SN2：循环里至少有一步必须翻转，另一些步可能保持，后来的研究还提示某些「保持」经过内酯一类邻基参与。Hughes–Ingold 的贡献，是把翻转从光学现象改写成可检验的双分子背面进攻。

## SN1：两步、碳正离子、外消旋化

**SN1** = Substitution, Nucleophilic, **unimolecular**（单分子）。决速步是 R–X 独自离解，X⁻ 离去，生成平面三角形的**碳正离子**中间体；亲核试剂再从平面任一面进攻，生成产物。

立体化学后果：若反应中心原本是手性碳，产物通常倾向**外消旋混合物**（retention + inversion 近半）——因为平面碳正离子两面在理想极限里等价。动力学：速率 = k[R–X]，**只取决于底物浓度**；亲核试剂浓度几乎不影响速率，因为它不参与决速步。

碳正离子是缺电子的平面物种，中心碳用三根键铺开，空的 p 轨道垂直于平面。亲核试剂从上面或从下面送上电子对，得到的构型相反。若溶剂把离子对拆得很开，两面机会接近相等，手性信息被抹掉，这正是 SN1 与 SN2 在立体化学上的分水岭。Hughes 1935 年对 **t-BuCl** 水解的研究是 SN1 的经典证据：速率与氢氧根浓度无关，只与叔丁基氯浓度成正比。

底物要求：**三级**卤代烃 SN1 最易（碳正离子最稳定）；**一级**底物 SN1 极难，因为一级碳正离子太高能。溶剂：**极性质子溶剂**（水、醇）稳定碳正离子与 X⁻，利于 SN1。离去基团同样要好：没有愿意离开的 X，碳正离子根本生不成。溶剂与离去基团在这里不是配菜，而是让不让第一条键先断的条件。

理想的五十五十外消旋，常常被离子对打破。离去基团刚离开时，仍可能挡在碳正离子的一面，亲核试剂只好从背面补位，产物里翻转会多于保持。Winstein 后来把接触离子对与溶剂分隔离子对写进溶剂解，提醒我们：SN1 的「平面中间体」是极限图像，不是每一滴溶液里的实况。

## 如何选择路径：一张决策地图

| 因素 | 利于 SN2 | 利于 SN1 |
|------|----------|----------|
| 底物 | 甲基、一级 | 三级 |
| 亲核试剂 | 强、浓度高 | 弱也可（不参与决速步） |
| 溶剂 | 非质子极性 | 极性质子 |
| 离去基团 | 好离去（I⁻ > Br⁻ > Cl⁻） | 同样要好离去 |
| 立体化学 | 翻转 | 外消旋倾向 |

很多底物（如二级卤代烃）在条件切换下**两条路竞争**，产物比例是实验条件的设计问题，不是背口诀能一劳永逸的。教材常把二级碳画成「两可」，后来的溶剂解研究则强调：在常见条件下，许多二级体系仍以背面进攻为主，所谓 SN1 份额被高估了。争论本身有用，它说明「二级」不是一张可以自动盖章的标签。

选择条件可以收成两句。离去基团决定旧键能不能断；溶剂决定断了之后是同步换上新伙伴，还是先变成碳正离子再等人来。亲核试剂的强度与浓度主要推动 SN2，却几乎推不动 SN1 的决速步。把这三样当作旋钮，比把底物级别背成咒语更接近 Ingold 的原意。

## 离去基团与亲核试剂：谁走、谁留

**离去基团**（leaving group）越弱碱、越稳定，越容易带着电子对离开——常见卤素里大致是 I⁻ > Br⁻ > Cl⁻ > F⁻。氟离子是强碱，碳氟键又短又强，烷基氟很少走这条亲核取代；碘离子稳定、碳碘键较弱，所以碘代烃常常是更好的底物。甲磺酸酯（OMs）、对甲苯磺酸酯（OTs）是人为安装的「超级离去基团」，用来让醇羟基变成愿意离开的物种，而不是让人去制备更危险的卤代烷化剂。

**亲核试剂**强弱受溶剂影响极大：在水或醇里，F⁻ 被强烈溶剂化，亲核性反而弱于 I⁻；在 DMSO 等非质子溶剂中，F⁻ 裸露出强亲核性。硬软酸碱（HSAB）概念也有用：硬亲核试剂（F⁻、RO⁻）偏好硬中心（甲基、一级碳）；软亲核试剂（RS⁻、I⁻）对软中心（部分二级碳）有时更灵活。亲核性描述的是进攻碳的速率，碱性描述的是夺质子的平衡，两者相关却不是同一张表。

离去基团给出「能不能走」，亲核试剂给出「谁来补位」，二者不能互相替代。溶剂再决定：走的时候是同步换上新伙伴，还是先变成碳正离子再等人来。

## 溶剂效应：质子 vs 非质子

**质子溶剂**（H₂O、ROH）通过氢键稳定负离子，也稳定正在生成的碳正离子——因此利于 SN1，却削弱 SN2 所需「裸」亲核试剂。**非质子极性溶剂**（丙酮、DMF、DMSO、乙腈）能溶解离子，却不向 Nu⁻ 强氢键，SN2 常用。换溶剂有时等于换机理，不必先换分子骨架。

**非质子非极性溶剂**（四氯化碳、苯）对离子溶解差，多数离子型取代不适用，除非借助相转移等特殊条件。Ingold 的系统研究强调：溶剂的电离能力与亲核能力是两套坐标。极性质子溶剂电离能力强，把 SN1 的离子中间体托住；极性非质子溶剂则把亲核试剂从氢键牢笼里放出来，让背面进攻加速。把溶剂只当成「把东西溶掉的液体」，会看丢这对选择条件。

水既是溶剂也常是亲核试剂，溶剂解因此特别容易混淆级数。当溶剂分子本身就是进攻者，浓度几乎恒定，动力学外表会像一级，分子性却仍可能是双分子背面进攻。这正是二级底物争论多年的根源之一：表观级数不等于分子数，立体化学与盐效应必须一起看。

## 竞争与选择性：当两条路同时存在

叔丁基溴在极性溶剂中几乎只走 SN1；甲基碘在丙酮中与碘离子交换几乎只走 SN2。**二级底物**最麻烦：2-溴丁烷既可能被写成 SN1 也可能被写成 SN2，条件稍变，产物比例就变。这是考试常考点，也是合成设计时必须用立体化学结果去核对的事实，而不是用一份试剂表去「调出」某条路。

**位阻**阻碍 SN2 背面进攻，却可能稳定 SN1 的碳正离子。若碳正离子还能重排到更稳定的骨架，主产物甚至不再是直接取代物——这是 SN1 的经典陷阱，也是它与单纯「换基团」叙事分道扬镳的地方。**亲核试剂浓度**只影响 SN2 速率，不改变 SN1 决速步：加大 Nu⁻ 无法加速已经生成的碳正离子，却能让 SN2 在竞争里抬头。

消除反应会来抢同一批底物。强碱、高温、拥挤的三级碳更偏向夺氢而不是补位，E1 与 SN1 共享碳正离子，E2 与 SN2 则都对背面几何敏感。选择取代还是消除，仍然是溶剂、碱强度与结构的函数，不是另开一套神秘规则。

## 与手性、异构的关系

SN2 的翻转使 [[chirality]] 在合成中可预测：已知反应物 R，可预期产物 S（在接近理想的 SN2 条件下）。SN1 的外消旋化则提醒：若需保留立体化学，必须避免自由的平面碳正离子——或引入邻基参与等特殊路径。邻位参与时，中间体不是简单平面碳正离子，可能出现**保留构型**，这是 SN1 叙事里必须留下的例外。

旋光符号与绝对构型不是同一张地图。瓦尔登看见的是(+)变成(−)，Hughes–Ingold 要证明的是碳上四根键的空间排列被翻面。把两个对映体只当成 [[isomerism|同分异构]] 里的一对镜像，还不够：还要问镜像是在哪一步被翻过去的。醇变成磺酸酯时，通常不断开碳氧键，构型保持；真正的取代发生在磺酸酯被亲核试剂赶走的那一步。

[[functional-groups|官能团]] 在这里变得具体：卤代烃与磺酸酯是常见离去端，氧、硫、氮上的孤对电子是常见进攻端。改变的不是有没有官能团，而是这根键会在给定溶剂里被同步替换，还是先断成碳正离子。

## 为什么重要：机理思维的原型课

SN1/SN2 不只是两个缩写。它们教会化学家：**同一总反应式可以对应不同微观路径**；**立体化学是机理的证人**；**溶剂与浓度是切换路径的旋钮**。药物合成中，一个手性中心的错误构型可能让药效归零甚至有害——机理意识不是考试题，是判断「这条路线会不会把立体信息丢掉」的纪律。

背面进攻给出可设计的翻转，碳正离子给出可预期的信息损失。合成路线若在某一步需要特定构型，就必须在选底物级别和选溶剂时避开会生成自由碳正离子的条件，而不是事后靠拆分补救。反过来，若目标就是毁掉手性或利用重排，SN1 就不再是事故，而是选项。两种读法都依赖同一套选择条件。

## 局限与误区

并非所有亲核取代都是 SN1 或 SN2。芳香族的 SNAr、邻基参与、接触离子对等更复杂的路径，都会让「两分法」显得太干净。把入门分类当成自然界的全部剧本，会在遇到保留构型或重排产物时无处安放。

- **「100% SN2 翻转」是理想极限**：大基团、特殊溶剂或离子对存在时，可能部分外消旋。
- **碳正离子会重排**：SN1 中若生成更稳定的重排碳正离子，产物骨架可能改变——这是 SN1 的经典「陷阱题」。
- **瓦尔登循环本身机理曾受争议**：早期认为某步保留构型，后研究提示可能涉及内酯中间体——历史提醒我们：机理是不断修正的故事。
- **Ingold 不是唯一贡献者**：Paul Walden、Hughes、Standish Masterman 等同属这条脉络；Ingold 的系统命名与溶剂效应理论影响最深。
- **二级碳的教科书说法并不统一**：有的把溶剂解写成 SN1，有的坚持常见条件下仍是 SN2。Murphy 2009 年的教学评论把分歧追到 1930 年代的实验困难，说明「口诀」落后于证据时，应当改口诀。

## 跨域连接

- **[[medical-genetics-and-genomics|医学遗传与基因组学]]**：氮芥类烷化剂先经分子内进攻形成氮丙啶正离子，再对 DNA 做取代，最常见的加合位点是鸟嘌呤 N7。**这条化学决定了它留下的突变谱是有特征的**，因此肿瘤基因组里的突变签名可以反推暴露史，也解释了烷化剂化疗后继发白血病的风险来源。取代反应的位点选择性，在这里被直接写进了基因组。
- **[[atmosphere-structure|大气结构]]**：甲基氯与甲基溴既是生物甲基转移的产物，也是人工熏蒸剂；它们的碳-卤键既能被细胞内的亲核体进攻，也能在平流层被光解。**释放出的溴原子按催化循环破坏臭氧，单原子效率远高于氯**，这正是甲基溴被优先淘汰的原因。同一根键在细胞里走取代、在平流层走均裂，去向由环境而非分子本身决定。
- **[[differential-equation|微分方程]]**：速率定律本质上是一组常微分方程，实验设计的任务是让参数可辨识。**把亲核试剂做成大过量，二级动力学就退化为伪一级，指数衰减的单参数拟合远比双参数稳健**——这不是省事的小技巧，而是"让数据足以确定模型"的标准做法。拟合结果反常时，通常该先检查条件，而不是换一个模型。
- **[[philosophy-of-science|科学哲学]]**：速率定律只约束决速步及其之前的组成，**同一条速率方程可以与多种机理相容**，因此动力学证据天然是欠定的。SN1 与 SN2 之所以能被钉死，靠的是立体化学结果、溶剂效应与同位素效应等相互独立的证据收敛。把"符合二级动力学"直接说成"证明了背面进攻"，是把一致性当成了唯一性。
- **[[chirality|手性]]**：SN2 的完全构型翻转把立体信息变成可设计的资源：知道底物构型就能预期产物构型。**而 SN1 经由平面碳正离子，立体信息被抹掉**。因此一条要求特定构型的路线，必须在设计阶段就避开会生成碳正离子的条件——立体化学的得失，在选底物级别和溶剂时就已决定，而不是最后靠拆分补救。
