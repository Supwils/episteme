# Cahn–Ingold 1951：序列规则怎样把四配位不对称原子的构型写成 d 与 l

一九五一年，《化学会志》刊出编号一三一的论文，作者是罗伯特·S·卡恩（R. S. Cahn）与克里斯托弗·英戈尔德（Christopher Ingold，C. K. Ingold），题目按字面是 “Specification of Configuration about Quadricovalent Asymmetric Atoms”，页码从六一二到六二二。作者栏分别写在伦敦皮卡迪利伯灵顿宅的化学会，以及伦敦大学学院。卡恩当时是这份期刊的编辑。英戈尔德当时尚未受封爵士。DOI：10.1039/JR9510000612。对象是四配位、四面体不对称原子上的序列规则：按永久的内部性质给四枚配体排队，再把排好的三维样式收成可印进名称的字母。描述符仍是小写 d 与 l，不是后来的 R 与 S。后到的 CIP 把本页当作序列规则的第一份印刷。本页是一九五一年这十一页。本页不把某分子怎样逐步标成 d、l 或 R、S 写成可照做的课堂操练单，也不把甾体、激素或手性药物怎样制备写成可照做的规程。对象是证据，不是菜谱。

它不是 [[cahn-ingold-prelog-1966|Cahn–Ingold–Prelog 1966]]。一九六六年三十一页把权限扩到构象手性与配位数六，封面词已经是 R 与 S。本页桌上没有普雷洛格，也没有那一对拉丁字母。它不是 [[bijvoet-1951-absolute-configuration|比佛特一九五一年]]。同年《自然》二七一页用反常散射选出酒石酸盐与镜像哪一只落在晶胞里。本页没有锆辐射，也没有钠铷盐。它不是 [[vant-hoff-1874-tetrahedron|范霍夫一八七四年的四面体碳]]。荷兰小册钉的是单碳四根亲和力指向四面体顶点。本页假定四面体已经站住，未知数改成：四枚彼此不同的配体按哪条内部尺子排队，才能把两只手印成两个字母。它不是 [[pasteur-1848-tartaric|巴斯德一八四八年的酒石酸钠铵盐]]。那一盘晶体用半面和镊子把左右手分成两堆。本页桌上没有镊子，旋光管也不是封面量具。它不是 [[barton-1950-steroid-conformation|Barton 1950]]。八月那五页问甾核椅式上非环价分成赤道与极向，哪一种更稳。本页可以把某一枚已经选定的四面体中心写成字母，并不回答哪一张椅子更该坐。它更不是一份应当照着给课堂分子排队、改环、制激素或制造手性药物的规程。

## 破除误解：不是一九六六年的印刷税制，不是同年的酒石酸盐测定，不是一八七四年的四面体，不是一八四八年的镊子，不是费歇尔的 D/L，也不是操练单或制激素规程

第一个误解，是把本页读成 [[cahn-ingold-prelog-1966|Cahn–Ingold–Prelog 1966]] 的提前抽印，或读成“序列规则一经写出，R 与 S 就已经开印”。一九六六年长文把权限扩展到构象手性，以及配位数到六的无机构型。封面硬物是第五卷三八五到四一五页。本页停在四配位不对称原子。描述符仍是 d 与 l。把三八五页的拉丁字母倒填进六一二页，会把十五年的邻篇焊成同一份封面。

第二个误解，是把本页读成 [[bijvoet-1951-absolute-configuration|比佛特、皮尔德曼与范博梅尔一九五一年]] 的命名附录，或把同年两份印刷物焊成一篇。乌得勒支那两页的对象是钠铷右旋酒石酸盐四水合物 $\mathrm{NaRbC_4H_4O_6\cdot 4H_2O}$。反常散射在弗里德尔对上选出与天然右旋酒石酸相符的那一只手。测定是晶体学的权限，见 [[x-ray-crystallography|X 射线晶体学]]。本页的权限是：已经画出的那一只手，名称按哪一条税则选字母。年份重合，封面硬物不重合。本页没有把酒石酸根钉进晶胞。

第三个误解，是把本页读成 [[vant-hoff-1874-tetrahedron|范霍夫一八七四年的四面体碳]] 的再版，或读成“碳已经是四面体，手的名字就不必另写”。四面体回答单碳四根键指向哪里，以及四个彼此不同的基团有两种不能重合的贴法。一八七四年用旋光正负作为当时唯一普及的读数，并不给出按原子序数排队的字母。有四面体，才有两只手可数。有序列规则，两只手才有可以邮寄的字母。小册服务几何。本页服务几何已经成立之后，四配位中心怎样被印进名称。

第四个误解，是把本页读成 [[pasteur-1848-tartaric|巴斯德一八四八年的酒石酸钠铵盐]] 的理论附录，或读成“那一盘盐已经把构型字母写进瓶子”。一八四八年的装置是半面晶面、镊子和两根相反的管子。拆开证明格子拆掉之后分子自己仍带着一只手。名字是后到的填充，并不回头改写当年看见的事实。本页桌上没有那盘钠铵盐。

第五个误解，是把本页的小写 d 与 l，读成费歇尔相对甘油醛的大写 D 与 L，或读成偏振面往哪边转的旋光符号。一八九一年费歇尔在《德国化学会会志》第二十四卷为糖族写出相对构型，DOI：10.1002/cber.18910240196。罗萨诺夫一九〇六年把甘油醛收成这棵树的根。大写字母服务糖与氨基酸的相对辖区。溶液的 d、l 或 (+)、(-) 描述指定条件下偏振面怎么转。本页的 d 与 l 是序列规则收成的构型名字，不随波长、溶剂和浓度改写。三套符号共用过相似的字母，正是后来必须换字母的原因。不要把本页读成费歇尔投影课，也不要把 d 读成右旋。

第六个误解，是把[[cahn-ingold-prelog-1956|一九五六年三人印在《经验》第十二卷八一到九四页的 “The specification of asymmetric configuration in organic chemistry”]]，焊成六一二页的封面。那一份里普雷洛格加入，改用 R 与 S，把权限从费歇尔那套相对记号里拉开。DOI：10.1007/BF02157171。邻篇是邻篇。封面硬物仍是《化学会志》六一二到六二二页。看见 R 或 S，不要把八一页提前写成六一二页的标题。

第七个误解，是把“标定”读成一份应当照着给课堂分子排队、把最低优先基放到后方、顺时针写 d 的操练单，或读成甾体改环、激素制备、手性药物工艺。十一页给出的是概念判决：一套按原子序数向下比较的词典序，怎样把四配位中心上的手收成可印进名称的字母。看见优先或描述符，不是拿到一份应当动手标某个分子或准备教学样品的步骤清单。[[barton-1950-steroid-conformation|Barton 1950]] 问的是椅式上哪一种排布更稳。本页不回答稳定次序，也不写如何跑反应。对象是证据，不是菜谱。

## 对象：序列规则、四配位中心、d 与 l 作为印刷字母，以及十一页的权限

第一件公开硬物是序列规则本身。配体必须按一种永久的内部性质排序，排好的三维样式再直接当作分类依据。内部性质的第一把尺子是原子序数。直接相连的原子，原子序数高者在前。若这一层仍平手，再向外一层比较，像查字典，而不是像测旋光。质量数是下一把较细的尺子，用来分开同位素。不饱和处用重复出现的原子把双键、三键写进同一套词典序，使优先不因“看起来像双键”而另起炉灶。这些条款印在纸上，是名称怎样选择字母的税则。[[bonding-theory|价键理论与分子轨道理论]] 总览会问键怎样被写成轨道。本页问的是已经画出的配体按核电荷标签怎样排队。原子序数在这里是排序键，不是杂化表。卡恩当时是期刊编辑，面对费歇尔–罗萨诺夫相对记号不够用的手册条目。英戈尔德把内部尺子写成可共用的条款。封面仍是这两人署名的十一页。

第二件硬物是权限的边界：四配位不对称原子，也就是四面体中心上四枚彼此不同的配体。标题里的 quadricovalent 不是又一次颁布碳的四价。它把当时这套税则的辖区钉在四面体配位数四，而不是轴、面、螺旋，也不是配位数六的八面体。碳是最常见的例子，不是唯一入口。氮、硅一类也可以落在同一辖区，只要中心是四配位四面体、四枚配体可以按内部性质分开。一九六六年才会把对象从“不对称原子”改写成“分子手性”。本页尚未做这一扩。看见四面体，不要读成构象手性已经开印。

第三件硬物是把排好的样式收成 d 与 l 的转换约定。四面体中心上，最低优先的配体被放到远离观察者一侧之后，其余三枚若按优先顺序呈顺时针，印 d；逆时针印 l。这对字母是按序列规则写出的构型名字，不是偏振面往哪边转，也不是费歇尔投影里相对甘油醛的 D 与 L。字母形状碰巧与旋光符号、也与费歇尔那对大写字母相近。相近不是同一套税则。本页把对象从“必须接到某一枚参考物上才能开口”改成“按内部性质排队后可以直接印字母”。它没有宣布糖与氨基酸上的 D/L 作废。范围较窄的旧系统仍有其受限辖区。通用字母若不能与旧记号共生，手册条目就无法开印。

第四件硬物是十一页的权限。它确认的是：四配位不对称原子上的构型，可以被写成一套不依赖某一次旋光读数的印刷字母；优先以原子序数为第一把内部尺子；d 与 l 从模型转写进名称。它没有把旋光正负写成 d/l 的定义，也没有把费歇尔的 D/L 从糖与氨基酸上抹掉。它没有把绝对构型的实验测定收进封面；那是[[bijvoet-1951-absolute-configuration|比佛特]]一侧的晶体学。它没有把赤道与极向写成甾核上的稳定次序。它没有写出 R 与 S，没有把权限扩到构象手性，也没有处理配位数六。一九五六年那一份才改字母。一九六六年那一份才扩辖区。本页只读六一二到六二二页。封面硬物仍是四配位中心上的序列规则，加上当时用来进入名字的那一对 d 与 l。

## 它钉死了什么，以及它没有量到的东西

它钉死的是：四配位上两只不能重合的手，不能再只靠一张图、一只共享的参考物或一根指定条件下的旋光管，在实验室之间传递。若继续坚持“看见了就不需要名字”，或坚持“一切构型都必须接到甘油醛上才能开口”，手册条目就会在四面体这一层上失语。一八七四年看对了四面体上有两种贴法。一八四八年看对了左右手可以被分成两堆。本页看对了：真正要被迁移到名称里的，不是某一次旋光读数，而是一套按内部性质排序后再收成字母的税则。

它钉死的是手性作为几何性质，而不是把光学活性写成定义本身。溶液转不转，依赖于波长、溶剂、浓度和是否外消旋。名称里按序列规则印出的 d 或 l 不随这些条件改写。这一判决后来被一九六六年写得更硬。一九五一年已经把方向选对：字母服务模型上的手，不服务管子里的读数。[[chirality|手性与对映异构]] 总览后到会把左右手套、R/S 与旋光符号分成三层。本页停在第三层尚未改用拉丁字母之前，四配位中心怎样被写成 d 与 l。

它也钉死了通用系统必须另起一把内部尺子，而不能把费歇尔那棵相对树无限加长。糖与氨基酸上的 D/L 仍有用，是因为那一块田已经被化学关联织密。田外的四面体中心越来越多，根仍只有甘油醛一枚。卡恩面对的就是这种手册危机。同年布坎南在《自然》第一六七卷写过：除开糖与 α-氨基酸那些确实有用的部分，D 与 L 作前缀已经含混到不如放弃。那是邻居短讯，不是本页封面。本页给出的答案不是放弃旧字母，而是另写一套按原子序数排队的税则。旧字母留下受限辖区。新字母当时仍借用 d 与 l，于是视觉碰撞还没有被切断。

它没有测定任何分子的绝对构型。[[bijvoet-1951-absolute-configuration|比佛特一组]]用反常散射把酒石酸盐的绝对构型钉进晶体学。序列规则给已经测定、或已经由化学关联接到测定上的那一只手起名字。没有测定，税则仍只是空的字母表。[[organic-synthesis|有机合成]] 检验的是目标分子怎样被逐步构建。本页只提供：构建完成之后，四配位这一层怎样被印进名称。

它也没有把描述符写成后来的 R 与 S，没有把构象手性与配位数六写进六一二页。[[cahn-ingold-prelog-1956|一九五六年《经验》第十二卷八一到九四页]]才改用 R 与 S。改字母是为了让绝对构型的名字在印刷上看起来不像费歇尔的相对记号，也不像旋光读数。那是五年后的邻篇。[[prelog-helmchen-1982|一九八二年普雷洛格与黑尔姆兴的修订]]、一九七五年诺贝尔化学奖演说，都是更后的印刷物。演说不能代替六一二到六二二页。

## 跨域连接

- **[[cahn-ingold-prelog-1966|Cahn–Ingold–Prelog 1966]]**：三十一页把序列规则扩成分子手性的通用税制，封面词是 R 与 S。本页十五年前只处理四配位不对称原子，描述符仍是 d 与 l。不要把三八五页读成六一二页的再版。一九五一年服务四面体中心的印刷名。一九六六年服务辖区扩大之后的印刷名。
- **[[bijvoet-1951-absolute-configuration|比佛特一九五一年]]**：两页通信用弗里德尔差选出酒石酸根是哪一只手，并不给这只手起通用字母。本页同年只提供字母表，并不把任何一只手钉进晶胞。测定服务模型与晶体是否重合。序列规则服务重合之后名称选哪一个字母。
- **[[vant-hoff-1874-tetrahedron|范霍夫一八七四年的四面体碳]]**：荷兰小册把单碳四根亲和力写成四面体顶点，未知数是空间结构式与不对称碳上的两种贴法。本页七十七年后再问这两种贴法怎样被印成可传递的字母。四面体服务单碳的几何。本页服务几何已经成立之后、四配位中心上的印刷名。
- **[[pasteur-1848-tartaric|巴斯德一八四八年的酒石酸钠铵盐]]**：那一页的对象是半面、镊子和两堆相反的溶液。本页的对象是一百零三年后的印刷税制。晶体回答不旋光的酸是不是混合物。序列规则回答混合物里的每一只手在名称里该占用哪一个字母。
- **[[chirality|手性与对映异构]]**：那一篇从左右手套讲到 R/S、沙利度胺和不对称催化，对象是立体化学这张地图。本页只收一九五一年的印刷物：四配位中心、原子序数尺子、以及当时的 d 与 l。地图在那一篇；税则在这一篇。
- **[[isomerism|同分异构]]**：异构先被写成同组成、不同连法。本页处理的是连法已经相同、纸面式却仍必须另加一层字母的那一层。构造课回答哪根键接在哪。本页回答四面体上已经不同的样式，怎样被印成不附图也能传递的名字。
- **[[bonding-theory|价键理论与分子轨道理论]]**：总览会把四面体方向接到杂化。本页用原子序数作排序键，并不问键为什么愿意取这个方向。成键理论服务键为什么在那里。本页服务键已经在那里之后，名称选哪一个字母。
- **[[organic-synthesis|有机合成]]**：总览要把碳骨架怎样被逐步构建写成手续。本页停在一九五一年把四配位这一层写成可印刷的描述符。不要把本页读成一份应当照着改环、制激素或制备手性药物的规程。手续服务分子怎样被做出来。税则服务做出来的四面体怎样被写进名字。
- **[[barton-1950-steroid-conformation|Barton 1950]]**：八月短文把甾核写成椅式，并把非环价分成赤道与极向，未知数是哪一种排布更稳。本页可以把某一枚已经选定的四面体中心写成字母，并不回答哪一张椅子更该坐。椅式服务坐姿与稳定次序。本页服务名称里的字母。
