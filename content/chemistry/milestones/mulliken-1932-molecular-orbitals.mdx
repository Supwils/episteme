# 马利肯 1932：分子轨道怎样把多原子分子的价写成遍布全分子的单电子函数

一九三二年四月一日，《物理评论》第四十卷第一期刊出罗伯特·桑德森·马利肯的短文，题目按字面是 “Electronic Structures of Polyatomic Molecules and Valence”，页码从五十五到六十二，文末署收稿二月二十三日。作者当时在芝加哥大学赖尔森物理实验室。对象是把水、氨、甲烷、二氧化碳以及若干含氧酸根写成一套单电子波函数，再用一条建立在不相容原理上的简单规则去读价。七月一日，第四十一卷第一期第四十九到七十一页续出 “II. General Considerations”。那一篇才把 atomic orbital 与 molecular orbital 收成可并列使用的两个词，并把路易斯的电子对键改写成：一对电子占着一条成键分子轨道。分子轨道不必挤在两核之间。九月十五日，同卷第七五一页起把乙烯的双键写成同一套管。本页读的是这一组一九三二年印刷物已经钉住的语言。本页不把基组选择、系数求解、对角化步骤或任何计算软件的按钮顺序写成可照做的规程。

它不是 [[bonding-theory|价键与分子轨道]] 的对照讲义。总览要从氧气顺磁讲到键级口诀。本页桌上只有一九三二年这几份芝加哥印刷物。它不是 [[huckel-1931-benzene-mo|休克尔 1931]]。那一组德文页把苯里六只 π 电子写成环状能级；样品是闭合共轭环，不是水与甲烷的通式。它不是 [[pauling-1931-chemical-bond|鲍林 1931]]。四月那份《会志》把杂化、顺磁判据和极限式叠加写成化学家的价键语言。本页把电子对键本身改记到遍布分子的轨道上。它不是 [[heitler-london-1927|海特勒–伦敦 1927]]。苏黎世长文的样品是两核两电子的交换谷。它更不是 [[chemical-bond|化学键]] 总览，也不是 [[aromaticity|芳香性]] 口诀，更不是一份应当把原子轨道加起来去应付作业的计算课。履历与一九六六年的诺贝尔奖不在本页。

## 破除误解：不是人物传，不是休克尔的苯，不是鲍林的价键全书，不是成键理论总览，也不是一份可以照跑的规程

第一个误解，是把本页读成马利肯的节选传记，或读成“他在一九三二年发明了分子轨道”。双原子的 σ、π 分类与电子组态，洪特在一九二七年起那一组《分子光谱的诠释》里已经写，马利肯自己一九二八年的《物理评论》第三十二卷也已经给分子里的电子派过量子数。缺的不是“电子可以写成单电子函数”，而是：这套管怎样接到三个核以上的分子，并且用化学家听得懂的词把价说完。本页停在《物理评论》把多原子分子收进分子轨道语言的那一年。

第二个误解，是把本页读成 [[huckel-1931-benzene-mo|休克尔 1931]] 的英文版，或读成“苯的 π 电子表已经被重印一遍”。斯图加特长文的未知数是：六只垂直于环平面的电子怎样占满循环边界下的能级。芝加哥系列的未知数是另一张桌子上的通式：水的弯曲、氨的锥、甲烷的四面体，怎样用同一套单电子函数说话。两页都用遍布分子的轨道。样品与未知数不能同一句。$4n+2$ 不在四月短文的标题里。

第三个误解，是把本页读成 [[pauling-1931-chemical-bond|鲍林 1931]] 的分子轨道附录，或读成“杂化已经被改名为轨道”。鲍林那年的硬物是四面体本征函数、角向最大值，以及用磁矩在两张路易斯式之间作否证。电子仍被写成落在两核之间的一对。马利肯那年的硬物是：同一只电子可以先从每个核的角度看一次，再从整个分子的角度看一次；后一种看法里，轨道不必定域在某一根短线上。价键让化学家继续画短线。分子轨道让他们改用一张属于分子的能级表。两套一九三一到一九三二年的改口不要焊在同一句里。

第四个误解，是把本页读成 [[bonding-theory|价键与分子轨道]] 或 [[chemical-bond|化学键]] 的节选，或读成课堂里那张氧气键级图已经印在一九三二年的摘要里。总览必须处理两套管何时收敛、键级怎样数、液氧为什么挂在磁极上。一九三二年交出的是一套描述方式：原子轨道与分子轨道并列，电子对键被改写成占满。本页的新对象是多原子。不要把后到的键级口诀倒填成四月已经贴上的分类。

第五个误解，是把“原子轨道的线性组合”读成一份应当照着选基组、写久期行列式、调软件关键字的作业。原论文给出的是写法判决：分子轨道可以被近似写成原子轨道的线性组合，并按核骨架的对称性分类。后到的自洽场、斯莱特型或高斯型基、按钮顺序，属于另一些印刷物。本页若把求解顺序写出来，对象就会滑成操作手册。对象不是手册。看见 $\phi=c_{a}\chi_{a}+c_{b}\chi_{b}+\cdots$，不是拿到一份计算许可。

第六个误解，是把四月第四十卷五十五页读成已经印出 “II. General Considerations”，或把九月的双键文读成又一篇总论。系列第一篇没有罗马数字副题，样品是具体分子的组态。总论在七月，页码改到第四十一卷四十九到七十一。双键专论在九月，印出的副题仍写罗马数字 II；次年第四篇改称它为系列第三篇。把各篇焊成一次顿悟，会把印刷顺序删掉。本页把顺序分开写。

## 对象：单电子组态、orbital 一词、两套描述、不必定域的分子轨道，以及乙烯的双键

第一件公开硬物是四月那篇已经印出的多原子组态。马利肯把水、氨、甲烷、四氟化碳、四氯化碳、高氯酸根、硫酸根、氯酸根、亚硫酸根、二氧化碳写成一套单电子波函数，并说其他类型可以按同样方式补上。核的几何先当作已知的骨架。未知数收缩成：价电子怎样分配到属于整个分子的单电子态上。许多价现象，被他读成这些函数加上一条建立在 [[量子物理--pauli-exclusion-principle|泡利不相容原理]] 上的简单规则。规则是解释，不是从第一原理逐步推完的本征值表。本页停在：多原子分子可以先用单电子函数说话。它不把应当如何指定每个系数写成可照做的下一步。

第二件硬物是七月总论里那两个名词，以及它们强迫写下的双重描述。马利肯把 one-electron orbital wave function 缩写成 orbital，并区分 atomic orbital 与 molecular orbital。共享电子被要求从两个角度看。第一个角度仍用原子轨道，站在分子里的每一个核上往外看。第二个角度用分子轨道，把分子当成一个整体。两套看法要同时保留。只保留第一套，价会退回“这对电子属于哪两颗原子”。只保留第二套，化学家会丢掉“这个核周围仍然像某种原子”的近核事实。七月长文的主张是：路易斯当初用来发明电子对键的那些化学证据，现在都可以用量子理论说明，而不必再把电子对键本身当作不可缺少的概念。海特勒–伦敦与斯莱特–鲍林的量子力学电子对，被他写明与路易斯的概念并不相同，对化学事实的覆盖也更窄。主张要标成一九三二年的主张。价键没有因此从化学里消失。

第三件硬物是：电子对键被改写成占满，以及分子轨道不必挤在两核之间。马利肯同意洪特：让海特勒–伦敦–斯莱特–鲍林电子对键对化学有用的那些性质，分子轨道同样具备。鲍林与斯莱特的“重叠越大键越强”，对成键分子轨道同样成立。于是他写下那句后来被课堂压缩过头的话：一根电子对键，差不多就是两只电子占着一条成键分子轨道。更一般的说法必须把定域放开：$n$ 根电子对键，应读成 $2n$ 只电子占着 $n$ 条分子轨道，因为分子轨道不一定像电子对键那样被关在两核之间。水里的电子不必先被切成两根 O–H 短线再谈量子力学。线性组合是把这句主张写下来的脚手架，不是一份应当按步骤对角化的规程。伦纳德–琼斯一九二九年已经在双原子上用原子函数的加减去读氟与氧。本页要把那套管接到三个核以上。缩写 LCAO 后到。一九三二年印出的是线性组合这件事本身。

第四件硬物是九月那篇双键专论。乙烯被写成两块激发态的亚甲基靠近。用斯莱特–鲍林的重叠判据，基态能量在两块 $\mathrm{CH}_{2}$ 共平面时明显低于两块互相垂直。碳碳双键与氧氧双键被拿来对照。乙硼烷里两块 $\mathrm{BH}_{3}$ 之间那条键，他判断更像氧氧而不是碳碳。后到的桥式三中心键不在一九三二年的封面里。同一篇还处理激发态：某些紫外吸收所到达的态，平面反而比垂直更贵。吸收之后，分子倾向转到垂直，再落到另一侧的平面。顺反异构被光改写，第一次有了一条用分子轨道说话的机制。公式是组态判决，不是一份应当照着照射样品、调节波长的实验课。

第五件硬物是总论收尾处那条半经验的价规则。马利肯写明：分子电子结构的要点，可以定性地理解成上面那套双重描述，加上一条并不全新的价规则。它没有声称已经从 [[量子物理--schrodinger-equation|薛定谔方程]] 解完多原子本征值。波函数怎样对着计数，见 [[量子物理--born-1926-probability|玻恩 1926]]：平方是概率读法，不是一张已经拍好的多中心电子云照片。本页停在语言与组态。定量的重叠积分表、自洽场循环，属于另一些年份。

短线说键是两核之间的一对。分子轨道说那一对往往只是占满一条成键轨道的简便说法；当真的分子里轨道伸过两核以上，短线就成了投影。两句话可以指向同一只抗磁的甲烷。记账单位不同。[[chemical-bond|化学键]] 总览后来会把两套管都收进去。本页只提供分子轨道这一侧第一次把多原子价写成可推广语言的现场。

## 它钉死了什么，以及它没有量到的东西

它钉死的是：多原子分子里的价电子，可以先属于分子，再被投影回某一根短线。若继续坚持“每一对电子必须先指定给某两颗原子”，水的孤对、二氧化碳的离域、后来苯环上那六只 π 电子，就只能被写成例外。辅助假设被这套双重描述逼到墙角之后，分子轨道才作为化学对象进场。四月的组态表证明这不是双原子光谱的转抄。七月的总论证明这需要新名词。九月的乙烯证明双键不必先画成两套四面体共用一条棱。

它钉死的是 orbital 作为单电子轨道波函数的缩写，以及原子轨道与分子轨道的并列。玻尔式的经典轨道不在这组印刷物里复活。名字是收缩。收缩之后，化学家可以讨论“这条轨道成键还是不成键”，而不必每次把 one-electron orbital wave function 写全。

它没有量到光谱精度的多原子本征值，也没有交出哈特里–福克自洽场的分子版。定性组态在先。罗特汉与霍尔把线性组合推进成可矩阵化的自洽方程，是二十年后的事，对象见 [[roothaan-1951-lcao-scf|罗特汉 1951]]。本页若把后到的基组与收敛判据写成一九三二年已经备好的工具箱，会把补全算进原论文。原论文钉住的是写法，不是软件。

它没有发明苯的 $4n+2$，也没有把芳香性判据束写完。那是 [[huckel-1931-benzene-mo|休克尔 1931]] 与 [[aromaticity|芳香性]] 总览的权限。封面样品是水、氨、甲烷与乙烯。不要把德文苯谱焊进四月的芝加哥短文。

它也没有覆盖杂化最大值表、电负性标，或用磁矩去判决氰镍配离子。那些是 [[pauling-1931-chemical-bond|鲍林 1931]] 的对象。本页的未知数是电子属于分子还是属于键。第一种看法仍被要求保留，因为它对近核的原子事实有用。偏爱第二种，是因为价的规律在分子轨道里更干净，不是因为价键已经被证伪。现场不是终审。

它没有量到布居分析。一九五五年的净电荷表是同一人后到的仪器。一九三二年要的是：线性组合被允许当作分子轨道的写法。

## 跨域连接

- **[[huckel-1931-benzene-mo|休克尔 1931]]**：斯图加特长文把苯的六只 π 电子写成循环边界下的占满图。本页一年后把同一类“电子先属于分子”的写法交给水、氨、甲烷与乙烯。不要把一九三二年读成又一次算出了苯的 $k$ 量子数，也不要把一九三一年读成已经给四氟化碳派好了分子轨道。休克尔的样品是闭合共轭环。马利肯的样品是多原子通式。两页共用离域。未知数不能同一句。
- **[[pauling-1931-chemical-bond|鲍林 1931]]**：四月《会志》把交换语言改写成杂化、磁判据与极限式叠加。本页把电子对键改记成占满一条成键分子轨道，并允许这条轨道伸过两核以上。不要把七月总论读成又一份四面体本征函数，也不要把帕萨迪纳长文读成已经把短线从化学里删掉。重叠判据两页都用。判据服务的对象不同：一根定域键的方向，对上一条不必定域的成键轨道。
- **[[heitler-london-1927|海特勒–伦敦 1927]]**：苏黎世长文把两个中性氢的同极键写成空间对称、自旋单态的交换下降。本页五年后把“一对自旋相反的电子”读成两只电子占着一条成键分子轨道。不要把一九三二年读成又一次算出了氢分子的解离能，也不要把一九二七年读成已经给出了水与甲烷的分子轨道表。交换谷回答两核两电子为什么下降。本页回答那一对在三个核以上要不要仍被关在两核之间。
- **[[bonding-theory|价键理论与分子轨道理论]]**：总览要把两套管的教学分工、氧气顺磁与键级口诀写成一束。本页停在一九三二年那一次把多原子价改写成分子轨道的印刷。不要把液氧挂在磁极上提前写成四月短文的封面实验，也不要把本页读成已经把价键判成过时。总览记得住两套管会收敛。装置解释的是分子轨道这一侧怎样先取得多原子的发言权。
- **[[量子物理--pauli-exclusion-principle|泡利不相容原理]]**：一九二五年的光谱短文把同一组量子数的占用写成禁止。本页把这条禁止收成化学口吻：单电子函数按不相容往里填，闭壳层与成对出现，价的稳定性才有一条可执行的规则。不要把一九三二年读成又一次推导了费米子反对称，也不要把不相容读成已经给出了乙烯必须共平面。不相容回答为什么不能把两只电子塞进同一套量子数。本页回答怎样在属于分子的轨道表上执行这条禁止。
- **[[philosophy-of-science|科学哲学]]**：一个理论可以把每根键派给某两颗原子之间的一对电子，而不必让价这个词裂开。一九三二年的双重描述让这个辅助假设变贵：它必须同时解释近核仍像原子、价电子却可以伸过两核以上、乙烯基态共平面、激发态却倾向转过直角。若乙烯基态被证明垂直更稳，九月那篇用重叠读双键的论证就会垮。当时的结构化学没有那样说。马利肯自己把价规则写成半经验总结，等于承认模型是脚手架。短线被从默认底层拿掉之后，分子轨道才作为化学对象进场。
