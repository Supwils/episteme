# Cahn–Ingold–Prelog 1966：序列规则怎样让印刷的名字记下三维排布

一九六六年四月，《应用化学》国际英文版第五卷第四期刊出罗伯特·S·卡恩（R. S. Cahn）、克里斯托弗·英戈尔德爵士（Sir Christopher Ingold）与弗拉迪米尔·普雷洛格（V. Prelog）的长文，题目按字面是 “Specification of Molecular Chirality”，页码从三八五到四一五。作者栏分别写在伦敦皮卡迪利伯灵顿宅的化学会、伦敦大学学院，以及苏黎世联邦理工学院。DOI：10.1002/anie.196603851。同年德文《应用化学》第七十八卷第八期把同一套标定印成 “Spezifikation der molekularen Chiralität”，页码从四一三到四四七，DOI：10.1002/ange.19660780803；四月二十一日见刊。德文本是同年同伴印刷，不是第二份封面。对象是一套序列规则：按永久的内部性质给配体排队，再把排好的三维样式收成可印进名称的立体描述符，使印刷的名字记下三维排布，而不必附图。后到简称 CIP。本页是一九六六年这三十一页。本页不把某分子怎样逐步标成 R 或 S 写成可照做的课堂操练单，也不把甾体、激素或手性药物怎样制备写成可照做的规程。对象是证据，不是菜谱。

它不是 [[vant-hoff-1874-tetrahedron|范霍夫一八七四年的四面体碳]]。荷兰小册钉的是单碳四根亲和力指向四面体顶点，并由此数出不对称碳上有两种不能重合的贴法。本页假定四面体已经在化学里站住，未知数改成：两只手要印成哪两个字母，才能在实验室之间传递而不必附一张图。它不是 [[barton-1950-steroid-conformation|Barton 1950]]。八月那五页问甾核椅式上非环价分成赤道与极向，哪一种更稳。本页可以把某一张已经选定的三维快照写成描述符，并不回答哪一张椅子更该坐。它不是 [[pasteur-1848-tartaric|巴斯德一八四八年的酒石酸钠铵盐]]。那一盘晶体用半面和镊子把左右手分成两堆。本页桌上没有镊子，也没有旋光管作为封面量具。它更不是一份应当照着改环、制激素或制造手性药物的规程。

## 破除误解：不是四面体碳，不是甾核椅式，不是酒石酸盐，不是一九五一或一九五六年的邻篇，也不是操练单或制激素规程

第一个误解，是把本页读成 [[vant-hoff-1874-tetrahedron|范霍夫一八七四年的四面体碳]] 的再版，或读成“碳已经是四面体，手的名字就不必另写”。四面体回答单碳四根键指向哪里，以及四个彼此不同的基团有两种不能重合的贴法。一八七四年用旋光正负作为当时唯一普及的读数，并不给出后来那一对 R 与 S。正负号描述指定条件下偏振面怎么转，不是顶点上的标签顺序。[[chirality|手性与对映异构]] 总览后到会把左右手套、R/S 与旋光符号分成三层。本页停在可印刷的税则怎样被写成通用装置。有四面体，才有两只手可数。有序列规则，两只手才有可以邮寄的字母。

第二个误解，是把本页读成 [[barton-1950-steroid-conformation|Barton 1950]] 的命名附录，或读成“构象分析已经把立体描述符印完”。一九五〇年的未知数是骈接六元环取椅还是取船，以及非环价分成哪两类。一九六六年长文把系统扩展到构象手性，使某一张已经选定的三维快照也可以被写成螺旋描述符。扩展的是命名权限，不是又一张甾核平衡表。哪一种椅式更稳，仍是三一六页的几何证据。看见构象，不要把三一六页提前写成三八五页的标题实验。

第三个误解，是把本页读成 [[pasteur-1848-tartaric|巴斯德一八四八年的酒石酸钠铵盐]] 的理论附录，或读成“那一盘盐已经把 R/S 写进瓶子”。一八四八年的装置是半面晶面、镊子和两根相反的管子。拆开证明格子拆掉之后分子自己仍带着一只手。名字是后到的填充，并不回头改写当年看见的事实。本页桌上没有那盘钠铵盐。

第四个误解，是把[[cahn-ingold-1951|一九五一年卡恩与英戈尔德]]印在《化学会志》六一二到六二二页的 “Specification of Configuration about Quadricovalent Asymmetric Atoms”，或[[cahn-ingold-prelog-1956|一九五六年三人印在《经验》第十二卷八一到九四页的 “The specification of asymmetric configuration in organic chemistry”]]，焊成一九六六年的封面。一九五一年那一份把序列规则写到四配位不对称原子上，描述符仍用 d 与 l。一九五六年普雷洛格加入，改用 R 与 S，把权限从费歇尔那套相对记号里拉开。一九六六年把一九五六年及以前已经用于有机构型的部分大体保留，又按拜耳施泰因研究所等地十年经验改写若干结构类型，并把权限扩展到构象手性，以及配位数到六的无机构型。邻篇是邻篇。封面硬物仍是第五卷三八五到四一五页。

第五个误解，是把“标定”读成一份应当照着给课堂分子排队、把最低优先基放到后方、顺时针写 R 的操练单，或读成甾体改环、激素制备、手性药物工艺。长文给出的是概念判决：一套按原子序数向下比较的词典序，怎样把模型上的手性收成可印进名称的字母。看见优先、同类对或描述符，不是拿到一份应当动手标某个分子或准备教学样品的步骤清单。[[bijvoet-1951-absolute-configuration|比佛特一九五一年]]用反常 X 射线散射测定酒石酸盐的绝对构型，见 [[x-ray-crystallography|X 射线晶体学]]。测定是晶体学的权限。本页的权限是测定之后字母按哪一条税则进入印刷的名字。对象是证据，不是菜谱。

第六个误解，是把德文第七十八卷四一三到四四七页读成第二份封面，或把英文国际版读成德文的后到翻译附录。两种文字同年印出同一套标定。期刊自己的引用惯例把可引用的页码与 DOI 放在国际英文版。本页按第五卷三八五到四一五页读。德文本是同伴，不是另一套税则。

## 对象：序列规则、优先、同类对与描述符作为印刷税制，以及三十一页的权限

第一件公开硬物是序列规则本身：配体必须按一种永久的内部性质排序，排好的三维样式再直接当作分类依据。长文把这套拓扑分析写成通用系统的骨架。内部性质的第一把尺子是原子序数。直接相连的原子，原子序数高者在前。若这一层仍平手，再向外一层比较，像查字典，而不是像测旋光。质量数是下一把较细的尺子，用来分开同位素。不饱和处用重复出现的原子把双键、三键写进同一套词典序，使优先不因“看起来像双键”而另起炉灶。这些条款印在纸上，是名称怎样选择字母的税则。[[bonding-theory|价键理论与分子轨道理论]] 总览会问键怎样被写成轨道。本页问的是已经画出的配体按核电荷标签怎样排队。原子序数在这里是排序键，不是杂化表。

第二件硬物是把排好的样式收成描述符的转换约定。四面体中心上，最低优先的配体被放到远离观察者一侧之后，其余三枚若按优先顺序呈顺时针，印 R（rectus）；逆时针印 S（sinister）。这对字母是绝对构型的名字，不是偏振面往哪边转，也不是费歇尔投影里相对甘油醛的 D 与 L。长文自己讨论通用系统与范围较窄的旧系统如何共生：糖与氨基酸上的 D/L 并不被宣布作废，只是不再被当成一切手性的通用税则。螺旋手性另印 M 与 P。双键几何在一九六六年的封面词是 seqcis 与 seqtrans，seqcis 在序列比较里先于 seqtrans。后到的 [[blackwood-1968-ez|E/Z]] 是一九六八年布莱克伍德一组的邻居，不要焊进三八五页的标题。看见 R 或 S，不要读成右旋或左旋。三套符号各管一层。[[isomerism|同分异构]] 总览后到会把构造、构型与构象分成三层。本页停在构型——以及被选来写入名称的那一层构象手性——怎样被印成字母。

第三件硬物是同类对。当两枚配体在元素组成上无法分开、却各自已经带着立体描述符时，词典序不能停在“都是碳”。长文把同类配对写进较后的子规则：相同的一对描述符（两枚都是 R，或两枚都是 S；螺旋上则是两枚都是 M，或两枚都是 P）排在不相同的一对之前。再下一层，R 先于 S，M 先于 P。这是给已经有名字的配体继续排队的条款，用来处理假不对称一类“组成相同、三维样式不同”的分支。没有同类对，序列规则会在那些分支上失语，印刷的名字就无法从两只几何上不同的手之间选出唯一的字母。条款的权限是让词典不中断。

第四件硬物是权限的扩展，以及名称与模型之间的转写。摘要写明：一九五六年及以前已经用于有机构型的部分大体保留；若干结构类型按拜耳施泰因研究所等地的经验重新定义；系统现在还要处理有机化学里的构象，以及配位数到六的无机构型。手册条目是铅字，不是插图册。通用字母若不能与范围较窄的旧记号共生，条目就无法开印。构象手性在这里是：某一张已经选定的三维快照，可以按螺旋描述符进入名称，并不回答哪一张快照在能量上更该出现。配位数六是：八面体一类中心也可以按同一套序列思想被印成描述符。扩展的是税则的辖区，并不把测定或合成提前写成封面实验。

第五件硬物是三十一页的权限。它确认的是：分子手性可以被写成一套可印刷的立体描述符；优先以原子序数为第一把内部尺子；同类对与 R 先于 S 使词典在三维分支上仍能给出唯一排序；字母可以从模型转写进名称。它没有把旋光正负写成 R/S 的定义，也没有把费歇尔的 D/L 从糖与氨基酸上抹掉。它没有把绝对构型的实验测定收进封面；那是[[bijvoet-1951-absolute-configuration|比佛特]]一侧的晶体学。它没有把赤道与极向写成甾核上的稳定次序，也没有把 seqcis/seqtrans 改名为 E/Z。本页只读第五卷三八五到四一五页。封面硬物仍是序列规则作为印刷税制，加上让三维排布能够不附图而进入名字的那一套描述符。

## 它钉死了什么，以及它没有量到的东西

它钉死的是：两只不能重合的手，不能再只靠一张图、一只共享的晶体或一根指定条件下的旋光管，在实验室之间传递。若继续坚持“看见了就不需要名字”，手册条目与化合物登记就会在立体一层上失语。一八七四年看对了四面体上有两种贴法。一八四八年看对了左右手可以被分成两堆。本页看对了：真正要被迁移到名称里的，不是某一次旋光读数，也不是某一次衍射的坐标表，而是一套按内部性质排序后再收成字母的税则。

它钉死的是手性作为几何性质，而不是把光学活性写成定义本身。溶液转不转，依赖于波长、溶剂、浓度和是否外消旋。名称里的 R 或 S 不随这些条件改写。长文把对象从“不对称碳”扩成“分子手性”，使轴、面与螺旋不必再被假装成又一个四面体碳。不对称碳是常见特例，不是唯一入口。这一扩，是命名辖区的扩，不是又一次颁布四面体。

它钉死的是通用系统必须与范围较窄的旧系统共生，而不是一次性地替换全部旧字母。D/L 在糖与氨基酸上仍有其受限辖区。(+)/(-) 仍是实验读数。R/S 是按序列规则印出的绝对构型名字。三套符号不能互相直接换算。把 R 读成右旋，是把税则读成旋光管。本页把这种误读挡在封面之外。

它没有测定任何分子的绝对构型。[[bijvoet-1951-absolute-configuration|比佛特、皮尔德曼与范博梅尔一九五一年]]在《自然》第一六八卷用反常散射把酒石酸盐的绝对构型钉进晶体学。CIP 给已经测定或已经由化学关联接到测定上的那一只手起名字。没有测定，税则仍只是空的字母表。[[organic-synthesis|有机合成]] 检验的是目标分子怎样被逐步构建。本页只提供：构建完成之后，立体一层怎样被印进名称。

它也没有把双键几何的封面词写成后来的 E 与 Z，没有把[[prelog-helmchen-1982|一九八二年普雷洛格与黑尔姆兴的修订]]写成已经印在三八五页。[[blackwood-1968-ez|布莱克伍德一组一九六八年]]才把 E/Z 写进《美国化学会志》。一九八二年那一份是对 CIP 原则的重述与修订提案，页码不在第五卷。一九七五年诺贝尔化学奖表彰普雷洛格与康福思在有机分子与反应立体化学上的研究，奖状是九年后的印刷物。演说不能代替三八五到四一五页。

## 跨域连接

- **[[vant-hoff-1874-tetrahedron|范霍夫一八七四年的四面体碳]]**：荷兰小册把单碳四根亲和力写成四面体顶点，未知数是空间结构式与不对称碳上的两种贴法。本页九十二年后问这两种贴法怎样被印成可传递的字母。不要把三八五页读成又一次颁布四面体，也不要把一八七四年读成已经写出 R 与 S。四面体服务单碳的几何。序列规则服务几何已经成立之后的印刷名。
- **[[barton-1950-steroid-conformation|Barton 1950]]**：八月短文把甾核写成椅式，并把非环价分成赤道与极向，未知数是哪一种排布更稳。本页可以把某一张已经选定的三维快照写成描述符，包括把构象手性收进螺旋字母。不要把三一六页读成已经印出 CIP，也不要把三八五页读成又一张甾核平衡表。椅式服务坐姿与稳定次序。本页服务名称里的字母。
- **[[pasteur-1848-tartaric|巴斯德一八四八年的酒石酸钠铵盐]]**：那一页的对象是半面、镊子和两堆相反的溶液。本页的对象是一百十八年后的印刷税制。把长文写成镊子实验的理论附录，或把一八四八年写成 R/S 的提前演示，都会把两张桌子焊成一张年表。晶体回答不旋光的酸是不是混合物。序列规则回答混合物里的每一只手在名称里该占用哪一个字母。
- **[[chirality|手性与对映异构]]**：那一篇从左右手套讲到 R/S、沙利度胺和不对称催化，对象是立体化学这张地图。本页只收一九六六年的印刷物：序列规则、同类对、以及描述符怎样从模型进入名称。把总览里的药物与工业催化提前写进第五卷，会把一次命名装置夸成一门学科的预告。地图在那一篇；税则在这一篇。
- **[[isomerism|同分异构]]**：异构先被写成同组成、不同连法。本页处理的是连法已经相同、纸面式却仍必须另加一层字母的那一层。把一九六六年读成又一次构造课，会把立体一层误并进断键一层。构造课回答哪根键接在哪。本页回答四面体以及轴、面、螺旋上已经不同的样式，怎样被印成不附图也能传递的名字。
- **[[bonding-theory|价键理论与分子轨道理论]]**：总览要把两套管的教学分工写成一束，并会把四面体方向接到杂化。本页用原子序数作排序键，并不问键为什么愿意取这个方向。不要把序列规则读成电负性表，也不要把 R 与 S 读成另一种轨道对称。成键理论服务键为什么在那里。CIP 服务键已经在那里之后，名称选哪一个字母。
- **[[organic-synthesis|有机合成]]**：总览要把碳骨架怎样被逐步构建写成手续，并已经把立体化学当作装基团时必须交代的一层。本页停在一九六六年把那一层写成可印刷的描述符。不要把全合成路线图提前写成三八五页的封面实验，也不要把本页读成一份应当照着改环、制激素或制备手性药物的规程。手续服务分子怎样被做出来。税则服务做出来的三维怎样被写进名字。
