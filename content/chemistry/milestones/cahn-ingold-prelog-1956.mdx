# Cahn–Ingold–Prelog 1956：有机构型怎样被改印成 R 与 S

一九五六年，《经验》（Experientia）第十二卷第三期刊出十四页论文，作者是罗伯特·S·卡恩（R. S. Cahn）、克里斯托弗·英戈尔德（Christopher Ingold，C. K. Ingold）与弗拉迪米尔·普雷洛格（V. Prelog），题目按字面是 “The specification of asymmetric configuration in organic chemistry”，页码从八一到九四。作者栏分别写在伦敦皮卡迪利伯灵顿宅的化学会、伦敦大学学院，以及苏黎世联邦理工学院。卡恩当时是化学会期刊的编辑。英戈尔德当时尚未受封爵士，爵士衔一九五八年才到。DOI：10.1007/BF02157171。对象是把一九五一年的序列规则留下来给配体排队，同时把印进名称的字母从 d 与 l 改成 R（rectus）与 S（sinister），使绝对构型的名字不再看起来像费歇尔的 D/L，也不再像旋光符号 d/l。普雷洛格加入署名。权限仍主要停在有机不对称原子，尚未扩到构象手性与配位数六。后到的 CIP 把本页当作 R 与 S 第一次开印的封面。本页是一九五六年这十四页。本页不把某分子怎样逐步标成 R 或 S 写成可照做的课堂操练单，也不把甾体、激素或手性药物怎样制备写成可照做的规程。对象是证据，不是菜谱。

它不是 [[cahn-ingold-1951|Cahn–Ingold 1951]]。《化学会志》六一二到六二二页只有卡恩与英戈尔德，描述符仍是小写 d 与 l。本页五年后改字母，第三人加入。它不是 [[cahn-ingold-prelog-1966|Cahn–Ingold–Prelog 1966]]。三十一页把权限扩到构象手性与配位数六，封面词已经是分子手性。本页停在有机构型，十四页不是那份长税制。它不是 [[bijvoet-1951-absolute-configuration|比佛特一九五一年]]。《自然》二七一页用反常散射选出酒石酸盐与镜像哪一只落在晶胞里。测定是哪一只手。本页是已经画出的那一只手印哪两个字母。它不是 [[vant-hoff-1874-tetrahedron|范霍夫一八七四年的四面体碳]]。荷兰小册钉的是单碳四根亲和力指向四面体顶点。本页假定四面体已经站住，未知数改成：绝对构型该用哪一对不会被误读的字母。它不是 [[pasteur-1848-tartaric|巴斯德一八四八年的酒石酸钠铵盐]]。那一盘晶体用半面和镊子把左右手分成两堆。本页桌上没有镊子。它不是 [[barton-1950-steroid-conformation|Barton 1950]]。同属《经验》这一家，八月那五页问甾核椅式上哪一种排布更稳。期刊家族相同，封面对象不同。它更不是费歇尔一八九一年相对甘油醛的 D/L，也不是一份应当照着给课堂分子排队、改环、制激素或制造手性药物的规程。

## 破除误解：不是一九五一年的 d 与 l，不是一九六六年的长税制，不是酒石酸盐测定，不是一八七四年的四面体，不是一八四八年的镊子，不是费歇尔的 D/L，也不是操练单或制激素规程

第一个误解，是把本页读成 [[cahn-ingold-1951|Cahn–Ingold 1951]] 的再版，或读成“序列规则一经写出，R 与 S 就已经开印”。一九五一年十一页把序列规则写到四配位不对称原子上，描述符仍是 d 与 l。桌上没有普雷洛格。看见原子序数尺子，不要把八一页提前写成六一二页的标题。邻篇是邻篇。封面硬物仍是《经验》八一到九四页。

第二个误解，是把本页读成 [[cahn-ingold-prelog-1966|Cahn–Ingold–Prelog 1966]] 的提前抽印，或读成“R 与 S 一开印，辖区就已经扩到构象与配位数六”。一九六六年长文把一九五六年及以前已经用于有机构型的部分大体保留，并把权限扩展到构象手性，以及配位数到六的无机构型。本页停在有机化学里的不对称构型。把三八五页的长税制倒填进八一页，会把十年的邻篇焊成同一份封面。

第三个误解，是把本页读成 [[bijvoet-1951-absolute-configuration|比佛特、皮尔德曼与范博梅尔一九五一年]] 的命名附录，或把测定与改字母焊成一篇。乌得勒支那两页的对象是钠铷右旋酒石酸盐四水合物。反常散射选出与天然右旋酒石酸相符的那一只手。测定是晶体学的权限，见 [[x-ray-crystallography|X 射线晶体学]]。本页的权限是：已经画出的那一只手，名称按哪一条税则选字母，以及那两个字母该长成什么形状才不会被误读。本页没有把酒石酸根钉进晶胞。

第四个误解，是把本页读成 [[vant-hoff-1874-tetrahedron|范霍夫一八七四年的四面体碳]] 的再版，或读成“碳已经是四面体，手的名字就不必另写”。四面体回答单碳四根键指向哪里，以及四个彼此不同的基团有两种不能重合的贴法。一八七四年用旋光正负作为当时唯一普及的读数，并不给出按原子序数排队的拉丁字母。有四面体，才有两只手可数。有序列规则，两只手才有可以邮寄的字母。有改字母，邮寄出去的字母才不会在铅字上撞上旧记号。

第五个误解，是把本页读成 [[pasteur-1848-tartaric|巴斯德一八四八年的酒石酸钠铵盐]] 的理论附录，或读成“那一盘盐已经把 R 与 S 写进瓶子”。一八四八年的装置是半面晶面、镊子和两根相反的管子。拆开证明格子拆掉之后分子自己仍带着一只手。名字是后到的填充，并不回头改写当年看见的事实。本页桌上没有那盘钠铵盐。

第六个误解，是把本页的 R 与 S，读成费歇尔相对甘油醛的大写 D 与 L，或读成偏振面往哪边转的旋光符号。一八九一年费歇尔在《德国化学会会志》第二十四卷为糖族写出相对构型，DOI：10.1002/cber.18910240196。罗萨诺夫一九〇六年把甘油醛收成这棵树的根。大写字母服务糖与氨基酸的相对辖区。溶液的 d、l 或 (+)、(-) 描述指定条件下偏振面怎么转。本页改用 R 与 S，正是因为一九五一年那对小写 d 与 l 在印刷上太像这两套旧记号。不要把本页读成费歇尔投影课，也不要把 R 读成右旋。

第七个误解，是把“标定”读成一份应当照着给课堂分子排队、把最低优先基放到后方、顺时针写 R 的操练单，或读成甾体改环、激素制备、手性药物工艺。十四页给出的是概念判决：序列规则可以继承，印进名称的字母必须改形状，才能让绝对构型的名字不再看起来像相对记号或旋光读数。看见优先或描述符，不是拿到一份应当动手标某个分子或准备教学样品的步骤清单。[[barton-1950-steroid-conformation|Barton 1950]] 问的是椅式上哪一种排布更稳。本页不回答稳定次序，也不写如何跑反应。对象是证据，不是菜谱。

## 对象：改字母、继承的序列规则、R 与 S 作为印刷税制，普雷洛格加入，以及十四页的权限

第一件公开硬物是改字母本身。一九五一年已经把四配位不对称原子上的手收成 d 与 l。那一对字母形状碰巧与旋光符号相近，也与费歇尔那对大写 D 与 L 相近。相近不是同一套税则，却足够让手册条目在铅字上互相撞车。本页把描述符改成 R 与 S。R 取拉丁文 rectus，意思是右。S 取拉丁文 sinister，意思是左。选这一对，不是因为偏振面往右转为正，而是因为铅字看起来不再像 D/L，也不再像 d/l。改的是印刷税制上的字母，不是排队的尺子。看见 R 或 S，不要读成右旋或左旋。三套符号各管一层。本页停在绝对构型第一次改用这一对拉丁字母的那一次印刷。

第二件硬物是序列规则被继承，而不是被重写。配体仍须按一种永久的内部性质排序，排好的三维样式再直接当作分类依据。内部性质的第一把尺子仍是原子序数。直接相连的原子，原子序数高者在前。若这一层仍平手，再向外一层比较，像查字典，而不是像测旋光。这些条款在一九五一年已经开印。本页把它们留下来给有机不对称原子继续排队。[[bonding-theory|价键理论与分子轨道理论]] 总览会问键怎样被写成轨道。本页问的是已经画出的配体按核电荷标签怎样排队。封面变化落在字母，不落在尺子。

第三件硬物是把排好的样式收成 R 与 S 的转换约定，作为印刷税则，而不是作为课堂操练单。四面体中心上，最低优先的配体被放到远离观察者一侧之后，其余三枚若按优先顺序呈顺时针，印 R；逆时针印 S。这对字母是按序列规则写出的绝对构型名字，不是偏振面往哪边转，也不是费歇尔投影里相对甘油醛的 D 与 L。本页把对象从“按内部性质排队后印 d 或 l”改成“按同一把尺子排队后印 R 或 S”。它没有宣布糖与氨基酸上的 D/L 作废。范围较窄的旧系统仍有其受限辖区。通用字母若不能与旧记号在视觉上分开，手册条目就仍会在铅字上含混。一九五一年已经另起尺子。一九五六年才切断视觉碰撞。

第四件硬物是普雷洛格加入，以及十四页的权限。卡恩仍写在化学会。英戈尔德仍写在大学学院，当时还不是爵士。普雷洛格把苏黎世联邦理工学院写进同一份封面。三人合署，使 C、I、P 三个字母第一次在同一条作者栏里排齐。题目写的是有机化学里的不对称构型，不是后来的分子手性。辖区仍主要停在有机不对称原子，也就是四面体中心上四枚彼此不同的配体。它确认的是：有机构型可以被写成一套不依赖某一次旋光读数的印刷字母；优先仍以原子序数为第一把内部尺子；印进名称的字母从 d、l 改成 R、S。它没有把绝对构型的实验测定收进封面；那是[[bijvoet-1951-absolute-configuration|比佛特]]一侧的晶体学。它没有把权限扩到构象手性，也没有处理配位数六。一九六六年那一份才扩辖区。本页只读八一到九四页。

## 它钉死了什么，以及它没有量到的东西

它钉死的是：绝对构型的通用名字，不能再借用一套在铅字上会与相对记号、旋光符号撞车的字母。若继续坚持 d 与 l，手册条目就会在“这是构型还是旋光、是绝对还是相对”这一层上失语。一八七四年看对了四面体上有两种贴法。一八四八年看对了左右手可以被分成两堆。一九五一年看对了真正要被迁移到名称里的是一套按内部性质排序后再收成字母的税则。本页看对了：税则已经有了，字母形状仍会把三套符号焊在一起。要切断视觉碰撞，必须换一对看起来不像 D/L、也不像 d/l 的拉丁字母。

它钉死的是手性作为几何性质，而不是把光学活性写成定义本身。溶液转不转，依赖于波长、溶剂、浓度和是否外消旋。名称里按序列规则印出的 R 或 S 不随这些条件改写。一九五一年已经把方向选对：字母服务模型上的手，不服务管子里的读数。本页把那一对容易被误读的小写字母换成 R 与 S，使这一判决在印刷上站稳。[[chirality|手性与对映异构]] 总览后到会把左右手套、R/S 与旋光符号分成三层。本页是第三层第一次以这一对拉丁字母开印。

它也钉死了通用系统必须与范围较窄的旧系统共生，而不是一次性地替换全部旧字母。D/L 在糖与氨基酸上仍有其受限辖区。(+)/(-) 仍是实验读数。R/S 是按序列规则印出的绝对构型名字。三套符号不能互相直接换算。把 R 读成右旋，是把税则读成旋光管。把 R 读成费歇尔的 D，是把绝对名字读成相对树。本页把这两种误读挡在封面之外。一九五一年给出的答案是另写尺子，新字母当时仍借用 d 与 l。本页给出的答案是改字母。

它没有测定任何分子的绝对构型。[[bijvoet-1951-absolute-configuration|比佛特一组]]用反常散射把酒石酸盐的绝对构型钉进晶体学。序列规则给已经测定、或已经由化学关联接到测定上的那一只手起名字。没有测定，税则仍只是空的字母表。改字母并不使空表变满。[[organic-synthesis|有机合成]] 检验的是目标分子怎样被逐步构建。本页只提供：构建完成之后，有机不对称这一层怎样被印进不会被误读的名称。

它也没有把描述符的辖区写成后来的分子手性，没有把构象手性与配位数六写进八一页。一九六六年《应用化学》国际英文版第五卷三八五到四一五页才扩辖区。[[prelog-helmchen-1982|一九八二年普雷洛格与黑尔姆兴的修订]]、一九七五年诺贝尔化学奖演说，都是更后的印刷物。演说不能代替八一到九四页。

## 跨域连接

- **[[cahn-ingold-1951|Cahn–Ingold 1951]]**：十一页写出四配位不对称原子上的序列规则，描述符仍是 d 与 l，署名里没有普雷洛格。本页五年后继承那把尺子，改印 R 与 S，第三人加入。不要把八一页读成六一二页的再版。
- **[[cahn-ingold-prelog-1966|Cahn–Ingold–Prelog 1966]]**：三十一页把序列规则扩成分子手性的通用税制，并处理构象手性与配位数六。本页十年前只处理有机构型，封面词已经是 R 与 S，辖区尚未扩大。不要把三八五页读成八一页的再版。
- **[[bijvoet-1951-absolute-configuration|比佛特一九五一年]]**：两页通信用弗里德尔差选出酒石酸根是哪一只手，并不给这只手起通用字母。本页五年后提供一对不再像 d/l 的字母，并不把任何一只手钉进晶胞。测定服务模型与晶体是否重合。改字母服务重合之后名称选哪一个铅字。
- **[[vant-hoff-1874-tetrahedron|范霍夫一八七四年的四面体碳]]**：荷兰小册把单碳四根亲和力写成四面体顶点，未知数是空间结构式与不对称碳上的两种贴法。本页八十二年后再问这两种贴法怎样被印成看起来不像相对记号或旋光符号的字母。四面体服务几何。本页服务几何已经成立之后被改印的名字。
- **[[pasteur-1848-tartaric|巴斯德一八四八年的酒石酸钠铵盐]]**：那一页的对象是半面、镊子和两堆相反的溶液。本页的对象是一百零八年后的印刷税制。晶体回答不旋光的酸是不是混合物。改字母回答每一只手在名称里该占用哪一个看起来不像旧记号的铅字。
- **[[chirality|手性与对映异构]]**：那一篇从左右手套讲到 R/S、沙利度胺和不对称催化，对象是立体化学这张地图。本页只收一九五六年的印刷物：继承的序列规则、改印的 R 与 S、以及普雷洛格加入。地图在那一篇；税则在这一篇。
- **[[isomerism|同分异构]]**：异构先被写成同组成、不同连法。本页处理的是连法已经相同、纸面式却仍必须另加一层字母的那一层。构造课回答哪根键接在哪。本页回答四面体上已经不同的样式，怎样被印成不附图也能传递的名字。
- **[[bonding-theory|价键理论与分子轨道理论]]**：总览会把四面体方向接到杂化。本页用原子序数作排序键，并不问键为什么愿意取这个方向。成键理论服务键为什么在那里。本页服务键已经在那里之后，名称选哪一个字母。
- **[[organic-synthesis|有机合成]]**：总览要把碳骨架怎样被逐步构建写成手续。本页停在一九五六年把有机不对称这一层改印成 R 与 S。不要把本页读成一份应当照着改环、制激素或制备手性药物的规程。手续服务分子怎样被做出来。税则服务做出来的四面体怎样被写进名字。
- **[[barton-1950-steroid-conformation|Barton 1950]]**：八月短文把甾核写成椅式，并把非环价分成赤道与极向，未知数是哪一种排布更稳。同属《经验》这一家。本页可以把某一枚已经选定的四面体中心写成字母，并不回答哪一张椅子更该坐。椅式服务坐姿与稳定次序。本页服务名称里被改印的字母。
