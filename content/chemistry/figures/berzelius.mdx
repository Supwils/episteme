# 永斯·贝采利乌斯

每当你写下 H₂O、NaCl、CO₂，你都在使用贝采利乌斯发明的语言。这套写法如此自然，以至于很少有人停下来想：它是谁、在什么时候定下来的。

这位瑞典化学家也许不像拉瓦锡或门捷列夫那样家喻户晓，但化学的日常工作几乎离不开他。用字母表示元素的符号系统、可靠的原子量、"催化"这个词，以及一系列新元素的发现，都出自他或经他奠定。如果说有人为化学制定了"书写规则"和"度量衡"，那就是他。

## 破除误解：化学符号不是"自古就有的约定"

我们太习惯用 O 表示氧、Fe 表示铁，以至于以为这是化学与生俱来的写法。其实在十九世纪初，情况一片混乱。

[[dalton]] 提出原子论时，用的是一套**图形符号**：小圆圈加点、加线、加阴影，各代表一种元素。氢是空心圆，氧是带点的圆……元素一多，这些符号既难画、又难记、更没法排版印刷，化合物写出来像一串密码。

贝采利乌斯在 1813 年提出了一个简单到天才的方案：**用元素拉丁名（或希腊名）的首字母来表示该元素**，首字母相同的就再加一个字母区分。

于是氧是 O（oxygenium），铁是 Fe（ferrum），钠是 Na（natrium）；化合物则把符号并排，用数字标注原子个数。

这套系统清晰、可印刷、可计算，迅速通行全球，沿用至今。我们今天书写化学的方式，本质上就是贝采利乌斯定下的。

## 生平与现场：把天平用到极致

贝采利乌斯出身寒微，早年学医，后来转向化学，在斯德哥尔摩长期从事研究和教学。他最为人称道的，是近乎偏执的**实验精确性**。

[[dalton]] 虽然提出了原子量的概念，但他的数据相当粗糙，化合物的原子比例也常常搞错。贝采利乌斯接过这个任务，用极其严谨的称量和分析，在二十多年里系统测定了大量元素的原子量：他分析了约两千种化合物，把当时已知元素中大部分的原子量测到了相当接近现代值的精度。

这是一项枯燥而浩大的工作，需要纯化样品、反复称重、控制误差。但正是这些可靠的原子量，后来成了 [[mendeleev]] 排列元素周期表的数据基础——没有可信的原子量，周期律就排不出来。

## 核心贡献：符号、原子量与催化

贝采利乌斯的贡献分布在几个看似不同、实则都关乎"化学如何成为精密科学"的方向上。

**化学符号系统**：如前所述，他建立了用字母+数字表示元素和化合物的记法，给了化学一套通用的书写语言。

**精确的原子量**：他用扎实的定量分析，把原子量从粗略估计提升为可靠数据，这为后来的化学计量和周期表打下了基础。

**命名与新元素**：他发现或参与确认了多种元素，包括硒（selenium）、硅（silicon）、钍（thorium）、铈（cerium）等。他还引入了"有机化合物""同分异构（isomerism）""同素异形（allotropy）"等一批至今通用的术语。

**催化（catalysis）概念**：1835 年，他注意到有一类物质本身不被消耗，却能显著改变化学反应的进行，于是创造了"catalysis"这个词来概括这种现象。

虽然催化的微观机制要等后人阐明，但他第一个把这类现象命名、归类，为后来的工业催化（如 [[mendeleev]] 之后哈伯-博施合成氨所依赖的催化剂）埋下了概念种子。

## 数字：一个人给整个学科定度量衡

把贝采利乌斯的工作按年份铺开，就能看出"给化学定度量衡"具体是多大的工程量：

| 年份 | 他做的事 | 规模 |
| --- | --- | --- |
| 1803 | 与希辛格共同发现**铈** | 他参与发现的第一种元素 |
| 1813 | 提出**字母元素符号**（O、Fe、Na……） | 取代道尔顿的图形符号，沿用至今 |
| 1817 | 与甘恩发现**硒** | |
| 1818 | 系统测定原子量 | 当时已知的 **49 种元素中测了 45 种** |
| 1824 | 首次制得足够纯的**硅** | 使其性质第一次可被测定 |
| 1826 | 发表修订原子量表 | 以 **O = 100** 为基准；累计分析约 **2000 种化合物** |
| 1828 | 发现**钍** | |
| 1835 | 创造 **catalysis**（催化）一词 | 为一整类现象命名 |

两个细节值得停下来看。

**第一，他为什么以氧为基准？** 道尔顿用最轻的氢作 1，看似自然。但十九世纪的定量分析靠的是**称重**，而氧几乎与所有元素化合，可以把样品烧成氧化物、再称重来定组成。以氧为参照，等于把基准放在实验最容易接触到的那个元素上——**基准的选择本身就是一个分析化学的判断**，而不是审美偏好。

**第二，他为什么比道尔顿准得多？** 不只是天平更好。[[dalton]] 的致命问题是那条"若两元素只生成一种化合物，则各取一个原子"的先验规则——它让水成了 HO，氧的原子量因此偏小一倍。贝采利乌斯拒绝这类先验规则，坚持从大量化合物的实测组成、以及不同化合物之间的类比关系里去反推原子比例。**换句话说，他用样本量替代了假设。** 代价是极其枯燥的重复劳动：纯化、称重、复算，二十多年。回报是他 1826 年的表已经与现代值相当接近，成为 [[mendeleev]] 半个世纪后排周期表的原材料。

## 争议：三个氯原子推翻了他的理论

贝采利乌斯的电化学二元论是怎么倒下的？答案在一组 pKa 数字里。

二元论主张：化合物由带正电和带负电的两部分靠静电吸引结合。推论很硬——如果你把分子里带"正电"的氢，换成电负性极强的氯，那么这个分子的性质**必然剧变**，因为它的电性结构被颠倒了。

1830 年代末，法国人杜马（Jean-Baptiste Dumas）做了这个实验。醋酸（CH₃COOH）分子上有四个氢，他用氯逐个取代甲基上的三个，最终得到三氯乙酸（CCl₃COOH）。结果是：

| 化合物 | 甲基上的氯 | pKa | 相对酸强度 |
| --- | --- | --- | --- |
| 醋酸 CH₃COOH | 0 | 4.76 | 1 |
| 一氯乙酸 CH₂ClCOOH | 1 | 2.86 | ≈ 80 倍 |
| 二氯乙酸 CHCl₂COOH | 2 | 1.29 | ≈ 3 000 倍 |
| 三氯乙酸 CCl₃COOH | 3 | 0.66 | ≈ 10⁴ 倍 |

**这张表同时判了两个结论。**

一方面，它证明贝采利乌斯**在物理上是对的**：氯的电负性确实通过碳链把电子密度从羧基那头拽走，使质子更容易离去——酸性整整强了四个数量级，而且每加一个氯效果都累加。这就是今天所说的**诱导效应**，它是电性思维的直接后代。

另一方面，它彻底否定了他的**分类学**：三氯乙酸仍然是一种羧酸，仍然与碱成盐，仍然属于"同一类"物质。杜马的学生洛朗（Auguste Laurent）由此把这个过程明确叫作**取代**（substitution），而不是二元论所要求的"两部分交换"。分子的骨架是可以保留的，被换掉的只是骨架上挂的原子——这正是**结构**观念取代**电性**观念的起点，也直接通向 [[kekule]] 的结构式。

贝采利乌斯到死都在反对取代理论。这里有一层反讽：**"同分异构"（isomerism）这个词正是他自己在 1830 年造的。** 起因是氰酸银与雷酸银——两者的实验式都是 AgCNO，一个稳定、一个一碰就爆；再加上维勒 1828 年发现尿素与氰酸铵组成相同而性质迥异。这类现象本身就在喊一句话：**决定性质的不只是"有哪些原子"，还有"原子怎么连接"**——而这恰恰是取代理论与结构理论的前提。他给了后人一把钥匙，却拒绝用它开自己的门。

## 代价与局限

贝采利乌斯的精确，也伴随着他的固执。他长期主张一种"电化学二元论"：认为所有化合物都由带正电和带负电的两部分通过静电吸引结合而成。这个理论对许多无机盐（如金属氧化物、酸碱成盐）解释得相当成功，曾是当时的主流。

但如上一节所述，它在有机化学面前碰了壁——当人们发现取代掉分子中带"正电"的氢之后，分子的**类别属性**并不改变时，二元论的根基就开始动摇。贝采利乌斯到晚年仍坚决捍卫自己的理论，与新一代化学家（包括提出取代反应观念的人）激烈论战，某种程度上阻碍了有机结构理论的早期发展。

一位为化学立下度量衡的人，在范式转折点上，也成了旧框架的守卫者。这并不奇怪：任何一个深刻塑造过一门学科的人，都容易把自己时代的成功经验，误当成永恒的真理。

## 跨域连接

- **修正并接续原子论**：贝采利乌斯用精密测定大幅修正了 [[dalton]] 粗糙的原子量，并发明了沿用至今的元素符号。这把原子论从一个定性假说变成了可精确书写和计算的工具。
- **为周期表备好数据**：他测定的可靠原子量，正是 [[mendeleev]] 几十年后排列元素周期表的原材料。周期律的发现，站在贝采利乌斯多年枯燥称量的肩膀上。
- **连接物理学与工业**：他的电化学二元论把化学键与电的吸引联系起来，是化学与电学交叉的早期尝试。他命名的"催化"概念，则一路延伸到现代工业化学和生命体内酶的作用机制。
