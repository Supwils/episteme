# 当代（公元1945年 - 至今）

## 概述

当代是人类历史上变化速度最快的时代。从冷战的核恐惧到互联网的普及，从殖民体系的瓦解到全球化的深入，从登月到人工智能，人类在短短几十年间经历了前所未有的变革。

速度本身不是解释。1945年以后真正改变日常的，是化石燃料、民族独立、核武器与跨国金融机构被放进同一套时间表。谁控制石油运输线，谁发行储备货币，谁能把新独立国家的海关与军队纳入自己的阵营，这些物质安排比口号更能说明"当代"为何显得快。

理解这一时代，需要避免"欧美单中心"的视角。1945年后真正塑造世界格局的，不仅是美苏的两极对峙，还有第三世界的集体登场：1955年万隆会议上29个亚非国家寻求第三条道路，到1960年"非洲年"一年内17个国家独立，全非洲最终诞生54个独立国家；不结盟运动（1961年贝尔格莱德首次峰会）一度涵盖全球过半人口。与此同时，中国从1949年世界上最贫穷的国家之一（据估计当时人均GDP不足百美元、文盲率超过80%）走向2010年世界第二大经济体，印度成为人口第一大国与软件服务中心，拉美在威权与民主之间反复探索。当代史是一部多中心的全球史。

## 关键主题

### 冷战（1947年 - 1991年）

美苏两个超级大国的对峙：

```
美国（资本主义阵营）          苏联（社会主义阵营）
    │                              │
北约（1949年）               华约（1955年）
    │                              │
    ├── 太空竞赛                    ├── 人造卫星（1957年）
    ├── 核武竞赛                    ├── 加加林太空飞行（1961年）
    ├── 古巴导弹危机（1962年）      ├── 阿富汗战争（1979年）
    └── 阿波罗登月（1969年）        └── 解体（1991年）
```

两极不是棋盘上的两个棋手，而是两套动员体系。1947年杜鲁门主义把援助写成遏制，1949年北大西洋公约把西欧防务条约化。1955年华沙条约组织把东欧军事同盟写成对等物。[[alliances-and-nato|同盟与北约]]与核武库一起，把欧洲的大战变成高成本禁忌。

马歇尔计划用美元重建西欧市场，经济互助委员会则把东欧贸易收进莫斯科的账本。两套货币与两套联盟是同一分裂的两面。1950—1953年朝鲜战争把分裂写成停战线上的事实，这条停火线延续到冷战正式结束之后。

朝鲜战争、越南战争、阿富汗以及非洲、拉美的代理人冲突说明：稳定的是大国之间的"不直接开火"，不是外围的和平。1962年古巴导弹危机把核门槛推到可见处，双方在十三天里各自后退。1975年赫尔辛基进程把边界与人权写进同一份文件，军备竞赛并未因此停止。

1979年苏联入侵阿富汗，两极再次绷紧。[[事件--冷战|冷战]]在欧洲显得"冷"，在许多新独立国家却是热的。1991年[[当代--苏联解体|苏联解体]]结束了这套两极结构，并不等于结束核门槛，也不等于结束代理冲突的习惯。

### 殖民体系瓦解与第三世界的兴起

```
1947年 - 印度、巴基斯坦从英国独立（伴随分治悲剧）
1949年 - 中华人民共和国成立
1954年 - 越南奠边府战役，终结法国在印度支那的殖民统治
1955年 - 万隆会议，29个亚非国家共商"第三条道路"
1957年 - 加纳独立（撒哈拉以南非洲第一个独立国家）
1960年 - "非洲年"，17个非洲国家独立
1961年 - 不结盟运动首次峰会（贝尔格莱德）
1990年 - 纳米比亚独立（非洲最后一个殖民地）
1994年 - 南非废除种族隔离，曼德拉当选总统
1997年 - 香港回归中国
1999年 - 澳门回归中国
```

去殖民化不是欧洲"恩准"的结果，而是亚非拉人民长期斗争的产物。全非洲最终形成54个独立国家；万隆精神与不结盟运动为它们提供了在冷战二元框架之外的话语空间。

独立的时间表比欧洲议会的辩论更硬。1947年印度与巴基斯坦在分治中建国，1949年荷兰被迫承认印度尼西亚主权。1954年奠边府战役结束法国在北越的殖民战争，1955年万隆会议把反殖民写成亚非国家的共同语言。

1956年苏伊士危机里，英、法、以色列出兵后被迫撤退。旧帝国发现自己再也压不住新独立国家与两个超级大国的交叉压力。纳赛尔把运河国有化，不是一场局部外交事故，而是去殖民与冷战在同一条水道上相遇。

1957年加纳独立。1960年联合国大会第1514号决议要求迅速终结殖民统治。1962年《埃维昂协议》确认阿尔及利亚独立。[[去殖民化浪潮|去殖民化浪潮]]不是宗主国的道德觉醒史。

政治主权到手之后，货币区、矿山合同、军事基地和单一作物出口，仍可把新国家留在旧分工里。[[postcolonialism|后殖民主义]]后来要追问的，正是这层法理独立与物质依附的错位。独立是法律事件，也是尚未完成的经济史。

### 信息时代

```
1947年 - 晶体管发明
1958年 - 集成电路
1969年 - 互联网前身ARPANET
1971年 - 微处理器
1976年 - 苹果公司成立
1983年 - 互联网（TCP/IP）
1989年 - 万维网
1998年 - 谷歌成立
2004年 - Facebook
2007年 - iPhone
2010年 - Instagram
2022年 - ChatGPT发布，引爆生成式AI革命
```

据国际电信联盟（ITU）估计，全球互联网用户已从1995年的数千万增长到2024年的约58亿、2025年的约60亿（约占世界人口四分之三）——但"数字鸿沟"依然存在：高收入与低收入国家在网络接入与速率上差距悬殊。

### 全球化

经济、文化和政治的全球互联：

- 世界贸易组织（WTO，1995年成立，中国2001年加入）
- 欧盟（1993年《马斯特里赫特条约》生效）
- 全球供应链与跨国生产网络
- 文化全球化与本土化的张力
- 反全球化运动与2010年代的"逆全球化"思潮

全球化既缩小了国家之间的差距（中国、印度等新兴经济体追赶），也在许多国家内部扩大了贫富差距——经济学家米拉诺维奇用"大象曲线"刻画了这一双重效应：全球中产（多在亚洲）和顶端1%受益最多，发达国家中下层相对停滞。

石油把战后增长钉在井口上。1960年伊朗、伊拉克、科威特、沙特阿拉伯与委内瑞拉在巴格达成立石油输出国组织。1973年10月，第四次中东战争之后，阿拉伯石油输出国组织对部分西方国家实行禁运，原油标价在数月内翻了数倍。

工厂、航运、化肥与城市取暖同时涨价，增长与通胀不再按旧公式反向运动。这就是[[stagflation-1970s|1970年代滞胀]]进入政治史的入口。1979年伊朗革命再次冲击供应，美元利率随后被大幅抬高。

石油美元回流银行，再贷给进口能源的发展中国家。1982年墨西哥宣布无力按期偿债，[[latin-america-debt-crisis|拉美债务危机]]把出口经济的脆弱性写成金融危机。油价冲击不是一次"中东新闻"，而是化石能源网络改写国家财政的时刻。

[[volcker-disinflation-policy|沃尔克反通胀]]把美国利率推到极高，资本回流纽约，负债以美元计价的国家被利息压住。滞胀在工业国表现为失业与物价，在进口石油的发展中国家表现为偿债。同一套利率，两套社会后果。

1947年关税及贸易总协定先在关税上做减法，冷战把社会主义阵营大体留在这套减税谈判之外。[[bretton-woods|布雷顿森林体系]]的金汇兑安排在1971年尼克松关闭黄金窗口时结束。1991年苏联解体之后，资本账户开放、跨国银行与机构投资者把浮动美元秩序推得更远。

1995年世界贸易组织取代关税及贸易总协定，2001年中国加入。1990年代的加速，是政治壁垒倒塌之后把更多经济体接进已有规则，而不是突然发明了自由贸易。

1997年东亚金融危机证明：短期资本可以比工厂更快进出。[[trade-politics-and-wto|贸易政治与WTO]]管理的是关税与争端，并不自动管理热钱。所谓金融全球化，是法律允许资金跨境寻找收益率，而不是世界变成一个公平的市场。[[全球化三次浪潮|全球化三次浪潮]]里，这一次的特点是生产链与资本市场同时加速。

2008年全球金融危机把这套跨境资产负债表的风险写回政治议程。救援首先发生在发行储备货币的国家，进口资本的国家则通过出口与汇率消化冲击。金融全球化没有取消国家，它改变的是国家必须应付的危机速度。[[financial-crises-anatomy|金融危机的解剖]]所处理的，正是这种速度。

### 中国的崛起

```
1949年 - 中华人民共和国成立（当时人均GDP据估计不足百美元）
1958年 - 大跃进（1958—1962年大饥荒造成巨大人口损失）
1966年 - 文化大革命（1966—1976年）
1978年 - 改革开放
1997年 - 香港回归
2001年 - 加入WTO
2008年 - 北京奥运会、应对全球金融危机
2010年 - 超越日本成为世界第二大经济体
2020年 - 新冠疫情
2022年 - 中国空间站（天宫）完成在轨建造
```

改革开放四十余年间，中国经济年均增长近10%，使数亿人脱贫——据世界银行估计，中国脱贫人口占同期全球脱贫总数的相当大比重。这是人类历史上规模最大的减贫进程；但增长也伴随环境压力、贫富差距与区域不平衡等代价。

## 重大挑战

### 21世纪的全球性问题

- 气候变化：全球长期升温已达约1.3°C；据世界气象组织，2024年成为有记录以来最暖年份、首个全年均温超过1.5°C的年份（这是单一年度，并不等于《巴黎协定》长期目标已失败）
- 人口老龄化：东亚、欧洲生育率持续走低，多国进入深度老龄化社会
- 贫富差距：据估计全球最富有的1%人口掌握的财富份额显著高于底层一半人口
- 地缘政治冲突：从中东到俄乌战争（2022年起），大国博弈重新升温
- AI伦理：生成式AI引发就业、版权、虚假信息与"对齐"难题
- 公共卫生危机：新冠疫情暴露全球卫生治理的脆弱

数据说明：上述统计多为机构估算，会随口径与年份变化，应以"约/据估计"理解。

气候首先是物质史，而不是伦理口号。煤与石油一旦成为工业与战争的燃料，大气里的二氧化碳就不再只是自然循环的一部分。1958年查尔斯·[[charles-keeling|基林]]在夏威夷莫纳罗亚开始连续测量，曲线此后单向抬升。

1988年政府间气候变化专门委员会成立。1992年里约热内卢地球峰会通过联合国气候变化框架公约。2015年巴黎协定把升温目标写成国际法语言。

[[climate-and-history|气候与历史]]要处理的是：发电厂、汽车、水泥与毁林如何把[[carbon-cycle|碳循环]]拖进人类制度。它与1970年代的油价冲击同源，都是化石能源网络的政治史，而不是突然出现的新闻话题。[[思想史--环保主义|环保主义]]把这一物质过程译成公共语言，本身也是当代史的一部分。

化石燃料基础设施一旦铺开，就有自己的惯性。油轮航线、炼厂、发电厂和汽车城市互相锁定，转用其他能源变成改写整张物质网，而不是换一种燃料那么简单。1970年代的油价冲击已经让人看见这张网的政治敏感，气候账本则把同一张网的废气写成地球系统的记录。

## 历史启示

> 当代史最大的教训是：技术是一把双刃剑。核能可以发电也可以毁灭城市，互联网可以连接世界也可以散布虚假信息，AI可以辅助人类也可以取代人类。人类能否驾驭自己创造的力量，是21世纪最大的考验。

## 跨域连接

- **[[万隆会议|万隆会议]]**：理解当代必须放弃欧美单中心的视角——1955年万隆会议、1960年"非洲年"与不结盟运动（一度涵盖全球过半人口）标志着第三世界的集体登场。以美苏两极对抗为主线的叙述，会系统性地漏掉世界多数人口的政治经验。
- **[[the-web-and-http|万维网与HTTP]]**：当代史面临前所未有的史料问题：纸会自己留下来，网页不会。数字记录需要持续的迁移与维护，平台倒闭、格式过时即意味着史料消失——未来历史学家面对的史料空洞，反而可能大于二十世纪，且空洞的分布将由商业机构的存续决定。
- **[[inequality-economics|不平等经济学]]**：全球化同时缩小了国家间差距与扩大了国家内差距——"大象曲线"显示全球中产与顶端1%受益最多，发达国家中下层相对停滞。推论是：逆全球化的政治压力，其地理分布应当与发达国家中下层长期停滞的区域高度重合。
- **[[mutually-assured-destruction|相互确保摧毁]]**：核威慑把大国直接战争的成本推向无限，冷战对抗因此被迫转入代理人战争、太空与军备竞赛、意识形态竞争。威慑稳定的是"不直接开战"，而不是外围的冲突——古巴导弹危机展示了这套稳定究竟有多薄。
- **[[ageing-societies|老龄化社会]]**：东亚与欧洲的生育率持续走低，多国进入深度老龄化社会，现收现付的养老金与劳动力供给模型随之承压。老龄化不是周期性波动而是结构性变量——它将重塑福利国家的财政基础，且无法靠任何短期政策逆转。
